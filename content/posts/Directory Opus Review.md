Made by [GP Software](https://www.gpsoft.com.au/)   
Price: $89 AUD - Single License  
Supports **Windows** 7, 8, 10, and 11, but not ARM.

![](images/directory_opus_box.webp)

I absolutely LOVE Directory Opus. As soon as I tried it for the first time, I knew I never wanted to go back to the mess that is Windows Explorer, and don't even get me started on its buggier successor. I found DOpus when looking for an alternative to Windows Explorer that would allow me to scroll while dragging files; a very nice quality of life bonus to any file browser. At first, the high price point of $89 AUD (about $60 USD) put me off, but after running the trial, I knew it was the right choice. Really what amazes me the most, besides how polished it feels, is its INSANE amount of customization options available, including the ability to run scripts to customize functions.

Let's be real, if you're not a Windows power user, you're probably not gonna need something like this, and using Windows Explorer or one of the other free file browser options out there may be sufficient for you. But, if you feel like Windows Explorer is restricting your workflows, Directory Opus is for you.
