## **Useful Packages**

Homebrew - [https://brew.sh/](https://brew.sh/)

INSTALL COMMAND: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`

Homebrew is a free and open-source package manager that simplifies the installation of software on macOS and Linux.

UV - [https://docs.astral.sh/uv/#installation](https://docs.astral.sh/uv/#installation)

INSTALL COMMAND: `curl -LsSf https://astral.sh/uv/install.sh | sh`

UV is an extremely fast Python package and project manager written in Rust, designed to replace tools like pip and pip-tools.

TMUX - [https://github.com/tmux/tmux](https://github.com/tmux/tmux)

INSTALL COMMAND: `sudo apt install tmux`

Note: This is installed by default on Ubuntu server.  
Tmux is a terminal multiplexer allowing multiple terminal sessions within one window/session. 

FZF - [https://junegunn.github.io/fzf/installation/](https://junegunn.github.io/fzf/installation/)

INSTALL COMMAND: `sudo apt install fzf`

FZF is a command-line fuzzy finder that allows for quick, interactive selection of files or other list items.

Dust - [https://github.com/bootandy/dust](https://github.com/bootandy/dust)

INSTALL COMMAND: `brew install dust`

Dust is a Rust-written command-line tool providing an intuitive overview of disk space usage, serving as a visual alternative to 'du'.

BTOP - [https://github.com/aristocratos/btop](https://github.com/aristocratos/btop)

INSTALL COMMAND: `brew install btop`

Btop is a comprehensive and customizable resource monitor that displays real-time statistics for CPU, memory, disk, network, and processes.

TLDR - [https://tldr.sh/](https://tldr.sh/)

INSTALL COMMAND: `npm install -g tldr`

TLDR is a command-line tool that provides simplified, community-driven examples for Linux commands, offering a concise alternative to traditional man pages.
