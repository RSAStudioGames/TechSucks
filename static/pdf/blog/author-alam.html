Creator and maintainer of BentoPDF

I’m Alam, and I build BentoPDF, a free, open-source PDF toolkit with 100+ tools that run entirely in your browser.

There’s no uploading your files to a server, no account to create, and no tracking. Your documents stay on your device. The source code is public, so you can see how it works yourself. BentoPDF is AGPL-licensed and self-hostable.

I write every post on this blog myself. I’ll write about PDFs, how they work, things I learn while building BentoPDF, and occasionally things that go wrong.

When I compare BentoPDF with another PDF tool, I’ll link to its documentation so you can check what I’m saying. If there’s something BentoPDF doesn’t do well, I’ll say that too.

And if I get something wrong, please open an issue. I’ll fix it and add a note to the post.

You can find me on GitHub, LinkedIn and X.
