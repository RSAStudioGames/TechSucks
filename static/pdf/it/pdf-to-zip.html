Domande frequenti

Cosa fa davvero PDF in ZIP ai miei file?

Nient'altro che l'impacchettamento. I PDF vengono copiati in un unico pdfs_archive.zip con i loro nomi originali, invariati, nell'ordine in cui li hai aggiunti, quindi ciò che esce dallo ZIP è byte per byte ciò che è entrato.

Comprimere in ZIP rende i PDF più piccoli?

No. L'archivio viene scritto senza compressione, perché il contenuto PDF è già compresso internamente e si ridurrebbe comunque di poco, quindi aspettati uno ZIP grande circa quanto la somma dei file. Per ridurre le dimensioni, passali prima da Comprimi PDF e poi crea lo ZIP con i risultati.

Che differenza c'è tra comprimere i PDF in ZIP e unirli?

Uno ZIP mantiene ogni PDF come file separato dentro un unico contenitore che il destinatario estrae. L'unione riunisce le pagine in un solo documento PDF, ed è ciò che serve quando i file vanno letti come un unico documento; per questo usa Unisci PDF.

E se due file hanno lo stesso nome?

I nomi duplicati vengono gestiti automaticamente: il secondo file diventa name (1).pdf, il terzo name (2).pdf e così via, così nulla viene sovrascritto nell'archivio. Rinomina i file prima del caricamento se preferisci nomi più significativi.

Posso aggiungere all'archivio file che non sono PDF?

No. Vengono accettati solo i file con estensione .pdf o di tipo PDF; tutto il resto che trascini viene ignorato. Per un pacchetto misto, usa invece la funzione zip integrata nel tuo sistema operativo.

Il destinatario avrà bisogno di software speciale per aprire l'archivio?

No. L'output è un file ZIP standard che Windows, macOS, iOS e Android aprono senza software aggiuntivo; fai doppio clic o tocca per estrarre i PDF.

I miei PDF vengono caricati per creare lo ZIP?

No. L'archivio viene assemblato nel tuo browser, quindi i file vengono letti dal tuo disco e lo ZIP viene riscritto su di esso senza alcun trasferimento in rete. Raggruppare fatture, contratti o cartelle cliniche in questo modo li tiene sul tuo dispositivo.
