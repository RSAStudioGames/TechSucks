Domande frequenti

Posso convertire qualsiasi file JSON in PDF con questo strumento?

No. Ricostruisce PDF solo da file JSON creati dallo strumento PDF in JSON di BentoPDF, che memorizza l'intera struttura interna del documento. Un'esportazione JSON da un'API, un database o un file di configurazione darà errore.

Come trasformo invece dati di un'API o un file di configurazione in un PDF leggibile?

Incolla o carica il JSON come testo semplice in Testo in PDF, che lo imposta come testo formattato sulle pagine. JSON in PDF serve solo per l'andata e ritorno di documenti nati come PDF.

Il PDF ricostruito corrisponderà all'originale?

Il JSON prodotto da PDF in JSON cattura gli oggetti del documento, quindi riconvertirlo riproduce pagine, testo e immagini dell'originale. Riconvertire e confrontare è anche un modo rapido per verificare che un'esportazione abbia catturato tutto.

Qual è il risultato quando converto più file JSON?

Ogni conversione viene scaricata come jsons-to-pdf.zip, anche per un solo file. All'interno, ogni PDF porta il nome del JSON di origine, quindi report.json diventa report.pdf.

Posso modificare il JSON prima di riconvertirlo?

Sì, purché la struttura resti valida per il motore CPDF. Le modifiche programmatiche al JSON, come metadati o oggetti di testo modificati, vengono ricostruite nel PDF; una modifica malformata produce un errore di conversione.

Perché lo strumento dice che il motore CPDF non è disponibile?

La conversione dipende dalla build WebAssembly di CPDF. Su bentopdf.com è inclusa, ma una copia in self-hosting richiede che i file WASM di CPDF siano configurati nelle impostazioni WASM prima che questo strumento funzioni.

Il mio file JSON viene caricato su un server?

No. I file vengono letti nel tuo browser e ricostruiti in PDF da un Web Worker che esegue il motore CPDF in locale, quindi nulla viene trasmesso e la pagina resta reattiva durante le conversioni grandi.
