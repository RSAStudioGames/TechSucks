    Domande frequenti

    L'unione mantiene i segnalibri?

    Sì. L'unione viene eseguita con il motore CoherentPDF, che porta i segnalibri di ogni file nel documento combinato, così la struttura resta navigabile. Contenuto delle pagine e annotazioni vengono copiati così come sono.

    Posso unire solo alcune pagine di ogni file?

    Sì. In Modalità file, scrivi un intervallo come 1-3, 5 nella casella Pagine accanto a un file per includere solo quelle pagine, oppure lasciala vuota per l'intero file. In Modalità pagina ogni pagina di ogni file appare come miniatura che puoi trascinare in qualsiasi sequenza, anche alternando pagine di documenti diversi.

    In che ordine saranno i file?

    L'ordine mostrato nell'elenco, dall'alto in basso. Trascina le voci per riordinarle prima di unire e usa Aggiungi altri file per accodare documenti senza perdere la disposizione che hai già.

    Perché i numeri di pagina sembrano sbagliati nel PDF unito?

    Per impostazione predefinita il file unito usa una numerazione semplice da 1 a N. Se gli originali usavano etichette di pagina come i, ii, iii o A-1, attiva Mantieni etichette di pagina originali per conservarle, tenendo presente che due file con le stesse etichette produrranno duplicati. Per stampare numeri visibili sulle pagine stesse, usa Numeri di pagina.

    Perché il file unito è così grande?

    I caratteri e le immagini di ogni file vengono copiati così come sono, quindi il risultato ha più o meno la dimensione combinata degli originali, e quando più file incorporano lo stesso carattere ogni copia viene mantenuta. Spunta Rimuovi caratteri duplicati per unire i caratteri identici in uno solo; per risparmiare di più, passa il risultato da Comprimi PDF.

    Posso unire PDF con formati o orientamenti di pagina diversi?

    Sì. Le pagine mantengono dimensione e rotazione proprie, quindi un disegno A3 orizzontale può seguire una pagina Letter verticale senza essere scalato. Per una dimensione uniforme in seguito, passa il file unito da Correggi formato pagina.

    I PDF vengono caricati su un server per essere uniti?

    No. I file vengono combinati all'interno del tuo browser dal modulo WebAssembly CoherentPDF e il PDF unito viene scritto nella tua cartella dei download, quindi contratti ed estratti conto non lasciano mai il tuo computer.

    Posso unire PDF protetti da password?

    Se un file richiede una password per essere aperto, lo strumento la chiede quando aggiungi il file e poi unisce le pagine decifrate. Il risultato unito non ha password; aggiungine una dopo con Proteggi PDF se serve.
