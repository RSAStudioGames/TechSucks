Domande frequenti

Qual è la differenza tra una password utente e una password proprietario?

La password utente serve per aprire il PDF. La password proprietario protegge le impostazioni dei permessi ed è quella che serve per cambiarle o rimuoverle in seguito. Imposta solo una password proprietario se chiunque deve poter aprire il file ma con stampa, copia o modifica limitate.

Perché lo strumento chiede una password proprietario quando imposto i permessi?

I flag dei permessi vengono applicati solo se esiste una password proprietario; senza, i lettori PDF trattano il file come senza restrizioni. Per questo lo strumento richiede una Nuova password proprietario ogni volta che imposti permessi o una password utente.

Come impedisco alle persone di copiare il testo o stampare il mio PDF?

Deseleziona "Consenti la copia del testo" e "Consenti la stampa", inserisci una Nuova password proprietario e clicca su Cambia permessi. Adobe Reader e altri visualizzatori conformi bloccheranno quelle azioni. Alcuni strumenti di terze parti ignorano i flag dei permessi, quindi per il materiale sensibile valuta anche di rasterizzare le pagine.

Quali permessi posso controllare?

Sette caselle: stampa, copia del testo, modifica del contenuto, annotazioni, compilazione dei moduli, assemblaggio del documento (inserire, eliminare o ruotare pagine) ed estrazione di pagine. Una casella deselezionata significa che l'azione non è consentita.

Quale crittografia usa Cambia permessi?

Il risultato è crittografato con AES a 256 bit. Questo lo rende anche un modo rapido per aggiornare un vecchio PDF crittografato con RC4: inserisci la sua password attuale, imposta nuove password e il file viene riscritto con AES-256.

Posso cambiare i permessi di un PDF già protetto da password?

Sì, inserisci la password esistente nel campo Password attuale. Lo strumento apre il file con essa, poi lo crittografa di nuovo con le tue nuove password e impostazioni dei permessi; una password attuale errata produce un errore e non viene cambiato nulla.

Come rimuovo tutte le restrizioni invece di cambiarle?

Lascia vuoti entrambi i campi delle nuove password e clicca su Cambia permessi. Il risultato è completamente decrittato, senza password e senza flag dei permessi. Se non hai la password attuale, usa invece Rimuovi restrizioni, che funziona senza quando il PDF si apre liberamente.

Il mio PDF o la sua password proprietario vengono inviati da qualche parte quando cambio i permessi?

No. La crittografia viene eseguita da QPDF compilato in WebAssembly dentro la scheda del tuo browser, quindi il file e ogni password che digiti restano sul tuo dispositivo.
