Domande frequenti

Mi serve WordPerfect installato per convertire i file WPD?

No. Lo strumento carica un motore LibreOffice nel tuo browser e il filtro WordPerfect di LibreOffice legge direttamente il file, quindi non serve installare nulla sul computer.

Quali versioni di WordPerfect sono supportate?

Tutte le principali versioni di WordPerfect che usano l'estensione .wpd, compresi i file dell'era DOS e dei primi Windows che i software attuali spesso rifiutano di aprire. Il file deve davvero terminare in .wpd; le altre estensioni non sono accettate dal selettore.

Perché la prima conversione WordPerfect è lenta?

Il motore LibreOffice pesa circa 75 MB compresso e viene scaricato la prima volta che converti, con una percentuale di avanzamento durante il caricamento. Le conversioni successive nella stessa sessione saltano questo passaggio e sono molto più veloci.

Cosa viene mantenuto del documento originale?

Testo, layout di pagina e formattazione di base come font, grassetto, corsivo e rientri passano nel PDF. Le macro di WordPerfect e i codici rivelati non vengono mantenuti, perché non hanno equivalente in un PDF.

Posso convertire più file WPD in una volta sola?

Seleziona o trascina più file e fai clic su Converti in PDF. Un file viene scaricato come PDF con lo stesso nome; più file vengono raccolti in wpd-to-pdf.zip con un PDF per ogni documento.

Posso trasformare un file WordPerfect in un documento Word?

Non da questo strumento. Converti prima qui in PDF, poi passa il risultato in PDF in Word se ti serve un .docx modificabile.

I miei vecchi documenti legali o ufficiali vengono caricati?

No. Il motore di conversione funziona interamente nel tuo browser, quindi i file WPD e i PDF risultanti restano sul tuo dispositivo. Viene scaricato solo il motore, non i tuoi documenti.

Perché la conversione di un file è fallita?

Le cause più comuni sono file danneggiati e file che non sono davvero WordPerfect nonostante l'estensione .wpd. Se il file si apre in LibreOffice desktop, dovrebbe convertirsi anche qui, perché viene usato lo stesso filtro di importazione.
