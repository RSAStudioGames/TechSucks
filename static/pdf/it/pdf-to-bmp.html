Domande frequenti

Che risoluzione hanno le immagini BMP?

Le pagine vengono rese a una scala fissa 2x, quindi una pagina Letter (8,5 x 11 pollici) diventa un'immagine di 1224 x 1584 pixel, circa 144 pixel per pollice. Questo strumento non ha un'impostazione DPI; per una scala regolabile usa PDF in PNG.

Come viene consegnato un PDF di più pagine?

Un PDF di una pagina viene scaricato come singolo .bmp con il nome del file. Un PDF di più pagine viene scaricato come ZIP chiamato filename_bmps.zip con page_1.bmp, page_2.bmp e così via, un'immagine per pagina.

Perché i file BMP sono così grandi?

BMP memorizza i dati dei pixel grezzi senza compressione, quindi una pagina occupa lo stesso spazio sia che sia vuota sia che sia piena di dettagli, e i file sono molto più grandi di un PNG o JPG della stessa pagina. Se il tuo software accetta PNG, anche quel formato è senza perdita, con una frazione dello spazio.

Posso convertire più PDF in BMP in un unico lotto?

No, un PDF per volta; se trascini più file viene usato solo il primo. Convertili uno dopo l'altro, oppure scegli prima le pagine che ti servono con Estrai pagine così ogni conversione resta leggera.

La conversione mantiene la trasparenza o la qualità vettoriale?

No. Ogni pagina diventa un'immagine raster piatta su sfondo bianco, e il testo diventa pixel, quindi nel BMP non si può cercare né ingrandire senza sfocature. Conserva il PDF originale per modificarlo.

Posso convertire in BMP un PDF protetto da password?

Sì, se conosci la password: lo strumento te la chiede quando il file si carica e poi rende le pagine normalmente. Un file con una password sconosciuta non si può aprire.

Il mio PDF viene caricato per convertirlo in BMP?

No. Il rendering avviene su un canvas nel tuo browser e le immagini vengono impacchettate nello ZIP in locale, quindi il documento non lascia mai il tuo computer. I PDF grandi richiedono solo più tempo perché il rendering lo fa la tua macchina.

Quale strumento dovrei usare se BMP non è obbligatorio?

Per un output senza perdita con file piccoli, PDF in PNG; per foto e file più leggeri, PDF in JPG; per sistemi fax o di scansione multipagina, PDF in TIFF. BMP ha senso soprattutto quando un'applicazione o un dispositivo datato lo richiede.
