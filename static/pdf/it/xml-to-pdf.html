Domande frequenti

Come decide lo strumento l'aspetto del PDF?

Analizza l'XML, raggruppa per nome di tag gli elementi fratelli ripetuti e rende ogni gruppo come una tabella con una colonna per ogni elemento figlio, usando i nomi degli elementi come intestazioni. Se la radice non ha figli ripetuti, ottieni una tabella a due colonne Proprietà e Valore. Il risultato è in A4 orizzontale con il nome dell'elemento radice come titolo.

Che tipo di XML funziona meglio?

XML in stile dati: record con lo stesso insieme di elementi figlio ripetuti sotto un unico genitore, come esportazioni di database, righe di fattura, feed di prodotti, feed RSS o sitemap. L'XML molto annidato o in stile documento viene appiattito, quindi i valori annidati vengono uniti in una singola cella e perdono la gerarchia.

Perché ricevo un errore XML non valido?

Il file non è ben formato: un tag non chiuso, un elemento radice mancante, un carattere & o < senza escape o una codifica errata. Il messaggio include il motivo indicato dal parser, quindi correggi il file in un editor o validatore e riprova.

Gli attributi XML sono inclusi nel PDF?

In parte. Nella vista a tabella solo gli elementi figlio diventano colonne, quindi gli attributi dei record ripetuti non vengono mostrati. Nella vista Proprietà e Valore per una radice senza ripetizioni, gli attributi sono elencati dopo i valori dei figli.

Posso convertire più file XML in una volta?

Sì. Aggiungi più file e vengono convertiti in un unico gruppo in xml-to-pdf.zip con un PDF per file. Un singolo file viene scaricato direttamente con lo stesso nome e l'estensione .pdf.

Applica il mio foglio di stile XSLT o CSS?

No. Le istruzioni dei fogli di stile e le dichiarazioni DOCTYPE vengono rimosse prima dell'analisi, e il layout è generato solo dalla struttura dei dati. Se ti serve il rendering con lo stile, apri l'XML in un browser che applica il foglio di stile e stampalo in PDF da lì.

Il testo cinese, arabo, cirillico o in altri alfabeti non latini viene reso?

Non in modo affidabile. Il PDF è creato con il font Helvetica standard di jsPDF, che copre i caratteri latini, quindi il testo in altri alfabeti può apparire con caratteri sbagliati o mancanti.

Il file XML viene caricato per la conversione?

No. L'analisi usa un parser XML JavaScript e il PDF viene generato con jsPDF, entrambi nel tuo browser, quindi fatture, registri delle transazioni e altri dati sensibili del file non lasciano mai il tuo dispositivo.
