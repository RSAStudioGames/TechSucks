Domande frequenti

Quale formato di output devo scegliere?

Il CSV si apre in Excel, Google Sheets o in qualsiasi importazione di database. Il JSON fornisce un array di righe, ognuna un array di stringhe di celle, per script e API. Il Markdown fornisce una tabella con barre verticali che puoi incollare in GitHub, in una wiki o nella documentazione.

Cosa ottengo quando il PDF contiene più tabelle?

Ogni tabella viene salvata come file a sé, con un nome come table_1_page3.csv, e tutte vengono raccolte in filename_tables.zip. Una singola tabella viene scaricata direttamente come filename_table.csv, .json o .md. Se preferisci avere tutte le tabelle in un unico file, usa PDF in CSV.

Perché dice che non sono state trovate tabelle?

Il rilevamento lavora sul livello di testo del documento. I PDF scansionati contengono solo un'immagine, quindi passali prima da OCR PDF. Anche il testo che sembra una tabella solo per la spaziatura, senza una vera struttura di tabella, può non essere rilevato.

Una tabella continua su più pagine. Verrà estratta come un unico file?

No. Ogni pagina viene analizzata separatamente, quindi una tabella che si estende su più pagine viene esportata come un file per pagina, ognuno con il numero di pagina nel nome. Unisci i pezzi in un foglio di calcolo dopo l'estrazione.

Posso estrarre le tabelle solo da alcune pagine?

Viene sempre analizzato l'intero documento, anche se il numero di pagina in ogni nome di file ti dice da dove viene una tabella. Per limitare l'analisi, salva prima le pagine che ti servono con Estrai pagine e usa questo strumento sul file più piccolo.

Il CSV gestisce virgole e interruzioni di riga dentro le celle?

Sì. Le celle che contengono virgole, virgolette o a capo vengono racchiuse tra virgolette doppie, con le virgolette interne raddoppiate, così i programmi di fogli di calcolo le leggono correttamente. Le celle vuote vengono scritte come campi vuoti.

Si possono estrarre tabelle da un PDF protetto da password?

Se il file richiede una password per essere aperto, ti viene chiesta prima che inizi l'estrazione, e le tabelle vengono lette da una copia decifrata tenuta in memoria.

Il PDF viene caricato per il rilevamento delle tabelle?

No. Il motore di rilevamento (PyMuPDF compilato in WebAssembly) viene scaricato da una CDN la prima volta che lo usi, poi funziona all'interno del tuo browser. Il tuo PDF resta sul tuo dispositivo.
