Domande frequenti

Qual è la differenza tra la password utente e la password del proprietario?

La password utente è obbligatoria ed è quella che chiunque deve digitare per aprire il file. La password del proprietario è facoltativa; se ne imposti una diversa, il PDF riceve anche restrizioni d'uso, quindi chi lo apre con la sola password utente non può stampare, copiare, modificare, annotare, compilare moduli o riordinare le pagine.

Quale cifratura usa Proteggi PDF?

AES a 256 bit, applicato con l'implementazione di QPDF dello standard di cifratura PDF 2.0. Non c'è un'opzione per scegliere un algoritmo più debole, quindi la forza della protezione dipende da quanto è robusta la tua password.

Cosa succede se dimentico la password?

Non esiste alcun recupero. L'AES-256 non può essere forzato con la forza bruta in tempi pratici, e BentoPDF non conserva alcuna copia del file né della password. Conserva la password in un posto sicuro e tieni per te un originale non protetto.

Ottengo comunque delle restrizioni se inserisco solo una password utente?

No. Con la sola password utente il file richiede la password per essere aperto, ma una volta aperto non ci sono limiti a stampa, copia o modifica. Aggiungi una password del proprietario separata se vuoi queste restrizioni.

Posso limitare la stampa o la copia senza richiedere una password per aprire il file?

Non con questo strumento, perché qui la password utente è obbligatoria. Usa invece Cambia permessi, che applica restrizioni lasciando il file apribile senza password.

Come rimuovo la password in seguito?

Apri il file protetto nello strumento di rimozione password, inserisci la password e scarica una copia senza cifratura. Per farlo ti serve la password; non esiste alcun modo per aggirarla.

Il PDF protetto si aprirà in qualsiasi lettore?

Qualsiasi lettore PDF attuale, inclusi Adobe Reader, Anteprima, Chrome, Firefox ed Edge, apre i file cifrati con AES-256. I lettori molto vecchi, usciti prima che venisse aggiunto il supporto AES-256, potrebbero rifiutare il file.

Il mio PDF o la mia password vengono inviati da qualche parte?

No. QPDF viene eseguito come WebAssembly nel tuo browser, quindi il file viene cifrato sul tuo dispositivo e né il documento né le password vengono trasmessi. Condividi la password con il destinatario attraverso un canale diverso da quello del file.
