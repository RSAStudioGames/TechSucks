Pertanyaan yang Sering Diajukan

Bisakah saya mengubah teks yang sudah ada di PDF saya dengan editor ini?

Editor ini bekerja di atas halaman: sorotan, komentar, bentuk, gambar, gambar tangan bebas, redaksi, dan kotak teks baru. Untuk menulis ulang teks yang sudah ada di dokumen, gunakan Edit Teks PDF, yang memungkinkan Anda mengklik paragraf dan mengeditnya langsung di tempat.

Apakah anotasi saya akan muncul di Acrobat, Preview, atau Chrome?

Ya. Sorotan, komentar, bentuk, dan gambar disimpan sebagai anotasi PDF standar, sehingga penampil lain menampilkannya dan biasanya dapat mengedit atau menghapusnya. Kotak teks ditulis ke halaman sebagai teks biasa saat diunduh, jadi tampak identik di mana pun tetapi tidak bisa dipindahkan sesudahnya.

Apakah redaksinya permanen?

Ya, setelah diterapkan. Menandai teks atau area hanya memberi tanda. Menerapkan redaksi menghapus konten di bawah area yang ditandai dari file, bukan sekadar menutupinya dengan kotak, sehingga teksnya tidak dapat dipulihkan dengan menyalin atau mencari. Jika Anda mengunduh dengan tanda yang belum diterapkan, editor menawarkan untuk menerapkannya terlebih dahulu. Saat Anda meredaksi teks yang dipilih, salinannya di properti file, bookmark, komentar, dan lampiran juga dihapus saat diunduh, kecuali file terenkripsi. Buka file yang diunduh dan periksa sebelum Anda membagikannya.

Bisakah saya membuka lebih dari satu PDF sekaligus?

Hingga 10 dokumen dapat dibuka sekaligus, masing-masing di tab sendiri di atas penampil. Menambahkan lebih banyak file membuka lebih banyak tab, dan menghapus file dari daftar menutup tab-nya.

Apakah editor menyimpan perubahan saya secara otomatis?

Tidak. Semuanya tetap berada di memori browser Anda sampai Anda mengklik Unduh PDF yang Diedit, dan menutup atau menyegarkan tab akan membuang perubahan. Unduh sebelum Anda meninggalkan halaman.

Mengapa saya tidak bisa menyorot teks pada PDF hasil pindai?

Sorot, garis bawah, dan coret melekat pada teks asli, sedangkan halaman hasil pindai hanyalah gambar. Jalankan file melalui OCR PDF terlebih dahulu untuk menambahkan lapisan teks, atau tandai secara visual dengan alat pena atau persegi panjang.

Bisakah saya menambahkan teks dalam bahasa Mandarin, Jepang, Arab, atau aksara non-Latin lainnya?

Ya. Jika kotak teks berisi karakter di luar set Latin dasar, editor mengambil font Noto yang sesuai dan menyematkannya ke PDF sehingga teks tampil dengan benar di penampil lain.

Apakah editor mengunggah PDF saya?

Tidak. Editor menjalankan mesin PDF (PDFium yang dikompilasi ke WebAssembly) di dalam browser Anda. Satu-satunya permintaan jaringan adalah untuk kode editor dan file font opsional; dokumennya sendiri tidak pernah meninggalkan perangkat Anda.
