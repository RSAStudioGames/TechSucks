Pertanyaan yang Sering Diajukan

Bagaimana cara mengonversi file Markdown ke PDF?

Klik Unggah dan pilih file .md, .markdown, atau .txt, atau tempel teks ke panel kiri, dan pratinjau hasil render muncul di kanan. Klik Ekspor PDF atau tekan Ctrl+S (Cmd+S di Mac), lalu pilih Simpan sebagai PDF sebagai tujuan di dialog cetak yang terbuka.

Bisakah saya mengubah ukuran halaman atau margin PDF?

Atur di dialog cetak: pilih Letter, A4, atau ukuran kertas lain, sesuaikan margin, dan turunkan skala jika tabel lebar terpotong. Matikan juga Headers and footers di sana jika Anda tidak ingin tanggal dan URL dicetak di setiap halaman.

Apakah mendukung blok kode, tabel, dan diagram?

Blok kode berpagar mendapat penyorotan sintaks untuk JavaScript, TypeScript, Python, Go, Rust, Java, C#, C++, SQL, Bash, YAML, JSON, HTML, dan CSS, dan tabel pipa standar dirender sebagai tabel. Blok kode Mermaid digambar sebagai diagram alir, diagram urutan, dan jenis bagan lain di pratinjau maupun PDF.

Ekstensi Markdown apa saja yang berfungsi di luar dasar?

Daftar tugas, catatan kaki, daftar definisi, singkatan, subskrip dan superskrip, tanda ==highlight== dan ++insert++, kode singkat emoji seperti :smile:, dan penautan otomatis URL polos. Dialog pengaturan memiliki sakelar untuk HTML mentah, jeda baris, penautan otomatis, dan tanda kutip tipografis.

Apakah tema gelap memengaruhi PDF yang diekspor?

Tidak. Sakelar tema hanya mengubah warna editor di layar; stylesheet cetak memaksa latar putih dan teks gelap, jadi PDF terlihat sama dalam kedua kasus.

Bisakah saya menambahkan daftar isi ke PDF?

Letakkan ${toc} di barisnya sendiri di tempat yang Anda inginkan dan daftar isi dibuat dari judul Anda saat dokumen dirender. Judul juga mendapat ID jangkar, jadi tautan dalam dokumen ke sebuah judul berfungsi di pratinjau.

Bisakah saya menyertakan gambar di PDF?

Gunakan sintaks gambar Markdown standar dengan URL gambar lengkap atau data URI dan gambar dirender di pratinjau dan dicetak ke PDF. Path relatif ke file di disk Anda tidak akan dimuat, karena editor tidak memiliki akses ke folder lokal Anda.

Apakah teks Markdown saya diunggah ke server untuk membuat PDF?

Tidak. Markdown dirender menjadi HTML oleh markdown-it di browser Anda dan PDF dibuat oleh fungsi cetak browser, jadi baik teks maupun PDF jadi tidak menyentuh server. Catatan, draf, dan dokumen internal tetap di mesin Anda.
