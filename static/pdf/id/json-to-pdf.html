Pertanyaan yang Sering Diajukan

Bisakah saya mengonversi file JSON apa pun menjadi PDF dengan alat ini?

Tidak. Alat ini hanya membangun ulang PDF dari file JSON yang dibuat oleh alat PDF ke JSON BentoPDF, yang menyimpan struktur internal lengkap dokumen. Ekspor JSON dari API, database, atau file konfigurasi akan gagal dengan pesan kesalahan.

Bagaimana cara mengubah data API atau file konfigurasi menjadi PDF yang mudah dibaca?

Tempel atau unggah JSON sebagai teks biasa di Teks ke PDF, yang menatanya sebagai teks berformat di halaman. JSON ke PDF hanya untuk bolak-balik dokumen yang awalnya berupa PDF.

Apakah PDF yang dibangun ulang akan sama dengan aslinya?

JSON yang dihasilkan PDF ke JSON menangkap objek dokumen, jadi mengonversinya kembali mereproduksi halaman, teks, dan gambar sumber. Mengonversi kembali dan membandingkan juga cara cepat untuk memastikan ekspor menangkap semuanya.

Apa hasilnya jika saya mengonversi beberapa file JSON?

Setiap konversi diunduh sebagai jsons-to-pdf.zip, bahkan untuk satu file. Di dalamnya, setiap PDF memakai nama JSON sumbernya, jadi report.json menjadi report.pdf.

Bisakah saya mengedit JSON sebelum mengonversinya kembali?

Ya, selama strukturnya tetap valid untuk mesin CPDF. Perubahan terprogram pada JSON, seperti metadata atau objek teks yang diedit, dibangun ulang ke dalam PDF; suntingan yang salah format menghasilkan kesalahan konversi.

Mengapa alat ini mengatakan mesin CPDF tidak tersedia?

Konversi bergantung pada build WebAssembly CPDF. Di bentopdf.com sudah disertakan, tetapi salinan yang di-hosting sendiri memerlukan file WASM CPDF yang dikonfigurasi di pengaturan WASM sebelum alat ini dapat berjalan.

Apakah file JSON saya diunggah ke server?

Tidak. File dibaca di browser Anda dan dibangun ulang menjadi PDF oleh Web Worker yang menjalankan mesin CPDF secara lokal, jadi tidak ada yang dikirim dan halaman tetap responsif selama konversi besar.
