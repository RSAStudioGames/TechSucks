Pertanyaan yang Sering Diajukan

Versi PDF/A mana yang sebaiknya saya pilih?

PDF/A-2b, yang default, cocok untuk sebagian besar pengarsipan dan menerima transparansi serta gambar JPEG 2000. Pilih PDF/A-1b hanya jika penerima mengharuskannya, karena ini tingkat paling ketat dan melarang transparansi serta lapisan, dan PDF/A-3b jika arsip perlu membawa file tersemat, seperti data XML yang dipakai format e-faktur.

Apa sebenarnya yang diubah konversi pada file saya?

Ghostscript menulis ulang PDF agar memenuhi standar: setiap font disematkan sebagai subset, warna dikonversi ke warna independen perangkat dengan output intent sRGB, dan fitur yang dilarang tingkat yang dipilih dibuang alih-alih menggagalkan seluruh proses. Isi halaman tetap utuh dan teks tetap dapat dipilih.

Mengapa file PDF/A lebih besar daripada aslinya?

PDF/A mewajibkan semua font disematkan, sehingga font apa pun yang dirujuk aslinya tetapi tidak disertakan kini disimpan di dalam file, dan profil warna sRGB juga ditambahkan. Kompres PDF dapat mengurangi ukurannya; validasi ulang sesudahnya jika kepatuhan ketat penting.

Kapan sebaiknya saya mengaktifkan Pra-ratakan?

Hanya jika konversi biasa gagal. Pra-ratakan merender setiap halaman menjadi gambar 300 DPI sebelum Ghostscript berjalan, yang mengatasi font rusak atau transparansi tidak biasa tetapi membuat Anda tanpa teks yang bisa dipilih, jadi coba tanpa itu lebih dulu. Ini juga memerlukan modul PyMuPDF, yang dimuat saat pertama dipakai.

Apakah hasilnya dijamin lolos validator PDF/A?

Tidak dijamin. Ghostscript menghasilkan keluaran yang sesuai untuk sebagian besar file, tetapi bukan validator, jadi jika pengadilan, repositori, atau auditor memerlukan bukti, periksa hasilnya dengan validator PDF/A khusus seperti veraPDF.

Bisakah saya mengonversi beberapa PDF ke PDF/A sekaligus?

Bisa. Tambahkan beberapa file dan semuanya dikonversi satu per satu dengan pengaturan yang sama; satu file diunduh langsung dan beberapa file diunduh bersamaan sebagai pdfa-converted.zip.

Apakah arsip saya diunggah ke server untuk konversi PDF/A?

Tidak. Ghostscript berjalan sebagai modul WebAssembly di dalam browser Anda, sehingga konversi terjadi di mesin Anda dan file tidak pernah meninggalkannya. Modulnya sendiri diambil dari CDN saat pertama kali Anda memakai alat ini, itulah sebabnya proses pertama butuh waktu sedikit lebih lama.

Bisakah saya mengonversi PDF yang dilindungi kata sandi ke PDF/A?

Alat ini meminta kata sandi pembuka dulu, lalu mengonversi file yang sudah didekripsi. PDF/A sendiri melarang enkripsi, jadi hasilnya selalu tidak terlindungi; PDF/A yang dilindungi kata sandi tidak dimungkinkan.
