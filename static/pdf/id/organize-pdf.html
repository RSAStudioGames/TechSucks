Pertanyaan yang Sering Diajukan

Bagaimana cara memindahkan halaman ke posisi lain?

Seret thumbnail halaman ke posisi baru di kisi; label nomor halaman diperbarui otomatis. Untuk menyusun ulang seluruh dokumen, ketik urutan baru di kotak urutan halaman, misalnya 3, 1, 2, 4, lalu klik Terapkan.

Apa yang diharapkan kotak urutan halaman?

Daftar nomor halaman asli yang dipisahkan koma, sesuai urutan yang Anda inginkan, dan harus menyebut setiap halaman tepat satu kali. 3, 1, 2 untuk file tiga halaman berfungsi; 3, 1 (ada halaman yang hilang) atau 1, 1, 2 (ada yang berulang) akan ditolak. Gunakan tombol duplikat dan hapus untuk salinan dan penghapusan.

Bisakah saya menggandakan halaman lebih dari sekali?

Bisa. Setiap klik tombol duplikat hijau menambahkan satu salinan tepat setelah halaman itu, dan setiap salinan bisa diseret ke mana saja secara terpisah. Ini berguna untuk menaruh beberapa salinan kosong halaman formulir dalam satu file.

Bisakah saya menghapus halaman di sini juga?

Bisa. Klik tombol hapus merah pada thumbnail untuk membuangnya dari hasil; satu-satunya aturan adalah halaman terakhir yang tersisa tidak bisa dihapus. Untuk menghapus banyak halaman berdasarkan rentang, Hapus Halaman lebih cepat.

Apakah mengurutkan ulang halaman mempertahankan bookmark saya?

Isi halaman, gambar, dan anotasi pada setiap halaman tetap terjaga. Bookmark tidak, karena file hasil penyusunan ulang dibuat baru dari halaman yang disalin, sehingga dokumen dengan outline navigasi akan kehilangannya. Buat ulang setelahnya dengan alat Bookmark jika perlu.

Apakah kualitas halaman terpengaruh?

Tidak. Halaman disalin apa adanya, bukan dirender ulang, sehingga teks tetap dapat dipilih dan gambar mempertahankan resolusi aslinya. Hasilnya disimpan dengan nama yang sama seperti file asli.

Apakah PDF saya diunggah saat saya menyusun ulang halamannya?

Tidak. Thumbnail dirender oleh browser Anda dan file baru disusun secara lokal, sehingga tidak ada yang dikirim ke mana pun, bahkan untuk dokumen besar.

Bisakah saya mengatur halaman dari lebih dari satu PDF sekaligus?

Tidak, alat ini bekerja pada satu file. Untuk mengambil halaman dari beberapa dokumen menjadi satu urutan, gunakan Gabung PDF dalam Mode Halaman, yang menampilkan thumbnail dari semua file dalam satu kisi.
