Pertanyaan yang Sering Diajukan

Seperti apa tampilan nomor Bates di halaman?

Secara default berupa nomor enam digit dengan nol di depan seperti 000001 yang ditempatkan di tengah footer dengan Helvetica 10 pt. Preset bisa menambahkan nomor bukti, label perkara, dan nomor halaman, misalnya Exhibit 1 Case XYZ 000001 Page 1, dan kotak pratinjau menampilkan teks persisnya sebelum Anda memproses apa pun.

Bisakah saya memakai prefiks atau nomor perkara sendiri sebagai pengganti preset?

Bisa. Pilih gaya Kustom dan tulis templat dengan placeholder: [BATES] untuk nomor berurutan, [PAGE] untuk nomor halaman di dalam file, [FILE] untuk penghitung file, dan [FILENAME] untuk nama file sumber. Templat seperti SMITH-[BATES] menghasilkan SMITH-000001, SMITH-000002, dan seterusnya.

Apakah penomoran berlanjut di beberapa PDF atau dimulai ulang untuk setiap file?

Berlanjut. Jika file pertama memiliki 30 halaman dan penomoran dimulai dari 1, file kedua dimulai dari 000031, mengikuti urutan daftar file, yang bisa Anda atur ulang dengan menyeret. Tidak ada opsi untuk memulai ulang hitungan per file; proses file secara terpisah jika Anda memerlukannya.

Berapa digit yang bisa dimiliki nomor tersebut?

Padding nol bisa 3, 4, 5, atau 6 digit, atau dinonaktifkan sehingga 1, 2, 3 tercetak tanpa nol di depan. Jumlah itu sendiri tidak dibatasi; jika melebihi lebar padding, digit tambahannya tetap dicetak.

Di mana stempel ditempatkan, dan apakah akan menutupi konten saya?

Anda memilih salah satu dari enam posisi: header atau footer, di kiri, tengah, atau kanan. Margin menyesuaikan dengan halaman, sekitar 4 persen dari lebar atau tinggi dengan batas bawah 8 poin dan batas atas 40, sehingga stempel berada di posisi relatif yang sama pada Letter, A4, dan lampiran berukuran besar. Konten yang ada tidak digeser, jadi pada halaman yang dicetak penuh sampai ke tepi, stempel bisa tumpang tindih dengan konten.

Apakah nomor Bates berupa teks yang bisa dicari atau gambar?

Nomor ini berupa teks asli yang digambar dengan Helvetica, Times New Roman, atau Courier, sehingga bisa dipilih, dicari, dan dibaca oleh perangkat lunak peninjauan tanpa OCR. Font ini adalah font standar bawaan PDF yang hanya mencakup karakter Latin, jadi templat yang berisi aksara lain akan gagal.

Apakah dokumen discovery saya diunggah ke server untuk distempel?

Tidak. Proses stempel berlangsung di dalam browser Anda dan file yang sudah bernomor langsung ditulis ke folder unduhan Anda. Tidak ada informasi tentang dokumen, nama perkara, maupun penomoran yang meninggalkan perangkat, yang penting untuk materi yang bersifat rahasia secara hukum.

Apa yang saya dapatkan saat menstempel beberapa file sekaligus?

Setiap PDF diberi nomor sebagai file tersendiri dan mempertahankan nama aslinya; satu file diunduh langsung, dan dua file atau lebih diunduh bersama sebagai bates_numbered.zip. File tidak digabungkan, jadi jumlah halaman dan urutan di dalam setiap dokumen tetap seperti semula.
