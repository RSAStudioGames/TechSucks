Pertanyaan yang Sering Diajukan

Untuk apa Pembuat Alur Kerja PDF?

Alat ini merangkai beberapa operasi PDF menjadi satu proses. Alih-alih membuka alat, mengunduh, dan memasukkan hasilnya ke alat berikutnya untuk setiap langkah, Anda menghubungkan node di kanvas, seperti Input PDF, Kompres, Watermark, dan Unduh, mengatur opsi tiap node, lalu klik Jalankan untuk memproses semuanya secara berurutan.

Bisakah saya menjalankan alur kerja yang sama pada banyak PDF sekaligus?

Bisa. Node Input PDF menerima banyak file; node Gabung menggabungkannya menjadi satu dokumen, sedangkan node lain memproses setiap PDF secara terpisah. Jika lebih dari satu file keluar di akhir, node Unduh mengemasnya ke ZIP secara otomatis.

Mengapa dua node tidak bisa dihubungkan?

Soket memiliki tipe: PDF (satu dokumen), MultiPDF (beberapa dokumen), dan Gambar. Node yang mengharapkan satu PDF tidak menerima output MultiPDF, jadi taruh node Gabung di antaranya, dan output gambar hanya masuk ke node yang menerima gambar. Koneksi selalu berjalan dari bawah satu node ke atas node berikutnya.

Mengapa muncul peringatan bahwa Enkripsi harus menjadi langkah terakhir?

Setelah PDF dienkripsi, node berikutnya tidak bisa membacanya, sehingga mesin menolak alur kerja yang punya node apa pun selain output setelah Enkripsi. Pindahkan Enkripsi tepat sebelum Unduh. Input yang dilindungi kata sandi adalah kasus sebaliknya: proses berhenti sejenak dan meminta kata sandi.

Apa yang terjadi jika satu langkah gagal?

Proses berhenti di node itu, yang berubah merah dengan pesan kesalahan, dan tidak ada yang dihasilkan setelahnya. Perbaiki pengaturan atau input lalu jalankan lagi; cara termudah adalah membangun versi dua node dulu dan menambah langkah setelah itu berfungsi.

Bisakah saya menyimpan alur kerja dan memakainya lagi nanti?

Bisa. Simpan menyimpannya sebagai templat bernama di penyimpanan lokal browser Anda, dan Muat mengembalikannya di sesi berikutnya pada browser yang sama. Ekspor menulis tata letak ke file workflow.json yang bisa Anda cadangkan atau kirim ke rekan, dan Impor memulihkan node, posisi, koneksi, dan pengaturan dari file itu.

Apakah alur kerja yang disimpan berisi dokumen saya?

Tidak. Templat dan file JSON yang diekspor hanya menyimpan jenis node, pengaturannya, posisi, dan koneksi; PDF dipilih baru setiap kali Anda menjalankan. Pengaturan disimpan seperti yang diketik, jadi hindari mengekspor alur kerja dengan kata sandi yang dimasukkan di node Enkripsi jika Anda berencana membagikannya.

Apakah file diproses di server?

Tidak. Setiap node berjalan di browser Anda dengan mesin yang sama seperti alat individual, dan satu-satunya aktivitas jaringan adalah mengambil modul pemrosesan seperti Ghostscript saat node pertama kali membutuhkannya. PDF Anda tidak pernah meninggalkan mesin, bahkan dalam proses multi-langkah yang panjang.
