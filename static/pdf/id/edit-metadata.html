Pertanyaan yang Sering Diajukan

Kolom metadata apa saja yang bisa saya ubah?

Judul, Penulis, Subjek, Kata Kunci, Pembuat, Produsen, Tanggal Pembuatan, dan Tanggal Modifikasi, ditambah pasangan kunci-nilai kustom yang Anda tambahkan. Formulir dimuat dengan nilai file saat ini, jadi Anda hanya mengedit yang perlu diubah.

Bagaimana cara menghapus kolom seperti Penulis sepenuhnya?

Kosongkan kotaknya lalu simpan. Apa pun yang ada di formulir ditulis kembali, jadi kolom yang dikosongkan disimpan sebagai kosong. Untuk menghapus setiap kolom sekaligus, termasuk yang tersembunyi, gunakan Hapus Metadata.

Mengapa tanggal modifikasi berubah padahal saya tidak menyentuhnya?

Jika kotak Tanggal Modifikasi dibiarkan kosong, alat ini mencantumkan tanggal dan waktu saat ini ketika menyimpan. Atur tanggal tertentu di pemilih jika nilai tertentu perlu dipertahankan.

Bisakah saya menambahkan kolom sendiri seperti Departemen atau ID Proyek?

Ya. Klik tombol tambah, masukkan kunci dan nilai, lalu pasangan itu ditulis ke kamus info PDF bersama kolom standar. Tidak semua pembaca menampilkan entri kustom, tetapi entri tersebut tetap ada di file dan muncul di alat yang membaca seluruh kamus info, seperti Lihat Metadata.

Saya sudah mengubah judul tetapi Acrobat masih menampilkan yang lama. Mengapa?

Alat ini menulis ke kamus info dokumen. Beberapa PDF juga membawa aliran metadata XMP, dan pembaca seperti Acrobat lebih memilih XMP jika keduanya ada, sehingga judul lama masih bisa muncul di sana. Jalankan Hapus Metadata terlebih dahulu, lalu edit, untuk menghindari konflik.

Bagaimana cara memasukkan kata kunci?

Pisahkan dengan koma, misalnya faktur, 2026, Q3. Kata kunci disimpan sebagai daftar yang dapat diindeks oleh sistem manajemen dokumen dan pencarian desktop.

Apakah mengedit metadata mengubah halaman atau mengirim file saya ke suatu tempat?

Tidak. Hanya kamus info yang ditulis ulang; halaman, font, tautan, dan bookmark tidak disentuh, dan seluruh pengeditan terjadi di browser Anda, sehingga dokumen tidak pernah meninggalkan perangkat Anda.

Bisakah saya mengedit metadata pada PDF yang dilindungi kata sandi?

Jika file memerlukan kata sandi untuk dibuka, alat ini memintanya lalu memuat dokumen seperti biasa. Tanpa kata sandi, file tidak dapat dibuka di sini.
