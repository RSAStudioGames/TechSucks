Pertanyaan yang Sering Diajukan

Berapa resolusi gambar BMP?

Halaman dirender pada skala tetap 2x, sehingga halaman Letter (8,5 x 11 inci) menjadi gambar 1224 x 1584 piksel, sekitar 144 piksel per inci. Tidak ada pengaturan DPI di alat ini; untuk skala yang bisa diatur gunakan PDF ke PNG.

Bagaimana PDF multi-halaman dikirimkan?

PDF satu halaman diunduh sebagai satu file .bmp bernama sesuai file. PDF multi-halaman diunduh sebagai ZIP bernama filename_bmps.zip berisi page_1.bmp, page_2.bmp, dan seterusnya, satu gambar per halaman.

Mengapa file BMP begitu besar?

BMP menyimpan data piksel mentah tanpa kompresi, sehingga satu halaman memakan ruang yang sama baik kosong maupun penuh detail, dan file jauh lebih besar daripada PNG atau JPG dari halaman yang sama. Jika perangkat lunak tujuan Anda menerima PNG, format itu juga lossless dengan ukuran jauh lebih kecil.

Bisakah saya mengonversi beberapa PDF ke BMP sekaligus?

Tidak, satu PDF per proses; jika Anda meletakkan beberapa file, hanya yang pertama dipakai. Konversi satu per satu, atau pilih halaman yang Anda butuhkan lebih dulu dengan Ekstrak Halaman agar setiap proses tetap kecil.

Apakah konversi mempertahankan transparansi atau kualitas vektor?

Tidak. Setiap halaman menjadi gambar raster datar dengan latar putih, dan teks menjadi piksel, sehingga BMP tidak bisa dicari atau diperbesar tanpa menjadi buram. Simpan PDF asli untuk mengedit.

Bisakah saya mengonversi PDF yang dilindungi kata sandi ke BMP?

Bisa, jika Anda tahu kata sandinya: alat ini meminta kata sandi saat file dimuat lalu merender halaman seperti biasa. File dengan kata sandi yang tidak diketahui tidak bisa dibuka.

Apakah PDF saya diunggah untuk dikonversi ke BMP?

Tidak. Rendering terjadi pada canvas di browser Anda dan gambar dikemas ke ZIP secara lokal, sehingga dokumen tidak pernah meninggalkan komputer Anda. PDF besar hanya butuh waktu lebih lama karena mesin Anda sendiri yang merender.

Alat mana yang sebaiknya dipakai jika BMP tidak diperlukan?

Untuk hasil lossless dengan file kecil, PDF ke PNG; untuk foto dan file terkecil, PDF ke JPG; untuk sistem faks atau pemindaian multi-halaman, PDF ke TIFF. BMP terutama masuk akal jika aplikasi atau perangkat lama mengharuskannya.
