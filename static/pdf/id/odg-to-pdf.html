Pertanyaan yang Sering Diajukan

Apakah saya perlu memasang LibreOffice untuk mengonversi file ODG?

Tidak. Mesin LibreOffice yang dikompilasi ke WebAssembly berjalan di dalam browser Anda, jadi Anda tidak memerlukan LibreOffice, OpenOffice, atau plugin di komputer Anda, dan berfungsi di sistem operasi apa pun.

Apakah gambar tetap berupa vektor atau diubah menjadi gambar raster?

Bentuk, konektor, garis, dan kotak teks tetap berupa vektor di PDF, jadi gambar diskalakan dengan bersih ke ukuran cetak apa pun dan teks tetap dapat dipilih.

Apakah PDF mempertahankan ukuran halaman asli?

Ya. Dimensi halaman dari file ODG dipertahankan, termasuk lanskap dan ukuran kustom, jadi diagram yang ditata untuk A3 atau Tabloid dicetak pada ukuran itu.

Bisakah saya mengonversi beberapa file ODG sekaligus?

Ya. Tambahkan beberapa file dan hasilnya diunduh sebagai odg-to-pdf.zip, satu PDF per gambar. Satu file diunduh langsung dengan nama dasar yang sama dan ekstensi .pdf.

Mengapa konversi ODG pertama lebih lama daripada berikutnya?

Pada penggunaan pertama, browser mengunduh mesin LibreOffice, sekitar 75 MB terkompresi, dan memulainya. Konversi berikutnya dalam sesi yang sama melewati langkah itu dan selesai jauh lebih cepat.

Apakah font akan terlihat sama seperti di LibreOffice Draw?

Mesin merender dengan font yang dibundel di dalamnya, bukan font yang terpasang di komputer Anda, jadi font yang tidak umum mungkin diganti dengan yang serupa. Periksa hasilnya jika gambar bergantung pada huruf tertentu.

Apakah berfungsi dengan file dari Apache OpenOffice Draw?

Ya. File .odg apa pun berfungsi, termasuk yang disimpan oleh OpenOffice Draw, karena kedua program memakai format OpenDocument Graphics yang sama.

Apakah gambar saya diunggah ke mana pun?

Tidak. Konversi berjalan sepenuhnya di tab browser Anda; satu-satunya unduhan adalah mesinnya sendiri, dan file ODG tidak pernah meninggalkan perangkat Anda.
