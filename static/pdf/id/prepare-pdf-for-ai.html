Pertanyaan yang Sering Diajukan

Apa isi keluaran JSON?

Mengikuti skema dokumen LlamaIndex: satu dokumen per halaman dengan teks halaman tersebut dan kolom metadata. Dihasilkan oleh integrasi LlamaIndex milik PyMuPDF, sehingga dapat langsung dimuat ke LlamaIndex atau pipeline apa pun yang menerima teks per halaman beserta metadata.

Apa bedanya dengan PDF ke Teks atau PDF ke Markdown?

PDF ke Teks menghasilkan satu aliran teks biasa, dan PDF ke Markdown mempertahankan judul serta struktur untuk dibaca. Alat ini membagi konten halaman demi halaman dan membungkusnya dalam JSON terstruktur beserta metadata, yang dibutuhkan pipeline pencarian untuk membagi potongan dan mengutip sumber.

Apakah berfungsi pada PDF hasil pindaian?

Hanya jika sudah memiliki lapisan teks. Gambar hasil pindaian menghasilkan keluaran kosong atau hampir kosong, jadi jalankan dulu melalui OCR PDF, lalu ekstrak.

Bisakah saya memproses sekumpulan PDF sekaligus?

Bisa. Unggah beberapa file dan Anda akan mendapatkan pdf-for-ai.zip berisi satu yourfile_llm.json per PDF; satu file akan langsung diunduh sebagai yourfile_llm.json. Jika satu file dalam kelompok gagal, sisanya tetap selesai dan ringkasan akan memberi tahu berapa yang gagal.

Bisakah saya memilih halaman yang diekstrak atau mengatur ukuran potongan?

Tidak. Tidak ada opsi; setiap halaman diekstrak dengan teks lengkap dan metadatanya. Lakukan chunking di pipeline Anda sendiri, di mana Anda bisa memilih ukuran yang cocok dengan model embedding Anda, dan buang halaman yang tidak Anda butuhkan di sana.

Bisakah saya menyiapkan PDF yang dilindungi kata sandi untuk alat AI?

Bisa. Jika file terenkripsi, Anda diminta kata sandinya sebelum ekstraksi dimulai, dan teks diambil dari salinan yang sudah didekripsi.

Apakah dokumen saya dikirim ke layanan AI?

Tidak. Meski namanya begitu, tidak ada yang dikirim ke penyedia AI atau server mana pun; ekstraksi berjalan dengan PyMuPDF yang dikompilasi ke WebAssembly di dalam browser Anda. Anda sendiri yang memutuskan ke mana JSON dikirim setelahnya.

Apa yang bisa saya lakukan dengan file JSON?

Gunakan untuk pipeline RAG, membangun basis pengetahuan untuk chatbot, menjalankan analisis LLM pada laporan, atau mengubah kumpulan PDF menjadi data pelatihan. Karena konten dibagi per halaman beserta metadata, jawaban dapat merujuk kembali ke halaman asalnya.
