Pertanyaan yang Sering Diajukan

Apa sebenarnya yang dihapus Sanitasi PDF?

Sepuluh hal, masing-masing dengan kotak centangnya sendiri: kolom formulir diratakan, dan metadata, anotasi, JavaScript, file tersemat, layer, tautan, struktur tree, MarkInfo, serta font tersemat (opsional) dihapus. Semuanya dicentang secara bawaan kecuali penghapusan font.

Apakah PDF yang disanitasi akan tampak berbeda?

Konten halaman itu sendiri tidak tersentuh, tetapi beberapa bagian interaktif menjadi statis. Kolom formulir berubah menjadi teks biasa, hyperlink tidak lagi dapat diklik, dan komentar, sorotan, serta catatan tempel hilang, jadi periksa hasilnya sebelum mengirim.

Haruskah saya mencentang Hapus Font Tersemat?

Biasanya tidak. Opsi ini menghapus program font yang diandalkan PDF, dan jika pembaca tidak dapat mengganti dengan font yang sesuai, teks dapat tampil salah atau tidak tampil sama sekali. Biarkan tidak dicentang kecuali Anda punya alasan khusus dan sudah menguji hasilnya.

Apakah ini menghapus nama penulis, tanggal pembuatan, dan perangkat lunak pengedit?

Hapus Metadata membersihkan kamus Info, aliran metadata XMP, ID dokumen, dan PieceInfo khusus aplikasi, sehingga penulis, judul, tanggal, dan perangkat lunak pembuatnya hilang. Jika hanya itu yang Anda perlukan, Hapus Metadata hanya melakukan langkah ini.

Apakah ini menghentikan skrip yang berjalan saat PDF dibuka?

Hapus JavaScript menghapus pohon skrip dokumen, aksi bukanya, dan aksi otomatis yang melekat pada dokumen, halaman, anotasi, dan kolom formulir. Itu mencakup tempat-tempat umum di mana PDF dapat menyembunyikan kode yang berjalan saat dibuka, dicetak, atau saat kolom berubah.

Apakah sanitasi menyensor teks sensitif di halaman?

Tidak. Alat ini menghapus data tersembunyi dan interaktif di sekitar konten, bukan kata atau gambar yang terlihat, jadi apa pun yang dapat Anda baca di halaman tetap ada. Jika Anda memerlukan konten halaman menjadi gambar datar tanpa teks yang dapat dipilih, gunakan Rasterisasi PDF.

Bisakah saya menyanitasi PDF yang dilindungi kata sandi?

Anda akan diminta memasukkan kata sandi setelah mengunggah. Salinan yang disanitasi ditulis tanpa enkripsi, jadi jika dokumen harus tetap terlindungi, jalankan melalui Lindungi PDF sesudahnya.

Apakah aman menyanitasi PDF yang tidak saya percayai di sini?

File diurai sebagai data di browser Anda dan tidak pernah diunggah, dan alat ini tidak menjalankan skrip apa pun di dalamnya. Simpan file asli jika ternyata elemen yang dihapus diperlukan, karena sanitasi tidak dapat dibatalkan dari hasilnya.
