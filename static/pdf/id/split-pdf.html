Pertanyaan yang Sering Diajukan

Bagaimana cara mengekstrak rentang halaman dari PDF?

Pilih Ekstrak berdasarkan Rentang Halaman dan ketik halaman yang Anda inginkan, seperti 1-5, 8, 11-13. Secara bawaan halaman yang dipilih digabung menjadi satu PDF; ubah keluaran ke Satu PDF per rentang dan setiap rentang yang dipisahkan koma menjadi file sendiri di dalam split-pages.zip.

Bisakah saya memisahkan PDF menjadi satu file per halaman?

Bisa. Pilih Pisahkan Semua Halaman menjadi File Terpisah dan setiap halaman ditulis ke PDF-nya sendiri, bernama page-1.pdf, page-2.pdf, dan seterusnya, dikemas dalam split-pages.zip.

Bagaimana cara memisahkan PDF setiap N halaman?

Pilih Pisah N Kali dan masukkan ukuran potongan. File 23 halaman yang dipisah setiap 5 halaman menghasilkan lima PDF, dan alat memperingatkan Anda sebelumnya bahwa yang terakhir hanya berisi 3 halaman. File diunduh sebagai split-n-times.zip.

Bisakah saya memisahkan PDF berdasarkan bab atau bookmark?

Bisa, jika PDF memiliki bookmark. Pilih Pisah berdasarkan Bookmark dan sebuah tingkat (Semua, atau tingkat 0 hingga 3), dan file baru dimulai di halaman setiap bookmark, menghasilkan split-1.pdf, split-2.pdf, dan seterusnya dalam split-by-bookmarks.zip. PDF tanpa bookmark pada tingkat yang dipilih akan menampilkan kesalahan.

Bagaimana cara memisahkan halaman ganjil dan genap?

Pilih Pisah berdasarkan Halaman Genap/Ganjil dan pilih genap atau ganjil; halaman yang sesuai diekstrak ke satu PDF dengan urutan aslinya. Ini langkah umum untuk mencetak bolak-balik di printer satu sisi.

Bisakah saya memilih halaman secara visual, bukan mengetik nomor?

Bisa. Pilih Halaman Secara Visual menampilkan gambar mini setiap halaman; klik yang Anda inginkan dan halaman diekstrak sesuai urutan halaman. Keluaran gabungan menghasilkan satu PDF, dan opsi terpisah menghasilkan satu file per halaman dalam ZIP.

Apakah pemisahan menurunkan kualitas halaman?

Tidak. Halaman disalin oleh QPDF tanpa dirender ulang, sehingga teks, gambar, font, dan grafik vektor tetap persis seperti di file asli.

Apakah PDF saya diunggah saat saya memisahkannya?

Tidak. Ekstraksi halaman dan pengemasan ZIP berjalan di browser Anda, dan file hasilnya disimpan langsung dari perangkat Anda.
