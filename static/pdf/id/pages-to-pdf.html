Pertanyaan yang Sering Diajukan

Apakah saya perlu Mac atau aplikasi Pages untuk mengonversi file .pages?

Tidak. Konversi berjalan pada mesin LibreOffice di dalam browser Anda, sehingga berfungsi di Windows, Linux, Chromebook, dan Mac tanpa Pages terpasang.

Mengapa dokumen Pages pertama lambat dikonversi?

Mesin harus diunduh saat pertama dipakai, sekitar 75 MB terkompresi, lalu dijalankan. Konversi berikutnya di sesi yang sama memakainya kembali dan langsung dimulai.

Bisakah saya mengonversi beberapa dokumen Pages sekaligus?

Bisa. Tambahkan beberapa file .pages lalu klik Ubah ke PDF; Anda mendapat pages-to-pdf.zip dengan satu PDF per dokumen. File dengan nama yang sama diberi akhiran angka seperti Report (1).pdf agar tidak ada yang tertimpa.

Apakah PDF akan tampak persis seperti di Pages?

Biasanya mirip, tetapi tidak dijamin. Filter impor LibreOffice yang membaca file, bukan Pages sendiri, sehingga tata letak rumit, beberapa font, dan fitur Pages terbaru bisa tampil berbeda. Periksa hasilnya sebelum mengirimkannya.

Apa nama PDF hasilnya?

Nama dasarnya sama dengan dokumen Pages dengan ekstensi .pdf, jadi Resume.pages menjadi Resume.pdf.

Apa yang harus saya lakukan jika konversi gagal?

Pesan kesalahan menampilkan alasan yang dilaporkan mesin. Pastikan file adalah dokumen .pages asli dan tidak rusak; jika masih gagal, buka di Pages lalu ekspor ulang, atau ekspor ke PDF langsung dari Pages.

Bisakah saya mengonversi file Pages ke Word, bukan PDF?

Alat ini hanya menghasilkan PDF. Jika Anda butuh .docx, konversi file Pages di sini dulu lalu proses hasilnya lewat PDF ke Word.

Apakah dokumen Pages saya diunggah ke server?

Tidak. Mesin LibreOffice membaca dan merender dokumen di browser Anda; satu-satunya transfer jaringan adalah mengunduh mesinnya sendiri. File Anda tidak pernah meninggalkan perangkat Anda.
