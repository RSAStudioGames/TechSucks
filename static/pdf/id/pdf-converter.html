Pertanyaan yang Sering Diajukan

Format file apa saja yang bisa saya ubah ke PDF?

File Word, Excel, dan PowerPoint (termasuk format lama DOC, XLS, dan PPT), teks, spreadsheet, presentasi, dan gambar OpenDocument, RTF, teks biasa, Markdown, CSV, XML, ebook dalam EPUB, MOBI, FB2, dan CBZ, XPS, Publisher, Visio, WordPerfect, Microsoft Works, Apple Pages, dan gambar dalam JPG, PNG, HEIC, WebP, TIFF, BMP, SVG, dan PSD. Jika Anda punya folder berisi berbagai jenis gambar, Gambar ke PDF menerima semuanya sekaligus dan menaruh setiap gambar di halamannya sendiri.

PDF bisa saya ubah menjadi apa?

Word (DOCX), Excel (XLSX), CSV, teks biasa, Markdown, SVG, dan gambar halaman dalam JPG, PNG, WebP, TIFF, atau BMP, dengan PDF multi-halaman dikirim sebagai ZIP berisi satu gambar per halaman. Untuk pengarsipan jangka panjang, PDF ke PDF/A menghasilkan PDF/A-1b, 2b, atau 3b, dan alat terpisah mengubah PDF berwarna menjadi skala abu-abu.

Apakah PDF ke Word mempertahankan tata letak?

PDF ke Word membangun ulang dokumen dengan teks, format dasar, dan tata letak umumnya, dan bisa mengonversi sekumpulan file sekaligus. Halaman dengan banyak kolom, formulir tersemat, atau grafis berat mungkin tidak terbawa sempurna, jadi siapkan waktu merapikannya di pengolah kata Anda.

Mengapa file Word atau teks hasil konversi saya kosong?

PDF hampir pasti hasil pindaian, yang menyimpan setiap halaman sebagai gambar tanpa lapisan teks, sehingga PDF ke Word, PDF ke Teks, dan konverter tabel tidak punya apa pun untuk diambil. Jalankan file lewat OCR PDF dulu untuk menambahkan lapisan teks yang bisa dicari, lalu konversi hasilnya.

Bisakah saya mengambil tabel dari PDF ke Excel?

PDF ke Excel memindai setiap halaman untuk mencari tabel dan menulis masing-masing ke lembar kerjanya sendiri, dinamai sesuai halaman asalnya. Jika dilaporkan tidak ada tabel, berarti PDF menata data sebagai teks lepas, bukan struktur tabel sungguhan; PDF ke CSV dan Ekstrak Tabel memakai deteksi yang sama, jadi coba PDF ke Teks untuk mengambil isi mentahnya.

Apakah saya perlu Microsoft Office terpasang untuk mengonversi file Word, Excel, atau PowerPoint?

Tidak. File itu, bersama Publisher, Visio, RTF, dan WordPerfect, dikonversi oleh mesin LibreOffice yang berjalan di dalam browser Anda, jadi tidak ada yang perlu dipasang; Word ke PDF, misalnya, juga menerima DOC, ODT, dan RTF secara langsung. Mesin diunduh sekali per sesi, sehingga konversi pertama butuh beberapa detik lebih lama dibanding berikutnya.

Apakah mengubah PDF ke JPG atau PNG menurunkan kualitas?

Halaman dirender pada dua kali ukuran aslinya, sehingga halaman ukuran letter menjadi gambar sekitar 1.224 kali 1.584 piksel. PDF ke JPG bersifat lossy dengan penggeser kualitas yang default 90%, menjaga keseimbangan baik antara ketajaman dan ukuran file; PDF ke PNG dan PDF ke TIFF bersifat lossless, dan PNG menambahkan kontrol skala dari 1x sampai 3x untuk hasil berkualitas cetak.

Apakah file saya diunggah ke server selama konversi?

Tidak. Setiap konverter di halaman ini, termasuk konverter Office, ebook, dan gambar, berjalan sebagai WebAssembly di dalam tab browser Anda, sehingga file dibaca dari perangkat Anda dan hasilnya ditulis langsung kembali ke sana. Tidak ada antrean unggah, tidak ada salinan di server, dan tidak ada yang perlu dihapus sesudahnya.
