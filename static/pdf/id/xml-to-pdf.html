Pertanyaan yang Sering Diajukan

Bagaimana alat ini menentukan tampilan PDF?

Alat ini mengurai XML, mengelompokkan elemen sejajar yang berulang berdasarkan nama tag, dan merender setiap kelompok sebagai tabel dengan satu kolom per elemen anak, memakai nama elemen sebagai header. Jika root tidak memiliki anak yang berulang, Anda mendapat tabel dua kolom Properti dan Nilai. Hasilnya A4 lanskap dengan nama elemen root sebagai judul.

XML jenis apa yang paling cocok?

XML bergaya data: rekaman dengan kumpulan elemen anak yang sama berulang di bawah satu induk, seperti ekspor database, item baris faktur, feed produk, feed RSS, atau sitemap. XML yang bersarang dalam atau bergaya dokumen diratakan, sehingga nilai bersarang digabung ke satu sel dan kehilangan hierarkinya.

Mengapa saya mendapat kesalahan XML Tidak Valid?

File tidak well-formed: tag yang tidak ditutup, elemen root yang hilang, karakter & atau < yang tidak di-escape, atau pengodean yang salah. Pesan menyertakan alasan dari pengurai, jadi perbaiki file di editor atau validator lalu coba lagi.

Apakah atribut XML disertakan di PDF?

Sebagian. Pada tampilan tabel hanya elemen anak yang menjadi kolom, sehingga atribut pada rekaman yang berulang tidak ditampilkan. Pada tampilan Properti dan Nilai untuk root yang tidak berulang, atribut dicantumkan setelah nilai anak.

Bisakah saya mengonversi beberapa file XML sekaligus?

Bisa. Tambahkan beberapa file dan semuanya dikonversi dalam satu kelompok ke xml-to-pdf.zip dengan satu PDF per file. Satu file diunduh langsung dengan nama dasar yang sama dan ekstensi .pdf.

Apakah alat ini menerapkan stylesheet XSLT atau CSS saya?

Tidak. Instruksi stylesheet dan deklarasi DOCTYPE dihapus sebelum penguraian, dan tata letak dibuat dari struktur data saja. Jika Anda memerlukan tampilan bergaya, buka XML di browser yang menerapkan stylesheet dan cetak ke PDF dari sana.

Apakah teks Tionghoa, Arab, Sirilik, atau aksara non-Latin lainnya akan dirender?

Tidak dapat diandalkan. PDF dibuat dengan font Helvetica standar jsPDF, yang mencakup karakter Latin, sehingga teks dalam aksara lain dapat tampil sebagai karakter yang salah atau hilang.

Apakah file XML diunggah untuk dikonversi?

Tidak. Penguraian memakai pengurai XML JavaScript dan PDF dibuat dengan jsPDF, keduanya di dalam browser Anda, sehingga faktur, log transaksi, dan data sensitif lain di dalam file tidak pernah meninggalkan perangkat Anda.
