Pertanyaan yang Sering Diajukan

Apa perbedaan antara XPS dan OXPS, dan apakah berpengaruh di sini?

XPS adalah format asli Microsoft dari Windows Vista dan 7; OXPS adalah varian OpenXPS ECMA-388 yang ditulis secara bawaan oleh Windows 8 dan yang lebih baru. Kedua ekstensi diterima, dapat dicampur dalam satu kelompok, dan menghasilkan jenis PDF yang sama.

Mengapa saya tidak bisa lagi membuka file XPS saya?

Microsoft tidak lagi memasang XPS Viewer secara bawaan, dan macOS, Linux, serta ponsel tidak pernah mendukung format ini. Mengonversi ke PDF membuat dokumen dapat dibaca di browser atau pembaca PDF mana pun.

Apakah konversi mempertahankan kualitas aslinya?

Ya. Dimensi halaman, grafik vektor, font, dan gambar dibawa ke PDF tanpa resampling, sehingga dokumen yang dicetak ke XPS pada resolusi tinggi mempertahankan resolusi itu di PDF.

Apakah teks tetap dapat dipilih di PDF?

Teks di XPS ditulis ke PDF sebagai teks beserta fontnya, bukan sebagai gambar halaman, sehingga Anda dapat memilih, mencari, dan menyalinnya di pembaca PDF.

Bisakah saya mengonversi beberapa file XPS sekaligus?

Bisa. Tambahkan file .xps atau .oxps sebanyak yang Anda perlukan; satu file diunduh sebagai PDF, dan beberapa file dikemas dalam xps-converted.zip dengan satu PDF per dokumen.

Apakah konverter memasang sesuatu di komputer saya?

Tidak. Mesin PyMuPDF dimuat ke browser Anda sebagai WebAssembly saat pertama kali Anda mengonversi, dan tidak ada yang dipasang di sistem Anda.

Bisakah saya mengonversi PDF kembali ke XPS?

Tidak, alat ini hanya dari XPS atau OXPS ke PDF. Di Windows Anda dapat mencetak PDF apa pun ke Microsoft XPS Document Writer jika memerlukan salinan XPS.

Apakah dokumen XPS saya diunggah untuk dikonversi?

Tidak. Mesin PyMuPDF berjalan secara lokal di browser Anda, sehingga file XPS diurai dan PDF ditulis di perangkat Anda sendiri. Dokumen lama perusahaan atau pemerintah tidak pernah meninggalkan mesin Anda.
