Pertanyaan yang Sering Diajukan

Apa sebenarnya yang dilakukan rasterisasi PDF?

Setiap halaman dirender menjadi bitmap dan bitmap tersebut disusun ulang menjadi PDF baru. Hasilnya tampak sama tetapi tidak berisi objek teks, font, layer, kolom formulir, atau konten tersembunyi, hanya gambar tiap halaman, mirip fotokopi.

DPI mana yang harus saya pilih saat merasterisasi?

150, bawaan, cukup untuk membaca di layar dan pencetakan kantor biasa. Gunakan 300 untuk keluaran berkualitas cetak atau saat seseorang akan memperbesar tulisan kecil, 600 hanya untuk pengarsipan atau pencetakan profesional, dan 72 bila ukuran file sekecil mungkin lebih penting daripada ketajaman.

PNG atau JPEG?

PNG bersifat lossless, sehingga tepi teks tetap tajam, tetapi file lebih besar. JPEG (disimpan pada kualitas 95) jauh lebih kecil dan cocok untuk halaman hasil pindaian atau foto, tetapi dapat meninggalkan artefak samar di sekitar teks yang tajam. Skala abu-abu tersedia untuk keduanya dan memperkecil file lebih jauh untuk dokumen hitam-putih.

Mengapa file hasil rasterisasi lebih besar dari aslinya?

PDF teks menyimpan beberapa kilobyte data font dan glif per halaman, sedangkan gambar 300 DPI satu halaman Letter berukuran 2550 x 3300 piksel. Turunkan DPI, beralih ke JPEG, atau jalankan hasilnya melalui Kompres PDF jika ukuran penting.

Bisakah saya membuat teks dapat dipilih lagi setelahnya?

Tidak dari file hasil rasterisasi itu sendiri; operasinya satu arah, jadi simpan file aslinya. Anda dapat menambahkan kembali lapisan teks yang dapat dicari dengan OCR PDF, meski teks hasil pengenalan tidak pernah seakurat aslinya.

Apa bedanya dengan meratakan PDF?

Perataan menggabungkan kolom formulir dan anotasi ke dalam halaman tetapi mempertahankan teks sebagai teks. Rasterisasi melangkah lebih jauh dan mengubah semuanya, termasuk teks, menjadi piksel. Jika Anda hanya perlu mengunci kolom formulir atau komentar, Ratakan PDF menjaga file tetap dapat dicari dan jauh lebih kecil.

Apakah dokumen rahasia saya diunggah untuk dirasterisasi?

Tidak. Rendering dilakukan oleh modul WebAssembly PyMuPDF yang berjalan di browser Anda, sehingga halaman digambar dan dikemas ulang di mesin Anda sendiri. Itulah yang menjadikan alat ini cara aman untuk menghapus teks tersembunyi dan layer dari file sensitif sebelum dibagikan.

Bisakah saya merasterisasi beberapa PDF sekaligus?

Bisa. Tambahkan sebanyak yang Anda mau; masing-masing diproses dengan pengaturan DPI, format, dan skala abu-abu yang sama, dan hasilnya diunduh bersama sebagai rasterized-pdfs.zip. Satu file diunduh sendiri.
