Pertanyaan yang Sering Diajukan

Bagaimana cara melihat file apa saja yang dilampirkan pada PDF?

Unggah PDF dan alat ini memindainya lalu mencantumkan setiap file tersemat berdasarkan nama, menandai masing-masing sebagai lampiran tingkat dokumen atau lampiran halaman beserta nomor halamannya. Jika tidak ada yang tersemat, alat ini memberi tahu Anda, bukan menampilkan daftar kosong.

Bisakah saya menghapus satu lampiran saja, bukan semuanya?

Klik ikon tempat sampah di samping lampiran mana pun untuk menandainya, dan klik lagi untuk membatalkan tanda sebelum menyimpan. Hapus Semua Lampiran memilih semuanya sekaligus, dan PDF baru ditulis hanya dengan file yang ditandai dikeluarkan.

Apakah menghapus lampiran mengubah bagian PDF lainnya?

Halaman, teks, dan gambar tidak disentuh. Lampiran yang Anda pertahankan disematkan kembali dengan nama aslinya dan, untuk lampiran halaman, pada halaman aslinya, tetapi teks deskripsi yang tersimpan bersamanya tidak ikut terbawa.

Apakah menghapus lampiran membuat PDF saya lebih kecil?

Biasanya, dan sering kali jauh lebih kecil, karena file tersemat disimpan utuh di dalam PDF. Dokumen yang membawa lampiran spreadsheet atau gambar besar dapat mengecil menjadi sebagian kecil dari ukuran semula setelah file itu dihapus.

Apa perbedaan antara lampiran tingkat dokumen dan tingkat halaman?

Lampiran tingkat dokumen berada di daftar file tersemat PDF dan muncul di panel lampiran penampil. Lampiran tingkat halaman adalah anotasi lampiran file yang ditempatkan di satu titik pada sebuah halaman, biasanya ditampilkan sebagai ikon klip kertas atau pin. Alat ini mencantumkan dan menghapus kedua jenis.

Bisakah saya mengunduh lampiran sebelum menghapusnya?

Alat ini hanya mencantumkan dan menghapusnya. Untuk menyimpan file tersemat ke komputer Anda terlebih dahulu, jalankan PDF melalui Ekstrak Lampiran, lalu kembali ke sini untuk menghapusnya.

Bisakah saya menambah atau mengganti lampiran di sini?

Tidak, alat ini hanya menghapus lampiran. Gunakan Tambah Lampiran untuk menyematkan file baru, dan gabungkan kedua langkah itu jika Anda ingin mengganti lampiran lama dengan versi yang lebih baru.

Apakah lampiran diunggah ke suatu tempat saat saya mengeditnya?

Tidak. PDF diurai oleh mesin cpdf yang berjalan sebagai WebAssembly di browser Anda, daftar lampiran dibuat secara lokal, dan file yang sudah dibersihkan disimpan langsung dari browser Anda. Baik dokumen maupun lampirannya tidak dikirim ke server, yang penting jika lampiran justru bagian yang sensitif.
