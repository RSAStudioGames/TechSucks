Pertanyaan yang Sering Diajukan

Punya pertanyaan? Kami punya jawabannya. Berikut beberapa hal yang paling sering ditanyakan orang tentang BentoPDF.

Apakah file saya aman dan privat?

Tentu saja. Ini adalah fitur terpenting BentoPDF. Semua pemrosesan terjadi 100% secara lokal di browser web Anda. File Anda tidak pernah diunggah ke server mana pun, yang berarti kami, atau siapa pun, tidak akan pernah bisa melihatnya. Privasi Anda terjamin.

Apakah BentoPDF benar-benar gratis? Apa syaratnya?

Ya, sepenuhnya gratis, dan tidak ada syaratnya. Tidak ada biaya tersembunyi, tidak ada paket berlangganan, tidak ada batas penggunaan, dan tidak ada fitur khusus premium. Kami percaya alat-alat penting harus dapat diakses oleh semua orang.

Apakah saya perlu koneksi internet untuk menggunakan alat-alat ini?

Setelah Anda memuat situs web untuk pertama kalinya, sebagian besar alat akan bekerja sepenuhnya offline! Karena semua pustaka pemrosesan dimuat ke browser Anda, Anda dapat memutus koneksi internet dan tetap menggabungkan, memisahkan, mengompres, dan mengedit PDF Anda dengan aman. Beberapa alat khusus yang memerlukan data eksternal (seperti Markdown ke PDF dengan gambar web) mungkin memerlukan koneksi.

Apakah ada batasan ukuran file atau penggunaan?

Tidak, kami tidak memberlakukan batas buatan pada ukuran file, jumlah file, atau seberapa sering Anda dapat memakai alat. Satu-satunya batasan praktis adalah daya pemrosesan dan memori komputer Anda sendiri, karena file yang sangat besar atau kompleks mungkin butuh waktu lebih lama untuk diproses.

Mengapa PDF saya gagal diproses?

Kegagalan jarang terjadi tetapi bisa muncul karena beberapa alasan:

  • PDF mungkin rusak atau tidak sesuai dengan spesifikasi standar.
  • File mungkin dienkripsi dengan kata sandi yang tidak Anda miliki. Silakan gunakan alat Dekripsi kami terlebih dahulu.
  • File mungkin berupa PDF berbasis formulir "XFA" atau dinamis khusus, yang tidak dapat diproses oleh sebagian alat kami.

Apakah kalian melacak aktivitas saya di BentoPDF?

Tidak. BentoPDF sama sekali tidak melacak Anda. Kami tidak menggunakan cookie, analitik, atau skrip pelacak apa pun, bahkan tidak di situs web langsung di bentopdf.com. Kami tidak pernah tahu siapa Anda atau apa yang Anda lakukan dengan alat-alat ini.

Teknologi apa yang digunakan BentoPDF?

BentoPDF dibangun di atas kekuatan teknologi web modern. Kami terutama menggunakan pustaka JavaScript seperti PDF-lib.js dan PDFKit.js yang dikompilasi agar berjalan efisien di browser Anda melalui WebAssembly. Ini memungkinkan pemrosesan canggih seperti di server tanpa data Anda pernah meninggalkan perangkat Anda.

Masih ada pertanyaan?
