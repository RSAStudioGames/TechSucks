Pertanyaan yang Sering Diajukan

Apa perbedaan antara kata sandi pengguna dan kata sandi pemilik?

Kata sandi pengguna wajib diisi dan harus diketik oleh siapa pun yang membuka file. Kata sandi pemilik bersifat opsional; jika Anda menetapkan yang berbeda, PDF juga mendapat pembatasan penggunaan, sehingga orang yang membukanya hanya dengan kata sandi pengguna tidak dapat mencetak, menyalin, mengedit, menganotasi, mengisi formulir, atau menyusun ulang halaman.

Enkripsi apa yang digunakan Lindungi PDF?

AES 256-bit, diterapkan dengan implementasi QPDF dari standar enkripsi PDF 2.0. Tidak ada opsi untuk memilih cipher yang lebih lemah, jadi kekuatan perlindungan bergantung pada seberapa kuat kata sandi Anda.

Apa yang terjadi jika saya lupa kata sandi?

Tidak ada pemulihan. AES-256 tidak dapat ditembus dengan brute force dalam waktu yang praktis, dan BentoPDF tidak menyimpan salinan file maupun kata sandi. Simpan kata sandi di tempat yang aman dan simpan salinan asli yang tidak diproteksi untuk Anda sendiri.

Apakah pembatasan tetap berlaku jika saya hanya memasukkan kata sandi pengguna?

Tidak. Dengan hanya kata sandi pengguna, file memerlukan kata sandi untuk dibuka, tetapi setelah terbuka tidak ada batasan untuk mencetak, menyalin, atau mengedit. Tambahkan kata sandi pemilik terpisah jika Anda menginginkan pembatasan tersebut.

Bisakah saya membatasi pencetakan atau penyalinan tanpa kata sandi untuk membuka file?

Tidak dengan alat ini, karena kata sandi pengguna wajib diisi di sini. Gunakan Ubah Izin sebagai gantinya, yang menerapkan pembatasan sambil tetap membiarkan file dapat dibuka tanpa kata sandi.

Bagaimana cara menghapus kata sandi nanti?

Buka file yang dilindungi di alat penghapus kata sandi, masukkan kata sandi, lalu unduh salinan tanpa enkripsi. Anda memerlukan kata sandinya; tidak ada cara untuk melewatinya.

Apakah PDF yang dilindungi dapat dibuka di pembaca mana pun?

Pembaca PDF terkini mana pun, termasuk Adobe Reader, Preview, Chrome, Firefox, dan Edge, dapat membuka file terenkripsi AES-256. Pembaca yang sangat lama, yang dirilis sebelum dukungan AES-256 ditambahkan, mungkin menolak file tersebut.

Apakah PDF atau kata sandi saya dikirim ke suatu tempat?

Tidak. QPDF berjalan sebagai WebAssembly di browser Anda, sehingga file dienkripsi di perangkat Anda dan baik dokumen maupun kata sandi tidak dikirim. Bagikan kata sandi kepada penerima melalui saluran yang berbeda dari file itu sendiri.
