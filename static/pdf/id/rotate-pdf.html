Pertanyaan yang Sering Diajukan

Bisakah saya memutar hanya satu halaman, bukan seluruh dokumen?

Bisa. Setiap halaman tampil sebagai gambar mini dengan tombol kiri dan kanannya sendiri, jadi satu pindaian yang miring ke samping dalam file 40 halaman dapat diperbaiki sendiri. Tombol di bagian atas memutar semua halaman sekaligus saat seluruh dokumen terbalik.

Bagaimana cara memutar halaman 180 derajat?

Klik arah yang sama dua kali. Rotasi bertambah dalam kelipatan 90 derajat, jadi dua klik menghasilkan 180 dan tiga klik menghasilkan 270, sama seperti satu klik ke arah sebaliknya. Gambar mini diperbarui sehingga Anda dapat melihat kondisi saat ini sebelum menyimpan.

Apakah memutar menurunkan kualitas halaman?

Tidak. Alat ini mengubah atribut rotasi setiap halaman tanpa merender ulang apa pun, sehingga teks tetap dapat dipilih, gambar mempertahankan resolusinya, dan ukuran file hampir sama.

Apakah rotasi tetap berlaku saat saya membuka file di aplikasi lain atau mencetaknya?

Ya. Rotasi ditulis ke halaman PDF itu sendiri, yang dihormati oleh setiap penampil dan printer, tidak seperti tombol putar sementara di penampil yang kembali semula saat Anda menutup file.

Bisakah saya memutar dengan sudut selain 90 derajat, misalnya untuk meluruskan pindaian yang miring?

Tidak di sini; alat ini hanya bekerja dalam langkah 90 derajat. Gunakan Putar dengan Derajat Kustom untuk sudut bebas, atau Luruskan PDF untuk meluruskan pindaian secara otomatis.

Bisakah saya memutar hanya halaman ganjil atau genap?

Alat ini tidak memiliki pemilihan halaman atau kolom rentang; Anda memutar halaman satu per satu dengan tombolnya atau semuanya sekaligus. Untuk memilih sekelompok halaman, PDF Multi Tool lebih cocok.

Apakah PDF saya diunggah untuk memutar halamannya?

Tidak. Gambar mini dirender oleh browser Anda dan file hasil rotasi ditulis secara lokal, sehingga dokumen tidak pernah meninggalkan komputer Anda. PDF hasil rotasi diunduh dengan nama file asli.

Apakah memutar mempertahankan bookmark saya?

Konten halaman, gambar, dan anotasi tetap utuh, tetapi bookmark tidak ikut terbawa, karena file hasil rotasi dibangun dari halaman yang disalin. Dokumen yang bergantung pada outline perlu menambahkannya kembali dengan alat Bookmark.
