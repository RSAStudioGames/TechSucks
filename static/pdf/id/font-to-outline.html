Pertanyaan yang Sering Diajukan

Apa yang terjadi pada PDF saat font diubah ke outline?

Setiap karakter teks diganti dengan path vektor yang menggambar bentuk yang sama, dan hasilnya tidak lagi merujuk font apa pun. Tampilannya sama di perangkat atau printer mana pun, bahkan yang tidak memiliki huruf aslinya.

Kapan saya perlu mengubah font ke outline sebelum mencetak?

Percetakan sering meminta font dalam bentuk outline untuk menghindari penggantian font atau masalah lisensi pada peralatan mereka. Lakukan sebagai langkah terakhir, setelah semua pengeditan teks selesai, karena teks tidak dapat diedit setelahnya.

Bisakah saya tetap memilih, mencari, atau menyalin teks setelah diubah ke outline?

Tidak. Teks outline hanyalah bentuk, jadi pemilihan, pencarian Ctrl+F, salin tempel, dan akses pembaca layar semuanya berhenti berfungsi. Simpan PDF asli untuk apa pun yang memerlukan teks hidup.

Bisakah saya mengubah outline kembali menjadi teks yang dapat diedit?

Tidak, konversi ini satu arah. Jika Anda kehilangan file asli, menjalankan OCR pada file outline menambahkan lapisan teks yang dikenali untuk pencarian, tetapi tidak akan mengembalikan font asli atau teks yang dapat diedit.

Mengapa PDF saya lebih besar setelah font diubah ke outline?

Setiap karakter disimpan sebagai path bezier, bukan referensi singkat ke program font, dan satu halaman teks isi bisa berisi ribuan di antaranya. Ukuran file sering bertambah cukup besar; jalankan melalui Kompres PDF setelahnya jika ukuran penting.

Apakah mengubah ke outline mengubah tampilan dokumen?

Font yang tertanam di PDF ditelusuri persis, sehingga tampilannya tetap sama. Jika font tidak tertanam, Ghostscript menggantinya dengan font serupa sebelum diubah ke outline, jadi periksa hasilnya jika dokumen mengandalkan font sistem.

Bisakah saya mengubah font ke outline di beberapa PDF sekaligus?

Ya. Unggah beberapa PDF dan konversi bersamaan; satu file diunduh sebagai PDF, dan beberapa file diunduh sebagai outlined_pdfs.zip dengan satu entri per masukan.

Apakah PDF saya diunggah selama konversi font?

Tidak. Ghostscript berjalan sebagai WebAssembly di dalam browser Anda, jadi file diproses di perangkat Anda dan salinan outline ditulis secara lokal tanpa unggahan apa pun.
