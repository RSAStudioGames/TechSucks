Pertanyaan yang Sering Diajukan

Bisakah saya menggabungkan beberapa file BMP menjadi satu PDF?

Bisa. Setiap BMP yang Anda tambahkan menjadi halaman tersendiri dalam satu PDF, sesuai urutan yang ditampilkan di daftar file. Tidak ada opsi untuk membuat satu PDF per file, jadi konversikan file secara terpisah jika Anda membutuhkannya terpisah.

Mengapa PDF lebih kecil daripada file BMP saya?

BMP menyimpan piksel tanpa kompresi, sehingga ukuran file besar. Konverter menggambar ulang setiap gambar dan menyimpannya di PDF sebagai PNG tanpa kehilangan kualitas, yang biasanya mengecilkan ukurannya secara signifikan tanpa mengubah satu piksel pun.

Apakah ada kualitas gambar yang hilang dalam konversi?

Tidak. Piksel disimpan tanpa kehilangan kualitas dan alat ini tidak memiliki pengaturan kualitas, sehingga hasilnya memiliki resolusi dan warna yang sama dengan sumbernya. Jika Anda memerlukan file yang lebih kecil setelahnya, jalankan PDF melalui Kompres PDF.

Berapa ukuran halaman PDF saat saya mengonversi BMP?

Setiap halaman berukuran sesuai dimensi piksel gambar dengan satu poin per piksel, jadi hasil pindai 2480 kali 3508 piksel menghasilkan halaman sekitar 34 kali 49 inci, bukan A4. Penampil dan printer akan menyesuaikan skalanya, dan Perbaiki Ukuran Halaman bisa mengubah ukuran setiap halaman menjadi A4 atau Letter setelahnya.

Mengapa muncul pesan bahwa salah satu file saya tidak valid?

Gambar didekode oleh browser Anda, yang menangani bitmap Windows standar. Varian yang tidak lazim seperti header OS/2 atau mode kompresi yang jarang dipakai bisa gagal; simpan ulang file sebagai BMP 24-bit standar atau sebagai PNG di editor gambar apa pun untuk mengatasinya.

Bisakah saya mencampur BMP dengan file JPG atau PNG?

Alat ini hanya menerima file .bmp dan melewati file lain yang Anda tambahkan. Gunakan Gambar ke PDF jika Anda perlu menggabungkan beberapa format menjadi satu dokumen.

Apakah pengaturan DPI pada BMP memengaruhi hasilnya?

Tidak. Resolusi yang tersimpan di header file diabaikan dan ukuran halaman hanya ditentukan oleh jumlah piksel, jadi dua gambar dengan dimensi piksel yang sama menghasilkan halaman yang identik berapa pun DPI-nya.

Apakah file BMP saya diunggah ke suatu tempat?

Tidak. Pendekodean memakai dukungan gambar bawaan browser Anda dan PDF disusun secara lokal dengan pdf-lib, sehingga hasil ekspor pemindai atau pencitraan medis tidak pernah meninggalkan komputer Anda.
