Kompres PDF ke 500KB

Buat PDF Anda di bawah 500KB sambil mempertahankan gambar tetap tajam.

Klik untuk memilih file atau seret dan jatuhkan

Satu atau lebih file PDF

File Anda tidak pernah meninggalkan perangkat Anda.

Didukung oleh Hyper Compress: mengompres ulang gambar, membuat subset dan menggabungkan font, serta membuang beban yang tidak perlu sementara teks, tautan, dan formulir tetap berfungsi. Untuk pindaian berisi gambar saja, aktifkan Rasterisasi halaman di Pengaturan Kustom.

Hyper Compress mencari kualitas terbaik yang masih muat. Biarkan kosong untuk memakai tingkat apa adanya.

Setel Hyper Compress secara rinci. Memilih tingkat kompresi akan mengatur ulang pengaturan ini, kecuali Abaikan perlindungan konten, Ubah ke skala abu-abu, Pertahankan PDF/A, dan Brotli.

Peringatan

Untuk mengompres PDF ke 500KB, tambahkan file Anda di bawah dan klik Kompres PDF. Ukuran target sudah diatur ke 500 KB. Ini target yang nyaman: sebagian besar dokumen mencapainya tanpa perbedaan yang terlihat, dan file Anda tidak pernah meninggalkan browser Anda.

Target yang paling pas

Setengah megabyte adalah yang paling longgar di antara batas unggah yang umum, dipakai oleh unggahan CMS, portal tender, dan sistem pengumpulan tugas kuliah. Tingkat Sedang sering sudah cukup untuk membuat dokumen kantor atau pindaian ringan di bawah 500KB, dengan gambar tetap tajam dan teks tetap jernih.

Jika Anda hanya sedikit melewati batas

Jika tingkat Sedang saja menghasilkan ukuran sedikit di atas 500KB, ukuran target membuat Hyper Compress menurunkan kualitas gambar sedikit lagi hingga file muat. Periksa apakah ada halaman sampul berfoto atau logo beresolusi tinggi di setiap halaman: gambar yang berulang adalah biaya tersembunyi yang umum dan dapat ditangani dengan baik oleh kompresi.

Pertanyaan yang Sering Diajukan

Apakah kompresi 500KB akan mengubah hasil cetak PDF saya?

Kualitas cetak tetap sangat baik untuk teks dan grafik vektor, yang tidak pernah diturunkan oleh kompresi. Foto dioptimalkan untuk penggunaan layar dan cetak; hanya pencetakan format besar yang akan memperlihatkan perbedaannya.

Bisakah saya mengompres beberapa PDF ke 500KB sekaligus?

Ya. Tambahkan beberapa file dan masing-masing dikompres secara independen di browser Anda, tanpa antrean dan tanpa biaya per file.

Mengapa file terkompresi saya sudah di bawah 500KB tetapi portal masih menolaknya?

Beberapa portal mengukur ukuran dalam mebibyte atau menolak versi PDF tertentu. Periksa kembali bunyi batas yang tepat, dan coba alat Bersihkan PDF untuk menghapus metadata yang tidak biasa jika file yang sudah sesuai tetap ditolak.
