Kurangi ukuran file PDF Anda.

Klik untuk memilih file atau seret dan jatuhkan

Satu atau lebih file PDF

File Anda tidak pernah meninggalkan perangkat Anda.

Didukung oleh Hyper Compress: mengompres ulang gambar, membuat subset dan menggabungkan font, serta membuang beban yang tidak perlu sementara teks, tautan, dan formulir tetap berfungsi. Untuk pindaian berisi gambar saja, aktifkan Rasterisasi halaman di Pengaturan Kustom.

Hyper Compress mencari kualitas terbaik yang masih muat. Biarkan kosong untuk memakai tingkat apa adanya.

Setel Hyper Compress secara rinci. Memilih tingkat kompresi akan mengatur ulang pengaturan ini, kecuali Abaikan perlindungan konten, Ubah ke skala abu-abu, Pertahankan PDF/A, dan Brotli.

Pertanyaan yang Sering Diajukan

Mengapa PDF saya masih besar setelah dikompres?

Sebagian besar ukuran PDF berasal dari gambar, jadi file dengan sedikit gambar, atau gambar yang sudah kecil, tidak akan banyak mengecil, dan pesan hasil akan memberi tahu jika ukurannya tidak bisa dikurangi. Coba tingkat Tinggi, tetapkan ukuran file target, atau aktifkan Ubah ke skala abu-abu di Pengaturan Kustom. Untuk pindaian berisi gambar saja, aktifkan juga Rasterisasi halaman di sana.

Seberapa besar setiap tingkat kompresi menurunkan kualitas gambar?

Rendah mengenkode ulang gambar pada kualitas JPEG 80 dan menurunkan resolusi apa pun di atas 200 DPI, Sedang memakai kualitas 50 dan 150 DPI, dan Tinggi memakai kualitas 20 dan 72 DPI. Lossless tidak mengubah gambar dan hanya mengoptimalkan font serta struktur file. Sedang adalah default dan terbaca baik di layar; Rendah adalah pilihan yang lebih aman untuk apa pun yang akan dicetak.

Apakah saya masih bisa memilih dan mencari teks setelah kompresi?

Ya. Kompresi mengompres ulang gambar, membuat subset font, dan merapikan struktur file tanpa menyentuh lapisan teks, sehingga pemilihan teks, pencarian, dan tautan tetap berfungsi. Rasterisasi halaman hanya berlaku untuk pindaian berisi gambar saja dan dilewati setiap kali dokumen memiliki teks yang dapat dipilih, kecuali Anda mengaktifkan Abaikan perlindungan konten di Pengaturan Kustom.

Apakah kompresi menghapus metadata dari PDF saya?

Kompresi mempertahankan detail dokumen seperti judul dan penulis. Kompresi membuang thumbnail halaman yang tertanam dan data pribadi yang ditinggalkan aplikasi pengedit, dan file PDF/A kehilangan label PDF/A-nya kecuali Anda mengaktifkan Pertahankan PDF/A di Pengaturan Kustom. Untuk menghapus detail dokumen juga, gunakan Hapus Metadata.

Bisakah saya mengompres PDF hasil pindai?

PDF hasil pindai berupa gambar satu halaman penuh, jadi responsif terhadap kompresi. Sedang atau Tinggi menurunkan resolusi pindaian di tempat dan mempertahankan lapisan teks OCR yang ada. Jika pindaian tidak memiliki lapisan teks sama sekali, mengaktifkan Rasterisasi halaman di Pengaturan Kustom bisa membuatnya lebih kecil lagi.

Apa fungsi Pengaturan Kustom?

Pengaturan ini menyetel Hyper Compress secara rinci. Anda dapat mengatur kualitas gambar dan resolusi maksimum, mengontrol cara font di-subset dan digabung, meratakan anotasi, kolom formulir, atau tautan, menghapus thumbnail dan data tersembunyi lainnya, merasterisasi pindaian berisi gambar saja, mempertahankan kesesuaian PDF/A, dan mengaktifkan Brotli. Abaikan perlindungan konten memungkinkan Anda mengompres PDF bertanda tangan dengan menghapus tanda tangannya dan merasterisasi halaman yang memiliki teks. Memilih tingkat kompresi akan mengatur ulang sisanya ke nilai tingkat tersebut.

Bisakah saya mengompres PDF ke ukuran tertentu seperti 1 MB?

Ya. Masukkan ukuran di Ukuran File Target dan Hyper Compress mencari kualitas gambar terbaik yang masih muat. Jika file tidak bisa sekecil itu, Anda mendapat versi terkecil yang bisa dibuat beserta catatan mengenai hal itu. Untuk batas yang umum, tersedia halaman dengan target yang sudah terisi, seperti Kompres PDF ke 1MB.

Apakah PDF saya diunggah ke server untuk dikompres?

Tidak. Kompresi menjalankan Hyper Compress, mesin milik BentoPDF sendiri, yang dikompilasi ke WebAssembly dan disajikan bersama aplikasi, sehingga semuanya terjadi di perangkat Anda. Anda dapat mengompres satu file atau satu batch sekaligus, yang hasilnya berupa compressed-pdfs.zip, dan tidak ada satu pun yang keluar dari komputer Anda.
