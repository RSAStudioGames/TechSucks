    Pertanyaan yang Sering Diajukan

    Apa yang dilakukan gabung selang-seling yang tidak bisa dilakukan gabung biasa?

    Gabung biasa menambahkan seluruh file satu demi satu. Gabung selang-seling mengambil halaman 1 dari setiap file secara bergantian, lalu halaman 2 dari masing-masing, dan seterusnya, sehingga halaman dari dua PDF atau lebih disisipkan selang-seling menjadi satu dokumen. Jika Anda hanya perlu menyambung file satu demi satu, gunakan Gabung PDF.

    Bagaimana cara memperbaiki hasil pindai bolak-balik yang halaman depan dan belakangnya ada di PDF terpisah?

    Unggah PDF halaman depan terlebih dahulu dan PDF halaman belakang kedua, lalu klik Campur Halaman. Hasilnya berselang-seling: depan 1, belakang 1, depan 2, belakang 2, dan seterusnya. Jika halaman belakang dipindai dari halaman terakhir lebih dulu, balik file tersebut dengan Balik Halaman sebelum mencampur.

    Halaman depan dan belakang ada di PDF yang sama, bukan file terpisah. Alat mana yang saya perlukan?

    Alat ini menyisipkan halaman dari file-file terpisah secara selang-seling. Jika satu PDF berisi semua halaman depan diikuti semua halaman belakang, Susun Ulang Pindaian Dupleks membagi file tunggal itu di titik tengah dan menyisipkan kedua bagiannya secara selang-seling, dengan opsi untuk membalik blok halaman belakang.

    Apa yang terjadi jika PDF memiliki jumlah halaman yang berbeda?

    Penyisipan selang-seling berlanjut sampai file yang lebih pendek habis, dan sisa halaman dari file yang lebih panjang ditambahkan berurutan di akhir. Tidak ada halaman yang dibuang.

    Bisakah saya menyisipkan selang-seling lebih dari dua PDF?

    Berapa pun jumlah file mulai dari dua. Dengan tiga file, hasilnya berurutan A1, B1, C1, A2, B2, C2 dan seterusnya, mengikuti urutan yang ditampilkan di daftar file, yang bisa Anda ubah dengan menyeret gagang pegangan.

    Apakah hasilnya mempertahankan bookmark dan nomor halaman dari file asli?

    Bookmark dari setiap file sumber dibawa ke PDF hasil campuran. Label halaman diatur ulang menjadi urutan biasa 1 sampai N secara default; aktifkan opsi untuk mempertahankan label halaman asli jika Anda menginginkan label milik tiap file, yang bisa menghasilkan duplikat seperti dua halaman yang sama-sama berlabel 1.

    Bisakah saya menyisipkan halaman selang-seling dari PDF yang dilindungi kata sandi?

    Jika file terenkripsi, Anda akan diminta memasukkan kata sandinya saat file dimuat, dan salinan yang sudah didekripsi dipakai untuk pencampuran. Hasilnya tidak terenkripsi, jadi gunakan Enkripsi PDF setelahnya jika memerlukan kata sandi lagi.

    Apakah PDF diunggah ke server saat disisipkan selang-seling?

    Tidak. File dibaca di browser Anda dan disisipkan selang-seling oleh build WebAssembly cpdf yang berjalan di worker latar belakang di perangkat Anda, dan file alternated-mixed.pdf yang sudah jadi disimpan langsung dari browser.
