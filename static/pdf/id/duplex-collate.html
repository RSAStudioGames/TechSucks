Susun Ulang Pindaian Dupleks

Susun ulang PDF yang dipindai dalam dua blok (semua halaman depan, lalu semua halaman belakang) menjadi urutan depan/belakang yang benar.

Klik untuk memilih file atau seret dan jatuhkan

File Anda tidak pernah meninggalkan perangkat Anda.

Total halaman: 0

Jika diaktifkan, hasilnya berupa ZIP berisi satu PDF untuk setiap dokumen yang dikelompokkan.

Pertanyaan yang Sering Diajukan

Pindaian jenis apa yang cocok untuk alat ini?

PDF yang dihasilkan dengan memasukkan tumpukan ke pemindai satu sisi dua kali, sekali untuk bagian depan dan sekali untuk bagian belakang, yang menghasilkan satu file dengan semua halaman depan lebih dulu dan semua halaman belakang sesudahnya. Alat ini menyisipkan kedua blok dengan urutan depan 1, belakang 1, depan 2, belakang 2. Jika bagian depan dan belakang berada di dua PDF terpisah, gunakan Selang-seling & Campur Halaman.

Bagaimana saya tahu di mana harus mengatur titik pembagian?

Titik pembagian adalah halaman terakhir blok depan, yang untuk pindaian dua kali normal tepat setengah dari total. Klik Deteksi otomatis pembagian (setengah) untuk mengisinya, lalu baca ringkasan pratinjau, yang menunjukkan ukuran setiap blok dan jumlah halaman hasil sebelum Anda memprosesnya.

Apa fungsi opsi ekspor berkelompok?

Jika tumpukan berisi beberapa dokumen pendek, seperti formulir dua halaman, masukkan jumlah halaman per dokumen dan hasil terkolasi dipotong menjadi bagian dengan panjang tersebut. Beberapa bagian diunduh sebagai ZIP dengan satu PDF per dokumen; satu bagian diunduh sebagai PDF biasa.

Nama file apa yang diberikan pada PDF terkolasi?

Satu file terkolasi diunduh dengan nama asli Anda ditambah _collated, misalnya scan_collated.pdf. Hasil berkelompok berupa ZIP bernama scan_collated_grouped.zip yang berisi PDF terpisah.

Bisakah saya melihat pratinjau hasil sebelum mengunduh?

Halaman menampilkan satu baris ringkasan saat Anda mengubah titik pembagian dan urutan belakang, termasuk ukuran blok depan dan belakang serta jumlah halaman hasil, dan memberi peringatan jika blok tidak sama panjang. Tidak ada pratinjau thumbnail, jadi periksa beberapa halaman pertama dari file unduhan dan ubah urutan blok belakang jika bagian belakangnya terbalik.

Apakah bookmark dari PDF hasil pindai dipertahankan?

Hasil disusun ulang halaman demi halaman, jadi isi halaman dan rotasi dipertahankan tetapi bookmark tingkat dokumen tidak ikut terbawa. Hasil pemindai jarang memilikinya, tetapi jika milik Anda ada, Anda bisa menambahkannya lagi dengan Edit Bookmark.

Apakah dokumen pindaian saya diunggah untuk diurutkan ulang?

Tidak. PDF dibuka di browser Anda, halaman disalin ke dokumen baru di perangkat Anda, dan hasilnya diunduh langsung, sehingga pindaian formulir dan catatan tidak pernah meninggalkan komputer Anda.
