Pertanyaan yang Sering Diajukan

Server stempel waktu mana yang dapat saya gunakan?

Menu menawarkan lima otoritas RFC 3161 publik: DigiCert, Sectigo, SSL.com, FreeTSA, dan MeSign. Tidak ada kolom untuk URL kustom, jadi pilihan terbatas pada preset tersebut.

Apakah stempel waktu berfungsi secara offline?

Tidak. Alat ini harus menghubungi TSA yang dipilih melalui internet untuk mendapatkan token stempel waktu bertanda tangan; semua yang lain, termasuk hashing file dan penyematan token, terjadi di browser Anda. Jika permintaan gagal, Anda dapat memilih server lain dan mencoba lagi.

Apa perbedaan antara stempel waktu dan tanda tangan digital?

Tanda tangan digital membuktikan siapa yang menandatangani dokumen dan memerlukan sertifikat Anda sendiri, sedangkan stempel waktu dokumen hanya membuktikan kapan dokumen itu ada, dijamin oleh TSA. Jika Anda memerlukan keduanya, tandatangani dulu dengan Tanda Tangan Digital PDF lalu tambahkan stempel waktu di sini.

Bisakah saya memberi stempel waktu pada PDF yang sudah ditandatangani?

Stempel waktu ditambahkan sebagai pembaruan inkremental, bukan penulisan ulang file, sehingga tanda tangan yang ada tetap utuh dan dapat diverifikasi, dan stempel waktu tampil sebagai entri tersendiri di panel tanda tangan pembaca.

Apakah sesuatu akan muncul di halaman?

Tidak. Stempel waktu tidak terlihat; ia berada di data tanda tangan file dan muncul di panel tanda tangan Acrobat dan pembaca serupa, bukan sebagai stempel di halaman. File yang diunduh mempertahankan nama aslinya.

Mengapa saya mendapat kesalahan Stempel Waktu Gagal?

Paling sering TSA tidak merespons atau koneksi Anda terputus, jadi coba server lain dari daftar. Pada salinan BentoPDF yang di-host sendiri melalui HTTPS, server yang hanya menawarkan endpoint HTTP memerlukan proxy CORS yang dikonfigurasi saat build; FreeTSA menggunakan HTTPS dan berfungsi tanpanya.

Berapa lama stempel waktu tetap valid?

Pembaca memvalidasi token terhadap rantai sertifikat TSA, sehingga token terverifikasi selama rantai itu dipercaya. Alat ini tidak menyematkan data validasi jangka panjang (LTV), jadi verifikasi bertahun-tahun kemudian bergantung pada kemampuan pembaca memeriksa sertifikat TSA.

Bagaimana cara memeriksa stempel waktu setelah mengunduh?

Buka panel tanda tangan di Adobe Acrobat Reader atau penampil lain yang mendukung tanda tangan; stempel waktu tercantum di sana beserta waktu dan otoritas yang menerbitkannya. Jika pembaca memercayai rantai sertifikat TSA, stempel waktu dilaporkan valid.
