Pertanyaan yang Sering Diajukan

Apa sebenarnya yang dilakukan PDF ke ZIP pada file saya?

Tidak ada selain pengemasan. PDF disalin ke satu pdfs_archive.zip dengan nama aslinya, tidak berubah, sesuai urutan Anda menambahkannya, sehingga yang keluar dari ZIP sama persis byte demi byte dengan yang masuk.

Apakah membuat ZIP memperkecil PDF?

Tidak. Arsip ditulis tanpa kompresi, karena isi PDF sudah terkompresi secara internal dan hampir tidak akan menyusut, jadi perkirakan ZIP berukuran sekitar gabungan ukuran file. Untuk memperkecil ukuran, proses dulu lewat Kompres PDF lalu zip hasilnya.

Apa bedanya mengompres PDF menjadi ZIP dan menggabungkannya?

ZIP menyimpan setiap PDF sebagai file terpisah di dalam satu wadah yang dibuka oleh penerima. Menggabungkan menyatukan halaman menjadi satu dokumen PDF, yang Anda inginkan jika file harus dibaca sebagai satu dokumen; gunakan Gabung PDF untuk itu.

Bagaimana jika dua file saya punya nama yang sama?

Nama ganda ditangani otomatis: file kedua menjadi name (1).pdf, ketiga name (2).pdf, dan seterusnya, sehingga tidak ada yang tertimpa di dalam arsip. Ganti nama file sebelum mengunggah jika Anda ingin nama yang bermakna.

Bisakah saya menambahkan file non-PDF ke arsip?

Tidak. Hanya file berekstensi .pdf atau bertipe file PDF yang diterima; yang lain diabaikan. Untuk paket campuran, gunakan fitur zip bawaan sistem operasi Anda.

Apakah penerima memerlukan perangkat lunak khusus untuk membuka arsip?

Tidak. Hasilnya adalah file ZIP standar yang dibuka Windows, macOS, iOS, dan Android tanpa perangkat lunak tambahan; klik dua kali atau ketuk untuk mengekstrak PDF.

Apakah PDF saya diunggah untuk membuat ZIP?

Tidak. Arsip disusun di browser Anda, sehingga file dibaca dari disk Anda dan ZIP ditulis kembali ke sana tanpa transfer jaringan. Menggabungkan faktur, kontrak, atau rekam medis dengan cara ini menjaganya tetap di perangkat Anda.
