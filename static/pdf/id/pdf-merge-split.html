Mengapa Memakai Alat Gabung & Pisah PDF BentoPDF?

Privasi 100% Utama

Semua proses terjadi di browser Anda. File Anda tidak pernah meninggalkan perangkat dan tidak pernah diunggah ke server. Privasi lengkap terjamin.

Tanpa Batas & Gratis

Gunakan semua alat sebanyak yang Anda mau, dengan file berukuran berapa pun. Tanpa batas file, tanpa batas alat. Sepenuhnya gratis selamanya.

Sangat Cepat

Pemrosesan berbasis browser berarti hasil instan. Tidak perlu menunggu unggahan atau unduhan. Berfungsi offline setelah halaman dimuat.

Tanpa Pendaftaran

Langsung pakai alat. Tanpa membuat akun, tanpa email, tanpa informasi pribadi. Cukup buka dan gunakan.

Pertanyaan yang Sering Diajukan

Bagaimana cara menggabungkan beberapa PDF menjadi satu file?

Tambahkan dua file atau lebih ke Gabung PDF dan seret sesuai urutan yang Anda inginkan. Mode File menggabungkan dokumen utuh, dengan rentang halaman opsional per file seperti 1-3, 5, sedangkan Mode Halaman menampilkan setiap halaman sebagai thumbnail agar Anda bisa menyusun urutan yang tepat. Tidak ada batas jumlah file atau total halaman, dan halaman disalin tanpa dikodekan ulang, sehingga kualitas tidak berubah.

Apa saja cara memisahkan PDF?

Pisah PDF punya enam mode: rentang halaman, pilihan visual dari thumbnail, hanya halaman genap atau ganjil, satu file per halaman, pemisahan di batas bookmark dengan pilihan tingkat bookmark, dan potongan tetap setiap N halaman. Satu rentang diunduh sebagai satu PDF, sedangkan beberapa rentang atau keluaran per halaman tiba sebagai ZIP. Mode bookmark memerlukan PDF yang benar-benar berisi bookmark.

Apa bedanya Pisah, Ekstrak Halaman, dan Hapus Halaman?

Ekstrak Halaman hanya mempertahankan halaman yang Anda daftar dan menyimpannya sebagai file baru, Hapus Halaman menghapus halaman yang Anda daftar dan mempertahankan sisanya, dan Pisah memecah satu dokumen menjadi beberapa file. Ekstrak dan Hapus saling berkebalikan, jadi pilih yang memerlukan daftar nomor halaman lebih pendek.

Bisakah saya menyusun ulang halaman atau menggandakan halaman?

Atur PDF menampilkan setiap halaman sebagai thumbnail yang bisa diseret dengan tombol duplikat dan hapus di masing-masing. Anda juga bisa mengetik urutan halaman lengkap seperti 3, 1, 2, 4 untuk menyusun ulang semuanya sekaligus, dan Balik Halaman membalik seluruh dokumen, atau sekumpulan dokumen, dengan satu klik.

Pemindai saya menaruh semua halaman depan dulu dan semua halaman belakang sesudahnya. Bagaimana memperbaiki urutannya?

Duplex Collate menangani hal itu: menyisipkan kedua blok dengan urutan depan 1, belakang 1, depan 2, belakang 2, dengan opsi membalik blok belakang untuk tumpukan yang dibalik sebelum pemindaian kedua. Jika bagian depan dan belakang ada di dua file terpisah, Gabung Bergantian menyisipkan halaman dari beberapa PDF dengan cara yang sama.

Bagaimana cara mencetak PDF sebagai booklet lipat?

Booklet PDF menyusun ulang halaman ke dalam imposisi saddle-stitch dan menampilkan pratinjau setiap lembar sebelum Anda mengunduh. Cetak hasilnya bolak-balik dengan "balik di sisi pendek", lipat tumpukan menjadi dua, dan staples di punggung; jika jumlah halaman bukan kelipatan empat, halaman kosong ditambahkan otomatis untuk mengisi lembar terakhir.

Bisakah saya melihat apa yang berubah antara dua versi PDF?

Bandingkan PDF memasangkan halaman dua dokumen dan menyorot perbedaan pada teks, gambar, anotasi, header dan footer, serta format, dalam tampilan berdampingan atau tumpang tindih. Filter memungkinkan Anda menyembunyikan jenis perubahan yang tidak penting, OCR bisa diaktifkan untuk dokumen hasil pindaian, dan perbandingan bisa diekspor sebagai laporan PDF.

Apakah file saya diunggah saat saya menggabungkan atau memisahkannya?

Tidak. Menggabungkan, memisahkan, dan menyusun ulang berjalan sebagai WebAssembly di dalam browser Anda, sehingga file dibaca dari disk Anda dan hasilnya ditulis kembali ke sana tanpa melewati server. Ini berlaku juga untuk pindaian besar dan kumpulan banyak file.
