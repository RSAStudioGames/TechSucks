Pertanyaan yang Sering Diajukan

Apa isi JSON-nya?

Struktur objek lengkap PDF seperti yang dibaca cpdf: trailer, katalog, pohon halaman, setiap dictionary, dan content stream tiap halaman yang diurai menjadi daftar operator gambar dan teks. Ini adalah dump lengkap file, bukan ringkasan.

Apakah ini alat yang tepat untuk mengambil teks dari PDF sebagai JSON?

Biasanya tidak. Teks di sini tersebar di operator content stream sesuai urutan penggambarannya, dengan font dan posisi tetapi tanpa paragraf. Untuk teks halaman yang mudah dibaca dalam format terstruktur gunakan Siapkan PDF untuk AI, dan untuk teks biasa gunakan PDF ke Teks.

Bisakah saya mengubah JSON kembali menjadi PDF?

Tidak dengan BentoPDF. Keluarannya mengikuti format JSON cpdf sendiri, yang bisa dibaca kembali menjadi PDF oleh alat baris perintah cpdf, tetapi alat di browser ini hanya berjalan satu arah.

Mengapa JSON jauh lebih besar daripada PDF?

Content stream dikembangkan menjadi array operator, data stream biner seperti gambar dikodekan sebagai teks, dan setiap objek ditulis lengkap dengan kuncinya, sehingga file JSON beberapa kali lipat ukuran sumbernya adalah hal wajar. PDF besar atau banyak gambar menghasilkan file yang sangat besar.

Bisakah saya mengonversi beberapa PDF ke JSON sekaligus?

Pilih sebanyak yang Anda mau; masing-masing dikonversi di worker latar belakang dan hasilnya dikemas ke pdfs-to-json.zip dengan satu .json per PDF, bernama sesuai file sumber. Satu PDF pun tiba sebagai ZIP.

Apakah berfungsi pada PDF terenkripsi?

Anda diminta kata sandi sebelum konversi dimulai dan salinan yang sudah didekripsi diserialisasi. Tanpa kata sandi, struktur objek tidak bisa dibaca.

Apa gunanya?

Memeriksa bagian dalam PDF saat men-debug generator, memeriksa isi content stream sebuah halaman, membandingkan dua versi secara struktural, atau memasukkan pohon objek ke skrip. Untuk properti dokumen saja, Lihat Metadata lebih cepat.

Apakah PDF diunggah untuk menghasilkan JSON?

Tidak. cpdf berjalan sebagai WebAssembly di web worker di browser Anda, dan JSON ditulis serta di-zip di perangkat Anda sebelum diunduh.
