Pertanyaan yang Sering Diajukan

Bisakah Buka Kunci PDF menghapus kata sandi yang tidak saya ketahui?

Tidak. Alat ini memerlukan kata sandi saat ini dan tidak membobol, menebak, atau melakukan brute force apa pun. Jika PDF terbuka tanpa kata sandi tetapi memblokir pencetakan atau penyalinan, gunakan Hapus Pembatasan sebagai gantinya.

Apakah berfungsi dengan kata sandi pemilik atau hanya kata sandi buka?

Keduanya bisa. Masukkan kata sandi mana pun yang Anda miliki; alat ini mengautentikasi dengannya dan menyimpan salinan dengan enkripsi dihapus sepenuhnya, sehingga tidak ada pembatasan yang tersisa.

Bisakah saya menghapus kata sandi dari beberapa PDF sekaligus?

Bisa, selama kata sandinya sama. Unggah semuanya, masukkan kata sandi sekali, dan Anda mendapatkan decrypted-pdfs.zip berisi file dengan nama aslinya. PDF dengan kata sandi berbeda memerlukan kelompok terpisah; file yang gagal dihitung di ringkasan sementara sisanya tetap diunduh.

Mengapa saya mendapat kesalahan kata sandi?

Kata sandi tidak cocok dengan file. Periksa caps lock dan spasi di akhir, dan pastikan Anda memakai kata sandi file ini, bukan dari dokumen serupa. File yang rusak menampilkan pesan Dekripsi Gagal; Perbaiki PDF mungkin dapat membantu di sana.

Apakah menghapus kata sandi akan mengubah dokumen?

Tidak. Halaman, teks, gambar, formulir, dan bookmark dipertahankan; hanya lapisan enkripsi yang dihapus, dan file tetap memakai namanya. Hasilnya tidak memiliki keamanan sama sekali, jadi lindungi kembali dengan Lindungi PDF jika memerlukan kata sandi baru.

Mengapa saya ingin menghapus kata sandi dari PDF saya sendiri?

Alasan umum: sistem manajemen dokumen yang menolak file terenkripsi, penggabungan dengan PDF lain (banyak alat penggabung tidak dapat membaca input terenkripsi), pengarsipan jangka panjang, atau kata sandi yang tidak lagi diperlukan.

Apakah kata sandi atau file saya dikirim ke suatu tempat?

Tidak. Dekripsi berjalan di browser Anda dengan mesin PDF WebAssembly (CoherentPDF, dengan PyMuPDF sebagai cadangan), sehingga file dan kata sandi tetap berada di perangkat Anda.

Apakah ini alat yang dulu bernama Dekripsi PDF?

Ya. Dekripsi PDF telah diganti namanya menjadi Buka Kunci PDF; ini alat yang sama dengan perilaku yang sama.
