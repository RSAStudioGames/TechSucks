Поширені запитання

Чи можна додати поля для заповнення до наявного PDF?

Завантажте PDF, і його сторінки з'являться в редакторі; виберіть тип поля на панелі інструментів і клацніть на сторінці, щоб розмістити його, а потім перетягніть або змініть розмір за потреби. Якщо в PDF уже є поля форм, їх буде виявлено й завантажено, тож їх можна переміщати, редагувати чи видаляти разом з новими.

Чи можна створити форму з нуля без наявного PDF?

Натисніть «Створити порожній PDF» і виберіть Letter, A4, A5, Legal, Tabloid, A3 або власні розміри в пунктах. Для багатосторінкових форм скористайтеся «Додати сторінку».

Які типи полів доступні?

Текст (однорядковий, багаторядковий або розбитий на гребінчасті поля), прапорець, групи радіокнопок, випадний список, список вибору, кнопка, підпис, дата, зображення та штрихкод. Кожне поле має панель властивостей для назви, значення за замовчуванням, розміру шрифту, кольору тексту, вирівнювання, підказки та прапорців обов'язковості чи лише читання. Поля підпису є стандартними полями підпису AcroForm, які відображаються лише в програмах перегляду з підтримкою підписання.

Як групуються радіокнопки, щоб можна було вибрати лише одну?

Кожне поле радіокнопки має назву групи, за замовчуванням RadioGroup1. Поля зі спільною назвою групи стають одним набором, де можна вибрати лише одне, тож дайте кожному запитанню власну назву групи й задайте різне експортоване значення для кожного варіанта.

Чи може кнопка показувати чи ховати інше поле або скидати форму?

Дії кнопок включають «Скинути форму», «Друкувати форму», «Відкрити URL», «Запустити JavaScript» і «Показати/сховати поле», що націлюється на інше поле й може показати, сховати чи перемкнути його. Вони зберігаються як стандартні дії PDF, тож працюють в Acrobat та інших програмах перегляду з підтримкою скриптів форм.

Як працює поле дати?

Це текстове поле із прикріпленим форматом дати, за замовчуванням мм/дд/рррр або власний шаблон, наприклад дд/мм/рррр. Програми перегляду з підтримкою JavaScript AcroForm перевіряють введене значення й форматують його; простіші програми сприймають його як звичайний текст.

Чи є штрихкоди та зображення справжніми полями форми?

Штрихкод (QR Code, Code 128, Code 39, EAN-13, UPC-A, DataMatrix або PDF417) генерується із введеного вами значення й малюється на сторінці як фіксоване зображення, тож той, хто заповнює форму, не може його змінити. Поле зображення є кнопкою, що дає користувачу змогу вибрати картинку зі свого комп'ютера, і працює в Acrobat та інших програмах перегляду з підтримкою імпорту зображень.

Чи зберігається форма або завантажений PDF на сервері?

Ні. Редактор працює у вашому браузері, поля записуються в PDF через pdf-lib на вашому пристрої, а «Завантажити PDF-форму» зберігає результат локально під оригінальною назвою файлу. Перевірити результат можна в Заповненні PDF-форм.
