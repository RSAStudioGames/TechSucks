Поширені запитання

Що саме «PDF у ZIP» робить з моїми файлами?

Нічого, крім пакування. PDF копіюються в один pdfs_archive.zip зі своїми початковими назвами, без змін, у порядку додавання, тож те, що виходить із ZIP, байт у байт збігається з тим, що туди потрапило.

Чи робить архівування PDF менш обсяжними?

Ні. Архів записується без стиснення, бо вміст PDF уже стиснутий усередині й майже не зменшився б, тож очікуйте, що ZIP матиме приблизно сумарний розмір файлів. Щоб зменшити розмір, спершу пропустіть їх через Стиснення PDF і заархівуйте результати.

Яка різниця між архівуванням PDF у ZIP та їх об'єднанням?

ZIP зберігає кожен PDF як окремий файл в одному контейнері, який отримувач розпаковує. Об'єднання з'єднує сторінки в один документ PDF, що потрібно, коли файли слід читати як єдиний документ; для цього скористайтеся Об'єднанням PDF.

Що, якщо два мої файли мають однакову назву?

Дублікати назв обробляються автоматично: другий файл стає name (1).pdf, третій name (2).pdf тощо, тож нічого не перезаписується всередині архіву. Перейменуйте файли перед завантаженням, якщо хочете осмислені назви.

Чи можна додавати до архіву файли, які не є PDF?

Ні. Приймаються лише файли з розширенням .pdf або типом файлу PDF; усе інше, що ви кидаєте, ігнорується. Для змішаного набору скористайтеся вбудованою функцією архівування вашої операційної системи.

Чи потрібне отримувачу спеціальне програмне забезпечення для відкриття архіву?

Ні. Результат це стандартний файл ZIP, який Windows, macOS, iOS та Android відкривають без додаткового програмного забезпечення; двічі клацніть або торкніться його, щоб розпакувати PDF.

Чи завантажуються мої PDF для створення ZIP?

Ні. Архів збирається у вашому браузері, тож файли читаються з вашого диска, а ZIP записується назад на нього без жодної передачі через мережу. Пакування рахунків, договорів чи медичних записів таким способом залишає їх на вашому пристрої.
