Поширені запитання

Наскільки добре PDF у Markdown зберігає структуру документа?

Заголовки, абзаци, списки та базове форматування жирним і курсивом конвертуються, а кожна сторінка відокремлюється в результаті горизонтальною лінією (---). Рівні заголовків визначаються за розмірами шрифтів, тож документ із неузгодженим стилем може мати деякі заголовки на неправильному рівні.

Що робить параметр «Включити зображення»?

Якщо позначено, зображення з PDF вбудовуються прямо в Markdown як дані base64, тож єдиний файл .md самодостатній, але може стати великим. Для документів, насичених текстом, залишайте вимкненим, щоб результат був малим і читабельним у простому редакторі.

Чому Markdown порожній або майже порожній?

Конвертер читає текстовий шар PDF, тож відсканований документ, що складається лише із зображень, не має чого конвертувати. Спершу пропустіть його через OCR PDF, щоб додати текстовий шар, а потім конвертуйте результат.

Як він обробляє багатоколонкові макети, виноски та бічні панелі?

Складні макети це слабке місце: багатоколонковий текст може перемішатися, а бічні панелі чи виноски можуть опинитися не на своєму місці. Для сторінок у стилі журналу очікуйте перевірки й доопрацювання результату, а одноколонкові документи потребують мало правок.

Чи можна конвертувати кілька PDF у Markdown одночасно?

Завантажте кілька PDF і натисніть «Конвертувати» один раз. Один файл завантажується як filename.md; кілька повертаються як markdown-files.zip з одним .md на PDF, а дублікати назв отримують нумерований суфікс.

Це те саме, що PDF у текст?

Ні. PDF у текст дає сирий текст без структури, що краще для передачі у скрипти. PDF у Markdown зберігає заголовки, списки та виділення, тож результат готовий для вставлення в Obsidian, вікі чи генератор статичних сайтів.

Чи можна конвертувати PDF, захищений паролем?

Якщо для відкриття файлу потрібен пароль, його буде запитано до початку конвертації, і текст видобувається як зазвичай. Пароль ніде не зберігається, а результат Markdown не має власного захисту.

Чи завантажується мій PDF для конвертації в Markdown?

Ні. Конвертація виконується рушієм PyMuPDF, завантаженим у ваш браузер як WebAssembly, а файл .md або ZIP створюється на вашій машині. Наукові статті, договори та внутрішні документи залишаються приватними.
