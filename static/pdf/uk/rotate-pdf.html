Поширені запитання

Чи можна повернути лише одну сторінку, а не весь документ?

Так. Кожна сторінка показується мініатюрою з власними кнопками ліворуч і праворуч, тож одну скановану боком сторінку в файлі на 40 сторінок можна виправити окремо. Кнопки вгорі повертають усі сторінки одразу, коли весь документ повернутий не тим боком.

Як повернути сторінку на 180 градусів?

Клацніть в одному напрямку двічі. Повороти додаються кроками по 90 градусів, тож два кліки дають 180, а три кліки дають 270, як один клік в інший бік. Мініатюра оновлюється, щоб ви бачили поточний стан перед збереженням.

Чи погіршує поворот якість сторінок?

Ні. Інструмент змінює атрибут повороту кожної сторінки, нічого не рендерячи заново, тож текст залишається виділюваним, зображення зберігають роздільну здатність, а розмір файлу майже не змінюється.

Чи збережеться поворот, якщо відкрити файл в іншому застосунку або надрукувати?

Так. Поворот записується в саму сторінку PDF, і його дотримуються всі засоби перегляду та принтери, на відміну від тимчасової кнопки повороту в засобі перегляду, що скидається після закриття файлу.

Чи можна повернути на кут, відмінний від 90 градусів, наприклад щоб вирівняти нахилений скан?

Тут ні; цей інструмент працює лише кроками по 90 градусів. Для довільних кутів скористайтеся Поворотом на довільний кут, а для автоматичного вирівнювання сканів «Вирівнюванням PDF».

Чи можна повернути лише непарні або парні сторінки?

У цьому інструменті немає вибору сторінок чи поля діапазону; ви або повертаєте сторінки по одній за їхніми кнопками, або всі разом. Для вибору груп сторінок краще підійде PDF мультиінструмент.

Чи завантажується мій PDF для повороту його сторінок?

Ні. Мініатюри рендеряться вашим браузером, а повернутий файл записується локально, тож документ ніколи не залишає ваш комп'ютер. Повернутий PDF завантажується під початковою назвою файлу.

Чи зберігаються закладки після повороту?

Вміст сторінок, зображення й анотації переносяться без змін, але закладки не переносяться, бо повернутий файл будується зі скопійованих сторінок. Документ, що спирається на зміст, потребуватиме повернення закладок за допомогою інструмента Закладки.
