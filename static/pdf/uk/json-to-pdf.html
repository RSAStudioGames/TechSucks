Поширені запитання

Чи можна конвертувати за допомогою цього інструмента будь-який файл JSON у PDF?

Ні. Він лише перебудовує PDF з файлів JSON, створених інструментом BentoPDF PDF у JSON, який зберігає повну внутрішню структуру документа. Експорт JSON з API, бази даних чи файлу конфігурації завершиться помилкою.

Як натомість перетворити дані API або файл конфігурації на читабельний PDF?

Вставте або завантажте JSON як звичайний текст у Текст у PDF, який розміщує його як форматований текст на сторінках. JSON у PDF призначений лише для круговорону документів, що спочатку були PDF.

Чи збігатиметься відновлений PDF з оригіналом?

JSON, створений через PDF у JSON, фіксує об'єкти документа, тож конвертація назад відтворює сторінки, текст і зображення джерела. Конвертація назад і порівняння також швидкий спосіб переконатися, що експорт охопив усе.

Що я отримаю, коли конвертую кілька файлів JSON?

Кожна конвертація завантажується як jsons-to-pdf.zip, навіть для одного файлу. Усередині кожен PDF має назву свого вихідного JSON, тож report.json стає report.pdf.

Чи можна редагувати JSON перед конвертацією назад?

Так, поки структура залишається коректною для рушія CPDF. Програмні зміни в JSON, як-от відредаговані метадані чи текстові об'єкти, відтворюються в PDF; некоректна правка призводить до помилки конвертації.

Чому інструмент пише, що рушій CPDF недоступний?

Конвертація залежить від збірки CPDF WebAssembly. На bentopdf.com вона є, але на самостійно розгорнутій копії файли CPDF WASM потрібно налаштувати в налаштуваннях WASM, перш ніж цей інструмент запрацює.

Чи завантажується мій файл JSON на сервер?

Ні. Файли читаються у вашому браузері й перебудовуються в PDF через Web Worker, що локально запускає рушій CPDF, тож нічого не передається, а сторінка залишається чутливою під час великих конвертацій.
