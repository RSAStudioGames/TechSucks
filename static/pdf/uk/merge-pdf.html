Об’єднати кілька PDF у один файл. Закладки зберігаються.

PDF або зображення

Ваші файли не покидають ваш пристрій.

Як це працює:

  • Натисніть і перетягніть значок , щоб змінити порядок файлів.
  • У полі «Сторінки» для кожного файлу можна вказати діапазони (напр., «1-3, 5»), щоб об'єднати лише ці сторінки.
  • Залиште поле «Сторінки» порожнім, щоб включити всі сторінки цього файлу.

    Як це працює:

    • Нижче показано всі сторінки із завантажених вами PDF.
    • Просто перетягніть мініатюри окремих сторінок, щоб створити потрібний порядок для нового файлу.

    Поширені запитання

    Чи зберігає об'єднання закладки?

    Так. Об'єднання виконується рушієм CoherentPDF, який переносить закладки кожного файлу в об'єднаний документ, тож структура залишається придатною для навігації. Вміст сторінок і анотації копіюються як є.

    Чи можна об'єднати лише деякі сторінки з кожного файлу?

    Так. У режимі файлів введіть діапазон, наприклад 1-3, 5, у поле «Сторінки» біля файлу, щоб включити лише ці сторінки, або залиште порожнім для всього файлу. У режимі сторінок кожна сторінка з кожного файлу з'являється як мініатюра, яку можна перетягнути в будь-яку послідовність, зокрема чергуючи сторінки з різних документів.

    У якому порядку підуть файли?

    Порядок, показаний у списку, згори донизу. Перетягніть записи, щоб переставити їх перед об'єднанням, і скористайтеся «Додати ще файли», щоб додати документи, не втрачаючи вже налаштованого порядку.

    Чому номери сторінок в об'єднаному PDF виглядають неправильно?

    За замовчуванням об'єднаний файл використовує просту нумерацію від 1 до N. Якщо в оригіналах були мітки сторінок, як-от i, ii, iii або A-1, увімкніть «Зберегти оригінальні мітки сторінок», щоб їх зберегти, пам'ятаючи, що два файли з однаковими мітками дадуть дублікати. Щоб надрукувати видимі номери на самих сторінках, скористайтеся Нумерацією сторінок.

    Чому об'єднаний файл такий великий?

    Шрифти та зображення кожного файлу копіюються як є, тож результат приблизно дорівнює сумі розмірів вхідних файлів, а коли кілька файлів вбудовують один шрифт, кожна копія зберігається. Позначте «Видалити дубльовані шрифти», щоб звести однакові шрифти в один; для більшої економії пропустіть результат через Стиснення PDF.

    Чи можна об'єднати PDF з різними розмірами чи орієнтацією сторінок?

    Так. Сторінки зберігають власний розмір і поворот, тож альбомне креслення A3 може йти після книжкової сторінки Letter без масштабування. Для однакового розміру потім пропустіть об'єднаний файл через Вирівнювання розміру сторінок.

    Чи завантажуються PDF на сервер для об'єднання?

    Ні. Файли об'єднуються у вашому браузері модулем CoherentPDF WebAssembly, а об'єднаний PDF записується у вашу папку завантажень, тож договори й виписки ніколи не залишають ваш комп'ютер.

    Чи можна об'єднати PDF, захищені паролем?

    Якщо для відкриття файлу потрібен пароль, інструмент запитує його під час додавання файлу, а потім об'єднує розшифровані сторінки. Об'єднаний результат не має пароля; за потреби додайте його потім через Захистити PDF.
