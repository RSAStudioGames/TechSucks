Часто задаваемые вопросы

Что содержит JSON?

Полная структура объектов PDF в том виде, как её читает cpdf: трейлер, каталог, дерево страниц, каждый словарь и поток содержимого каждой страницы, разобранный в список операторов рисования и текста. Это полный дамп файла, а не краткое содержание.

Подходит ли этот инструмент, чтобы получить текст из PDF в виде JSON?

Обычно нет. Текст здесь разбросан по операторам потока содержимого в порядке отрисовки, со шрифтами и позициями, но без абзацев. Для читаемого текста страниц в структурированном формате используйте Подготовить PDF для ИИ, а для обычного текста PDF в текст.

Можно ли конвертировать JSON обратно в PDF?

В BentoPDF нет. Результат следует собственному формату JSON cpdf, который консольная утилита cpdf может прочитать обратно в PDF, но браузерный инструмент работает только в одну сторону.

Почему JSON намного больше PDF?

Потоки содержимого разворачиваются в массивы операторов, двоичные данные потоков, например изображения, кодируются как текст, а каждый объект записывается вместе со своими ключами, поэтому JSON в несколько раз больше исходника это нормально. Большие PDF или PDF с обилием изображений дают очень большие файлы.

Можно ли конвертировать несколько PDF в JSON одновременно?

Выбирайте сколько угодно: каждый файл конвертируется в фоновом потоке, а результаты упаковываются в pdfs-to-json.zip с одним .json на каждый PDF с именем исходного файла. Один PDF тоже приходит в ZIP.

Работает ли он с зашифрованными PDF?

Пароль запрашивается до начала конвертации, а сериализуется расшифрованная копия. Без пароля структуру объектов прочитать нельзя.

Для чего это полезно?

Для изучения внутреннего устройства PDF при отладке генератора, проверки содержимого потока страницы, структурного сравнения двух версий или передачи дерева объектов в скрипт. Если нужны только свойства документа, быстрее Просмотр метаданных.

Загружается ли PDF для создания JSON?

Нет. cpdf работает как WebAssembly в веб-потоке вашего браузера, а JSON записывается и архивируется на вашем устройстве до скачивания.
