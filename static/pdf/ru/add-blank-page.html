Как это работает:

  • Укажите позицию, в которую нужно вставить пустые страницы.
  • Позиция 0 вставляет страницы в начало, позиция, равная числу страниц, вставляет их в конец.
  • Размер пустых страниц будет совпадать с размером первой страницы документа.

Введите 0, чтобы вставить в начало.

Часто задаваемые вопросы

Куда будет вставлена пустая страница?

Номер позиции показывает, сколько существующих страниц стоит перед новыми пустыми. Введите 0, чтобы поместить их в самое начало, 3, чтобы вставить после страницы 3, или общее число страниц, чтобы добавить их в конец.

Какого размера пустые страницы?

Каждая пустая страница копирует ширину и высоту первой страницы документа, поэтому в документ Letter попадут пустые страницы Letter, а в документ A4 пустые страницы A4. Если в PDF смешаны разные размеры страниц, пустые страницы всё равно соответствуют странице 1, а не соседним.

Можно ли добавить сразу несколько пустых страниц?

Введите любое число от 1 и больше, и все страницы будут вставлены вместе в одну позицию. Чтобы добавить пустые страницы в несколько разных мест, запустите инструмент повторно для результата или используйте Мультиинструмент PDF для визуального расположения страниц.

Сохраняются ли закладки и свойства документа?

Содержимое страниц, изображения, текст и аннотации сохраняются без изменений. Документ пересобирается постранично, поэтому закладки (панель оглавления) и свойства, такие как название и автор, в новый файл не переносятся.

Полностью ли пуста вставленная страница?

Да. На ней нет ни текста, ни номера страницы, ни пометок, это просто белая страница того же размера, что и страница 1. Если потом нужны номера страниц, пропустите результат через Номера страниц.

Можно ли с помощью этого инструмента сделать так, чтобы каждая глава начиналась с правой страницы для двусторонней печати?

Можно, по одной позиции за раз. Вставьте пустую страницу после каждой главы, которая заканчивается на нечётной странице, скачайте файл, а затем повторите то же для нового файла со следующей главой. Результат сохраняет исходное имя файла, поэтому переименовывайте копии по ходу работы, чтобы не запутаться.

Можно ли добавить пустые страницы в PDF, защищённый паролем?

Если для открытия файла нужен пароль, инструмент запрашивает его перед чтением числа страниц. Новый файл сохраняется без пароля, поэтому при необходимости защитите его снова.

Загружается ли мой PDF для добавления страницы?

Нет. Количество страниц считывается, а новый документ собирается в вашем браузере с помощью pdf-lib, JavaScript-библиотеки для работы с PDF, и скачивание идёт прямо из памяти. Ничего не отправляется на сервер.
