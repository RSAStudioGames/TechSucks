Добавить метки страниц

Применяйте метки страниц PDF с римскими цифрами, префиксами и пользовательскими начальными значениями.

Нажмите, чтобы выбрать файл или перетащите его сюда

PDF-файл

Ваши файлы не покидают ваше устройство.

Как работают метки

  • Оставьте диапазон страниц пустым, чтобы проставить метки на всех страницах.
  • Используйте стили вроде римских цифр для вводных страниц и десятичную нумерацию для основной части.
  • Используйте префикс со стартовым значением 0, чтобы создавать метки вроде A-0, A-1, A-2.
  • Включите продолжение нумерации, если одно правило использует несмежный диапазон, например 1-9,30-40 или нечётные страницы.

Правила меток

Этот инструмент использует CoherentPDF в вашем браузере. Если CoherentPDF не настроен, вам будет предложено настроить его в параметрах WASM.

Часто задаваемые вопросы

Как пометить страницы приложения как A-1, A-2, A-3?

Добавьте правило для диапазона страниц приложения, оставьте стиль «Десятичные арабские» и введите A- в поле «Префикс метки». При начальном значении 1 по умолчанию страницы получат метки A-1, A-2, A-3, а второе правило с префиксом B- обработает следующее приложение.

Может ли нумерация страниц начинаться с 0 или с числа, отличного от 1?

В каждом правиле есть поле «Начальное значение», по умолчанию равное 1. Задайте 0 для нумерации с нуля или любое другое число, например 15, чтобы глава, извлечённая из длинной книги, сохранила исходные номера страниц.

Что делает параметр «Продолжить нумерацию в несмежных диапазонах»?

Включите его, когда одно правило охватывает несмежные страницы, например 1-9,30-40 или odd, и вы хотите, чтобы метки продолжали счёт по порядку через разрыв. Если параметр выключен, каждый отдельный блок страниц начинается заново с начального значения.

Что происходит с метками страниц, которые уже есть в PDF?

Флажок «Удалить существующие метки страниц» установлен по умолчанию, поэтому старые метки очищаются перед применением ваших правил. Снимите его, если хотите изменить метки только у некоторых страниц, а у остальных оставить прежние.

В каких форматах можно вводить диапазон страниц?

Оставьте поле пустым, чтобы охватить все страницы, или используйте формы вроде 1-4, 7, odd или 1-9,30-40. Номера страниц относятся к физическому положению в файле, а не к меткам, которые PDF уже может показывать.

Можно ли добавить метки в PDF, защищённый паролем?

Напрямую нельзя. Инструмент остановится с сообщением «Защищённый PDF», поэтому сначала снимите пароль с помощью Разблокировать PDF, а затем загрузите копию, которой пароль уже не нужен.

Почему инструмент просит настроить CoherentPDF?

Метки страниц записываются движком CoherentPDF, который обычно загружается из CDN при первом использовании инструмента. Если в собственной сборке эта загрузка по умолчанию отключена, вам предложат указать настройки WASM на копию библиотеки.

Как проверить, что метки применились?

Откройте скачанный PDF в программе, которая показывает метки страниц, например в Adobe Acrobat или во встроенной программе просмотра Firefox, и посмотрите на поле номера страницы на панели инструментов. Там будет метка, например iv или A-1, а не обычный порядковый номер страницы.
