Часто задаваемые вопросы

Можно ли конвертировать в PDF любой файл JSON с помощью этого инструмента?

Нет. Он только пересобирает PDF из файлов JSON, созданных инструментом BentoPDF PDF в JSON, который хранит полную внутреннюю структуру документа. Экспорт JSON из API, базы данных или файла конфигурации завершится ошибкой.

Как вместо этого превратить данные API или файл конфигурации в читаемый PDF?

Вставьте или загрузите JSON как обычный текст в Текст в PDF, который разместит его на страницах как форматированный текст. «JSON в PDF» нужен только для обратного преобразования документов, которые изначально были PDF.

Совпадёт ли пересобранный PDF с оригиналом?

JSON, созданный инструментом «PDF в JSON», фиксирует объекты документа, поэтому обратная конвертация воспроизводит страницы, текст и изображения оригинала. Конвертация туда и обратно с последующим сравнением это ещё и быстрый способ убедиться, что экспорт захватил всё.

Что я получу, если конвертирую несколько файлов JSON?

Любая конвертация скачивается как jsons-to-pdf.zip, даже для одного файла. Внутри каждый PDF получает имя исходного JSON, так что report.json становится report.pdf.

Можно ли отредактировать JSON перед обратной конвертацией?

Да, если структура остаётся допустимой для движка CPDF. Программные изменения JSON, такие как отредактированные метаданные или текстовые объекты, пересобираются в PDF; некорректная правка приводит к ошибке конвертации.

Почему инструмент сообщает, что движок CPDF недоступен?

Конвертация зависит от сборки CPDF WebAssembly. На bentopdf.com она включена, но для копии на своём сервере нужно настроить файлы CPDF WASM в настройках WASM, прежде чем этот инструмент заработает.

Загружается ли мой файл JSON на сервер?

Нет. Файлы читаются в вашем браузере и пересобираются в PDF веб-воркером, на котором локально работает движок CPDF, поэтому ничего не передаётся, а страница остаётся отзывчивой при больших конвертациях.
