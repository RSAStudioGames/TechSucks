Объединение PDF

Объединить несколько PDF в один файл с сохранением закладок.

Нажмите, чтобы выбрать файл или перетащите его сюда

PDF или изображения

Ваши файлы не покидают ваше устройство.

Как это работает:

  • Нажмите и перетащите значок , чтобы изменить порядок файлов.
  • В поле «Страницы» для каждого файла можно указать диапазоны (например, «1-3, 5»), чтобы объединить только эти страницы.
  • Оставьте поле «Страницы» пустым, чтобы включить все страницы этого файла.

    Как это работает:

    • Все страницы из загруженных PDF показаны ниже.
    • Просто перетащите миниатюры отдельных страниц, чтобы задать нужный порядок для нового файла.

    Часто задаваемые вопросы

    Сохраняются ли при объединении закладки?

    Да. Объединение выполняется движком CoherentPDF, который переносит закладки каждого файла в общий документ, поэтому оглавление остаётся рабочим. Содержимое страниц и аннотации копируются как есть.

    Можно ли объединить только некоторые страницы из каждого файла?

    Да. В режиме файлов введите диапазон вроде 1-3, 5 в поле «Страницы» рядом с файлом, чтобы включить только эти страницы, или оставьте поле пустым для всего файла. В режиме страниц каждая страница каждого файла показана миниатюрой, которую можно перетащить в любую последовательность, в том числе чередуя страницы разных документов.

    В каком порядке будут файлы?

    Порядок, показанный в списке, сверху вниз. Перетаскивайте записи, чтобы изменить порядок до объединения, и используйте «Добавить ещё файлы», чтобы добавить документы, не теряя уже заданный порядок.

    Почему номера страниц в объединённом PDF выглядят неправильно?

    По умолчанию в объединённом файле используется простая нумерация от 1 до N. Если в оригиналах были метки страниц вроде i, ii, iii или A-1, включите «Сохранить исходные метки страниц», учитывая, что два файла с одинаковыми метками дадут дубликаты. Чтобы напечатать видимые номера на самих страницах, используйте Номера страниц.

    Почему объединённый файл такой большой?

    Шрифты и изображения каждого файла копируются как есть, поэтому результат примерно равен суммарному размеру исходных файлов, а если в нескольких файлах встроен один и тот же шрифт, сохраняется каждая копия. Отметьте «Удалить повторяющиеся шрифты», чтобы свести одинаковые шрифты в один; для большей экономии пропустите результат через Сжатие PDF.

    Можно ли объединять PDF с разными размерами или ориентацией страниц?

    Да. Страницы сохраняют свой размер и поворот, поэтому альбомный чертёж A3 может следовать за книжной страницей Letter без масштабирования. Для единого размера потом пропустите объединённый файл через Исправление размера страниц.

    Загружаются ли PDF на сервер для объединения?

    Нет. Файлы объединяются в вашем браузере модулем CoherentPDF WebAssembly, а объединённый PDF записывается в вашу папку загрузок, поэтому договоры и выписки не покидают ваш компьютер.

    Можно ли объединять PDF, защищённые паролем?

    Если для открытия файла нужен пароль, инструмент запрашивает его при добавлении файла, а затем объединяет расшифрованные страницы. У объединённого результата пароля нет; при необходимости добавьте его позже с помощью Защиты PDF.
