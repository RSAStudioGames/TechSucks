Часто задаваемые вопросы

Можно ли добавить заполняемые поля в уже имеющийся PDF?

Загрузите PDF, и его страницы появятся в редакторе; выберите тип поля на панели инструментов и щёлкните по странице, чтобы разместить его, затем перетащите или измените размер по необходимости. Если в PDF уже есть поля формы, они обнаруживаются и загружаются, чтобы вы могли перемещать, редактировать или удалять их вместе с новыми.

Можно ли создать форму с нуля, без готового PDF?

Нажмите «Создать пустой PDF» и выберите Letter, A4, A5, Legal, Tabloid, A3 или свои размеры в пунктах. Для многостраничных форм используйте «Добавить страницу».

Какие типы полей доступны?

Текст (однострочный, многострочный или разбитый на ячейки-«гребёнку»), флажок, группы переключателей, выпадающий список, список с выбором, кнопка, подпись, дата, изображение и штрихкод. У каждого поля есть панель свойств: имя, значение по умолчанию, размер шрифта, цвет текста, выравнивание, подсказка, флаги «обязательное» и «только чтение». Поля подписи это стандартные поля подписи AcroForm, которые отображаются только в программах просмотра с поддержкой подписания.

Как группируются переключатели, чтобы можно было выбрать только один?

У каждого переключателя есть имя группы, по умолчанию RadioGroup1. Поля с одинаковым именем группы образуют один набор с взаимным исключением, поэтому задайте каждому вопросу своё имя группы и своё экспортируемое значение для каждого варианта.

Может ли кнопка показывать или скрывать другое поле или сбрасывать форму?

Действия кнопки: сбросить форму, распечатать форму, открыть URL, выполнить JavaScript и показать или скрыть поле: она нацеливается на другое поле и может показать, скрыть или переключить его. Они хранятся как стандартные действия PDF, поэтому работают в Acrobat и других программах просмотра с поддержкой скриптов форм.

Как работает поле даты?

Это текстовое поле с форматом даты: по умолчанию мм/дд/гггг или свой шаблон, например дд/мм/гггг. Программы просмотра с поддержкой JavaScript AcroForm проверяют введённое значение и форматируют его; более простые программы воспринимают его как обычный текст.

Штрихкоды и изображения это настоящие поля формы?

Штрихкод (QR-код, Code 128, Code 39, EAN-13, UPC-A, DataMatrix или PDF417) создаётся из введённого вами значения и рисуется на странице как неизменное изображение, поэтому тот, кто заполняет форму, не может его изменить. Поле изображения это кнопка, которая позволяет пользователю выбрать картинку на своём компьютере; она работает в Acrobat и других программах просмотра с поддержкой импорта изображений.

Хранится ли форма или загруженный PDF на сервере?

Нет. Редактор работает в вашем браузере, поля записываются в PDF с помощью pdf-lib на вашем устройстве, а «Скачать PDF-форму» сохраняет результат локально под исходным именем файла. Проверить результат можно в Заполнении PDF-форм.
