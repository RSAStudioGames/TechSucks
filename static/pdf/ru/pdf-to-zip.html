Часто задаваемые вопросы

Что на самом деле делает «PDF в ZIP» с моими файлами?

Ничего, кроме упаковки. PDF копируются в один pdfs_archive.zip с исходными именами, без изменений, в том порядке, в котором вы их добавили, поэтому то, что выходит из ZIP, байт в байт совпадает с тем, что в него вошло.

Делает ли упаковка в ZIP файлы PDF меньше?

Нет. Архив записывается без сжатия, поскольку содержимое PDF уже сжато внутри и почти не уменьшилось бы, поэтому ZIP будет примерно размером с суммарный объём файлов. Чтобы уменьшить размер, сначала пропустите их через Сжать PDF, а затем упакуйте результаты.

Чем упаковка PDF в ZIP отличается от их объединения?

ZIP хранит каждый PDF как отдельный файл внутри одного контейнера, который получатель распаковывает. Объединение соединяет страницы в один документ PDF, что нужно, когда файлы должны читаться как единый документ; для этого используйте Объединить PDF.

Что, если у двух моих файлов одинаковые имена?

Одинаковые имена обрабатываются автоматически: второй файл становится name (1).pdf, третий name (2).pdf и так далее, поэтому внутри архива ничего не перезаписывается. Если хотите осмысленные имена, переименуйте файлы перед загрузкой.

Можно ли добавлять в архив файлы, не являющиеся PDF?

Нет. Принимаются только файлы с расширением .pdf или типом PDF; всё остальное игнорируется. Для смешанного набора используйте встроенную функцию архивации вашей операционной системы.

Понадобится ли получателю специальное ПО, чтобы открыть архив?

Нет. Результат это стандартный файл ZIP, который Windows, macOS, iOS и Android открывают без дополнительного ПО; дважды щёлкните или коснитесь его, чтобы распаковать PDF.

Загружаются ли мои PDF для создания ZIP?

Нет. Архив собирается в вашем браузере: файлы читаются с вашего диска, а ZIP записывается обратно на него без какой-либо передачи по сети. Так счета, договоры или медицинские документы остаются на вашем устройстве.
