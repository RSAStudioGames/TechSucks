Разделение PDF

Извлечь часть страниц в новый документ PDF.

Нажмите, чтобы выбрать файл или перетащите его сюда

Один PDF-файл

Ваши файлы не покидают ваше устройство.

Как это работает:

  • Вводите номера страниц через запятую (например, 2, 8, 14).
  • Вводите диапазоны страниц через дефис (например, 5-10).
  • Сочетайте их для сложного выбора (например, 1-3, 7, 12-15).

Как это работает:

  • Извлеките все чётные (2, 4, 6...) или все нечётные (1, 3, 5...) страницы в новый PDF.

Как это работает:

  • Каждая страница PDF будет сохранена как отдельный PDF-файл.
  • Результат будет скачан в виде ZIP-файла со всеми страницами.

Как это работает:

  • Щёлкайте миниатюры страниц ниже, чтобы выбрать страницы для извлечения.
  • Выбранные страницы будут подсвечены.

Как это работает:

  • Разделите PDF по его закладкам (оглавлению).
  • Выберите уровень закладок для разделения.

Как это работает:

  • Разделите PDF на несколько файлов, каждый из которых содержит N страниц.

Результат

Несколько файлов скачиваются вместе в виде ZIP.

Часто задаваемые вопросы

Как извлечь диапазон страниц из PDF?

Выберите «Извлечь по диапазону страниц» и введите нужные страницы, например 1-5, 8, 11-13. По умолчанию выбранные страницы объединяются в один PDF; переключите вывод на «Один PDF на диапазон», и каждый диапазон через запятую станет отдельным файлом в архиве split-pages.zip.

Можно ли разделить PDF на файлы по одной странице?

Да. Выберите «Разделить все страницы на отдельные файлы», и каждая страница будет записана в свой PDF с именами page-1.pdf, page-2.pdf и так далее в архиве split-pages.zip.

Как разделить PDF каждые N страниц?

Выберите «Разделить каждые N страниц» и введите размер части. Файл из 23 страниц, разделённый по 5 страниц, даёт пять PDF, и инструмент заранее предупредит, что в последнем будет только 3 страницы. Файлы скачиваются в архиве split-n-times.zip.

Можно ли разделить PDF по главам или закладкам?

Да, если в PDF есть закладки. Выберите «Разделить по закладкам» и уровень (все или уровни от 0 до 3), и новый файл начнётся на странице каждой закладки, получатся split-1.pdf, split-2.pdf и так далее в архиве split-by-bookmarks.zip. Если на выбранном уровне закладок нет, вместо этого появится ошибка.

Как отделить нечётные и чётные страницы?

Выберите «Разделить по чётным/нечётным страницам» и укажите чётные или нечётные; соответствующие страницы извлекаются в один PDF в исходном порядке. Это обычный шаг для двусторонней печати на принтере с односторонней печатью.

Можно ли выбирать страницы визуально, а не вводить номера?

Да. «Выбрать страницы визуально» показывает миниатюру каждой страницы; щёлкните нужные, и они будут извлечены в порядке страниц. Общий вывод даёт один PDF, а отдельный вывод даёт по файлу на страницу в ZIP.

Снижает ли разделение качество страниц?

Нет. Страницы копируются с помощью QPDF без повторной отрисовки, поэтому текст, изображения, шрифты и векторная графика остаются точно такими же, как в оригинале.

Загружается ли мой PDF при разделении?

Нет. Извлечение страниц и упаковка в ZIP выполняются в вашем браузере, а готовые файлы сохраняются прямо с вашего устройства.
