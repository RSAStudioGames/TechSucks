Preguntas frecuentes

¿Qué resolución tienen las imágenes BMP?

Las páginas se renderizan a una escala fija de 2x, así que una página Carta (8,5 x 11 pulgadas) se convierte en una imagen de 1224 x 1584 píxeles, unos 144 píxeles por pulgada. Esta herramienta no tiene ajuste de DPI; para una escala ajustable usa PDF a PNG.

¿Cómo se entrega un PDF de varias páginas?

Un PDF de una página se descarga como un único .bmp con el nombre del archivo. Un PDF de varias páginas se descarga como un ZIP llamado filename_bmps.zip con page_1.bmp, page_2.bmp, y así sucesivamente, una imagen por página.

¿Por qué los archivos BMP son tan grandes?

BMP guarda los datos de píxeles sin comprimir, así que una página ocupa el mismo espacio esté en blanco o llena de detalle, y los archivos son mucho más grandes que un PNG o JPG de la misma página. Si tu software de destino acepta PNG, ese formato también es sin pérdida y ocupa mucho menos.

¿Puedo convertir varios PDF a BMP en un lote?

No, un PDF por vez; si sueltas varios archivos solo se usa el primero. Conviértelos uno tras otro, o elige antes las páginas que necesitas con Extraer páginas para que cada conversión sea pequeña.

¿La conversión conserva la transparencia o la calidad vectorial?

No. Cada página se convierte en una imagen raster plana sobre fondo blanco, y el texto pasa a ser píxeles, así que el BMP no permite búsquedas ni se puede ampliar sin que se vea borroso. Conserva el PDF original para editarlo.

¿Puedo convertir a BMP un PDF protegido con contraseña?

Sí, si conoces la contraseña: la herramienta la pide al cargar el archivo y luego renderiza las páginas con normalidad. Un archivo con contraseña desconocida no se puede abrir.

¿Mi PDF se sube para convertirlo a BMP?

No. El renderizado se hace en un canvas de tu navegador y las imágenes se empaquetan en el ZIP de forma local, así que el documento nunca sale de tu ordenador. Los PDF grandes solo tardan más porque el renderizado lo hace tu propio equipo.

¿Qué herramienta debo usar si BMP no es obligatorio?

Para una salida sin pérdida con archivos pequeños, PDF a PNG; para fotos y los archivos más pequeños, PDF a JPG; para sistemas de fax o escaneo de varias páginas, PDF a TIFF. BMP solo tiene sentido cuando una aplicación o un dispositivo antiguo lo exige.
