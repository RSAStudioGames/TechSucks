Preguntas frecuentes

¿Puedo convertir cualquier archivo JSON en un PDF con esta herramienta?

No. Solo reconstruye PDF a partir de archivos JSON creados con la herramienta PDF a JSON de BentoPDF, que guarda la estructura interna completa del documento. Un JSON exportado de una API, una base de datos o un archivo de configuración fallará con un error.

¿Cómo convierto en su lugar datos de una API o un archivo de configuración en un PDF legible?

Pega o sube el JSON como texto plano en Texto a PDF, que lo organiza como texto con formato en las páginas. JSON a PDF solo sirve para el ida y vuelta de documentos que empezaron siendo PDF.

¿El PDF reconstruido coincidirá con el original?

El JSON que produce PDF a JSON captura los objetos del documento, así que al volver a convertirlo se reproducen las páginas, el texto y las imágenes del original. Volver a convertir y comparar también es una forma rápida de confirmar que una exportación lo capturó todo.

¿Cuál es el resultado cuando convierto varios archivos JSON?

Cada conversión se descarga como jsons-to-pdf.zip, incluso con un solo archivo. Dentro, cada PDF lleva el nombre de su JSON de origen, así que report.json se convierte en report.pdf.

¿Puedo editar el JSON antes de volver a convertirlo?

Sí, siempre que la estructura siga siendo válida para el motor CPDF. Los cambios programáticos en el JSON, como metadatos o objetos de texto editados, se reconstruyen en el PDF; una edición mal formada produce un error de conversión.

¿Por qué la herramienta dice que el motor CPDF no está disponible?

La conversión depende de la compilación WebAssembly de CPDF. En bentopdf.com viene incluida, pero una copia autoalojada necesita los archivos WASM de CPDF configurados en los ajustes de WASM antes de que esta herramienta funcione.

¿Mi archivo JSON se sube a un servidor?

No. Los archivos se leen en tu navegador y un Web Worker que ejecuta el motor CPDF localmente los reconstruye como PDF, así que no se transmite nada y la página sigue respondiendo durante las conversiones grandes.
