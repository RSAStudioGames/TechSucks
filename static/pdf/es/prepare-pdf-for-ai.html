Formato de salida:

Cada PDF se extraerá como un archivo JSON que contiene una matriz de objetos Document de LlamaIndex con:

  • text - Contenido de texto extraído por página
  • metadata - Número de página, encabezados e información del documento
  • extra_info - Contexto adicional para sistemas RAG

Preguntas frecuentes

¿Qué contiene la salida JSON?

Sigue el esquema de documentos de LlamaIndex: un documento por página con el texto de esa página y campos de metadatos. Lo genera la integración de LlamaIndex de PyMuPDF, así que puede cargarse directamente en LlamaIndex o en cualquier sistema que acepte texto por página con metadatos.

¿En qué se diferencia de PDF a texto o PDF a Markdown?

PDF a texto da un único flujo de texto plano, y PDF a Markdown conserva los encabezados y la estructura para leer. Esta herramienta divide el contenido página por página y lo envuelve en un JSON estructurado con metadatos, que es lo que necesitan los sistemas de recuperación para fragmentar y citar fuentes.

¿Funciona con PDF escaneados?

Solo si ya tienen una capa de texto. Las imágenes escaneadas generan una salida vacía o casi vacía, así que pásalas primero por OCR de PDF y luego extrae.

¿Puedo procesar un lote completo de PDF?

Sí. Sube varios archivos y obtendrás pdf-for-ai.zip con un yourfile_llm.json por cada PDF; un solo archivo se descarga directamente como yourfile_llm.json. Si falla un archivo del lote, el resto se completa igualmente y el resumen te indica cuántos fallaron.

¿Puedo elegir qué páginas extraer o controlar el tamaño de los fragmentos?

No. No hay opciones; cada página se extrae con todo su texto y metadatos. Haz la fragmentación en tu propio flujo, donde puedes elegir tamaños que encajen con tu modelo de embeddings, y descarta allí las páginas que no necesites.

¿Puedo preparar para herramientas de IA un PDF protegido con contraseña?

Sí. Si un archivo está cifrado, se te pide su contraseña antes de empezar la extracción, y el texto se obtiene de la copia descifrada.

¿Mi documento se envía a un servicio de IA?

No. A pesar del nombre, no se envía nada a ningún proveedor de IA ni a ningún servidor; la extracción se ejecuta con PyMuPDF compilado a WebAssembly dentro de tu navegador. Tú decides después adónde va el JSON.

¿Qué puedo hacer con el archivo JSON?

Úsalo en un sistema RAG, crea una base de conocimiento para un chatbot, ejecuta análisis con LLM sobre informes o convierte una colección de PDF en datos de entrenamiento. Como el contenido se divide por página con metadatos, las respuestas pueden remitir a la página de la que proceden.
