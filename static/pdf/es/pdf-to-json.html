Preguntas frecuentes

¿Qué contiene el JSON?

La estructura completa de objetos del PDF tal como la lee cpdf: el trailer, el catálogo, el árbol de páginas, cada diccionario y el flujo de contenido de cada página convertido en una lista de operadores de dibujo y de texto. Es un volcado completo del archivo, no un resumen.

¿Es esta la herramienta adecuada para sacar el texto de un PDF como JSON?

Normalmente no. Aquí el texto está disperso entre los operadores del flujo de contenido en el orden en que se dibujó, con fuentes y posiciones pero sin párrafos. Para obtener texto de página legible en un formato estructurado usa Preparar PDF para IA, y para texto sin formato usa PDF a texto.

¿Puedo convertir el JSON de nuevo en un PDF?

No con BentoPDF. La salida sigue el formato JSON propio de cpdf, que la herramienta de línea de comandos cpdf puede volver a leer como PDF, pero la herramienta del navegador solo funciona en una dirección.

¿Por qué el JSON es mucho más grande que el PDF?

Los flujos de contenido se expanden en arreglos de operadores, los datos binarios de los flujos, como las imágenes, se codifican como texto, y cada objeto se escribe con sus claves, así que es normal que un archivo JSON sea varias veces más grande que el origen. Los PDF grandes o con muchas imágenes producen archivos muy grandes.

¿Puedo convertir varios PDF a JSON a la vez?

Selecciona todos los que quieras; cada uno se convierte en un worker en segundo plano y los resultados se empaquetan en pdfs-to-json.zip con un .json por PDF, con el nombre del archivo de origen. Un solo PDF también llega en un ZIP.

¿Funciona con PDF cifrados?

Se te pide la contraseña antes de empezar la conversión y se serializa la copia descifrada. Sin la contraseña no se puede leer la estructura de objetos.

¿Para qué sirve?

Para inspeccionar el interior de un PDF al depurar un generador, comprobar qué contiene el flujo de contenido de una página, comparar dos versiones de forma estructural o pasar el árbol de objetos a un script. Solo para las propiedades del documento, Ver metadatos es más rápido.

¿El PDF se sube para generar el JSON?

No. cpdf se ejecuta como WebAssembly en un web worker de tu navegador, y el JSON se escribe y se comprime en ZIP en tu dispositivo antes de la descarga.
