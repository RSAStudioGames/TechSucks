Preguntas frecuentes

¿Cómo sabe qué píxeles son texto?

No lee el texto; cada página se renderiza como imagen y cada píxel oscuro (rojo, verde y azul por debajo de 120 en una escala de 0 a 255) se repinta con el color que elijas. Se detecta la tipografía negra y gris oscuro, mientras que el texto gris claro, el texto de color y las fotos no se tocan.

¿Por qué también cambiaron de color las líneas, los bordes y mi logotipo?

Como la herramienta trabaja con píxeles oscuros y no con objetos de texto, cualquier elemento oscuro, incluidas las líneas de tablas, los subrayados y las ilustraciones negras, se recolorea junto con el texto. En esta herramienta no hay forma de excluir zonas.

¿Puedo cambiar el color solo de ciertas palabras o párrafos?

No. Se aplica un solo color a todo el contenido oscuro de cada página. Para cambiar palabras o títulos concretos y dejar el resto como está, edita el texto directamente en el Editor de PDF.

¿El texto seguirá siendo seleccionable y con búsqueda?

No. El resultado se basa en imágenes: cada página se renderiza a 2x y se incrusta como PNG, así que el texto ya no se puede seleccionar, buscar ni copiar. Conserva el original si necesitas una versión editable, o ejecuta OCR de PDF sobre el resultado para volver a añadir una capa de texto.

¿Por qué el archivo pesa mucho más?

Una página de texto pesa unos pocos kilobytes como texto, pero al recolorearla se convierte en una imagen PNG de página completa, así que los documentos de varias páginas pueden crecer muchas veces. Comprimir PDF puede reducir el resultado a costa de algo de nitidez.

¿Puedo convertir el texto negro en blanco para un fondo oscuro?

Sí, funciona cualquier color, incluido el blanco, pero el fondo de la página no cambia, así que el texto blanco sobre la página blanca original desaparece. Elige un color que contraste con el fondo que ya tiene la página.

¿Se sube mi documento para cambiar el color del texto?

No. Cada página se renderiza y se recolorea en un lienzo en tu navegador, y el PDF nuevo también se ensambla allí, así que el archivo nunca sale de tu dispositivo. Un indicador de progreso muestra qué página se está procesando.

¿Por qué el texto de color o gris claro no cambia?

Solo se repintan los píxeles lo bastante oscuros para superar el umbral. Los títulos rojos, los enlaces azules, los pies de foto gris medio y los bordes suavizados más claros que el límite conservan su color original, lo que puede dejar un leve halo alrededor de las letras recoloreadas.
