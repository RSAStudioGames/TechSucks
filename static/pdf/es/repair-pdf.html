Preguntas frecuentes

¿Qué tipos de PDF dañados puede arreglar?

Reconstruye la estructura interna del archivo, lo que recupera tablas de referencias cruzadas rotas o ausentes, números de objeto y longitudes de flujo incorrectos, finales cortados por una descarga incompleta y rarezas dejadas por generadores de PDF con errores. Si los datos reales del contenido siguen en el archivo, normalmente se recuperan.

¿Qué no puede recuperar Reparar PDF?

Archivos en los que falta la mayor parte de los bytes del contenido, archivos que en realidad no son PDF a pesar de la extensión y archivos cifrados cuya contraseña no tienes. Tampoco puede regenerar datos de imagen: una imagen dañada dentro de un PDF por lo demás reparado sigue dañada.

¿Cómo funciona la reparación?

Cada archivo pasa por QPDF, que lee la estructura que pueda encontrar, reconstruye la tabla de objetos y escribe un PDF nuevo y limpio. El archivo reescrito se descarga como repaired-<nombre original>.pdf.

¿Puedo reparar un PDF protegido con contraseña?

Sí, si conoces la contraseña. Se te pide antes de iniciar la reparación, y la copia reparada se escribe sin cifrado, así que pásala de nuevo por Proteger PDF si aún necesita contraseña.

¿Puedo reparar varios PDF a la vez?

Sí. Un archivo reparado se descarga directamente, y varios se descargan juntos como repaired_pdfs.zip. Los archivos que no se pudieron reparar aparecen por nombre en un mensaje, y el resto se descarga igualmente.

La reparación falló. ¿Qué más puedo probar?

Abre el archivo en un navegador web como Chrome o Firefox, que tienen su propia lógica de recuperación, y usa la función de imprimir o guardar del navegador para escribir un PDF nuevo. Si el archivo está cifrado, quita primero la contraseña con la herramienta para quitar contraseñas y después repara el resultado.

¿Reparar cambiará el aspecto de mi PDF?

No. El contenido de las páginas, las fuentes y las imágenes se conservan tal cual; solo se reescribe la estructura del archivo que los rodea.

¿Se sube mi PDF dañado a un servidor para repararlo?

No. QPDF se ejecuta como WebAssembly dentro de tu navegador, así que el archivo roto se lee y se reescribe en tu propio dispositivo. Un archivo que no se repara aquí tampoco se copió nunca a ningún sitio.
