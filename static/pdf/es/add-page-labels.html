Cómo funcionan las etiquetas

  • Deja vacío el rango de páginas para etiquetar todas las páginas.
  • Usa estilos como números romanos para las páginas preliminares y numeración decimal para el cuerpo principal.
  • Usa un prefijo con valor inicial 0 para crear etiquetas como A-0, A-1 y A-2.
  • Activa la progresión cuando una regla use un rango discontinuo como 1-9,30-40 o páginas impares.

Preguntas frecuentes

¿Cómo etiqueto las páginas de un apéndice como A-1, A-2, A-3?

Agrega una regla para el rango de páginas del apéndice, deja “Números decimales” como estilo y escribe A- en el campo Prefijo de etiqueta. Con el valor inicial predeterminado de 1, las páginas pasan a ser A-1, A-2, A-3, y una segunda regla con el prefijo B- se encarga del siguiente apéndice.

¿La numeración de páginas puede empezar en 0 o en un número distinto de 1?

Cada regla tiene un campo Valor inicial que por defecto es 1. Ponlo en 0 para numerar desde cero, o en cualquier otro número, por ejemplo 15, para que un capítulo extraído de un libro más largo conserve sus números de página originales.

¿Qué hace “Continuar la numeración en rangos discontinuos”?

Actívala cuando una regla abarque páginas que no son contiguas, como odd o 1-9,30-40, y quieras que las etiquetas sigan contando en secuencia a través del salto. Si está desactivada, cada bloque de páginas separado vuelve a empezar desde el valor inicial.

¿Qué pasa con las etiquetas de página que el PDF ya tiene?

La casilla “Eliminar las etiquetas de página existentes” está marcada de forma predeterminada, así que las etiquetas antiguas se borran antes de aplicar tus reglas. Desmárcala si solo quieres cambiar la etiqueta de algunas páginas y conservar las existentes en el resto.

¿Qué formatos de rango de páginas puedo escribir?

Deja el campo vacío para abarcar todas las páginas, o usa formas como 1-4, 7, odd o 1-9,30-40. Los números de página se refieren a las posiciones físicas en el archivo, no a las etiquetas que el PDF ya pueda mostrar.

¿Puedo agregar etiquetas a un PDF protegido con contraseña?

No directamente. La herramienta se detiene con un mensaje de PDF protegido, así que primero quita la contraseña con Desbloquear PDF y luego sube la copia que ya no necesita una.

¿Por qué la herramienta me pide configurar CoherentPDF?

Las etiquetas de página las escribe el motor CoherentPDF, que normalmente se carga desde una CDN la primera vez que usas la herramienta. Si esa opción predeterminada se desactivó en una instalación autoalojada, se te pedirá que indiques en Ajustes de WASM una copia de la biblioteca.

¿Cómo compruebo que se aplicaron las etiquetas?

Abre el PDF descargado en un lector que muestre etiquetas de página, como Adobe Acrobat o el visor integrado de Firefox, y fíjate en el cuadro de número de página de la barra de herramientas. Muestra la etiqueta, por ejemplo iv o A-1, en lugar del simple índice de página.
