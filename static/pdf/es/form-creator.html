Preguntas frecuentes

¿Puedo agregar campos rellenables a un PDF que ya tengo?

Sube el PDF y sus páginas aparecen en el editor; elige un tipo de campo en la barra de herramientas y haz clic en la página para colocarlo, luego arrástralo o cambia su tamaño según necesites. Si el PDF ya tiene campos de formulario, se detectan y se cargan para que puedas moverlos, editarlos o eliminarlos junto con los nuevos.

¿Puedo crear un formulario desde cero sin un PDF existente?

Haz clic en Crear PDF en blanco y elige Carta, A4, A5, Legal, Tabloid, A3 o dimensiones personalizadas en puntos. Usa Agregar página para formularios de varias páginas.

¿Qué tipos de campo hay disponibles?

Texto (de una línea, de varias líneas o dividido en casillas), casilla de verificación, grupos de botones de opción, desplegable, cuadro de lista, botón de acción, firma, fecha, imagen y código de barras. Cada campo tiene un panel de propiedades para nombre, valor predeterminado, tamaño de fuente, color de texto, alineación, información sobre herramientas e indicadores de obligatorio o solo lectura. Los campos de firma son campos de firma AcroForm estándar, que solo aparecen en visores compatibles con la firma.

¿Cómo se agrupan los botones de opción para que solo se pueda seleccionar uno?

Cada campo de opción tiene un nombre de grupo, RadioGroup1 de forma predeterminada. Los campos que comparten el mismo nombre de grupo forman un conjunto mutuamente excluyente, así que da a cada pregunta su propio nombre de grupo y asigna un valor de exportación distinto a cada opción.

¿Un botón puede mostrar u ocultar otro campo, o restablecer el formulario?

Las acciones de los botones incluyen Restablecer formulario, Imprimir formulario, Abrir URL, Ejecutar JavaScript y Mostrar u ocultar campo, que apunta a otro campo y puede mostrarlo, ocultarlo o alternarlo. Se guardan como acciones PDF estándar, así que funcionan en Acrobat y en otros visores compatibles con scripts de formularios.

¿Cómo funciona el campo de fecha?

Es un campo de texto con un formato de fecha asociado, mm/dd/aaaa de forma predeterminada o un patrón personalizado como dd/mm/aaaa. Los visores compatibles con JavaScript de AcroForm validan el valor escrito y le dan formato; los visores más simples lo tratan como texto normal.

¿Los códigos de barras y las imágenes son campos de formulario reales?

Un código de barras (código QR, Code 128, Code 39, EAN-13, UPC-A, DataMatrix o PDF417) se genera a partir del valor que introduces y se dibuja en la página como una imagen fija, así que quien rellene el formulario no puede cambiarlo. El campo de imagen es un botón que permite al usuario elegir una imagen de su computadora, y funciona en Acrobat y en otros visores compatibles con la importación de imágenes.

¿El formulario o el PDF subido se almacenan en un servidor?

No. El editor se ejecuta en tu navegador, los campos se escriben en el PDF con pdf-lib en tu dispositivo, y Descargar formulario PDF guarda el resultado localmente con el nombre de archivo original. Puedes probar el resultado en Rellenar Formularios PDF.
