Agregar página en blanco

Inserta una página vacía en cualquier lugar de tu PDF.

Haz clic para seleccionar un archivo o arrastra y suelta

Un solo archivo PDF

Tus archivos nunca salen de tu dispositivo.

Cómo funciona:

  • Indica la posición donde se deben insertar las páginas en blanco.
  • La posición 0 inserta al principio; una posición igual al número de páginas inserta al final.
  • Las páginas en blanco tendrán el mismo tamaño que la primera página de tu documento.

Escribe 0 para insertar al principio.

Preguntas frecuentes

¿Dónde se insertará la página en blanco?

El número de posición indica cuántas páginas existentes van antes de las nuevas páginas en blanco. Escribe 0 para ponerlas al principio del todo, 3 para insertarlas después de la página 3, o el número total de páginas para añadirlas al final.

¿Qué tamaño tienen las páginas en blanco?

Cada página en blanco copia el ancho y el alto de la primera página de tu documento, así que un documento Carta recibe páginas en blanco tamaño Carta y uno A4 las recibe tamaño A4. Si tu PDF mezcla tamaños de página, las páginas en blanco siguen coincidiendo con la página 1 y no con las páginas contiguas.

¿Puedo agregar más de una página en blanco a la vez?

Escribe cualquier cantidad a partir de 1 y todas se insertan juntas en la misma posición. Para agregar páginas en blanco en varios puntos distintos, ejecuta la herramienta de nuevo sobre el resultado, o usa la Multiherramienta PDF para organizar las páginas de forma visual.

¿Conserva los marcadores y las propiedades del documento?

El contenido de las páginas, las imágenes, el texto y las anotaciones se conservan tal como están. El documento se reconstruye página por página, por lo que los marcadores (el panel de esquema) y propiedades como el título y el autor no se transfieren al nuevo archivo.

¿La página insertada está completamente vacía?

Sí. No tiene texto, ni número de página, ni ninguna nota impresa, solo una página blanca del mismo tamaño que la página 1. Si después quieres números de página, pasa el resultado por Números de Página.

¿Puedo usar esto para que cada capítulo empiece en una página derecha en la impresión a doble cara?

Sí, una posición por ejecución. Inserta una página en blanco después de cada capítulo que termine en página impar, descarga el resultado y repite el proceso con el nuevo archivo para el siguiente capítulo. El resultado conserva el nombre de archivo original, así que ve renombrando las copias para no mezclarlas.

¿Puedo agregar páginas en blanco a un PDF protegido con contraseña?

Si el archivo necesita una contraseña para abrirse, la herramienta la pide antes de leer el número de páginas. El nuevo archivo se guarda sin la contraseña, así que vuelve a protegerlo después si lo necesitas.

¿Se sube mi PDF para agregar la página?

No. El número de páginas se lee y el nuevo documento se ensambla en tu navegador con pdf-lib, una biblioteca PDF de JavaScript, y la descarga sale directamente de la memoria. No se envía nada a ningún servidor.
