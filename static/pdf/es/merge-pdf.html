Fusionar PDF

Combina múltiples PDFs en un solo archivo. Preserva Marcadores.

Haz clic para seleccionar un archivo o arrastra y suelta

PDFs o Imágenes

Tus archivos nunca salen de tu dispositivo.

Cómo funciona:

  • Haz clic y arrastra el icono para cambiar el orden de los archivos.
  • En el cuadro "Páginas" de cada archivo puedes especificar rangos (p. ej., "1-3, 5") para fusionar solo esas páginas.
  • Deja el cuadro "Páginas" en blanco para incluir todas las páginas de ese archivo.

    Cómo funciona:

    • Todas las páginas de tus PDF subidos se muestran abajo.
    • Simplemente arrastra y suelta las miniaturas de cada página para crear el orden exacto que quieras en tu nuevo archivo.

    Preguntas frecuentes

    ¿Fusionar conserva los marcadores?

    Sí. La fusión se hace con el motor CoherentPDF, que traslada los marcadores de cada archivo al documento combinado para que el índice siga siendo navegable. El contenido de las páginas y las anotaciones se copian tal cual.

    ¿Puedo fusionar solo algunas páginas de cada archivo?

    Sí. En el Modo archivo, escribe un rango como 1-3, 5 en el cuadro Páginas junto a un archivo para incluir solo esas páginas, o déjalo en blanco para todo el archivo. En el Modo página, todas las páginas de todos los archivos aparecen como miniaturas que puedes arrastrar a cualquier secuencia, incluso intercalando páginas de distintos documentos.

    ¿En qué orden quedarán los archivos?

    El orden que se muestra en la lista, de arriba abajo. Arrastra las entradas para reorganizarlas antes de fusionar, y usa Agregar más archivos para añadir documentos sin perder la disposición que ya tienes.

    ¿Por qué los números de página se ven mal en el PDF fusionado?

    De forma predeterminada, el archivo fusionado usa una numeración simple de 1 a N. Si los originales usaban etiquetas de página como i, ii, iii o A-1, activa Conservar etiquetas de página originales para mantenerlas, teniendo en cuenta que dos archivos con las mismas etiquetas producirán duplicados. Para imprimir números visibles en las propias páginas, usa Números de Página.

    ¿Por qué el archivo fusionado es tan grande?

    Las fuentes y las imágenes de cada archivo se copian tal cual, así que el resultado pesa aproximadamente lo mismo que la suma de los originales, y cuando varios archivos incrustan la misma fuente se conserva cada copia. Marca Eliminar fuentes duplicadas para unir las fuentes idénticas en una; para ahorrar más, pasa el resultado por Comprimir PDF.

    ¿Puedo fusionar PDF con distintos tamaños de página u orientaciones?

    Sí. Las páginas conservan su propio tamaño y rotación, así que un plano A3 horizontal puede ir después de una página Carta vertical sin escalarse. Para un tamaño uniforme después, pasa el archivo fusionado por Fijar Tamaño de Página.

    ¿Los PDF se suben a un servidor para fusionarlos?

    No. Los archivos se combinan dentro de tu navegador con el módulo WebAssembly de CoherentPDF y el PDF fusionado se escribe en tu carpeta de descargas, así que los contratos y extractos nunca salen de tu equipo.

    ¿Puedo fusionar PDF protegidos con contraseña?

    Si un archivo necesita una contraseña para abrirse, la herramienta la pide al agregar el archivo y luego fusiona las páginas descifradas. El resultado fusionado no tiene contraseña; agrégala después con Proteger PDF si hace falta.
