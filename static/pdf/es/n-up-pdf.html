N-Up PDF

Organiza múltiples páginas en una sola hoja.

Haz clic para seleccionar un archivo o arrastra y suelta

Un solo archivo PDF

Tus archivos nunca salen de tu dispositivo.

Cómo funciona:

  • Elige cuántas páginas caben en cada hoja (2, 4, 9 o 16).
  • Selecciona el tamaño y la orientación de la página de salida.
  • Si quieres, agrega márgenes y bordes alrededor de cada página.

Preguntas frecuentes

¿Cuántas páginas puedo poner en una hoja?

Elige 2-up (1x2), 4-up (2x2), 9-up (3x3) o 16-up (4x4) en el menú Páginas por hoja. Las páginas se colocan de izquierda a derecha y de arriba abajo en el orden del documento, y la última hoja tiene celdas vacías si el número de páginas no se divide de forma exacta.

¿Qué tamaño de papel y orientación tendrá el resultado?

Elige Carta, A4, Legal o A3 para la hoja de salida, y Vertical, Horizontal o Automática para la orientación. Automática usa horizontal para un diseño 2-up de páginas horizontales y vertical para todo lo demás.

¿Mis páginas se estirarán o se recortarán?

Ninguna de las dos cosas. Cada página se escala proporcionalmente para caber en su celda y se centra, así que las páginas cuya forma no coincide con la celda tienen algo de espacio en blanco alrededor en lugar de deformarse.

¿El texto se mantiene nítido después de N-up?

Las páginas originales se incrustan como contenido vectorial y no se convierten en imágenes, así que el texto y las líneas se mantienen nítidos a cualquier tamaño de impresión. En diseños densos como 16-up el texto sigue siendo diminuto en papel, lo que es un límite de legibilidad y no de calidad.

¿Puedo agregar márgenes o un borde alrededor de cada página?

Agregar márgenes deja un margen de media pulgada alrededor de la hoja y un pequeño espacio entre celdas, lo que ayuda cuando una impresora no puede imprimir hasta el borde. Agregar borde dibuja un contorno de un punto alrededor de cada página colocada, en el color que elijas.

¿Cómo imprimo 4 diapositivas de PowerPoint por página?

Exporta primero las diapositivas a PDF, o usa PowerPoint a PDF, luego sube ese PDF aquí y elige 4-up. Las diapositivas horizontales en una hoja vertical caben bien en una cuadrícula de 2x2.

¿N-up es lo mismo que imprimir un folleto?

No. N-up solo reduce las páginas a una cuadrícula en orden de lectura. Un folleto necesita páginas reordenadas y emparejadas para que se plieguen como un libro, y eso es lo que hace Folleto PDF.

¿El PDF se sube para crear el diseño N-up?

No. Las hojas nuevas se crean en tu navegador con pdf-lib y se descargan con el nombre de archivo original, así que el documento nunca sale de tu dispositivo.
