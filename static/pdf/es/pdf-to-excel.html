Preguntas frecuentes

¿Por qué PDF a Excel dice que no se encontraron tablas?

El detector busca estructura de tabla, como líneas de separación y celdas alineadas. El texto dispuesto en columnas con espacios, o una tabla que existe solo como parte de una imagen escaneada, no se reconoce. Para escaneos, ejecuta primero OCR PDF; para texto con formato poco definido, PDF a texto te da el contenido sin formato para ordenarlo a mano.

¿Cómo se organizan varias tablas en la hoja de cálculo?

Cada tabla detectada tiene su propia hoja, con nombres como Table 1 (Page 3), Table 2 (Page 5), y así sucesivamente, para que veas de qué página procede. Un PDF con una sola tabla produce una hoja llamada Table. Los nombres de hoja se cortan a 31 caracteres porque Excel no permite más.

¿Se conservan el formato, los colores y las celdas combinadas?

No. Solo se transfiere el texto de las celdas; no se reproducen fuentes, rellenos, bordes, anchos de columna ni celdas combinadas. Los números pueden llegar como celdas de texto, así que si una columna no suma, selecciónala y usa la opción Convertir en número de Excel.

¿Puedo convertir solo ciertas páginas a Excel?

No hay opciones de página; se analiza cada página y se exportan todas las tablas encontradas. Si solo necesitas una tabla, saca primero esas páginas a un PDF aparte, o usa Extraer tablas, que muestra una vista previa de cada tabla y te deja descargarlas una a una.

¿Cuál es la diferencia entre PDF a Excel, PDF a CSV y Extraer tablas?

PDF a Excel reúne todas las tablas en un único libro .xlsx con una hoja por tabla. PDF a CSV genera archivos planos separados por comas, y Extraer tablas muestra una vista previa de cada tabla y ofrece descargas por tabla en varios formatos. Elige Excel cuando quieras todo en un solo libro con referencias de página.

¿Funciona con PDF protegidos con contraseña?

Si el archivo necesita contraseña para abrirse, la herramienta la pide antes de empezar la extracción. El .xlsx resultante no está protegido con contraseña.

¿Mis datos financieros se suben durante la conversión?

No. La detección de tablas se ejecuta en un motor de PDF cargado en tu navegador como WebAssembly, y la hoja de cálculo la crea de forma local una biblioteca de JavaScript. Los extractos bancarios y las facturas nunca salen de tu equipo.
