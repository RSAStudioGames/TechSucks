Preguntas frecuentes

¿Qué ajustes dan el aspecto de escaneo más realista?

Los valores sutiles funcionan mejor: ruido de entre 10 y 20, una rotación de unos 0,5 grados con algo de Variación de rotación para que cada página se incline distinto, y un toque de desenfoque. Activa Escala de grises para un aspecto de fotocopiadora, añade Borde para el borde oscuro que deja un escáner plano y baja la Resolución a 100-150 DPI para un resultado tipo fax.

¿Qué hace la Variación de rotación?

Añade una cantidad aleatoria, hasta el valor que fijes (de 0 a 3 grados), a la rotación base de cada página, para que un documento de diez páginas no tenga diez páginas inclinadas exactamente igual. La vista previa muestra solo la rotación base; la variación se aplica al hacer clic en Aplicar.

¿Puedo seguir seleccionando o buscando el texto después?

No. Cada página se renderiza, se procesa como píxeles y se guarda como imagen JPEG, así que el resultado es solo imagen. Normalmente ese es el objetivo de un efecto de escaneo, pero conserva el original si más adelante necesitas texto editable.

¿Por qué la vista previa se ve distinta del archivo final?

La vista previa renderiza la primera página a resolución de pantalla e ignora el control de Resolución, así que el ruido y el desenfoque pueden verse algo más fuertes o más débiles en el resultado final, y no puede mostrar la variación de rotación por página. El resto de los ajustes coinciden con lo que obtendrás.

¿Cómo afecta el ajuste de Resolución al archivo?

Define los DPI a los que se renderizan las páginas antes de aplicar los efectos, de 72 a 300. Los valores bajos hacen las páginas más suaves y pixeladas, como un escáner barato, y generan archivos más pequeños; 300 DPI mantiene el texto nítido pero genera un PDF mucho más grande.

¿Puedo hacer que el papel parezca viejo o amarillento?

Sube el control Amarillento para añadir un tono cálido que imita el papel envejecido o reciclado. Combínalo con Escala de grises para un aspecto de fotocopia de una fotocopia, y baja un poco el Brillo y sube el Contraste para imitar un cartucho de tóner cansado.

¿Procesa más de un PDF a la vez?

No. Esta herramienta trabaja con un solo PDF por vez, aplicando tus ajustes a todas las páginas de ese archivo. Carga el siguiente archivo cuando termine la primera descarga.

¿Se sube mi documento para aplicar el efecto?

No. El renderizado, el ruido, el desenfoque y la rotación se aplican en un lienzo en tu navegador, y el PDF resultante se ensambla en local, así que el archivo nunca sale de tu ordenador.
