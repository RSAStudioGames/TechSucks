Preguntas frecuentes

¿El PDF es vectorial o una imagen?

Una imagen. Tu navegador renderiza cada SVG sobre un lienzo y el mapa de bits se coloca en una página PDF, así que el resultado no escala sin pérdida y el texto no se puede seleccionar. Si necesitas una salida vectorial real, exporta el PDF desde un editor vectorial como Inkscape.

¿Qué tamaño tendrá la página?

La página coincide con los atributos width y height del SVG en píxeles, un píxel por punto de PDF. Un SVG sin width ni height (solo viewBox) se renderiza a 800 por 600, así que define dimensiones explícitas en el archivo para obtener resultados predecibles.

¿Qué cambian los ajustes de calidad en la conversión de SVG?

Alta mantiene el PNG sin pérdida a tamaño completo. Media lo recodifica como JPEG con calidad del 75 por ciento y limita el lado más largo a 2500 píxeles; Baja usa 50 por ciento y 1500 píxeles, lo que también reduce la página. Para dibujos de líneas y texto, Alta evita los artefactos de JPEG.

¿Puedo controlar la resolución de salida, por ejemplo 300 DPI?

No hay ajuste de DPI; el renderizado usa las dimensiones en píxeles del propio SVG. Para obtener más píxeles, aumenta los atributos width y height en el código del SVG manteniendo el viewBox, y luego convierte.

¿Por qué mi SVG salió sin texto, fuentes o imágenes?

El SVG se renderiza a partir de su propio marcado, así que las referencias a archivos externos (imágenes enlazadas, fuentes importadas, CSS externo) no pueden cargarse en ese contexto y se sustituyen o desaparecen. Incrusta las imágenes como URI de datos y convierte el texto en trazados antes de convertir.

¿Se conserva la transparencia?

No. El lienzo se rellena de blanco antes de dibujar el SVG, así que las zonas transparentes se vuelven blancas en el PDF.

¿Puedo poner varios SVG en un solo PDF?

Sube varios archivos y se convierten en páginas consecutivas de un único from_svgs.pdf, en el orden que muestra la lista de archivos. Cada página toma el tamaño de su propio SVG.

¿Se sube el SVG para convertirlo?

No. El renderizado se hace en un lienzo en tu navegador y el PDF se construye con pdf-lib en tu dispositivo; no se envía nada a ningún sitio.
