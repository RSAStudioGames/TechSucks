Preguntas frecuentes

¿Cómo decide la herramienta el aspecto del PDF?

Analiza el XML, agrupa los elementos hermanos repetidos por nombre de etiqueta y renderiza cada grupo como una tabla con una columna por elemento hijo, usando los nombres de los elementos como encabezados. Si la raíz no tiene hijos repetidos, obtienes una tabla de dos columnas con Propiedad y Valor. La salida es A4 apaisado con el nombre del elemento raíz como título.

¿Qué tipo de XML funciona mejor?

XML de tipo datos: registros con el mismo conjunto de elementos hijo repetidos bajo un mismo padre, como exportaciones de bases de datos, líneas de factura, feeds de productos, feeds RSS o sitemaps. El XML muy anidado o de tipo documento se aplana, así que los valores anidados se unen en una sola celda y pierden su jerarquía.

¿Por qué me sale un error de XML no válido?

El archivo no está bien formado: una etiqueta sin cerrar, falta el elemento raíz, un carácter & o < sin escapar, o una codificación incorrecta. El mensaje incluye el motivo del analizador, así que corrige el archivo en un editor o validador y vuelve a intentarlo.

¿Se incluyen los atributos XML en el PDF?

En parte. En la vista de tabla solo los elementos hijo se convierten en columnas, así que los atributos de los registros repetidos no se muestran. En la vista de Propiedad y Valor de una raíz sin repetición, los atributos se listan después de los valores de los hijos.

¿Puedo convertir varios archivos XML a la vez?

Sí. Añade varios archivos y se convierten en un solo lote en xml-to-pdf.zip con un PDF por archivo. Un solo archivo se descarga directamente con el mismo nombre base y la extensión .pdf.

¿Aplica mi hoja de estilo XSLT o CSS?

No. Las instrucciones de hojas de estilo y las declaraciones DOCTYPE se eliminan antes del análisis, y el diseño se genera solo a partir de la estructura de datos. Si necesitas el renderizado con estilo, abre el XML en un navegador que aplique la hoja de estilo e imprímelo a PDF desde ahí.

¿Se mostrará texto en chino, árabe, cirílico u otras escrituras no latinas?

No de forma fiable. El PDF se crea con la fuente Helvetica estándar de jsPDF, que cubre caracteres latinos, así que el texto en otras escrituras puede aparecer con caracteres incorrectos o ausentes.

¿Se sube el archivo XML para convertirlo?

No. El análisis usa un analizador XML de JavaScript y el PDF se genera con jsPDF, ambos dentro de tu navegador, así que las facturas, los registros de transacciones y otros datos sensibles del archivo nunca salen de tu dispositivo.
