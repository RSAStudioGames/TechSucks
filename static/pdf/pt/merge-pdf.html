    Perguntas frequentes

    Mesclar mantém os marcadores?

    Sim. A mesclagem é feita com o mecanismo CoherentPDF, que leva os marcadores de cada arquivo para o documento combinado, mantendo o sumário navegável. O conteúdo das páginas e as anotações são copiados como estão.

    Posso mesclar só algumas páginas de cada arquivo?

    Sim. No Modo arquivo, digite um intervalo como 1-3, 5 na caixa Páginas ao lado de um arquivo para incluir só essas páginas, ou deixe em branco para o arquivo inteiro. No Modo página, todas as páginas de todos os arquivos aparecem como miniaturas que você pode arrastar para qualquer sequência, inclusive intercalando páginas de documentos diferentes.

    Em que ordem os arquivos ficarão?

    A ordem mostrada na lista, de cima para baixo. Arraste os itens para reorganizá-los antes de mesclar e use Adicionar mais arquivos para incluir documentos sem perder a disposição que você já tem.

    Por que os números de página parecem errados no PDF mesclado?

    Por padrão, o arquivo mesclado usa numeração simples de 1 a N. Se os originais usavam rótulos de página como i, ii, iii ou A-1, ative Manter rótulos de página originais para preservá-los, lembrando que dois arquivos com os mesmos rótulos vão gerar duplicatas. Para imprimir números visíveis nas próprias páginas, use Números de página.

    Por que o arquivo mesclado fica tão grande?

    As fontes e imagens de cada arquivo são copiadas como estão, então o resultado tem aproximadamente o tamanho combinado dos arquivos de entrada, e quando vários arquivos incorporam a mesma fonte, cada cópia é mantida. Marque Remover fontes duplicadas para unir fontes idênticas em uma só; para economizar mais, passe o resultado por Comprimir PDF.

    Posso mesclar PDFs com tamanhos ou orientações de página diferentes?

    Sim. As páginas mantêm o próprio tamanho e rotação, então um desenho A3 em paisagem pode vir depois de uma página Carta em retrato sem ser redimensionado. Para um tamanho uniforme depois, passe o arquivo mesclado por Corrigir tamanho da página.

    Os PDFs são enviados a um servidor para serem mesclados?

    Não. Os arquivos são combinados dentro do seu navegador pelo módulo WebAssembly do CoherentPDF e o PDF mesclado é gravado na sua pasta de downloads, então contratos e extratos nunca saem da sua máquina.

    Posso mesclar PDFs protegidos por senha?

    Se um arquivo precisar de senha para abrir, a ferramenta a solicita quando você adiciona o arquivo e depois mescla as páginas descriptografadas. O resultado mesclado não tem senha; adicione uma depois com Proteger PDF, se precisar.
