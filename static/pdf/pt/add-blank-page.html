  • A posição 0 insere no início, e a posição igual ao número de páginas insere no fim.

Perguntas frequentes

Onde a página em branco será inserida?

O número da posição indica quantas páginas existentes vêm antes das novas páginas em branco. Digite 0 para colocá-las no início, 3 para inseri-las depois da página 3, ou o total de páginas para adicioná-las no fim.

Qual é o tamanho das páginas em branco?

Cada página em branco copia a largura e a altura da primeira página do seu documento, então um documento Carta recebe páginas em branco Carta e um documento A4 recebe páginas A4. Se o seu PDF mistura tamanhos de página, as páginas em branco ainda seguem a página 1, e não as páginas vizinhas.

Posso adicionar mais de uma página em branco por vez?

Digite qualquer quantidade a partir de 1 e todas serão inseridas juntas na mesma posição. Para adicionar páginas em branco em vários pontos diferentes, execute a ferramenta novamente no resultado ou use a Multiferramenta PDF para organizar as páginas visualmente.

Ela mantém os favoritos e as propriedades do documento?

O conteúdo das páginas, imagens, texto e anotações são mantidos como estão. O documento é reconstruído página por página, então os favoritos (painel de estrutura de tópicos) e propriedades como título e autor não são transferidos para o novo arquivo.

A página inserida fica completamente vazia?

Sim. Ela não tem texto, número de página nem nota impressa, é só uma página branca do mesmo tamanho da página 1. Se quiser números de página nela depois, passe o resultado por Números de Página.

Posso usar isso para fazer cada capítulo começar em uma página à direita, para impressão frente e verso?

Pode, uma posição por vez. Insira uma página em branco depois de cada capítulo que termina em página ímpar, baixe e repita no novo arquivo para o próximo capítulo. A saída mantém o nome original do arquivo, então renomeie as cópias ao longo do caminho para não misturá-las.

Posso adicionar páginas em branco a um PDF protegido por senha?

Se o arquivo precisar de senha para abrir, a ferramenta a pede antes de ler a contagem de páginas. O novo arquivo é salvo sem a senha, então proteja-o novamente depois, se precisar.

Meu PDF é enviado para adicionar a página?

Não. A contagem de páginas é lida e o novo documento é montado no seu navegador com o pdf-lib, uma biblioteca JavaScript de PDF, e o download vem direto da memória. Nada é enviado a um servidor.
