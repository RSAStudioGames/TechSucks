Perguntas frequentes

Qual formato de saída devo escolher?

O CSV abre no Excel, no Google Sheets ou em qualquer importação de banco de dados. O JSON entrega uma matriz de linhas, cada uma uma matriz de textos de células, para scripts e APIs. O Markdown entrega uma tabela com barras verticais que você pode colar no GitHub, em uma wiki ou em documentação.

O que recebo quando o PDF contém várias tabelas?

Cada tabela é salva como um arquivo próprio, com nome como table_1_page3.csv, e todas são reunidas em filename_tables.zip. Uma única tabela é baixada direto como filename_table.csv, .json ou .md. Se preferir todas as tabelas em um só arquivo, use PDF para CSV.

Por que aparece que nenhuma tabela foi encontrada?

A detecção funciona na camada de texto do documento. PDFs digitalizados contêm apenas uma imagem, então passe-os antes por PDF com OCR. Texto que só parece uma tabela por causa do espaçamento, sem estrutura de tabela, também pode não ser detectado.

Uma tabela continua por várias páginas. Ela sairá em um único arquivo?

Não. Cada página é analisada separadamente, então uma tabela que se estende por várias páginas é exportada como um arquivo por página, cada um com o número da página no nome. Junte as partes em uma planilha depois da extração.

Posso extrair tabelas de apenas algumas páginas?

O documento inteiro é sempre analisado, embora o número da página em cada nome de arquivo mostre de onde veio a tabela. Para limitar a análise, salve antes as páginas de que precisa com Extrair páginas e use esta ferramenta no arquivo menor.

O CSV lida com vírgulas e quebras de linha dentro das células?

Sim. Células com vírgulas, aspas ou quebras de linha são envolvidas em aspas duplas, com as aspas internas duplicadas, para que o software de planilhas as leia corretamente. Células vazias são gravadas como campos vazios.

É possível extrair tabelas de um PDF protegido por senha?

Se o arquivo precisar de senha para abrir, ela é solicitada antes de a extração começar, e as tabelas são lidas de uma cópia descriptografada mantida na memória.

O PDF é enviado para a detecção de tabelas?

Não. O mecanismo de detecção (PyMuPDF compilado para WebAssembly) é baixado de uma CDN na primeira vez que você o usa e depois roda dentro do seu navegador. Seu PDF fica no seu dispositivo.
