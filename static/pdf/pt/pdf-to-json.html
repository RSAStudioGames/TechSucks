Perguntas frequentes

O que o JSON contém?

A estrutura completa de objetos do PDF como o cpdf a lê: o trailer, o catálogo, a árvore de páginas, cada dicionário e o fluxo de conteúdo de cada página convertido em uma lista de operadores de desenho e texto. É um despejo completo do arquivo, não um resumo.

Esta é a ferramenta certa para obter o texto de um PDF em JSON?

Geralmente não. Aqui o texto fica espalhado entre operadores do fluxo de conteúdo, na ordem em que foi desenhado, com fontes e posições, mas sem parágrafos. Para obter o texto legível das páginas em formato estruturado, use Preparar PDF para IA, e para texto simples use o PDF para Texto.

Posso converter o JSON de volta em PDF?

Não com o BentoPDF. A saída segue o formato JSON próprio do cpdf, que a ferramenta de linha de comando do cpdf consegue converter de volta em PDF, mas a ferramenta no navegador só funciona em uma direção.

Por que o JSON é muito maior que o PDF?

Os fluxos de conteúdo são expandidos em matrizes de operadores, dados binários de fluxo, como imagens, são codificados como texto e cada objeto é escrito com suas chaves, então é normal que um arquivo JSON tenha várias vezes o tamanho da origem. PDFs grandes ou com muitas imagens geram arquivos muito grandes.

Posso converter vários PDFs para JSON de uma vez?

Selecione quantos quiser; cada um é convertido em um worker em segundo plano e os resultados são empacotados em pdfs-to-json.zip com um .json por PDF, com o nome do arquivo de origem. Um único PDF também chega em um ZIP.

Funciona com PDFs criptografados?

A senha é solicitada antes de a conversão começar e a cópia descriptografada é serializada. Sem a senha, a estrutura de objetos não pode ser lida.

Para que isso serve?

Inspecionar os componentes internos de um PDF ao depurar um gerador, verificar o que há no fluxo de conteúdo de uma página, comparar duas versões estruturalmente ou alimentar um script com a árvore de objetos. Só para as propriedades do documento, Ver Metadados é mais rápido.

O PDF é enviado para gerar o JSON?

Não. O cpdf roda como WebAssembly em um web worker no seu navegador, e o JSON é gerado e compactado em ZIP no seu dispositivo antes do download.
