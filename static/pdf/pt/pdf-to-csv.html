Perguntas frequentes

Como a ferramenta encontra tabelas em um PDF?

Ele executa a detecção de tabelas do PyMuPDF em cada página, que procura as linhas de grade e o texto alinhado que formam uma tabela. Cada tabela encontrada é gravada no CSV linha por linha, e todas as páginas são analisadas de uma só vez.

O que acontece se meu PDF tiver várias tabelas?

Todas são gravadas em um único arquivo .csv na ordem das páginas, com as linhas de uma tabela logo após as da anterior e sem separador entre elas. Se você precisa de cada tabela em um arquivo ou planilha próprios, use PDF para Excel.

Por que o PDF para CSV diz que nenhuma tabela foi encontrada?

Em geral, o PDF organiza os dados com espaços e tabulações que só parecem uma tabela, sem a estrutura de que o detector precisa, ou a página é uma digitalização sem camada de texto. Para digitalizações, execute OCR de PDF primeiro para que haja texto a detectar.

Como vírgulas, aspas e quebras de linha dentro das células são tratadas?

Células que contêm vírgula, aspas duplas ou quebra de linha são envolvidas por aspas duplas, e as aspas dentro delas são duplicadas, seguindo a RFC 4180. O arquivo é salvo em UTF-8, então caracteres acentuados e alfabetos não latinos sobrevivem à passagem para uma planilha.

O CSV mantém a formatação do PDF?

Não. O CSV é texto simples, então negrito, cores, células mescladas e larguras de coluna são descartados e restam apenas os valores das células. Os números são exportados como o texto mostrado no PDF, incluindo símbolos de moeda ou separadores de milhar.

Posso extrair tabelas de um PDF protegido por senha?

A senha é solicitada depois do envio, e a extração continua quando ela é digitada. A senha é usada apenas para abrir o arquivo no seu navegador.

O PDF é enviado para extrair as tabelas?

Não. O mecanismo de detecção de tabelas é carregado no seu navegador como WebAssembly e o CSV é gerado localmente, então o documento nunca sai do seu dispositivo. A primeira execução demora um pouco mais enquanto o mecanismo carrega.

Como abro o CSV no Excel sem quebrar as colunas?

Dar dois cliques no arquivo funciona na maioria das configurações, pois a ferramenta usa o delimitador padrão de vírgula. Se o seu Excel estiver configurado para uma região que espera ponto e vírgula, use Dados > De Texto/CSV e escolha a vírgula como delimitador.
