Perguntas frequentes

Posso girar apenas uma página em vez do documento inteiro?

Sim. Cada página aparece como miniatura com seus próprios botões de esquerda e direita, então um único scan de lado em um arquivo de 40 páginas pode ser corrigido isoladamente. Os botões no topo giram todas as páginas de uma vez quando o documento inteiro está de cabeça para baixo.

Como giro uma página em 180 graus?

Clique duas vezes na mesma direção. As rotações se somam em passos de 90 graus, então dois cliques dão 180 e três cliques dão 270, o mesmo que um clique para o outro lado. A miniatura é atualizada para você ver o estado atual antes de salvar.

Girar reduz a qualidade das páginas?

Não. A ferramenta altera o atributo de rotação de cada página em vez de renderizar qualquer coisa novamente, então o texto continua selecionável, as imagens mantêm a resolução e o tamanho do arquivo fica praticamente igual.

A rotação vai permanecer ao abrir o arquivo em outro aplicativo ou imprimir?

Sim. A rotação é gravada na própria página do PDF, que todo visualizador e impressora respeitam, ao contrário do botão de girar temporário de um visualizador, que volta ao normal quando você fecha o arquivo.

Posso girar em um ângulo diferente de 90 graus, por exemplo para endireitar um scan inclinado?

Aqui não; esta ferramenta funciona apenas em passos de 90 graus. Use Girar em Graus Personalizados para ângulos quaisquer, ou Corrigir Inclinação de PDF para endireitar scans automaticamente.

Posso girar apenas as páginas pares ou ímpares?

Esta ferramenta não tem seleção de páginas nem campo de intervalo; você gira as páginas uma de cada vez com os botões delas ou todas juntas. Para selecionar grupos de páginas, o PDF Multi Tool é mais adequado.

Meu PDF é enviado para girar as páginas?

Não. As miniaturas são renderizadas pelo seu navegador e o arquivo girado é gerado localmente, então o documento nunca sai do seu computador. O PDF girado é baixado com o nome de arquivo original.

Girar mantém meus marcadores?

O conteúdo das páginas, as imagens e as anotações são mantidos, mas os marcadores não são levados, porque o arquivo girado é montado a partir de páginas copiadas. Um documento que depende do sumário precisará adicioná-lo de volta com a ferramenta Marcador.
