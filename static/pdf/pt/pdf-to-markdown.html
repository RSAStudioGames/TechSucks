Perguntas frequentes

Quão bem o PDF para Markdown preserva a estrutura do documento?

Títulos, parágrafos, listas e formatação básica de negrito e itálico são convertidos, e cada página é separada por uma linha horizontal (---) na saída. Os níveis de título são deduzidos pelos tamanhos de fonte, então um documento com estilos inconsistentes pode ter alguns títulos no nível errado.

O que a opção Incluir Imagens faz?

Quando marcada, as imagens do PDF são incorporadas diretamente no Markdown como dados base64, então o arquivo .md único fica autossuficiente, mas pode ficar grande. Deixe desmarcada para documentos com muito texto, para manter a saída pequena e legível em um editor simples.

Por que o Markdown está vazio ou quase vazio?

O conversor lê a camada de texto do PDF, então um documento digitalizado que contém apenas imagens não tem nada para converter. Passe-o primeiro pelo OCR de PDF para adicionar uma camada de texto e depois converta o resultado.

Como ele lida com layouts de várias colunas, notas de rodapé e barras laterais?

Layouts complexos são o ponto fraco: texto em várias colunas pode sair intercalado, e barras laterais ou notas de rodapé podem parar no lugar errado. Espere revisar e arrumar a saída de páginas estilo revista, enquanto documentos de coluna única precisam de pouca limpeza.

Posso converter vários PDFs para Markdown de uma vez?

Envie vários PDFs e clique em Converter uma vez. Um arquivo é baixado como filename.md; vários voltam como markdown-files.zip com um .md por PDF, e nomes duplicados recebem um sufixo numerado.

Isso é o mesmo que PDF para Texto?

Não. O PDF para Texto entrega texto bruto sem estrutura, o que é melhor para alimentar scripts. O PDF para Markdown mantém títulos, listas e ênfases, então o resultado está pronto para colar no Obsidian, em uma wiki ou em um gerador de sites estáticos.

Posso converter um PDF protegido por senha?

Se o arquivo exigir senha para abrir, ela é solicitada antes de a conversão começar e o texto é extraído normalmente. A senha não é armazenada em lugar nenhum, e a saída em Markdown não tem proteção própria.

Meu PDF é enviado para ser convertido em Markdown?

Não. A conversão roda em um mecanismo PyMuPDF carregado no seu navegador como WebAssembly, e o arquivo .md ou o ZIP é gerado na sua máquina. Artigos de pesquisa, contratos e documentos internos permanecem privados.
