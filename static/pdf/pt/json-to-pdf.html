Perguntas frequentes

Posso converter qualquer arquivo JSON em PDF com esta ferramenta?

Não. Ela só reconstrói PDFs a partir de arquivos JSON criados pela ferramenta PDF para JSON do BentoPDF, que guarda a estrutura interna completa do documento. Uma exportação JSON de uma API, de um banco de dados ou de um arquivo de configuração falhará com um erro.

Como transformo dados de API ou um arquivo de configuração em um PDF legível?

Cole ou envie o JSON como texto simples em Texto para PDF, que o organiza como texto formatado nas páginas. JSON para PDF serve apenas para fazer o ciclo completo de documentos que começaram como PDFs.

O PDF reconstruído fica igual ao original?

O JSON gerado pelo PDF para JSON captura os objetos do documento, então converter de volta reproduz as páginas, o texto e as imagens da origem. Converter de volta e comparar também é um jeito rápido de confirmar que a exportação capturou tudo.

Qual é o resultado ao converter vários arquivos JSON?

Toda conversão é baixada como jsons-to-pdf.zip, mesmo para um único arquivo. Dentro dele, cada PDF leva o nome do JSON de origem, então report.json vira report.pdf.

Posso editar o JSON antes de convertê-lo de volta?

Sim, desde que a estrutura continue válida para o mecanismo CPDF. Alterações programáticas no JSON, como metadados ou objetos de texto editados, são reconstruídas no PDF; uma edição malformada gera um erro de conversão.

Por que a ferramenta diz que o mecanismo CPDF não está disponível?

A conversão depende do build WebAssembly do CPDF. No bentopdf.com ele já está incluído, mas uma cópia auto-hospedada precisa dos arquivos WASM do CPDF configurados em Configurações do WASM para esta ferramenta funcionar.

Meu arquivo JSON é enviado a um servidor?

Não. Os arquivos são lidos no seu navegador e reconstruídos em PDFs por um Web Worker rodando o mecanismo CPDF localmente, então nada é transmitido e a página continua responsiva durante conversões grandes.
