Preparar PDF para IA

Extrair conteúdo PDF como JSON LlamaIndex para pipelines RAG/LLM.

Clique para selecionar um arquivo ou arraste e solte

Formato de saída:

Cada PDF será extraído como um arquivo JSON contendo uma matriz de objetos Document do LlamaIndex com:

  • text - Conteúdo de texto extraído por página
  • metadata - Número da página, títulos e informações do documento
  • extra_info - Contexto adicional para sistemas RAG

Perguntas frequentes

O que a saída JSON contém?

Ele segue o esquema de documentos do LlamaIndex: um documento por página, com o texto da página e campos de metadados. É gerado pela integração do PyMuPDF com o LlamaIndex, então pode ser carregado diretamente no LlamaIndex ou em qualquer pipeline que aceite texto por página com metadados.

Qual é a diferença em relação ao PDF para Texto ou ao PDF para Markdown?

PDF para Texto gera um único fluxo de texto simples, e PDF para Markdown mantém títulos e estrutura para leitura. Esta ferramenta divide o conteúdo página por página e o envolve em JSON estruturado com metadados, que é o que os pipelines de recuperação precisam para dividir em blocos e citar fontes.

Funciona em PDFs escaneados?

Somente se já tiverem uma camada de texto. Imagens escaneadas geram resultado vazio ou quase vazio, então passe-as primeiro pelo OCR PDF e depois extraia.

Posso processar um lote inteiro de PDFs?

Sim. Envie vários arquivos e você recebe o pdf-for-ai.zip contendo um yourfile_llm.json por PDF; um único arquivo é baixado diretamente como yourfile_llm.json. Se um arquivo do lote falhar, os demais são concluídos normalmente e o resumo informa quantos falharam.

Posso escolher quais páginas extrair ou controlar o tamanho dos blocos?

Não. Não há opções; cada página é extraída com todo o seu texto e metadados. Faça a divisão em trechos no seu próprio pipeline, onde você pode escolher tamanhos que combinem com o seu modelo de embeddings, e descarte lá as páginas de que não precisa.

Posso preparar um PDF protegido por senha para ferramentas de IA?

Sim. Se um arquivo estiver criptografado, a senha é solicitada antes de a extração começar, e o texto é obtido da cópia descriptografada.

Meu documento é enviado para um serviço de IA?

Não. Apesar do nome, nada é enviado a um provedor de IA nem a qualquer servidor; a extração roda com o PyMuPDF compilado para WebAssembly dentro do seu navegador. Você decide depois para onde o JSON vai.

O que posso fazer com o arquivo JSON?

Alimente um pipeline RAG, crie uma base de conhecimento para um chatbot, execute análises com LLM em relatórios ou transforme uma coleção de PDFs em dados de treinamento. Como o conteúdo é dividido por página com metadados, as respostas podem apontar para a página de origem.
