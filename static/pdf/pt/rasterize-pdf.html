Perguntas frequentes

O que a rasterização de um PDF realmente faz?

Cada página é renderizada como bitmap e os bitmaps são reunidos em um novo PDF. O resultado parece igual, mas não contém objetos de texto, fontes, camadas, campos de formulário nem conteúdo oculto, apenas uma imagem de cada página, como uma fotocópia.

Qual DPI devo escolher ao rasterizar?

150, o padrão, é suficiente para ler na tela e para impressão comum de escritório. Use 300 para saída com qualidade de impressão ou quando alguém for ampliar letras miúdas, 600 apenas para arquivamento ou impressão profissional, e 72 quando o menor arquivo possível importa mais que a nitidez.

PNG ou JPEG?

O PNG não tem perdas, então as bordas do texto ficam nítidas, mas os arquivos são maiores. O JPEG (salvo com qualidade 95) é bem menor e funciona bem para páginas escaneadas ou fotográficas, mas pode deixar leves artefatos ao redor de texto nítido. Tons de cinza está disponível com ambos e reduz ainda mais os arquivos de documentos em preto e branco.

Por que o arquivo rasterizado é maior que o original?

Um PDF de texto armazena alguns kilobytes de dados de fontes e glifos por página, enquanto uma imagem de 300 DPI de uma página Carta tem 2550 x 3300 pixels. Reduza o DPI, mude para JPEG ou passe o resultado pelo Comprimir PDF se o tamanho importar.

Posso tornar o texto selecionável novamente depois?

Não a partir do próprio arquivo rasterizado; a operação é de mão única, então guarde o original. Você pode adicionar de volta uma camada de texto pesquisável com o OCR PDF, embora o texto reconhecido nunca seja tão exato quanto o original.

Qual é a diferença em relação a achatar um PDF?

Achatar mescla campos de formulário e anotações na página, mas mantém o texto como texto. A rasterização vai além e transforma tudo, inclusive o texto, em pixels. Se você só precisa travar campos de formulário ou comentários, o Achatar PDF mantém o arquivo pesquisável e bem menor.

Meus documentos confidenciais são enviados para serem rasterizados?

Não. A renderização é feita pelo módulo WebAssembly do PyMuPDF rodando no seu navegador, então as páginas são desenhadas e reempacotadas na sua própria máquina. É isso que torna a ferramenta uma forma segura de remover texto oculto e camadas de um arquivo sensível antes de compartilhá-lo.

Posso rasterizar vários PDFs de uma vez?

Sim. Adicione quantos quiser; cada um é processado com as mesmas configurações de DPI, formato e tons de cinza, e os resultados são baixados juntos como rasterized-pdfs.zip. Um único arquivo é baixado sozinho.
