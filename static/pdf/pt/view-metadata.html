Perguntas frequentes

Que informações um PDF pode revelar sobre mim?

O dicionário Info costuma conter o nome do autor (normalmente o usuário do sistema operacional ou do Office), o software usado e os carimbos de criação e modificação. Os metadados XMP podem acrescentar IDs de documento, histórico de revisões e detalhes de aplicativos, e os valores preenchidos nos campos de formulário também são exibidos. Se você vai publicar ou compartilhar o arquivo, use Remover Metadados depois.

Qual é a diferença entre o dicionário Info e os metadados XMP?

O dicionário Info é o conjunto mais antigo de campos fixos: Title, Author, Subject, Keywords, Creator, Producer e datas. O XMP é um bloco XML com namespaces como Dublin Core, xmp e pdf, e pode guardar muito mais. Os dois deveriam concordar, mas muitas vezes não concordam, e é por isso que a ferramenta mostra ambos.

Por que as datas aparecem diferentes do que o Acrobat mostra?

As datas do PDF são armazenadas como strings do tipo D:20240101120000Z. A ferramenta as converte em uma data legível no seu fuso horário local, então a hora pode diferir de um visualizador que mostra o valor bruto ou usa outro fuso.

Como descubro qual programa criou o PDF?

Veja o campo Creator (o aplicativo que criou o documento original, como Word ou InDesign) e o campo Producer (a biblioteca que gravou o PDF, como Acrobat Distiller ou um mecanismo de PDF). A seção XMP normalmente os repete como xmp:CreatorTool e pdf:Producer.

Ele mostra os valores preenchidos nos campos de formulário?

A seção Campos de formulário interativos lista o nome de cada campo com seu valor atual, ou Não definido quando está vazio, o que é uma forma rápida de conferir quais dados um formulário preenchido contém antes de enviá-lo.

Posso copiar ou exportar os metadados?

O botão Copiar metadados como JSON coloca os campos do dicionário Info na sua área de transferência como um objeto JSON. A árvore XMP e os valores dos campos de formulário são exibidos na página, mas não são incluídos no JSON copiado.

Posso alterar o que vejo aqui?

Esta ferramenta é somente leitura. Use Editar Metadados para alterar título, autor, palavras-chave e datas, ou Remover Metadados para apagar tudo antes de publicar.

O PDF é enviado para ler seus metadados?

Não. O arquivo é analisado pelo pdf.js no seu navegador assim que você o seleciona, e nada é transmitido, então você pode inspecionar um documento sensível antes de decidir para onde ele vai.
