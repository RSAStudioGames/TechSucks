Perguntas frequentes

Como aplico a sobreposição em apenas algumas páginas?

Digite um intervalo no campo Aplicar às páginas usando os números de página do documento base, por exemplo 1-5, 8, 10-z, em que z representa a última página. Deixe vazio para cobrir todas as páginas.

O que acontece quando os dois PDFs têm quantidades de páginas diferentes?

Com a opção de repetir ativada, as páginas da sobreposição se repetem em ordem até cobrir todas as páginas base, então uma sobreposição de 2 páginas em um documento de 5 páginas é aplicada como 1, 2, 1, 2, 1. Com ela desativada, as páginas são pareadas uma a uma e as páginas base além do tamanho da sobreposição ficam inalteradas.

Os tamanhos das páginas precisam ser iguais?

Não. Uma página de sobreposição maior que a página base é reduzida para caber e uma menor é centralizada sem ser ampliada. Não há controles de posição, escala ou opacidade, então crie o PDF de sobreposição no tamanho e na transparência desejados antes de combinar.

O PDF base continua pesquisável e editável?

Sim. O texto, os links, os campos de formulário e os marcadores do documento base ficam intactos; a sobreposição é adicionada a cada página como uma camada de desenho extra, e qualquer texto nela também continua selecionável.

Links, campos de formulário ou comentários do PDF de sobreposição são copiados?

Não. Apenas o conteúdo visível da página de sobreposição é usado. As anotações das páginas de sobreposição, incluindo links, campos de formulário e comentários, não são transferidas para o resultado.

Qual modo devo usar para um papel timbrado?

Underlay, para que o papel timbrado fique atrás do conteúdo da página, com a opção de repetir ativada se o papel timbrado tiver uma única página. Para marcas d'água de texto ou imagem com opacidade, rotação e posição ajustáveis, Adicionar marca d'água oferece mais controle.

Por que falha em um PDF protegido por senha?

A ferramenta não pede senhas. Se algum dos arquivos precisar de senha para abrir, remova-a primeiro com a ferramenta de remoção de senha e depois aplique a sobreposição na cópia sem senha.

Os dois PDFs são enviados?

Não. A sobreposição é aplicada pelo qpdf compilado para WebAssembly, que roda inteiramente no seu navegador, então nem o documento base nem o arquivo de sobreposição saem do seu dispositivo. O PDF combinado é baixado com o nome do arquivo do documento base.
