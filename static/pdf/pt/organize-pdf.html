Perguntas frequentes

Como movo uma página para outra posição?

Arraste a miniatura até a nova posição na grade; os números das páginas são atualizados conforme você move. Para reorganizar o documento inteiro, digite a nova ordem na caixa de ordem das páginas, por exemplo 3, 1, 2, 4, e clique em Aplicar.

O que a caixa de ordem das páginas espera?

Uma lista separada por vírgulas com os números das páginas originais na ordem desejada, mencionando cada página exatamente uma vez. 3, 1, 2 funciona para um arquivo de três páginas; 3, 1 (falta uma página) ou 1, 1, 2 (repetição) é rejeitado. Use os botões de duplicar e excluir para cópias e remoções.

Posso duplicar uma página mais de uma vez?

Sim. Cada clique no botão verde de duplicar adiciona outra cópia logo depois da página, e cada cópia pode ser arrastada para qualquer lugar de forma independente. É útil para colocar várias cópias em branco de uma página de formulário em um só arquivo.

Também posso excluir páginas aqui?

Sim. Clique no botão vermelho de excluir em uma miniatura para removê-la do resultado; a única regra é que a última página restante não pode ser excluída. Para remover muitas páginas por intervalo, Excluir páginas é mais rápido.

Reordenar páginas mantém meus marcadores?

O conteúdo, as imagens e as anotações de cada página são mantidos. Os marcadores não, porque o arquivo reorganizado é montado do zero a partir de páginas copiadas, então um documento com estrutura de navegação a perde. Se precisar, recrie-a depois com a ferramenta Marcadores.

A qualidade das páginas é afetada?

Não. As páginas são copiadas como estão, sem nova renderização, então o texto continua selecionável e as imagens mantêm a resolução original. O resultado é salvo com o mesmo nome do arquivo original.

Meu PDF é enviado enquanto reorganizo as páginas?

Não. As miniaturas são renderizadas pelo seu navegador e o novo arquivo é montado localmente, então nada é enviado para lugar nenhum, mesmo em documentos grandes.

Posso organizar páginas de mais de um PDF ao mesmo tempo?

Não, esta ferramenta trabalha com um único arquivo. Para reunir páginas de vários documentos em uma sequência, use Mesclar PDF no Modo página, que mostra miniaturas de todos os arquivos em uma única grade.
