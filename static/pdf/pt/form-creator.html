Perguntas frequentes

Posso adicionar campos preenchíveis a um PDF que já tenho?

Envie o PDF e as páginas aparecem no editor; escolha um tipo de campo na barra de ferramentas e clique na página para posicioná-lo, depois arraste ou redimensione conforme precisar. Se o PDF já tiver campos de formulário, eles são detectados e carregados para você mover, editar ou excluir junto com os novos.

Posso criar um formulário do zero, sem um PDF existente?

Clique em Criar PDF em branco e escolha Carta, A4, A5, Legal, Tabloid, A3 ou dimensões personalizadas em pontos. Use Adicionar página para formulários de várias páginas.

Quais tipos de campo estão disponíveis?

Texto (linha única, várias linhas ou dividido em caixas de pente), caixa de seleção, grupos de botões de opção, lista suspensa, caixa de listagem, botão de ação, assinatura, data, imagem e código de barras. Cada campo tem um painel de propriedades para nome, valor padrão, tamanho da fonte, cor do texto, alinhamento, dica e opções de obrigatório ou somente leitura. Campos de assinatura são campos de assinatura AcroForm padrão, que só aparecem em leitores com suporte a assinatura.

Como os botões de opção são agrupados para que só um possa ser selecionado?

Todo campo de opção tem um nome de grupo, RadioGroup1 por padrão. Campos que compartilham o mesmo nome de grupo formam um conjunto mutuamente exclusivo, então dê a cada pergunta o próprio nome de grupo e defina um valor de exportação distinto em cada opção.

Um botão pode mostrar ou ocultar outro campo, ou redefinir o formulário?

As ações de botão incluem Redefinir formulário, Imprimir formulário, Abrir URL, Executar JavaScript e Mostrar/ocultar campo, que tem como alvo outro campo e pode mostrá-lo, ocultá-lo ou alternar sua exibição. Elas são armazenadas como ações PDF padrão, então funcionam no Acrobat e em outros leitores com suporte a scripts de formulário.

Como funciona o campo de data?

É um campo de texto com um formato de data associado, mm/dd/aaaa por padrão ou um padrão personalizado como dd/mm/aaaa. Leitores com suporte a JavaScript de AcroForm validam e formatam o valor digitado; leitores mais simples o tratam como texto comum.

Códigos de barras e imagens são campos de formulário de verdade?

Um código de barras (QR Code, Code 128, Code 39, EAN-13, UPC-A, DataMatrix ou PDF417) é gerado a partir do valor que você informa e desenhado na página como uma imagem fixa, então quem preencher o formulário não pode alterá-lo. O campo de imagem é um botão que permite ao usuário escolher uma foto do computador, o que funciona no Acrobat e em outros leitores com suporte a importação de imagens.

O formulário ou o PDF enviado fica armazenado em um servidor?

Não. O editor roda no seu navegador, os campos são gravados no PDF com o pdf-lib no seu dispositivo, e Baixar formulário PDF salva o resultado localmente com o nome original do arquivo. Você pode testar o resultado em Preenchimento de formulário PDF.
