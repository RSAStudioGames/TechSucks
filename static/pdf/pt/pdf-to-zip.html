Perguntas frequentes

O que o PDFs para ZIP realmente faz com os meus arquivos?

Nada além de empacotar. Os PDFs são copiados para um único pdfs_archive.zip com os nomes originais, sem alterações, na ordem em que você os adicionou, então o que sai do ZIP é byte por byte o que entrou.

Compactar em ZIP deixa os PDFs menores?

Não. O arquivo é gravado sem compressão, já que o conteúdo do PDF já é comprimido internamente e quase não diminuiria, então espere que o ZIP tenha cerca do tamanho combinado dos arquivos. Para reduzir o tamanho, passe-os primeiro pelo Comprimir PDF e depois compacte os resultados.

Qual é a diferença entre compactar PDFs em ZIP e juntá-los?

Um ZIP mantém cada PDF como um arquivo separado dentro de um único contêiner que o destinatário descompacta. Juntar une as páginas em um único documento PDF, que é o que você quer quando os arquivos devem ser lidos como um só documento; use o Juntar PDF para isso.

E se dois dos meus arquivos tiverem o mesmo nome?

Nomes duplicados são tratados automaticamente: o segundo arquivo vira name (1).pdf, o terceiro name (2).pdf e assim por diante, para que nada seja sobrescrito dentro do arquivo compactado. Renomeie os arquivos antes de enviar se preferir nomes mais significativos.

Posso adicionar arquivos que não são PDF ao ZIP?

Não. Só são aceitos arquivos com extensão .pdf ou do tipo PDF; qualquer outra coisa que você soltar é ignorada. Para um pacote misto, use o recurso de compactação do seu sistema operacional.

O destinatário precisará de um software especial para abrir o arquivo?

Não. A saída é um arquivo ZIP padrão que Windows, macOS, iOS e Android abrem sem software extra; dê dois cliques ou toque nele para extrair os PDFs.

Meus PDFs são enviados para criar o ZIP?

Não. O arquivo é montado no seu navegador, então os arquivos são lidos do seu disco e o ZIP é gravado de volta nele, sem nenhuma transferência pela rede. Reunir notas fiscais, contratos ou prontuários médicos desse jeito os mantém no seu dispositivo.
