Perguntas frequentes

Como a ferramenta decide qual será a aparência do PDF?

Ele analisa o XML, agrupa elementos irmãos repetidos pelo nome da tag e renderiza cada grupo como uma tabela com uma coluna por elemento filho, usando os nomes dos elementos como cabeçalhos. Se a raiz não tem filhos repetidos, você recebe uma tabela de duas colunas, Propriedade e Valor. A saída é em A4 paisagem, com o nome do elemento raiz como título.

Que tipo de XML funciona melhor?

XML em estilo de dados: registros com o mesmo conjunto de elementos filhos repetidos sob um mesmo pai, como exportações de banco de dados, itens de fatura, feeds de produtos, feeds RSS ou sitemaps. XML muito aninhado ou em estilo de documento é achatado, então valores aninhados são unidos em uma única célula e perdem a hierarquia.

Por que recebo um erro de XML inválido?

O arquivo não está bem formado: uma tag não fechada, um elemento raiz ausente, um caractere & ou < sem escape ou uma codificação inválida. A mensagem inclui o motivo informado pelo analisador, então corrija o arquivo em um editor ou validador e tente de novo.

Os atributos XML são incluídos no PDF?

Em parte. Na visualização em tabela, apenas elementos filhos viram colunas, então os atributos dos registros repetidos não são mostrados. Na visualização de Propriedade e Valor para uma raiz sem repetição, os atributos são listados depois dos valores dos filhos.

Posso converter vários arquivos XML de uma vez?

Sim. Adicione vários arquivos e eles são convertidos em um lote em xml-to-pdf.zip com um PDF por arquivo. Um único arquivo é baixado diretamente com o mesmo nome base e a extensão .pdf.

Ele aplica minha folha de estilo XSLT ou CSS?

Não. Instruções de folha de estilo e declarações DOCTYPE são removidas antes da análise, e o layout é gerado apenas a partir da estrutura dos dados. Se precisar da renderização estilizada, abra o XML em um navegador que aplique a folha de estilo e imprima em PDF a partir dele.

Texto em chinês, árabe, cirílico ou outras escritas não latinas será renderizado?

Não de forma confiável. O PDF é criado com a fonte Helvetica padrão do jsPDF, que cobre caracteres latinos, então texto em outras escritas pode aparecer com caracteres errados ou ausentes.

O arquivo XML é enviado para ser convertido?

Não. A análise usa um analisador XML em JavaScript e o PDF é gerado com o jsPDF, ambos dentro do seu navegador, então faturas, registros de transações e outros dados sensíveis do arquivo nunca saem do seu dispositivo.
