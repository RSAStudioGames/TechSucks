Frequently Asked Questions

Where will the blank page be inserted?

The position number is how many existing pages come before the new blank pages. Enter 0 to put them at the very start, 3 to insert them after page 3, or the total page count to append them at the end.

What size are the blank pages?

Each blank page copies the width and height of your document's first page, so a Letter document gets Letter blanks and an A4 document gets A4 blanks. If your PDF mixes page sizes, the blanks still match page 1 rather than the pages next to them.

Can I add more than one blank page at a time?

Enter any count of 1 or more and all of them are inserted together at the same position. To add blanks at several different spots, run the tool again on the output, or use PDF Multi Tool to arrange pages visually.

Does it keep bookmarks and document properties?

Page content, images, text, and annotations on the pages are kept as they are. The document is rebuilt page by page, so bookmarks (the outline panel) and properties such as title and author aren't carried over to the new file.

Is the inserted page completely empty?

Yes. It has no text, no page number, and no printed note, just a white page of the same size as page 1. If you want page numbers on it afterward, run the result through Page Numbers.

Can I use this to make every chapter start on a right-hand page for double-sided printing?

You can, one position per run. Insert a blank after each chapter that ends on an odd page, download, then repeat on the new file for the next chapter. The output keeps the original filename, so rename copies as you go to avoid mixing them up.

Can I add blank pages to a password-protected PDF?

If the file needs a password to open, the tool asks for it before reading the page count. The new file is saved without the password, so protect it again afterward if you need to.

Is my PDF uploaded to add the page?

No. The page count is read and the new document is assembled in your browser with pdf-lib, a JavaScript PDF library, and the download comes straight from memory. Nothing is sent to a server.
