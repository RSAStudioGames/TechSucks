Preguntes freqüents

Què conté el JSON?

L'estructura completa dels objectes del PDF tal com la llegeix cpdf: el trailer, el catàleg, l'arbre de pàgines, tots els diccionaris i el flux de contingut de cada pàgina analitzat en una llista d'operadors de dibuix i de text. És un bolcat complet del fitxer, no un resum.

Aquesta és l'eina adequada per treure el text d'un PDF com a JSON?

Normalment no. Aquí el text està dispers entre els operadors del flux de contingut en l'ordre en què es va dibuixar, amb tipus de lletra i posicions però sense paràgrafs. Per obtenir text de pàgina llegible en un format estructurat, utilitza Prepara el PDF per a la IA, i per a text pla, PDF a text.

Puc tornar a convertir el JSON en un PDF?

No amb BentoPDF. La sortida segueix el format JSON propi de cpdf, que l'eina de línia d'ordres de cpdf pot tornar a llegir i convertir en un PDF, però l'eina del navegador només va en una direcció.

Per què el JSON és molt més gran que el PDF?

Els fluxos de contingut s'expandeixen en matrius d'operadors, les dades de flux binàries, com les imatges, es codifiquen com a text, i cada objecte s'escriu amb totes les seves claus, de manera que és normal que un fitxer JSON sigui diverses vegades més gran que l'origen. Els PDF grans o amb moltes imatges produeixen fitxers molt grans.

Puc convertir diversos PDF a JSON alhora?

Selecciona'n tants com vulguis; cadascun es converteix en un worker en segon pla i els resultats s'empaqueten a pdfs-to-json.zip amb un .json per PDF, amb el nom del fitxer d'origen. Un sol PDF també arriba en un ZIP.

Funciona amb PDF xifrats?

Et demana la contrasenya abans de començar la conversió i se serialitza la còpia desxifrada. Sense la contrasenya, l'estructura dels objectes no es pot llegir.

Per a què serveix?

Per inspeccionar els elements interns d'un PDF quan depures un generador, comprovar què conté el flux de contingut d'una pàgina, comparar dues versions estructuralment o passar l'arbre d'objectes a un script. Només per a les propietats del document, Mostra les metadades és més ràpid.

El PDF es puja per generar el JSON?

No. cpdf s'executa com a WebAssembly en un web worker al navegador, i el JSON s'escriu i es comprimeix al teu dispositiu abans de la baixada.
