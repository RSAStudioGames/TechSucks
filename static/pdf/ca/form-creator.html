Preguntes freqüents

Puc afegir camps emplenables a un PDF que ja tinc?

Puja el PDF i les pàgines apareixen a l'editor; tria un tipus de camp a la barra d'eines i fes clic a la pàgina per col·locar-lo, i després arrossega'l o canvia'n la mida segons calgui. Si el PDF ja té camps de formulari, es detecten i es carreguen perquè els puguis moure, editar o eliminar juntament amb els nous.

Puc fer un formulari de zero sense un PDF existent?

Fes clic a Crea un PDF en blanc i tria Letter, A4, A5, Legal, Tabloid, A3 o unes dimensions personalitzades en punts. Fes servir Afegeix una pàgina per a formularis de diverses pàgines.

Quins tipus de camp hi ha disponibles?

Text (d'una línia, de diverses línies o dividit en caselles de pinta), casella de selecció, grups de botons d'opció, llista desplegable, quadre de llista, botó d'acció, signatura, data, imatge i codi de barres. Cada camp té un tauler de propietats per al nom, el valor per defecte, la mida del tipus de lletra, el color del text, l'alineació, la descripció emergent i els indicadors d'obligatori o de només lectura. Els camps de signatura són camps de signatura AcroForm estàndard, que només apareixen als visors que admeten signatura.

Com s'agrupen els botons d'opció perquè només se'n pugui seleccionar un?

Cada camp d'opció té un nom de grup, RadioGroup1 per defecte. Els camps que comparteixen el mateix nom de grup formen un conjunt mútuament exclusiu, així que dona a cada pregunta el seu propi nom de grup i defineix un valor d'exportació diferent a cada opció.

Un botó pot mostrar o amagar un altre camp, o reiniciar el formulari?

Les accions dels botons inclouen Reinicia el formulari, Imprimeix el formulari, Obre una URL, Executa JavaScript i Mostra/Amaga un camp, que apunta a un altre camp i el pot mostrar, amagar o alternar. Es desen com a accions PDF estàndard, així que s'executen a Acrobat i a altres visors que admeten scripts de formulari.

Com funciona el camp de data?

És un camp de text amb un format de data associat, mm/dd/aaaa per defecte o un patró personalitzat com dd/mm/aaaa. Els visors que admeten JavaScript d'AcroForm validen el valor escrit i el formaten; els visors més simples el tracten com a text normal.

Els codis de barres i les imatges són camps de formulari reals?

Un codi de barres (QR Code, Code 128, Code 39, EAN-13, UPC-A, DataMatrix o PDF417) es genera a partir del valor que introdueixes i es dibuixa a la pàgina com a imatge fixa, de manera que qui emplena el formulari no el pot canviar. El camp d'imatge és un botó que deixa l'usuari triar una imatge del seu ordinador, cosa que funciona a Acrobat i a altres visors que admeten la importació d'imatges.

El formulari o el PDF pujat es desa en un servidor?

No. L'editor s'executa al navegador, els camps s'escriuen al PDF amb pdf-lib al teu dispositiu, i Baixa el formulari PDF desa el resultat localment amb el nom original. Pots provar el resultat a Emplenador de formularis PDF.
