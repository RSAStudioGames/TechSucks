Preguntes freqüents

Puc convertir qualsevol fitxer JSON en un PDF amb aquesta eina?

No. Només reconstrueix PDF a partir de fitxers JSON creats per l'eina PDF a JSON de BentoPDF, que desa l'estructura interna completa del document. Una exportació JSON d'una API, una base de dades o un fitxer de configuració fallarà amb un error.

Com converteixo en canvi dades d'una API o un fitxer de configuració en un PDF llegible?

Enganxa o puja el JSON com a text pla a Text a PDF, que el distribueix com a text formatat a les pàgines. JSON a PDF només serveix per fer anar i tornar documents que van començar sent PDF.

El PDF reconstruït coincidirà amb l'original?

El JSON que produeix PDF a JSON captura els objectes del document, així que convertir-lo de nou reprodueix les pàgines, el text i les imatges de l'origen. Convertir de nou i comparar també és una manera ràpida de confirmar que l'exportació ho ha capturat tot.

Quina és la sortida quan converteixo diversos fitxers JSON?

Cada conversió es baixa com a jsons-to-pdf.zip, fins i tot per a un sol fitxer. A dins, cada PDF porta el nom del seu JSON d'origen, així que report.json esdevé report.pdf.

Puc editar el JSON abans de tornar-lo a convertir?

Sí, sempre que l'estructura continuï sent vàlida per al motor CPDF. Els canvis programàtics al JSON, com metadades o objectes de text editats, es reconstrueixen al PDF; una edició mal formada produeix un error de conversió.

Per què l'eina diu que el motor CPDF no està disponible?

La conversió depèn de la versió de CPDF per a WebAssembly. A bentopdf.com ja hi és inclosa, però una còpia d'allotjament propi necessita els fitxers WASM de CPDF configurats a Configuració WASM abans que aquesta eina funcioni.

Es puja el meu fitxer JSON a un servidor?

No. Els fitxers es llegeixen al navegador i els reconstrueix en PDF un Web Worker que executa el motor CPDF localment, així que no es transmet res i la pàgina continua responent durant les conversions grans.
