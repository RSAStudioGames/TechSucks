Preguntes freqüents

Quin format de sortida he de triar?

El CSV s'obre a Excel, Google Sheets o qualsevol importació de bases de dades. El JSON dona una matriu de files, cadascuna una matriu de cadenes de cel·la, per a scripts i API. El Markdown dona una taula amb barres verticals que pots enganxar a GitHub, una wiki o documentació.

Què obtinc quan el PDF conté diverses taules?

Cada taula es desa com a fitxer propi, amb un nom com table_1_page3.csv, i totes s'empaqueten a filename_tables.zip. Una sola taula es baixa directament com a filename_table.csv, .json o .md. Si prefereixes totes les taules en un sol fitxer, fes servir PDF a CSV.

Per què diu que no s'ha trobat cap taula?

La detecció funciona amb la capa de text del document. Els PDF escanejats només contenen una imatge, així que passa'ls primer per OCR de PDF. El text que només sembla una taula per l'espaiat, sense estructura de taula, també pot quedar sense detectar.

Una taula continua en diverses pàgines. Sortirà com un sol fitxer?

No. Cada pàgina s'escaneja per separat, així que una taula que s'estén per diverses pàgines s'exporta com un fitxer per pàgina, amb el número de pàgina al nom. Uneix les parts en un full de càlcul després de l'extracció.

Puc extreure taules només d'algunes pàgines?

Sempre s'escaneja tot el document, tot i que el número de pàgina de cada nom de fitxer t'indica d'on ve una taula. Per limitar l'escaneig, desa primer les pàgines que necessites amb Extreu pàgines i executa aquesta eina amb el fitxer més petit.

El CSV gestiona comes i salts de línia dins de les cel·les?

Sí. Les cel·les que contenen comes, cometes o salts de línia es posen entre cometes dobles, amb les cometes interiors duplicades, perquè el programari de fulls de càlcul les llegeixi correctament. Les cel·les buides s'escriuen com a camps buits.

Es poden extreure taules d'un PDF protegit amb contrasenya?

Si el fitxer necessita una contrasenya per obrir-se, te la demana abans de començar l'extracció, i les taules es llegeixen d'una còpia desxifrada que es guarda a la memòria.

Es puja el PDF per detectar les taules?

No. El motor de detecció (PyMuPDF compilat a WebAssembly) es descarrega d'una CDN la primera vegada que l'uses, i després s'executa dins del navegador. El teu PDF es queda al dispositiu.
