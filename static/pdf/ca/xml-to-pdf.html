Preguntes freqüents

Com decideix l'eina quin aspecte té el PDF?

Analitza l'XML, agrupa els elements germans repetits pel nom de l'etiqueta i renderitza cada grup com una taula amb una columna per element fill, fent servir els noms dels elements com a capçaleres. Si l'arrel no té fills repetits, obtens una taula de dues columnes amb Propietat i Valor. La sortida és A4 apaïsat amb el nom de l'element arrel com a títol.

Quin tipus d'XML funciona millor?

XML de tipus dades: registres amb el mateix conjunt d'elements fills repetits sota un mateix pare, com exportacions de bases de dades, línies de factura, fluxos de productes, fluxos RSS o mapes del lloc. L'XML molt niuat o de tipus document s'aplana, de manera que els valors niuats s'uneixen en una sola cel·la i perden la jerarquia.

Per què rebo un error d'XML no vàlid?

El fitxer no està ben format: una etiqueta sense tancar, un element arrel que falta, un caràcter & o < sense escapar, o una codificació incorrecta. El missatge inclou el motiu de l'analitzador, així que corregeix el fitxer en un editor o validador i torna-ho a provar.

S'inclouen els atributs XML al PDF?

En part. A la vista de taula, només els elements fills es converteixen en columnes, així que els atributs dels registres repetits no es mostren. A la vista de Propietat i Valor d'una arrel sense repeticions, els atributs es llisten després dels valors dels fills.

Puc convertir diversos fitxers XML alhora?

Sí. Afegeix diversos fitxers i es converteixen en un sol lot a xml-to-pdf.zip amb un PDF per fitxer. Un sol fitxer es baixa directament amb el mateix nom base i l'extensió .pdf.

Aplica el meu full d'estil XSLT o CSS?

No. Les instruccions de fulls d'estil i les declaracions DOCTYPE s'eliminen abans d'analitzar, i la maquetació es genera només a partir de l'estructura de dades. Si necessites la renderització amb estil, obre l'XML en un navegador que apliqui el full d'estil i imprimeix-lo a PDF des d'allà.

Es renderitzarà el text en xinès, àrab, ciríl·lic o altres escriptures no llatines?

No de manera fiable. El PDF es construeix amb el tipus de lletra Helvetica estàndard de jsPDF, que cobreix els caràcters llatins, així que el text en altres escriptures pot mostrar caràcters incorrectes o absents.

Es puja el fitxer XML per convertir-lo?

No. L'anàlisi es fa amb un analitzador d'XML de JavaScript i el PDF es genera amb jsPDF, tots dos dins del navegador, de manera que les factures, els registres de transaccions i altres dades sensibles del fitxer no surten mai del teu dispositiu.
