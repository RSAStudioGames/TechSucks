Preguntes freqüents

Quins camps de metadades puc canviar?

Títol, Autor, Assumpte, Paraules clau, Creador, Productor, Data de creació i Data de modificació, més qualsevol parell clau-valor personalitzat que afegeixis. El formulari es carrega amb els valors actuals del fitxer, de manera que només edites el que cal canviar.

Com elimino completament un camp com Autor?

Esborra el quadre i desa. Tot el que hi ha al formulari s'escriu de nou, de manera que un camp buidat es desa com a buit. Per eliminar tots els camps alhora, inclosos els ocults, utilitza Elimina les metadades.

Per què canvia la data de modificació tot i que no l'he tocada?

Si el quadre Data de modificació es deixa buit, l'eina hi posa la data i l'hora actuals en desar. Defineix una data concreta al selector si cal conservar un valor determinat.

Puc afegir camps propis, com Departament o ID de projecte?

Sí. Fes clic al botó d'afegir, introdueix una clau i un valor, i el parell s'escriu al diccionari d'informació del PDF juntament amb els camps estàndard. No tots els lectors llisten les entrades personalitzades, però es queden al fitxer i apareixen en eines que llegeixen tot el diccionari d'informació, com Visualitza les metadades.

He canviat el títol però Acrobat encara mostra l'antic. Per què?

L'eina escriu al diccionari d'informació del document. Alguns PDF també porten un flux de metadades XMP, i lectors com Acrobat prefereixen XMP quan existeixen tots dos, de manera que el títol antic hi pot continuar apareixent. Executa primer Elimina les metadades i després edita, per evitar el conflicte.

Com he d'introduir les paraules clau?

Separa-les amb comes, per exemple factura, 2026, T3. Es desen com una llista de paraules clau que els sistemes de gestió documental i la cerca d'escriptori poden indexar.

Editar les metadades altera les pàgines o envia el meu fitxer enlloc?

No. Només es reescriu el diccionari d'informació; les pàgines, els tipus de lletra, els enllaços i els marcadors queden intactes, i tota l'edició es fa al teu navegador, de manera que el document no surt mai del teu dispositiu.

Puc editar les metadades d'un PDF protegit amb contrasenya?

Si el fitxer necessita una contrasenya per obrir-se, l'eina te la demana i després carrega el document amb normalitat. Sense la contrasenya, el fitxer no es pot obrir aquí.
