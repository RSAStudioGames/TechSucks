Preguntes freqüents

Quina informació pot revelar un PDF sobre mi?

El diccionari Info sovint conté el nom de l'autor (normalment el nom d'usuari del sistema operatiu o d'Office), el programari utilitzat i les marques de temps de creació i modificació. Les metadades XMP poden afegir identificadors de document, historial de revisions i detalls de l'aplicació, i també es mostren els valors emplenats als camps de formulari. Si estàs a punt de publicar o compartir el fitxer, executa després Elimina les metadades.

Quina diferència hi ha entre el diccionari Info i les metadades XMP?

El diccionari Info és el conjunt més antic de camps fixos: Títol, Autor, Assumpte, Paraules clau, Creador, Productor i dates. XMP és un bloc XML amb espais de noms com Dublin Core, xmp i pdf, i pot contenir molt més. Haurien de coincidir però sovint no ho fan, per això l'eina mostra tots dos.

Per què les dates es mostren diferent del que mostra Acrobat?

Les dates del PDF es desen com a cadenes com D:20240101120000Z. L'eina les converteix en una data llegible a la teva zona horària local, així que l'hora pot ser diferent de la d'un visor que mostri el valor en brut o faci servir una altra zona.

Com puc saber quin programa ha creat el PDF?

Mira el camp Creador (l'aplicació que va crear el document original, com Word o InDesign) i el camp Productor (la biblioteca que va escriure el PDF, com Acrobat Distiller o un motor de PDF). La secció XMP normalment els repeteix com a xmp:CreatorTool i pdf:Producer.

Mostra els valors emplenats als camps de formulari?

La secció Camps de formulari interactius llista el nom de cada camp amb el seu valor actual, o No definit quan és buit, cosa que és una manera ràpida de comprovar quines dades conté un formulari emplenat abans d'enviar-lo.

Puc copiar o exportar les metadades?

El botó Copia les metadades com a JSON posa els camps del diccionari Info al porta-retalls com a objecte JSON. L'arbre XMP i els valors dels camps de formulari es mostren a la pàgina però no s'inclouen al JSON copiat.

Puc canviar el que veig aquí?

Aquesta eina és només de lectura. Fes servir Edita les metadades per canviar el títol, l'autor, les paraules clau i les dates, o Elimina les metadades per esborrar-ho tot abans de publicar.

Es puja el PDF per llegir-ne les metadades?

No. pdf.js analitza el fitxer al navegador tan bon punt el selecciones, i no es transmet res, de manera que pots inspeccionar un document sensible abans de decidir on va.
