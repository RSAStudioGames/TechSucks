Preguntes freqüents

Com de bé conserva PDF a Markdown l'estructura del document?

Es converteixen els encapçalaments, els paràgrafs, les llistes i el format bàsic de negreta i cursiva, i cada pàgina se separa amb una línia horitzontal (---) a la sortida. Els nivells dels encapçalaments s'dedueixen de les mides de lletra, de manera que un document amb estils incoherents pot sortir amb alguns encapçalaments al nivell equivocat.

Què fa l'opció Inclou les imatges?

Quan està marcada, les imatges del PDF s'incrusten directament al Markdown com a dades base64, de manera que el fitxer .md únic és autònom però pot arribar a ser gran. Deixa-la desmarcada per a documents amb molt de text per mantenir la sortida petita i llegible en un editor de text pla.

Per què el Markdown és buit o gairebé buit?

El convertidor llegeix la capa de text del PDF, de manera que un document escanejat que només té imatges no té res per convertir. Passa'l primer per OCR PDF per afegir-hi una capa de text i després converteix el resultat.

Com gestiona els dissenys de diverses columnes, les notes a peu de pàgina i les barres laterals?

Els dissenys complexos són el punt feble: el text de diverses columnes es pot intercalar, i les barres laterals o les notes a peu de pàgina poden quedar al lloc equivocat. Compta amb haver de revisar i retocar la sortida de pàgines d'estil revista, mentre que els documents d'una sola columna necessiten poca neteja.

Puc convertir diversos PDF a Markdown alhora?

Puja diversos PDF i fes clic a Converteix una sola vegada. Un fitxer es baixa com a filename.md; si en són diversos tornen en markdown-files.zip amb un .md per PDF, i els noms duplicats reben un sufix numerat.

És el mateix que PDF a text?

No. PDF a text et dona text en brut sense estructura, cosa que va millor per passar-lo a scripts. PDF a Markdown conserva els encapçalaments, les llistes i els èmfasis, de manera que el resultat està a punt per enganxar-lo a Obsidian, una wiki o un generador de llocs estàtics.

Puc convertir un PDF protegit amb contrasenya?

Si el fitxer necessita una contrasenya per obrir-se, te la demana abans de començar la conversió i el text s'extreu amb normalitat. La contrasenya no es desa enlloc, i la sortida en Markdown no té cap protecció pròpia.

El meu PDF es puja per convertir-lo a Markdown?

No. La conversió s'executa amb un motor PyMuPDF carregat al navegador com a WebAssembly, i el fitxer .md o el ZIP es genera a la teva màquina. Els articles de recerca, els contractes i els documents interns es mantenen privats.
