Format de sortida:

Cada PDF s'extraurà com un fitxer JSON amb una llista d'objectes Document de LlamaIndex que inclouen:

  • text - Contingut de text extret per pàgina
  • metadata - Número de pàgina, encapçalaments i informació del document
  • extra_info - Context addicional per a sistemes RAG

Preguntes freqüents

Què conté la sortida JSON?

Segueix l'esquema de documents de LlamaIndex: un document per pàgina amb el text i els camps de metadades d'aquesta pàgina. Es genera amb la integració de LlamaIndex de PyMuPDF, de manera que es pot carregar directament a LlamaIndex o a qualsevol sistema que accepti text per pàgina amb metadades.

En què es diferencia de PDF a text o PDF a Markdown?

PDF a text ofereix un únic flux de text pla, i PDF a Markdown conserva els encapçalaments i l'estructura per llegir-lo. Aquesta eina divideix el contingut pàgina per pàgina i l'empaqueta en un JSON estructurat amb metadades, que és el que necessiten els sistemes de recuperació per fragmentar el contingut i citar-ne les fonts.

Funciona amb PDF escanejats?

Només si ja tenen una capa de text. Les imatges escanejades donen una sortida buida o gairebé buida, així que passa-les primer per OCR PDF i després extreu-ne el contingut.

Puc processar un lot complet de PDF?

Sí. Puja diversos fitxers i obtindràs pdf-for-ai.zip amb un yourfile_llm.json per cada PDF; un sol fitxer es baixa directament com a yourfile_llm.json. Si un fitxer del lot falla, els altres es completen igualment i el resum t'indica quants han fallat.

Puc triar quines pàgines s'extreuen o controlar la mida dels fragments?

No. No hi ha opcions; cada pàgina s'extreu amb tot el seu text i les metadades. Fes la divisió en blocs al teu propi flux, on pots triar mides que s'ajustin al teu model d'incrustació, i descarta-hi les pàgines que no necessitis.

Puc preparar per a eines d'IA un PDF protegit amb contrasenya?

Sí. Si un fitxer està xifrat, te'n demana la contrasenya abans de començar l'extracció, i el text s'extreu de la còpia desxifrada.

S'envia el meu document a un servei d'IA?

No. Malgrat el nom, no s'envia res a cap proveïdor d'IA ni a cap servidor; l'extracció s'executa amb PyMuPDF compilat a WebAssembly dins del navegador. Tu decideixes després on va el JSON.

Què puc fer amb el fitxer JSON?

Fes-lo servir en un sistema RAG, per crear una base de coneixement per a un xatbot, per analitzar informes amb LLM o per convertir una col·lecció de PDF en dades d'entrenament. Com que el contingut es divideix per pàgines amb metadades, les respostes poden remetre a la pàgina d'on provenen.
