Preguntes freqüents

Com converteixo un fitxer Markdown a PDF?

Fes clic a Puja i tria un fitxer .md, .markdown o .txt, o enganxa el text al tauler esquerre, i la vista prèvia renderitzada apareix a la dreta. Fes clic a Exporta el PDF o prem Ctrl+S (Cmd+S en un Mac), i després tria Desa com a PDF com a destinació al diàleg d'impressió que s'obre.

Puc canviar la mida de pàgina o els marges del PDF?

Defineix-ho al diàleg d'impressió: tria Letter, A4 o una altra mida de paper, ajusta els marges i redueix l'escala si una taula ampla es talla. Desactiva també allà Capçaleres i peus de pàgina si no vols que la data i l'URL s'imprimeixin a cada pàgina.

Admet blocs de codi, taules i diagrames?

Els blocs de codi tancats amb tanques tenen ressaltat de sintaxi per a JavaScript, TypeScript, Python, Go, Rust, Java, C#, C++, SQL, Bash, YAML, JSON, HTML i CSS, i les taules estàndard amb barres verticals es renderitzen com a taules. Els blocs de codi Mermaid es dibuixen com a diagrames de flux, diagrames de seqüència i altres tipus de gràfics, tant a la vista prèvia com al PDF.

Quines extensions de Markdown funcionen a més de les bàsiques?

Llistes de tasques, notes a peu de pàgina, llistes de definicions, abreviatures, subíndexs i superíndexs, marques ==ressaltat== i ++inserit++, codis curts d'emoji com :smile: i enllaçat automàtic d'URL soltes. El diàleg de configuració té interruptors per a HTML en brut, salts de línia, enllaçat automàtic i cometes tipogràfiques.

El tema fosc afecta el PDF exportat?

No. L'interruptor de tema només canvia els colors de l'editor en pantalla; el full d'estil d'impressió força un fons blanc i text fosc, així que el PDF té el mateix aspecte en qualsevol cas.

Puc afegir una taula de continguts al PDF?

Posa ${toc} en una línia pròpia on vulguis la taula de continguts i es genera a partir dels teus encapçalaments quan es renderitza el document. Els encapçalaments també reben identificadors d'ancoratge, així que els enllaços dins del document cap a un encapçalament funcionen a la vista prèvia.

Puc incloure imatges al PDF?

Fes servir la sintaxi estàndard d'imatges de Markdown amb una URL d'imatge completa o un URI de dades, i la imatge es renderitza a la vista prèvia i s'imprimeix al PDF. Les rutes relatives a fitxers del teu disc no es carregaran, perquè l'editor no té accés a les teves carpetes locals.

Es puja el meu text Markdown a un servidor per fer el PDF?

No. El Markdown es renderitza a HTML amb markdown-it al teu navegador i el PDF el crea la funció d'impressió del navegador, així que ni el text ni el PDF acabat passen per cap servidor. Les notes, els esborranys i els documents interns es queden a la teva màquina.
