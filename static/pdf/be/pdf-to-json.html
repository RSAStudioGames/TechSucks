Частыя пытанні

Што змяшчае JSON?

Поўная структура аб'ектаў PDF у тым выглядзе, у якім яе чытае cpdf: трэйлер, каталог, дрэва старонак, кожны слоўнік і паток зместу кожнай старонкі, разабраны ў спіс аператараў малявання і тэксту. Гэта поўны дамп файла, а не кароткі змест.

Ці падыходзіць гэты інструмент, каб атрымаць тэкст з PDF у выглядзе JSON?

Звычайна не. Тэкст тут раскіданы па аператарах патоку зместу ў парадку малявання, са шрыфтамі і пазіцыямі, але без абзацаў. Для чытэльнага тэксту старонак у структураваным фармаце скарыстайцеся Падрыхтоўкай PDF для ШІ, а для звычайнага тэксту - «PDF у тэкст».

Ці можна пераўтварыць JSON назад у PDF?

Не ў BentoPDF. Вывад ідзе ва ўласным фармаце JSON cpdf, які інструмент каманднага радка cpdf можа прачытаць назад у PDF, але інструмент у браўзеры працуе толькі ў адзін бок.

Чаму JSON нашмат большы за PDF?

Патокі зместу разгортваюцца ў масівы аператараў, бінарныя даныя патокаў, напрыклад выяў, кадуюцца як тэкст, а кожны аб'ект запісваецца з усімі ключамі, таму JSON-файл у некалькі разоў большы за крыніцу - гэта нармальна. Вялікія PDF або PDF з багатымі выявамі даюць вельмі вялікія файлы.

Ці можна пераўтварыць некалькі PDF у JSON адначасова?

Абірайце колькі заўгодна; кожны пераўтвараецца ў фонавым воркеры, а вынікі пакуюцца ў pdfs-to-json.zip з адным .json на PDF з назвай зыходнага файла. Адзін PDF таксама прыходзіць у ZIP.

Ці працуе ён з зашыфраванымі PDF?

Пароль запытваецца перад пачаткам пераўтварэння, і серыялізуецца расшыфраваная копія. Без пароля структуру аб'ектаў прачытаць нельга.

Для чаго гэта карысна?

Для вывучэння ўнутранай будовы PDF пры адладцы генератара, праверкі таго, што ёсць у патоку зместу старонкі, структурнага параўнання дзвюх версій або перадачы дрэва аб'ектаў у скрыпт. Для адных толькі ўласцівасцей дакумента хутчэй спраўляецца Прагляд метаданых.

Ці запампоўваецца PDF, каб стварыць JSON?

Не. cpdf працуе як WebAssembly у web worker у вашым браўзеры, а JSON запісваецца і архівуецца на вашай прыладзе перад сцягваннем.
