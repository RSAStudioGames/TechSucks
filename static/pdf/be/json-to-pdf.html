Частыя пытанні

Ці магу я канвертаваць любы файл JSON у PDF з гэтым інструментам?

Не. Ён толькі перабудоўвае PDF з файлаў JSON, створаных інструментам PDF у JSON BentoPDF, які захоўвае поўную ўнутраную структуру дакумента. JSON-экспарт з API, базы даных або файла канфігурацыі скончыцца памылкай.

Як замест гэтага ператварыць даныя API або файл канфігурацыі ў чытэльны PDF?

Устаўце або загрузіце JSON як звычайны тэкст у Тэкст у PDF, які размяшчае яго як фарматаваны тэкст на старонках. JSON у PDF патрэбны толькі для зваротнага пераўтварэння дакументаў, якія пачыналіся як PDF.

Ці будзе перабудаваны PDF супадаць з арыгіналам?

JSON, створаны PDF у JSON, змяшчае аб'екты дакумента, таму канвертаванне назад аднаўляе старонкі, тэкст і відарысы зыходнага файла. Канвертаванне назад і параўнанне таксама хуткі спосаб пераканацца, што экспарт захапіў усё.

Што я атрымаю, калі канвертую некалькі файлаў JSON?

Кожнае канвертаванне спампоўваецца як jsons-to-pdf.zip, нават для аднаго файла. Унутры кожны PDF мае назву зыходнага JSON, таму report.json становіцца report.pdf.

Ці магу я рэдагаваць JSON перад канвертаваннем назад?

Так, пакуль структура застаецца сапраўднай для рухавіка CPDF. Праграмныя змены ў JSON, напрыклад адрэдагаваныя метаданыя або тэкставыя аб'екты, перабудоўваюцца ў PDF; няправільная праўка выклікае памылку канвертавання.

Чаму інструмент піша, што рухавік CPDF недаступны?

Канвертаванне залежыць ад зборкі CPDF WebAssembly. На bentopdf.com яна ўключана, але для копіі з уласным размяшчэннем файлы CPDF WASM трэба наладзіць у наладах WASM, перш чым гэты інструмент будзе працаваць.

Ці загружаецца мой файл JSON на сервер?

Не. Файлы чытаюцца ў вашым браўзеры і перабудоўваюцца ў PDF праз Web Worker з рухавіком CPDF лакальна, таму нічога не перадаецца, а старонка застаецца чуйнай падчас вялікіх канвертаванняў.
