Частыя пытанні

Што «PDF у ZIP» робіць з маімі файламі?

Нічога, акрамя ўпакоўкі. PDF капіююцца ў адзін pdfs_archive.zip з зыходнымі назвамі, без змен, у парадку іх дадання, таму тое, што выходзіць з ZIP, байт у байт такое самае, што ўвайшло.

Ці робіць архіваванне PDF меншымі?

Не. Архіў запісваецца без сціску, бо змест PDF ужо сціснуты ўнутры і амаль не паменшыўся б, таму чакайце, што ZIP будзе прыкладна роўны па памеры сумарнаму памеру файлаў. Каб паменшыць памер, спачатку прапусціце іх праз Сціск PDF і дадайце вынікі ў ZIP.

У чым розніца паміж архіваваннем PDF у ZIP і іх аб'яднаннем?

ZIP захоўвае кожны PDF як асобны файл унутры аднаго кантэйнера, які атрымальнік распакоўвае. Аб'яднанне злучае старонкі ў адзін дакумент PDF, што патрэбна, калі файлы трэба чытаць як адзін дакумент; для гэтага скарыстайцеся Аб'яднаннем PDF.

Што, калі ў двух маіх файлаў аднолькавая назва?

Паўторныя назвы апрацоўваюцца аўтаматычна: другі файл становіцца name (1).pdf, трэці name (2).pdf і гэтак далей, таму ўнутры архіва нічога не перазапісваецца. Перайменуйце файлы перад запампоўваннем, калі хочаце мець змястоўныя назвы.

Ці можна дадаваць у архіў файлы, што не з'яўляюцца PDF?

Не. Прымаюцца толькі файлы з пашырэннем .pdf або тыпам файла PDF; усё астатняе ігнаруецца. Для змешанага набору скарыстайцеся ўбудаванай функцыяй архівацыі вашай аперацыйнай сістэмы.

Ці патрэбна атрымальніку спецыяльная праграма, каб адкрыць архіў?

Не. Вывад - стандартны файл ZIP, які Windows, macOS, iOS і Android адкрываюць без дадатковых праграм; двойчы пстрыкніце або націсніце на яго, каб распакаваць PDF.

Ці запампоўваюцца мае PDF для стварэння ZIP?

Не. Архіў збіраецца ў вашым браўзеры, таму файлы чытаюцца з вашага дыска, а ZIP запісваецца назад на яго без якой-небудзь перадачы па сетцы. Такое збіранне рахункаў, кантрактаў або медыцынскіх запісаў пакідае іх на вашай прыладзе.
