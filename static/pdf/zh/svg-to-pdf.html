常见问题

PDF 是矢量还是图像？

是图像。每个 SVG 由您的浏览器渲染到画布上，位图再放入 PDF 页面，因此结果缩放会有损失，文本也无法选中。如果您需要真正的矢量输出，请改用 Inkscape 等矢量编辑器导出 PDF。

页面会是多大？

页面与 SVG 的 width 和 height 属性（以像素计）一致，一像素对应一个 PDF 点。没有 width 和 height（只有 viewBox）的 SVG 会按 800 x 600 渲染，因此请在文件中设置明确的尺寸以获得可预期的结果。

质量设置对 SVG 转换有什么影响？

“高”会以完整尺寸保留无损 PNG。“中”会将其重新编码为 75% 质量的 JPEG，并把长边限制在 2500 像素；“低”使用 50% 和 1500 像素，页面也会随之缩小。对于线稿和文字，“高”可避免 JPEG 瑕疵。

我能控制输出分辨率吗，比如 300 DPI？

没有 DPI 设置；渲染使用 SVG 自身的像素尺寸。如需更多像素，请在保留 viewBox 的情况下增大 SVG 源码中的 width 和 height 属性，然后再转换。

为什么我的 SVG 转换后缺少文本、字体或图像？

SVG 根据其自身标记渲染，因此对外部文件的引用（链接的图像、导入的字体、外部 CSS）无法在该环境中加载，会回退或消失。转换前请把图像嵌入为 data URI，并将文本转为路径。

透明度会保留吗？

不会。绘制 SVG 之前画布会先填充白色，因此透明区域在 PDF 中会变成白色。

我能把多个 SVG 放进一个 PDF 吗？

上传多个文件后，它们会按文件列表中显示的顺序成为单个 from_svgs.pdf 的连续页面。每一页采用各自 SVG 的尺寸。

转换时 SVG 会被上传吗？

不会。渲染在您浏览器的画布上进行，PDF 由 pdf-lib 在您的设备上生成；不会向任何地方发送内容。
