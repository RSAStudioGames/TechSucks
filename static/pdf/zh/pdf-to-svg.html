常见问题

SVG 中的文字仍然可以选择吗？

不会。每一页导出时文字都被绘制为矢量轮廓，因此缩放清晰，也不依赖已安装的字体，但它不是可以选择或搜索的实时文字。如果您需要文字本身，请在使用 SVG 的同时使用PDF 转文本。

是整个文档一个 SVG，还是每页一个？

每页一个，因为 SVG 没有页面的概念。单页 PDF 会下载为 filename.svg，多页 PDF 会变成 filename_svg.zip，其中包含 page_1.svg、page_2.svg 等，一次转换多个 PDF 则会下载为 pdf_to_svg.zip。

可以在 Illustrator 或 Inkscape 中编辑结果吗？

输出是标准的 SVG，可在 Inkscape、Illustrator、Figma 和任何网页浏览器中打开。形状、路径和文字轮廓会作为可编辑的矢量对象呈现，而 PDF 中嵌入的照片则在文件内保持为栅格图像。

为什么我的 SVG 文件这么大？

扫描件或照片较多的 PDF 会生成很大的 SVG，因为每张栅格图片都以 base64 数据嵌入文件，而带有成千上万个微小矢量路径的页面也会累积体积。对于基于图片的页面，PDF 转 PNG能给出更小、更实用的结果。

可以一次转换多个 PDF 吗？

可以把任意数量的 PDF 拖入工具，然后点击“转换”。每个文件依次处理，结果会收集到 pdf_to_svg.zip 中，并以其源文档命名。

有页面范围或尺寸之类的选项吗？

没有。每个上传文件的每一页都按其原始页面大小转换，没有缩放或范围选择。若只想转换某些页面，请先用提取页面把它们拆分出来。

可以把受密码保护的 PDF 转换为 SVG 吗？

上传后会提示您输入密码，密码被接受后转换才会继续。SVG 文件本身不带密码。

转换时我的 PDF 会被上传吗？

不会。PyMuPDF 以 WebAssembly 的形式在您的浏览器内运行，并在本地写入 SVG 文件，因此 PDF 不会离开您的机器。引擎会在首次使用时获取，所以第一次转换会稍慢一些。
