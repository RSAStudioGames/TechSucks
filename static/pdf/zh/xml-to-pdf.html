常见问题

工具如何决定 PDF 的外观？

它会解析 XML，按标签名对重复的同级元素分组，并将每组渲染为一张表，每个子元素一列，以元素名作为表头。如果根元素下没有重复的子元素，则得到一张“属性”和“值”两列的表。输出为横向 A4，以根元素名称作为标题。

什么样的 XML 效果最好？

数据型 XML：同一父元素下重复出现、带有相同子元素集合的记录，例如数据库导出、发票明细、商品数据源、RSS 订阅源或站点地图。深度嵌套或文档型 XML 会被展平，嵌套的值会合并到一个单元格中并失去层级。

为什么我会收到“无效 XML”错误？

文件格式不规范：标签未闭合、缺少根元素、存在未转义的 & 或 < 字符，或编码有误。消息中包含解析器给出的原因，请在编辑器或验证工具中修正文件后重试。

PDF 中包含 XML 属性吗？

部分包含。在表格视图中，只有子元素会成为列，因此重复记录上的属性不会显示。在非重复根元素的“属性”和“值”视图中，属性会列在子元素的值之后。

我能一次转换多个 XML 文件吗？

可以。添加多个文件后，它们会一次批量转换为 xml-to-pdf.zip，每个文件一个 PDF。单个文件会直接下载，文件名相同，扩展名为 .pdf。

它会应用我的 XSLT 样式表或 CSS 吗？

不会。样式表指令和 DOCTYPE 声明会在解析前被去除，版面仅由数据结构生成。如果您需要带样式的渲染效果，请在会应用样式表的浏览器中打开该 XML，并从那里打印为 PDF。

中文、阿拉伯文、西里尔文或其他非拉丁文字能正常渲染吗？

不能保证。PDF 使用 jsPDF 的标准 Helvetica 字体构建，它涵盖拉丁字符，因此其他文字的文本可能显示为错误或缺失的字符。

转换时 XML 文件会被上传吗？

不会。解析使用 JavaScript XML 解析器，PDF 由 jsPDF 生成，两者都在您的浏览器内完成，因此文件中的发票、交易日志和其他敏感数据不会离开您的设备。
