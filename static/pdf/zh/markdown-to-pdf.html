常见问题

如何将 Markdown 文件转换为 PDF？

点击“上传”并选择 .md、.markdown 或 .txt 文件，或将文本粘贴到左侧窗格，渲染后的预览会显示在右侧。点击“导出 PDF”或按 Ctrl+S（Mac 上为 Cmd+S），然后在打开的打印对话框中选择“另存为 PDF”作为目标。

可以更改 PDF 的页面尺寸或边距吗？

请在打印对话框中设置：选择 Letter、A4 或其他纸张尺寸，调整边距，如果宽表格被截断，可降低缩放比例。如果不想在每页上打印日期和 URL，也请在那里关闭“页眉和页脚”。

它支持代码块、表格和图表吗？

围栏代码块支持 JavaScript、TypeScript、Python、Go、Rust、Java、C#、C++、SQL、Bash、YAML、JSON、HTML 和 CSS 的语法高亮，标准的管道表格会渲染为表格。Mermaid 代码块会在预览和 PDF 中绘制为流程图、时序图和其他图表类型。

除基础语法外，还支持哪些 Markdown 扩展？

任务列表、脚注、定义列表、缩写、上标和下标、==高亮== 和 ++插入++ 标记、:smile: 等表情符号短代码，以及裸 URL 的自动链接。设置对话框中有原始 HTML、换行、自动链接和排版引号的开关。

深色主题会影响导出的 PDF 吗？

不会。主题切换只改变屏幕上的编辑器颜色；打印样式表会强制使用白色背景和深色文字，因此无论哪种主题，PDF 看起来都一样。

可以为 PDF 添加目录吗？

在需要目录的位置单独一行写上 ${toc}，文档渲染时就会根据您的标题生成目录。标题还会获得锚点 ID，因此文档内指向标题的链接可以在预览中使用。

可以在 PDF 中包含图片吗？

使用标准的 Markdown 图片语法，配合完整图片 URL 或 data URI，图片就会在预览中渲染并打印到 PDF 中。指向磁盘上文件的相对路径无法加载，因为编辑器无法访问您的本地文件夹。

生成 PDF 时我的 Markdown 文本会被上传到服务器吗？

不会。Markdown 由 markdown-it 在您的浏览器中渲染为 HTML，PDF 由浏览器的打印功能生成，因此文本和最终的 PDF 都不会经过服务器。笔记、草稿和内部文档都留在您的设备上。
