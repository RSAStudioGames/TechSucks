常见问题

什么是 FB2 文件？

FB2 是 FictionBook 2 电子书格式，一种基于 XML 的格式，在俄罗斯和东欧很常见。它将书籍的文字、章节结构和任何嵌入图片存储在单个文件中，但该地区以外的许多阅读器和手机无法打开它，因此转换为 PDF 会很有帮助。

转换会保留章节、格式和图片吗？

章节分隔、基本文字格式以及 FB2 文件中嵌入的图片都会带入 PDF。PyMuPDF 引擎直接读取 XML 结构，因此无需任何配置。

可以转换 .fb2.zip 文件吗？

不能直接转换。此工具只接受普通的 .fb2 文件，因此请先解压压缩包，再上传其中的 .fb2 文件。

可以一次转换多本 FB2 书籍吗？

可以选择或拖入任意数量的文件，然后点击“转换为 PDF”。单本书会下载为同名 PDF，多本书则会打包为 fb2-converted.zip，每本书对应一个 PDF。

转换前可以更改页面尺寸或字体吗？

不可以。此转换器没有版式选项；引擎会以默认的页面尺寸和排版为书籍分页。如果之后需要不同的页面尺寸，请将结果用修复页面尺寸处理。

俄语或其他西里尔文字能正确转换吗？

FB2 文件是 Unicode XML，转换器会渲染 Unicode 文本，因此西里尔文书籍会完整保留原有字符。文字在 PDF 中仍可选中和搜索。

转换期间我的电子书会被上传吗？

不会。FB2 文件由在您浏览器中运行的 PDF 引擎解析和排版，只有完成的 PDF 会保存到您的设备。不会向服务器发送任何内容，因此转换也适用于草稿和个人文档。

为什么 PDF 的页数与我的电子书阅读器显示的不同？

FB2 是可重排格式，因此页数取决于各阅读器中的屏幕尺寸和字体设置。PDF 会在转换时固定版式，通常会得到不同的页数，而且此后不再改变。
