常见问题

清理 PDF 实际会移除什么？

共十项，每项都有各自的复选框：表单字段会被拼合，元数据、批注、JavaScript、嵌入文件、图层、链接、结构树、MarkInfo 以及可选的嵌入字体会被清除。除字体移除外，其余默认全部勾选。

清理后的 PDF 看起来会不同吗？

页面内容本身不受影响，但一些交互部分会变为静态。表单字段变成普通文本，超链接不再可点击，评论、高亮和便笺会消失，因此发送前请检查结果。

我应该勾选“移除嵌入字体”吗？

通常不需要。它会删除 PDF 依赖的字体程序，如果阅读器无法替换匹配的字体，文本可能显示错误或完全无法显示。除非您有特定理由并已测试过结果，否则请保持不勾选。

它会移除作者姓名、创建日期和编辑软件吗？

“移除元数据”会清除信息字典、XMP 元数据流、文档 ID 和应用专用 PieceInfo，因此作者、标题、日期和生成软件都会消失。如果您只需要这一步，移除元数据只做这件事。

它能阻止 PDF 打开时运行的脚本吗？

“移除 JavaScript”会删除文档的脚本树、打开动作，以及附加在文档、页面、批注和表单字段上的自动动作。这涵盖了 PDF 在打开、打印或字段更改时可能隐藏运行代码的常见位置。

清理会涂黑页面上的敏感文本吗？

不会。它清除的是内容周围的隐藏数据和交互数据，而不是可见的文字或图像，因此页面上能读到的内容都还在。如果您需要把页面内容变成没有可选文本的扁平图片，请使用栅格化 PDF。

我能清理受密码保护的 PDF 吗？

上传后会要求您输入密码。清理后的副本不加密，因此如果文档仍需受保护，请之后再用保护 PDF 处理。

在这里清理一个我不信任的 PDF 安全吗？

文件在您的浏览器中作为数据解析，从不上传，工具也不会执行其中的任何脚本。请保留原件，以防被清除的元素日后需要，因为清理后无法从输出文件中还原。
