常见问题解答

用密码保护 PDF 和限制其权限有什么区别？

用保护 PDF设置的用户密码是打开文件所必需的。权限是存储在加密内部的标志，用于控制读者打开后可以做什么，例如打印、复制、编辑、批注或填写表单，只有在设置了所有者密码时才会生效。“更改权限”可让您逐项允许或禁止每个操作，而“保护 PDF”在您添加所有者密码时会立即应用最严格的一组权限。

密码保护有多强？

“保护 PDF”和“更改权限”使用 256 位 AES 加密（PDF 2.0 标准），由在您浏览器中运行的 QPDF 应用。加密本身无法通过暴力破解实现，所以薄弱环节在于密码：请使用较长的口令，并通过与文件不同的渠道发送。权限标志是另一回事，它们依赖阅读器遵守，有些第三方工具会忽略它们。

如果不知道密码，可以从 PDF 中移除密码吗？

不能。解锁 PDF需要密码，然后保存一份不再有任何加密或限制的副本，所有工具都不会破解或暴力枚举密码。如果文件可以正常打开但禁止打印或复制，请改用“移除限制”，如果文件设置了所有者密码，它会要求您输入。

签署 PDF 和数字签名有什么区别？

“签署 PDF”会把手绘、键入或上传的签名图片放到页面上，还可以选择将其拼合，这样之后就没有人能移动或删除它。数字签名使用您自己的 X.509 证书（.pfx、.p12 或 .pem）应用加密签名，可证明签署人身份以及文件自签署以来未被更改，“验证签名”则检查文件中已有的签名。证书签名可能需要联网获取证书链，自签名证书在 Adobe Reader 中会显示警告。

如何涂黑文字才能真正去除它？

请使用 PDF 编辑器中的涂黑工具。标记文字或区域只是做个标记。应用涂黑后，被标记的内容会从页面上被永久移除，而不是只用方框盖住；如果在尚未应用标记的情况下下载，编辑器会提示先应用它们。涂黑所选文字时，除非文件已加密，文件属性、书签、批注和附件中的该文字副本也会在下载时一并移除。区域涂黑没有可供搜索的文字，因此如果文件的属性、批注或附件可能泄露相同的信息，请再对结果运行“移除元数据”或“清理 PDF”。

移除元数据和清理 PDF 有什么区别？

移除元数据只清除文档属性：标题、作者、日期、生成程序、XMP 数据、文档 ID 以及特定应用程序的数据，页面、表单、链接和书签保持不变。“清理 PDF”更进一步，还可以拼合表单，并删除批注、嵌入的 JavaScript、附件、图层、链接和结构标签，每一项都可单独选择。两者都不可逆，所以请保留原始文件。

拼合 PDF 有什么作用，什么时候应该使用？

拼合 PDF会把表单字段和批注（评论、高亮、印章、便笺、签名字段）烧录进页面内容，使它们看起来不变，但无法再被编辑、移动或移除。请在表单填写完成或签名放置之后、发送文件之前使用它，因为无法撤销拼合。文字仍可选择和搜索，书签也会保留。

我的密码、证书或文件会被发送到服务器吗？

不会。加密、解锁、清理和签名都以 WebAssembly 的形式在您的浏览器中运行，因此文档、您输入的密码以及证书的私钥都保留在您的设备上。唯一的网络例外是数字签名，它可能会联系您证书颁发机构的服务器以获取证书链；文档本身仍然绝不会被发送。
