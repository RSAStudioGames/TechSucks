常见问题

可以为我已有的 PDF 添加可填写字段吗？

上传 PDF 后，其页面会出现在编辑器中；从工具栏选择字段类型并点击页面放置，然后根据需要拖动或调整大小。如果 PDF 已有表单字段，它们会被检测并载入，方便您与新字段一起移动、编辑或删除。

可以不依赖现有 PDF，从零开始创建表单吗？

点击“创建空白 PDF”，然后选择 Letter、A4、A5、Legal、Tabloid、A3，或以点为单位的自定义尺寸。多页表单请使用“添加页面”。

有哪些字段类型可用？

文本（单行、多行或分格梳状框）、复选框、单选按钮组、下拉菜单、列表框、命令按钮、签名、日期、图片和条形码。每个字段都有属性面板，可设置名称、默认值、字号、文字颜色、对齐方式、提示文字，以及必填或只读标记。签名字段是标准的 AcroForm 签名字段，只会在支持签名的阅读器中显示。

单选按钮如何分组，才能只选中一个？

每个单选字段都有一个组名，默认为 RadioGroup1。组名相同的字段会成为一组互斥选项，因此请为每个问题使用各自的组名，并为每个选项设置不同的导出值。

按钮可以显示或隐藏其他字段，或重置表单吗？

按钮动作包括重置表单、打印表单、打开 URL、运行 JavaScript 以及显示/隐藏字段，后者以另一个字段为目标，可以显示、隐藏或切换它。它们以标准 PDF 动作形式存储，因此可在 Acrobat 和其他支持表单脚本的阅读器中运行。

日期字段如何工作？

它是附带日期格式的文本字段，默认为 mm/dd/yyyy，也可以是自定义格式，如 dd/mm/yyyy。支持 AcroForm JavaScript 的阅读器会校验并格式化输入的值；较简单的阅读器则将其视为普通文本。

条形码和图片是真正的表单字段吗？

条形码（QR Code、Code 128、Code 39、EAN-13、UPC-A、DataMatrix 或 PDF417）会根据您输入的值生成，并作为固定图片绘制到页面上，因此填写表单的人无法更改。图片字段是一个按钮，用户可以从电脑中选择图片，这在 Acrobat 和其他支持图片导入的阅读器中可用。

表单或上传的 PDF 会存储在服务器上吗？

不会。编辑器在您的浏览器中运行，字段由 pdf-lib 在您的设备上写入 PDF，“下载 PDF 表单”会以原文件名将结果保存在本地。您可以在PDF 表单填写器中测试结果。
