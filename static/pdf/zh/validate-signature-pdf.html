常见问题

如何检查已签名的 PDF 在签署后是否被更改过？

上传 PDF 后验证会自动开始。对于每个签名，工具会对签名所覆盖的字节做哈希，将该哈希与签名内存储的摘要比较，然后用签名者的公钥验证签名；覆盖范围内的字节只要有任何改动，状态就会变为“无效”，原因显示在卡片上。文件中的每个签名都有各自的卡片，顶部的摘要会统计找到了多少个。

“有效”“无效”和“未验证”分别是什么意思？

“有效”表示签名已通过加密验证、覆盖整个文件并使用安全摘要。“无效”表示验证已运行但失败，例如字节被更改或密钥不匹配。“未验证”表示签名使用了工具无法检查的算法，如 Ed25519 或 SM2，因此在依赖它之前，请在 Adobe Acrobat 或用 openssl 确认。

支持哪些签名算法？

支持 PKCS#1 v1.5 填充的 RSA、RSA-PSS，以及 P-256、P-384 和 P-521 曲线上的 ECDSA，摘要为 SHA-224、SHA-256、SHA-384 或 SHA-512。使用 MD5 或 SHA-1 哈希的签名会被标记为“摘要不安全”状态，绝不会报告为有效，因为这两种算法都已有公开的碰撞攻击。

为什么卡片上显示“签名者身份未验证”？

工具没有内置的证书颁发机构列表，因此单靠自身只能确认签名完好，无法确认证书背后是谁。请上传贵组织的根证书或中间证书（.pem、.crt、.cer 或 .der 文件），验证会重新运行：证书与之匹配或链接到它的签名会获得“受信任”标记，摘要会将这些计为有效。

部分覆盖意味着文档被篡改了吗？

这表示在应用该签名之后又追加了字节。被签名的部分仍然完整，因此工具会显示“签署后已修改”警告，而不是将签名标记为无效。这本身并不能证明遭到篡改：第二个签名或增量保存会产生同样的结果，而且只有最后添加的签名才能覆盖整个文件。请把它当作查看新增内容的理由。

它会检查签名证书是否已被吊销吗？

不会。工具会检查证书的有效期、依据您提供的证书检查信任链，以及签名的加密完整性，但不会查询 OCSP 响应服务器或证书吊销列表。如需检查吊销情况，请在可联网的桌面工具中验证该文件。

如果证书在文档签署之后过期了会怎样？

有效期以今天的日期为准，因此证书如果已过“有效期至”日期，会显示“证书已过期”状态，即使签名本身验证通过，也不会在摘要中计为有效。请将卡片上的“签署时间”与“有效期自”和“有效期至”日期比较，以判断证书在签署时是否有效。

已签名的 PDF 或我的受信任证书会被上传到别处吗？

不会。签名解析和加密校验都在您的浏览器中使用 node-forge 和 Web Crypto API 运行，因此文档和您添加的任何证书都留在您的设备上。
