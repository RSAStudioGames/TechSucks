常见问题

JSON 包含什么内容？

cpdf 所读取的 PDF 的完整对象结构：尾部、目录、页面树、每个字典，以及每页被解析为绘图和文字操作符列表的内容流。这是文件的完整转储，而不是摘要。

这是把 PDF 中的文字提取为 JSON 的合适工具吗？

通常不是。这里的文字按绘制顺序分散在内容流操作符中，带有字体和位置，但没有段落。若要以结构化格式获取可读的页面文字，请使用为 AI 准备 PDF，纯文本请使用 PDF 转文本。

可以把 JSON 转换回 PDF 吗？

BentoPDF 做不到。输出遵循 cpdf 自己的 JSON 格式，cpdf 命令行工具可以把它读回 PDF，但浏览器工具只支持单向转换。

为什么 JSON 比 PDF 大这么多？

内容流会被展开为操作符数组，图片等二进制流数据会被编码为文本，每个对象都带着它的键写出，因此 JSON 文件比源文件大数倍是正常的。大型或图片较多的 PDF 会生成非常大的文件。

可以一次把多个 PDF 转换为 JSON 吗？

可以选择任意数量的文件；每个文件在后台 worker 中转换，结果会打包为 pdfs-to-json.zip，每个 PDF 对应一个以源文件命名的 .json。单个 PDF 也会以 ZIP 形式提供。

它能处理加密的 PDF 吗？

转换开始前会要求您输入密码，然后对解密后的副本进行序列化。没有密码就无法读取对象结构。

这有什么用？

在调试生成器时检查 PDF 的内部结构、查看页面内容流包含什么、从结构上比较两个版本，或把对象树输入脚本。如果只需要文档属性，查看元数据更快。

生成 JSON 时 PDF 会被上传吗？

不会。cpdf 以 WebAssembly 的形式在您浏览器的 web worker 中运行，JSON 在下载前就在您的设备上写入并压缩。
