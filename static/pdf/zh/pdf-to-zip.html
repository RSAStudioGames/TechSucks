常见问题

PDF 转 ZIP 究竟会对我的文件做什么？

除了打包什么都不做。这些 PDF 会按您添加的顺序，以原始名称原封不动地复制到单个 pdfs_archive.zip 中，因此从 ZIP 中取出的内容与放入的内容逐字节完全一致。

打包成 ZIP 会让 PDF 变小吗？

不会。压缩包是不经压缩写入的，因为 PDF 内容内部已经压缩过，几乎不会再缩小，所以 ZIP 的大小约等于这些文件大小之和。若要减小体积，请先用压缩 PDF处理，再把结果打包。

把 PDF 打包成 ZIP 和合并它们有什么区别？

ZIP 会把每个 PDF 作为独立文件放在一个容器中，由接收者解压。合并则是把页面合并成一个 PDF 文档，当这些文件应作为单个文档阅读时，这正是您想要的；请使用合并 PDF。

如果我的两个文件同名怎么办？

重名文件会自动处理：第二个文件变为 name (1).pdf，第三个变为 name (2).pdf，依此类推，因此压缩包内不会覆盖任何文件。如果您希望使用有意义的名称，请在上传前重命名文件。

可以把非 PDF 文件添加到压缩包吗？

不可以。只接受扩展名为 .pdf 或文件类型为 PDF 的文件；您放入的其他任何文件都会被忽略。若要打包混合文件，请改用操作系统内置的压缩功能。

接收者需要特殊软件才能打开压缩包吗？

不需要。输出是标准的 ZIP 文件，Windows、macOS、iOS 和 Android 无需额外软件即可打开；双击或点击它即可解压出这些 PDF。

生成 ZIP 时我的 PDF 会被上传吗？

不会。压缩包在您的浏览器中生成，文件从您的磁盘读取，ZIP 再写回磁盘，不经过任何网络传输。用这种方式打包发票、合同或医疗记录，可以让它们保留在您的设备上。
