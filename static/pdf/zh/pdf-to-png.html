常见问题

PNG 的分辨率是多少？

缩放 1.0x 以页面每英寸 72 像素渲染，因此一张 Letter 页面会变成 612 x 792 像素。默认的 2.0x 会翻倍到 1224 x 1584，而 3.0x 为 1836 x 2376，即每英寸 216 像素。

可以以 300 DPI 导出用于印刷吗？

不能直接设置。滑块最高为 3.0x，在标准页面上约为 216 DPI，这个工具中也没有输入自定义 DPI 的字段。

背景是透明的吗？

不是。页面绘制在白色背景上，因此没有内容的区域是白色而不是透明的，尽管 PNG 支持透明。

可以只把某些页面转换为 PNG 吗？

每一页都会转换；没有页面范围字段。请先用提取页面取出您需要的页面，再转换那个较小的文件。

文件是如何命名的？

单页 PDF 会下载为 filename.png。多页文档会下载为 filename_pngs.zip，其中包含按文档顺序排列的 page_1.png、page_2.png 等。

为什么 PNG 文件这么大？

PNG 是无损的，所以一整页在 2.0x 下往往有几兆字节，尤其是扫描件和照片。如果可以接受一定的压缩，PDF 转 JPG或 PDF 转 WebP 能从相同的页面生成小得多的图片。

批注和已填写的表单字段会出现在图片中吗？

高亮、印章和已填写的表单字段等可见标记会按它们在页面上的样子渲染。弹出批注中的文字不会被绘制，只会显示便笺图标。

PDF 是在服务器上渲染的吗？

不会。渲染在您的浏览器中使用 PDF.js 完成，ZIP 在本地构建，因此文档不会离开您的电脑。如果 PDF 需要密码，会先要求您输入。
