常见问题解答

哪些文件格式可以转换为 PDF？

Word、Excel 和 PowerPoint 文件（包括较旧的 DOC、XLS 和 PPT 格式）、OpenDocument 文本、电子表格、演示文稿和绘图、RTF、纯文本、Markdown、CSV、XML、EPUB、MOBI、FB2 和 CBZ 格式的电子书、XPS、Publisher、Visio、WordPerfect、Microsoft Works、Apple Pages，以及 JPG、PNG、HEIC、WebP、TIFF、BMP、SVG 和 PSD 格式的图片。如果您有一个包含多种图片类型的文件夹，图片转 PDF可以一次接受全部图片，并让每张图片单独占一页。

PDF 可以转换成什么？

Word（DOCX）、Excel（XLSX）、CSV、纯文本、Markdown、SVG，以及 JPG、PNG、WebP、TIFF 或 BMP 格式的页面图片，多页 PDF 会以 ZIP 形式提供，每页一张图片。若需长期归档，PDF 转 PDF/A可输出 PDF/A-1b、2b 或 3b，另有单独的工具可将彩色 PDF 转为灰度 PDF。

PDF 转 Word 会保留版面吗？

PDF 转 Word会重建文档的文字、基本格式和整体版面，并且一次可以转换一批文件。含有多栏、嵌入表单或大量图形的页面可能无法完美转换，因此请预留时间在文字处理软件中进行整理。

为什么转换后的 Word 或文本文件是空的？

这个 PDF 几乎可以肯定是扫描件，它把每一页存储为没有文本层的图片，所以 PDF 转 Word、PDF 转文本和表格转换器都没有内容可提取。请先用 OCR PDF添加可搜索的文本层，再转换处理后的文件。

可以把 PDF 中的表格提取到 Excel 吗？

PDF 转 Excel会扫描每一页中的表格，并把每个表格写入各自的工作表，工作表以来源页面命名。如果提示未找到表格，说明该 PDF 是以零散文字而不是真正的表格结构来排列数据的；PDF 转 CSV 和提取表格使用相同的检测方式，因此可以试试 PDF 转文本来获取原始内容。

转换 Word、Excel 或 PowerPoint 文件需要安装 Microsoft Office 吗？

不需要。这些文件，以及 Publisher、Visio、RTF 和 WordPerfect，都由在您浏览器内运行的 LibreOffice 引擎转换，因此无需安装任何东西；例如，Word 转 PDF也可以直接处理 DOC、ODT 和 RTF。引擎每个会话只下载一次，所以第一次转换会比之后的转换多花几秒钟。

把 PDF 转换为 JPG 或 PNG 会损失质量吗？

页面会以原始大小的两倍渲染，因此一张 Letter 尺寸的页面会变成约 1,224 x 1,584 像素的图片。PDF 转 JPG是有损格式，带有默认为 90% 的质量滑块，在清晰度和文件大小之间取得良好平衡；PDF 转 PNG 和 PDF 转 TIFF 是无损的，PNG 还提供 1x 到 3x 的缩放控制，可输出印刷品质。

转换时我的文件会被上传到服务器吗？

不会。此页面上的每个转换器，包括 Office、电子书和图片转换器，都以 WebAssembly 的形式在您的浏览器标签页中运行，因此文件从您的设备读取，结果也直接写回设备。没有上传队列，没有服务器副本，事后也无需删除任何内容。
