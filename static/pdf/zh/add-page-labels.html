页面标签的工作方式

  • 将页面范围留空即可为所有页面添加标签。
  • 前置页可使用罗马数字，正文部分可使用十进制编号等样式。
  • 将前缀与起始值 0 结合使用，可创建 A-0、A-1、A-2 之类的标签。
  • 当某条规则使用 1-9,30-40 或奇数页之类的不连续范围时，请启用连续编号。

常见问题

如何将附录页标为 A-1、A-2、A-3？

为附录页范围添加一条规则，样式保持“十进制阿拉伯数字”，并在“标签前缀”字段中输入 A-。使用默认起始值 1，页面就会变成 A-1、A-2、A-3，再用前缀 B- 添加第二条规则即可处理下一个附录。

页码可以从 0 或 1 以外的数字开始吗？

每条规则都有一个起始值字段，默认值为 1。设为 0 可从零开始编号，也可设为其他任意数字，例如设为 15，这样从长篇书籍中提取的章节就能保留原来的页码。

“跨不连续范围继续编号”有什么作用？

当一条规则覆盖不连续的页面（例如 1-9,30-40 或 odd），并且您希望标签跨过间隔继续按顺序计数时，请开启它。关闭后，每个独立的页面块都会从起始值重新开始。

PDF 中已有的页面标签会怎样？

“移除现有页面标签”选项默认勾选，因此在应用您的规则之前会清除旧标签。如果您只想为部分页面重新设置标签，并保留其余页面的现有标签，请取消勾选。

可以输入哪些页面范围格式？

留空表示覆盖所有页面，也可以使用 1-4、7、odd 或 1-9,30-40 这样的格式。页码指的是文件中的实际位置，而不是 PDF 可能已经显示的标签。

可以给受密码保护的 PDF 添加标签吗？

不能直接添加。工具会停止并提示“受保护的 PDF”，所以请先用解锁 PDF移除密码，再上传不再需要密码的副本。

为什么工具要求我配置 CoherentPDF？

页面标签由 CoherentPDF 引擎写入，该引擎通常在您首次使用工具时从 CDN 加载。如果在自行托管的版本中关闭了该默认设置，系统会提示您在 WASM 设置中指向该库的副本。

如何确认标签已应用？

在能显示页面标签的阅读器中打开下载的 PDF，例如 Adobe Acrobat 或 Firefox 内置查看器，然后查看工具栏中的页码框。它会显示标签（例如 iv 或 A-1），而不是单纯的页面索引。
