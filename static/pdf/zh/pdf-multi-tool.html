常见问题

PDF 多功能工具能做哪些单一用途工具做不到的事？

它把合并、重新排序、旋转、复制、删除、插入和拆分放在同一个页面网格中，因此您可以一次完成多项操作，无需在步骤之间下载再重新上传。每个操作都支持撤销和重做，所以在导出之前可以放心尝试。

如何把多个 PDF 中的页面合并到一个文档？

上传所有源文件后，它们的页面会按上传顺序一起显示在同一个网格中。将页面拖到您想要的顺序，删除不需要的页面，然后点击“导出 PDF”，即可将结果下载为单个文件。

可以把图片添加为页面吗？

把 JPG、PNG、WebP、HEIC、TIFF、BMP、GIF 或 SVG 文件和 PDF 一起拖入，每张图片都会成为一个页面，可以像其他页面一样移动、旋转或删除。也可以通过“Insert”菜单添加空白页。

如何把一个 PDF 拆分成多个文件？

点击“Split”，然后选择文档的拆分方式：按页面范围、奇偶页、每一页、书签、每 N 页或文件大小。只有一个部分时下载为 PDF；有多个部分时会一起打包成 ZIP 下载。

在这里旋转页面会降低质量吗？

不会。旋转是以 90 度为单位存储为页面属性的，而不是重新渲染内容，因此文字、矢量和图片都不会受影响。若要使用 90、180 或 270 度以外的角度，请使用按自定义角度旋转。

可以只导出部分页面吗？

勾选您想要的页面上的复选框，然后使用“下载所选页面”即可只获取这些页面，文件名为 selected-pages.pdf。工作区保持原样，因此您可以继续工作，稍后再导出其余页面。

导出时书签会怎样？

导出会逐页重建文档，因此源文件中的书签不会带入新的 PDF。包括文字和图片在内的页面内容会按原样复制。

使用多功能工具时我的 PDF 会被上传吗？

不会。页面缩略图在您的浏览器中渲染，最终的 PDF 或 ZIP 也在浏览器中生成，损坏的文件在加载前也会在本地修复。您放入网格的任何内容都不会离开您的电脑。
