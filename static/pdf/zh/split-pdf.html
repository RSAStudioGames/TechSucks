常见问题

如何从 PDF 中提取一段页面范围？

选择“按页面范围提取”并输入所需页面，例如 1-5, 8, 11-13。默认情况下，所选页面会合并为一个 PDF；将输出切换为“每个范围一个 PDF”后，每个以逗号分隔的范围会成为 split-pages.zip 中的独立文件。

我能把 PDF 拆分成每页一个文件吗？

可以。选择“将所有页面拆分为单独文件”，每一页都会写入各自的 PDF，命名为 page-1.pdf、page-2.pdf 等，并打包在 split-pages.zip 中。

如何每 N 页拆分一次 PDF？

选择“每 N 页拆分”并输入块大小。一个 23 页的文件每 5 页拆分一次会生成五个 PDF，工具会事先提醒最后一个只有 3 页。文件会下载为 split-n-times.zip。

我能按章节或书签拆分 PDF 吗？

可以，前提是 PDF 带有书签。选择“按书签拆分”和一个级别（全部，或 0 到 3 级），每个书签所在页面处会开始一个新文件，在 split-by-bookmarks.zip 中得到 split-1.pdf、split-2.pdf 等。如果 PDF 在所选级别没有书签，则会显示错误。

如何分开奇数页和偶数页？

选择“按奇偶页拆分”并选取偶数或奇数；匹配的页面会按原顺序提取到一个 PDF 中。这是在单面打印机上进行双面打印的常用步骤。

我能直观地选择页面，而不用输入页码吗？

可以。“直观选择页面”会显示每一页的缩略图；点击您想要的页面，它们会按页面顺序提取。合并输出为一个 PDF，分开输出则在 ZIP 中每页一个文件。

拆分会降低页面质量吗？

不会。页面由 QPDF 直接复制而不重新渲染，因此文本、图像、字体和矢量图形都与原文件完全一致。

拆分时我的 PDF 会被上传吗？

不会。页面提取和 ZIP 打包都在您的浏览器中运行，生成的文件直接从您的设备保存。
