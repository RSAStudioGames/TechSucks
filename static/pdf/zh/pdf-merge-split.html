常见问题解答

如何把多个 PDF 合并成一个文件？

向合并 PDF添加两个或更多文件，并拖动到您想要的顺序。文件模式会合并整个文档，每个文件还可以设置页面范围，例如 1-3, 5；页面模式则把每一页排成缩略图，方便您构建精确的顺序。文件数量和总页数都没有上限，页面是不经重新编码直接复制的，因此质量不会改变。

拆分 PDF 有哪些不同的方式？

拆分 PDF有六种模式：页面范围、从缩略图中可视化选择、仅偶数页或奇数页、每页一个文件、按书签边界拆分（可选择书签级别），以及每 N 页为一固定块。单个范围会下载为一个 PDF，多个范围或按页输出则以 ZIP 形式提供。书签模式需要确实包含书签的 PDF。

拆分、提取页面和删除页面有什么区别？

提取页面只保留您列出的页面并保存为新文件，删除页面则移除您列出的页面并保留其余部分，拆分则把一个文档分成多个文件。提取和删除互为逆操作，因此请选择需要填写页码更少的那一个。

可以重新排序页面或复制页面吗？

整理 PDF会把每一页显示为可拖动的缩略图，每页都有复制和删除按钮。您也可以输入完整的页面顺序，例如 3, 1, 2, 4，一步完成所有重排，“反转页面”则可一键翻转整个文档或一批文档。

我的扫描仪把所有正面放在前面，所有背面放在后面。如何修正顺序？

双面整理正是为此设计的：它会把两个块交错成正面 1、背面 1、正面 2、背面 2 的顺序，并可选择反转背面块，适用于第二遍扫描前被翻转过的纸叠。如果正面和背面在两个独立的文件中，交替合并也能以同样的方式交错多个 PDF 的页面。

如何把 PDF 打印成可折叠的小册子？

PDF 小册子会把页面重新排列为骑马订拼版，并在下载前显示每张纸的预览。请以“短边翻转”进行双面打印，将纸叠对折，并在书脊处装订；如果页数不是四的倍数，会自动添加空白页来填满最后一张纸。

可以查看 PDF 两个版本之间有哪些变化吗？

比较 PDF会把两个文档的页面配对，并以并排或叠加视图高亮显示文字、图片、批注、页眉页脚和格式上的差异。筛选器可以隐藏您不关心的更改类型，扫描文档可以开启 OCR，比较结果还可以导出为 PDF 报告。

合并或拆分时我的文件会被上传吗？

不会。合并、拆分和重新排序都以 WebAssembly 的形式在您的浏览器内运行，因此文件从您的磁盘读取，结果直接写回，不经过任何服务器。对于大型扫描件和多文件批处理同样如此。
