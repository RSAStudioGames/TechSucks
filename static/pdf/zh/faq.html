常见问题解答

有疑问？我们有答案。以下是人们最常问到的关于 BentoPDF 的一些问题。

我的文件安全且私密吗？

绝对不会。这是 BentoPDF 最重要的特性。所有处理都 100% 在您的网络浏览器本地完成。您的文件从不会上传到任何服务器，这意味着我们或其他任何人都无法看到它们。您的隐私有保障。

BentoPDF 真的免费吗？有什么陷阱？

是的，完全免费，没有任何陷阱。没有隐藏费用，没有订阅方案，没有使用限制，也没有仅限付费的功能。我们相信基础工具应当让每个人都能使用。

使用这些工具需要联网吗？

首次加载网站后，大多数工具都可以完全离线使用！由于所有处理库都已加载到您的浏览器中，您可以断开网络，继续安全地合并、拆分、压缩和编辑 PDF。少数需要外部数据的小众工具（如带网络图片的 Markdown 转 PDF）可能需要联网。

有文件大小或使用次数的限制吗？

不会，我们不对文件大小、文件数量或工具的使用次数设置任何人为限制。唯一的实际限制是您自己电脑的处理能力和内存，因为非常大或非常复杂的文件可能需要更长的处理时间。

为什么我的 PDF 处理失败了？

失败的情况很少见，但可能由以下几种原因造成：

  • PDF 可能已损坏，或不符合标准规范。
  • 文件可能使用了您不知道的密码加密。请先使用我们的解密工具。
  • 文件可能是特殊的“XFA”或基于动态表单的 PDF，我们的部分工具无法处理这类文件。

你们会追踪我在 BentoPDF 上的活动吗？

不会。BentoPDF 完全不会追踪您。我们不使用 Cookie、分析工具或任何追踪脚本，即使在 bentopdf.com 正式网站上也是如此。我们永远不知道您是谁，也不知道您用这些工具做了什么。

BentoPDF 使用了什么技术？

BentoPDF 建立在现代 Web 技术之上。我们主要使用 PDF-lib.js 和 PDFKit.js 等 JavaScript 库，它们通过 WebAssembly 编译后可在您的浏览器中高效运行。这使得在无需您的数据离开本机的情况下，也能实现媲美服务器的强大处理能力。
