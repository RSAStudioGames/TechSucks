常见问题

具体会移除哪些元数据？

文档信息字段（标题、作者、主题、关键词、创建者、生成器以及创建和修改日期）、XMP 元数据流、尾部的文档 ID 对，以及 Illustrator 或 InDesign 等工具留下的应用专用 PieceInfo。没有任何选项，它总是清除以上所有内容。

文件中还会保留什么？

所有可见内容，以及表单字段、批注、书签、链接和任何文件附件。存储在这些元素内部的名称，例如便笺评论上的作者，不会被改动。如需同时清除评论、脚本和附件，请使用清理 PDF。

它会移除 PDF 内图像的元数据吗？

不会。图像数据保持原样，因此照片放入 PDF 时自带的任何 EXIF 或 XMP 信息都会留在该图像中。如果这很重要，栅格化 PDF 会把每一页重新渲染为全新的图像，代价是文本不再可选中。

如何确认元数据已被清除？

在查看元数据中打开清理后的文件，检查各字段是否为空。先对原文件做同样的检查，可以准确看到即将被移除的内容。

可以撤销吗？

不能。清理后的文件不会保留被移除值的任何记录。如果以后可能需要作者、日期或其他详细信息，请保留您的原始副本。

移除元数据会减小文件大小吗？

会略微减小，因为 XMP 块和信息字段被删除，通常只有几千字节。如需真正缩小，请接着使用压缩 PDF。

它会移除评论、批注或隐藏文本吗？

不会，它只针对元数据。评论和标记属于批注，会保留；这些可由移除批注处理。隐藏的或白色的文本仍是页面内容的一部分，因此如果文档经过多次修订，请检查文档本身。

移除元数据时我的 PDF 会被上传吗？

不会。文件由 PDF 库在您的浏览器中打开并重写，当目标是匿名时这正是关键：文档不会接触服务器，也没有服务器日志记录您清理了什么。
