常见问题

可以把多个 BMP 文件合并成一个 PDF 吗？

可以。您添加的每个 BMP 都会成为同一个 PDF 中的单独一页，顺序与文件列表中显示的一致。没有每个文件生成一个 PDF 的选项，如有需要，请分别转换文件。

为什么 PDF 比我的 BMP 文件小？

BMP 存储的是未压缩的像素，所以文件很大。转换器会重新绘制每张图片，并以无损 PNG 的形式存入 PDF，通常能大幅缩小体积，而不会改变任何一个像素。

转换会损失图片质量吗？

不会。像素以无损方式存储，并且这个工具没有质量设置，所以输出与源文件的分辨率和颜色相同。如果之后需要更小的文件，请把 PDF 交给压缩 PDF处理。

转换 BMP 时，PDF 的页面大小是多少？

每一页的大小按图片像素尺寸确定，每像素一磅，所以 2480 x 3508 像素的扫描件会生成约 34 x 49 英寸的页面，而不是 A4。查看器和打印机会缩放以适应，之后也可以用修复页面尺寸把每一页调整为 A4 或 Letter。

为什么提示我的某个文件无效？

图片由您的浏览器解码，它支持标准 Windows 位图。OS/2 头或罕见压缩模式等特殊变体可能失败；用任意图片编辑器将文件另存为标准 24 位 BMP 或 PNG 即可解决。

可以把 BMP 与 JPG 或 PNG 文件混在一起吗？

这个工具只接受 .bmp 文件，并会跳过您添加的其他任何文件。如果需要把多种格式合并到一个文档中，请使用图片转 PDF。

BMP 的 DPI 设置会影响结果吗？

不会。文件头中存储的分辨率会被忽略，页面大小完全取决于像素数，所以两张像素尺寸相同的图片无论 DPI 是多少，生成的页面都完全一样。

我的 BMP 文件会被上传到任何地方吗？

不会。解码使用的是您浏览器自带的图片支持，PDF 在本地用 pdf-lib 生成，所以扫描仪或医学影像导出的文件不会离开您的电脑。
