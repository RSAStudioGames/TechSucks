常见问题

如何查看我的 PDF 是 A4 还是 Letter？

上传文件后会立即开始分析。摘要会显示总页数和出现的不同尺寸数量，表格会在匹配的标准尺寸旁列出每一页的宽度和高度，因此普通的 A4 或 Letter 文档所有页面都会显示同一种尺寸。

它能识别哪些标准纸张尺寸？

A3、A4、A5、Letter、Legal 和 Tabloid，纵向或横向均可，与官方尺寸相差不超过一磅即视为匹配。其他尺寸会报告为“自定义”，并给出确切的测量值。

“尺寸不一致”警告是什么意思？

在文档中发现了不止一种宽高组合，摘要会列出每种尺寸各有多少页。旋转后的页面会被视为与其未旋转的同类不同的尺寸，因此纵向 A4 文件中的一个横向 A4 页面就会触发警告。若要统一所有页面，请使用固定页面大小。

可以用英寸或毫米而不是磅来查看尺寸吗？

使用单位菜单可将整个表格在磅、英寸、毫米和像素之间切换。像素按 96 PPI 计算，与浏览器和大多数屏幕工具处理 PDF 页面的方式一致。

“旋转”列表示什么？

它显示页面上保存的旋转属性，单位为度。一个页面在阅读器中看起来是正的，实际上可能带有 90 或 270 度的旋转，这会给一些打印和转换流程带来麻烦，可以用旋转 PDF将其规范化。

可以导出结果吗？

点击“导出为 CSV”即可下载 page-dimensions.csv，每页一行：页码、宽度、高度、标准尺寸、方向、宽高比、面积和旋转，使用当前所选的单位。它可以直接在 Excel 或 Google 表格中打开。

这个工具会修改我的 PDF 吗？

不会。它只读取页面树并报告所发现的内容，不会重写任何内容，提供的唯一下载是可选的 CSV。

分析时 PDF 会被上传吗？

不会。文件在您的浏览器中解析，测量值在本地计算，这也是文件一加载完成结果就会立刻出现的原因。
