常见问题

线性化 PDF 究竟改变了什么？

QPDF 会重写文件，让第一页所需的对象排在最前面，添加线性化字典和提示表，并重建交叉引用表。页面、字体、图片、链接和表单字段保持不变；只有文件内部的字节顺序不同。

这能修复在 Acrobat 中显示“快速网页查看：否”的 PDF 吗？

“快速网页查看”是 Acrobat 对线性化的称呼，用此工具处理文件后会将其设为“是”。这仅在之后不再编辑 PDF 时才成立，因为几乎任何后续更改（如合并、添加页面或在大多数编辑器中重新保存）都会移除线性化。

线性化会让文件变小吗？

不会。这是结构重排，而不是压缩，提示表只会增加少量内容，通常不到 1%。如需缩小文件，请先运行压缩 PDF，最后再线性化。

我的网络服务器或阅读器真的会加载得更快吗？

仅当服务器支持 HTTP 字节范围请求时才会，大多数静态主机和 CDN 都支持。pdf.js 或浏览器内置阅读器等查看器就可以获取第一页并开始渲染，同时下载其余部分，而不必等待整个文件。

为什么我只上传了一个 PDF 却得到了 ZIP？

该工具始终将输出打包为 linearized-pdfs.zip，其中每个文件都会重命名为 linearized- 加原文件名。解压后即可得到 PDF。

如果文件线性化失败怎么办？

批处理会继续处理其他文件，完成消息会告诉您成功和失败的数量。常见原因是文件已损坏；请先用修复 PDF处理后再试。

PDF 会被上传进行优化吗？

不会。QPDF 以 WebAssembly 形式在您的浏览器中运行，在您设备的内存中读写文件，ZIP 也在本地生成。即使输出是为网络发布准备的，也不会向服务器发送任何内容。
