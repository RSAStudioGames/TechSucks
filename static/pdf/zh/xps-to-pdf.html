常见问题

XPS 和 OXPS 有什么区别，在这里有影响吗？

XPS 是 Microsoft 在 Windows Vista 和 7 中的原始格式；OXPS 是 Windows 8 及更高版本默认写出的 ECMA-388 OpenXPS 变体。两种扩展名都接受，可在同一批中混用，并生成同类的 PDF。

为什么我再也打不开 XPS 文件了？

Microsoft 已不再默认安装 XPS 查看器，而 macOS、Linux 和手机从未支持该格式。转换为 PDF 后，文档可在任何浏览器或 PDF 阅读器中阅读。

转换会保留原件的质量吗？

会。页面尺寸、矢量图形、字体和图像都会不经重新采样带入 PDF，因此以高分辨率打印为 XPS 的文档在 PDF 中保持该分辨率。

PDF 中的文本还能选中吗？

XPS 中的文本会连同字体以文本形式写入 PDF，而不是页面图片，因此您可以在 PDF 阅读器中选中、搜索和复制。

我能一次转换多个 XPS 文件吗？

可以。想添加多少 .xps 或 .oxps 文件都行；单个文件会下载为 PDF，多个文件会打包为 xps-converted.zip，每个文档一个 PDF。

转换器会在我的电脑上安装任何东西吗？

不会。PyMuPDF 引擎会在您第一次转换时以 WebAssembly 形式加载到浏览器中，不会在您的系统上安装任何东西。

我能把 PDF 转回 XPS 吗？

不能，本工具只支持从 XPS 或 OXPS 转为 PDF。在 Windows 上，如果需要 XPS 副本，您可以把任何 PDF 打印到 Microsoft XPS Document Writer。

我的 XPS 文档会被上传来转换吗？

不会。PyMuPDF 引擎在您的浏览器中本地运行，XPS 文件的解析和 PDF 的写出都在您自己的设备上完成。旧的企业或政府文档不会离开您的设备。
