常见问题

空白页会插入到哪里？

位置数字表示新空白页之前有多少个现有页面。输入 0 表示放在最前面，输入 3 表示插入到第 3 页之后，输入总页数则表示追加到末尾。

空白页是多大？

每个空白页都会复制您文档第一页的宽度和高度，所以 Letter 文档会得到 Letter 大小的空白页，A4 文档会得到 A4 大小的空白页。如果您的 PDF 混用了多种页面尺寸，空白页仍与第 1 页一致，而不是与相邻页面一致。

可以一次添加多个空白页吗？

输入 1 或更大的任意数量，它们会一起插入到同一位置。如需在多个不同位置添加空白页，请对输出文件再次运行该工具，或使用 PDF 多功能工具直观地排列页面。

会保留书签和文档属性吗？

页面上的内容、图片、文字和批注都会原样保留。文档是逐页重建的，因此书签（大纲面板）以及标题、作者等属性不会带到新文件中。

插入的页面是完全空白的吗？

是的。它没有文字、没有页码，也没有印刷的备注，只是一张与第 1 页大小相同的白页。如果之后想为它添加页码，可以把结果交给页码处理。

我可以用它让每一章都从右侧页面开始，以便双面打印吗？

可以，每次运行指定一个位置。在每个以奇数页结尾的章节后插入一个空白页，下载后，再对新文件重复操作，处理下一章。输出文件会保留原文件名，所以请随时给副本重命名，以免混淆。

可以给受密码保护的 PDF 添加空白页吗？

如果文件需要密码才能打开，工具会在读取页数之前向您索要密码。新文件保存时不带密码，如有需要，请之后重新加密保护。

添加页面时会上传我的 PDF 吗？

不会。页数的读取和新文档的生成都在您的浏览器中通过 pdf-lib（一个 JavaScript PDF 库）完成，下载直接来自内存。不会向服务器发送任何内容。
