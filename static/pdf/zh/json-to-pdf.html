常见问题

可以用此工具把任何 JSON 文件转换为 PDF 吗？

不能。它只能从 BentoPDF 的 PDF 转 JSON 工具创建的 JSON 文件重建 PDF，这些文件存储了文档的完整内部结构。来自 API、数据库或配置文件的 JSON 导出会失败并报错。

那么如何把 API 数据或配置文件转为可读的 PDF？

请在文本转 PDF中以纯文本形式粘贴或上传 JSON，它会将其排版为页面上的格式化文本。JSON 转 PDF 仅用于往返转换原本就是 PDF 的文档。

重建的 PDF 会与原件一致吗？

PDF 转 JSON 生成的 JSON 记录了文档的对象，因此转换回来能重现源文件的页面、文字和图片。转换回来再比较，也是确认导出是否捕获了全部内容的快速方法。

转换多个 JSON 文件时输出是什么？

每次转换都会下载为 jsons-to-pdf.zip，即使只有一个文件。压缩包内每个 PDF 都沿用其源 JSON 的名称，因此 report.json 会变成 report.pdf。

转换回 PDF 之前可以编辑 JSON 吗？

可以，只要结构对 CPDF 引擎保持有效。对 JSON 的程序化更改（如编辑后的元数据或文本对象）会被重建到 PDF 中；格式错误的编辑会导致转换错误。

为什么工具提示 CPDF 引擎不可用？

转换依赖于 CPDF WebAssembly 版本。在 bentopdf.com 上已包含，但自托管的副本需要先在 WASM 设置中配置 CPDF WASM 文件，此工具才能运行。

我的 JSON 文件会被上传到服务器吗？

不会。文件在您的浏览器中读取，并由本地运行 CPDF 引擎的 Web Worker 重建为 PDF，因此不会传输任何内容，在大型转换期间页面也保持响应。
