常见问题

为什么 .txt 文件是空的？

这个 PDF 很可能是扫描件或照片，没有可提取的文本层。请先运行 OCR PDF；该工具会添加文本层，也直接提供 .txt 下载。

文字的顺序正确吗？

文字按照 PDF 的内部结构，从左到右、从上到下读取，这对大多数单栏文档是正确的。多栏版面、侧栏和表格可能出现交错，页眉、页脚和页码会与页面上的其他内容一起包含在内。

会保留任何格式吗？

不会。输出是纯 UTF-8 文本，因此带重音的字符、西里尔文、中日韩文字和阿拉伯文都会保留，但粗体、标题、链接和图片不会，换行遵循 PDF 的行而不是段落。若想以 Markdown 保留标题和列表，请使用PDF 转 Markdown。

可以一次从多个 PDF 中提取文字吗？

可以。添加任意数量的 PDF 并点击一次“提取”；每个 PDF 会生成各自以源文件命名的 .txt 文件，并一起下载为 pdf-to-text.zip。单个 PDF 会直接下载为 filename.txt。

输出中的页面是如何分隔的？

页面一个接一个排列，页与页之间有一个换行。没有页面标记或换页符，因此文件读起来是一段连续的文字。

可以选择特定页面或页面范围吗？

不能，这个工具总是提取每一页。请先用提取页面把您需要的页面提取到单独的 PDF 中，再转换那个文件。

它能处理受密码保护的文件吗？

如果 PDF 在打开时需要密码，工具会在提取之前提示您输入。没有密码就无法读取文字。

提取文字时我的文档会被上传吗？

不会。提取在以 WebAssembly 加载到您浏览器中的 PDF 引擎里运行，因此合同、医疗记录以及其他任何内容从头到尾都保留在您的设备上。
