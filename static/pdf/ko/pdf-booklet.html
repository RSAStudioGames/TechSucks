자주 묻는 질문

인쇄할 때 소책자의 페이지 순서는 어떻게 되나요?

기본 1x2(소책자) 모드에서는 중철 제본 순서로 용지 한 면에 두 페이지가 나란히 놓입니다. 첫 번째 장의 앞면에는 마지막 페이지와 1페이지가, 뒷면에는 2페이지와 끝에서 두 번째 페이지가 들어가며 안쪽으로 계속 이어집니다. 짧은 변 기준으로 넘기는 설정으로 양면 인쇄한 뒤 반으로 접으면 페이지가 순서대로 읽힙니다.

페이지 수가 4의 배수가 아니면 어떻게 되나요?

페이지 수는 가장 가까운 4의 배수로 올림되고 부족한 칸은 빈 페이지로 남아 소책자의 맨 끝에 놓입니다. 10페이지 문서는 세 장에 걸친 12페이지 소책자가 되며, 미리보기에서 빈 칸이 빈 페이지로 표시됩니다.

어떤 용지 크기를 사용할 수 있나요?

Letter, Legal, Tabloid, Ledger, Executive, Folio와 A0부터 C7까지의 ISO A, B, C 시리즈 중에서 고를 수 있습니다. 기본값은 Letter이며, 각 원본 페이지는 용지의 해당 칸에 작은 여백을 두고 맞게 크기가 조정됩니다.

결과물은 세로와 가로 중 어느 방향이어야 하나요?

자동은 소책자 모드에서 가로를 선택해 세로 페이지 두 장이 가로 용지에 나란히 놓이고, 그리드 모드에서는 세로를 선택합니다. 어느 방향이든 직접 지정할 수 있으며, 원본 페이지는 선택한 방향에 맞게 비율을 유지한 채 크기가 조정됩니다.

2x2, 2x4, 4x4 그리드 모드는 무엇인가요?

소책자 순서가 아니라 읽는 순서대로 한 장에 4, 8 또는 16페이지를 배치하며, 유인물이나 축소판 교정용 시트에 유용합니다. 접기용으로 페이지 순서를 바꾸는 것은 1x2뿐이며, 더 많은 그리드 레이아웃은 N-Up PDF를 참고하세요.

가로 페이지를 소책자에 맞게 회전할 수 있나요?

원본 회전 옵션은 배치하기 전에 모든 페이지를 시계 방향 또는 시계 반대 방향으로 90도 돌리거나, 위아래가 맞붙은 채 스캔한 문서를 위해 홀수 페이지와 짝수 페이지의 방향을 번갈아 적용합니다. 다운로드하기 전에 미리보기 생성을 클릭해 레이아웃을 확인하세요.

소책자로 만들면 품질이 떨어지나요?

아니요. 페이지는 래스터화되지 않고 원본 PDF의 벡터 콘텐츠로 삽입되므로, 어떤 배율로 확대해도 텍스트가 선명하고 파일도 최고 품질로 인쇄됩니다.

소책자를 만들기 위해 내 PDF가 업로드되나요?

아니요. 페이지 순서 변경, 크기 조정, 미리보기 렌더링이 모두 브라우저에서 실행되며, 완성된 소책자 PDF는 서버를 거치지 않고 내 기기에서 바로 저장됩니다.
