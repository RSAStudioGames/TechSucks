PDF 병합

여러 PDF를 하나로 합칩니다. 북마크도 유지됩니다.

클릭하여 파일 선택 또는 파일을 끌어다 놓으세요

PDF 또는 이미지

파일이 기기 밖으로 나가지 않습니다.

사용 방법:

  • 아이콘을 클릭한 채 끌어 파일 순서를 바꾸세요.
  • 각 파일의 "페이지" 상자에 "1-3, 5" 같은 범위를 지정하면 해당 페이지만 병합할 수 있습니다.
  • "페이지" 상자를 비워 두면 해당 파일의 모든 페이지가 포함됩니다.

    사용 방법:

    • 업로드한 PDF의 모든 페이지가 아래에 표시됩니다.
    • 개별 페이지 썸네일을 끌어다 놓기만 하면 새 파일의 순서를 원하는 대로 만들 수 있습니다.

    자주 묻는 질문

    병합해도 북마크가 유지되나요?

    네. 병합은 CoherentPDF 엔진이 처리하며 각 파일의 북마크를 합쳐진 문서로 옮겨 목차를 계속 탐색할 수 있습니다. 페이지 내용과 주석은 그대로 복사됩니다.

    각 파일에서 일부 페이지만 병합할 수 있나요?

    네. 파일 모드에서 파일 옆 페이지 상자에 1-3, 5 같은 범위를 입력하면 해당 페이지만 포함되며, 비워 두면 파일 전체가 포함됩니다. 페이지 모드에서는 모든 파일의 모든 페이지가 썸네일로 나타나 원하는 순서로 끌어다 놓을 수 있으며, 서로 다른 문서의 페이지를 번갈아 배치할 수도 있습니다.

    파일 순서는 어떻게 되나요?

    목록에 표시된 순서, 즉 위에서 아래 순서입니다. 병합하기 전에 항목을 끌어 순서를 바꿀 수 있고, 파일 추가를 사용하면 기존 배열을 유지한 채 문서를 뒤에 붙일 수 있습니다.

    병합된 PDF에서 페이지 번호가 이상하게 보이는 이유는 무엇인가요?

    기본적으로 병합된 파일은 1부터 N까지의 단순 번호를 사용합니다. 원본이 i, ii, iii 또는 A-1 같은 페이지 레이블을 썼다면 원래 페이지 레이블 유지를 켜서 보존할 수 있으며, 같은 레이블을 가진 두 파일은 중복이 생긴다는 점에 유의하세요. 페이지에 보이는 번호를 인쇄하려면 페이지 번호를 사용하세요.

    병합된 파일이 이렇게 큰 이유는 무엇인가요?

    각 파일의 글꼴과 이미지는 그대로 복사되므로 결과물은 입력 파일들을 합친 크기에 가깝고, 여러 파일이 같은 글꼴을 포함하면 각각 유지됩니다. 중복 글꼴 제거를 선택하면 동일한 글꼴이 하나로 합쳐지며, 더 줄이려면 결과를 PDF 압축으로 처리하세요.

    페이지 크기나 방향이 다른 PDF도 병합할 수 있나요?

    네. 페이지는 각자의 크기와 회전을 유지하므로 가로 A3 도면이 세로 Letter 페이지 뒤에 와도 크기가 조정되지 않습니다. 이후 크기를 통일하려면 병합된 파일을 페이지 크기 통일로 처리하세요.

    PDF를 병합하려면 서버에 업로드되나요?

    아니요. 파일은 CoherentPDF WebAssembly 모듈이 브라우저 안에서 합치고 병합된 PDF는 다운로드 폴더에 저장되므로 계약서와 명세서가 컴퓨터 밖으로 나가지 않습니다.

    비밀번호로 보호된 PDF도 병합할 수 있나요?

    파일을 열려면 비밀번호가 필요한 경우 파일을 추가할 때 비밀번호를 물어보고 이후 암호가 해제된 페이지를 병합합니다. 병합된 결과물에는 비밀번호가 없으니 필요하면 나중에 PDF 보호로 설정하세요.
