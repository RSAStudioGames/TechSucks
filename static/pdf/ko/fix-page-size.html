자주 묻는 질문

페이지 크기를 조정할 때 맞춤과 채우기는 어떻게 다른가요?

맞춤은 페이지 전체가 목표 크기 안에 들어올 때까지 각 페이지를 축소하고 가운데 정렬한 뒤 남는 공간을 배경색으로 채웁니다. 채우기는 목표 영역이 완전히 덮일 때까지 확대하며 가장자리를 벗어나는 부분은 잘립니다. 내용 손실이 안 될 때는 맞춤을, 가장자리까지 꽉 찬 페이지가 좋을 때는 채우기를 사용하세요.

Letter 문서를 왜곡 없이 A4로 변환할 수 있나요?

목표를 A4로 선택하고 맞춤을 유지하세요. 내용은 늘어나지 않고 비율대로 축소되므로 Letter 페이지는 A4에서 폭이 약간 좁아지고 위아래에 배경색 띠가 얇게 생깁니다. 이후 페이지 크기 정보에서 모든 페이지가 일치하는지 확인할 수 있습니다.

자동 방향 옵션은 어떤 일을 하나요?

자동은 각 페이지를 개별적으로 살펴 가로 페이지는 가로로, 세로 페이지는 세로로 유지하며 목표 크기를 맞춰 회전합니다. 세로 또는 가로를 선택하면 모든 페이지를 해당 방향으로 강제하고 새 모양에 맞게 내용 크기를 조정합니다.

사용자 지정 페이지 크기를 설정할 수 있나요?

목표로 사용자 지정을 선택하고 너비와 높이를 인치 또는 밀리미터로 입력하세요. 단위의 100분의 1까지 입력할 수 있습니다. 6 x 9인치 책 페이지처럼 프리셋 목록에 없는 판형에도 쓸 수 있습니다.

텍스트를 계속 선택할 수 있나요, 아니면 페이지가 이미지로 바뀌나요?

페이지는 새 문서에서 벡터 콘텐츠로 다시 그려지므로 텍스트는 선명하고 선택 가능하며 래스터화되는 것은 없습니다. 페이지 모양만 복사되기 때문에 주석, 양식 필드, 링크, 북마크는 유지되지 않습니다. 입력한 양식 값을 보존해야 한다면 먼저 PDF 평탄화를 실행하세요.

페이지가 Letter 크기에 거의 가깝지만 정확히 같지는 않습니다. 이 도구로 해결되나요?

네. Letter와 맞춤을 선택하면 8.49 x 11.02인치 페이지가 1퍼센트에도 못 미치는 비율로 조정되어 정확히 8.5 x 11이 됩니다. 눈으로는 알 수 없지만 규격에서 벗어난 페이지를 거부하는 인쇄소나 문서 시스템의 요건을 충족합니다.

배경색은 어디에 쓰이나요?

원본 페이지의 모양이 목표 크기와 다를 때 맞춤 모드가 추가하는 여백을 채웁니다. 기본값은 흰색이며, 페이지 배경이 어두우면 여백이 눈에 띄지 않도록 어두운 색을 선택하세요.

페이지 크기를 수정하려면 PDF가 업로드되나요?

아니요. 크기 조정은 브라우저에서 실행되는 PDF 라이브러리가 처리하며 새 파일은 기기에서 만들어집니다. 어디로도 전송되지 않습니다.
