자주 묻는 질문

PDF를 반전하면 사진과 컬러 그래픽은 어떻게 되나요?

모든 픽셀이 보색 값으로 뒤집히므로 사진은 필름 네거티브처럼 보이고 브랜드 색상도 바뀝니다(파란색은 주황색, 빨간색은 청록색이 됩니다). 어두운 페이지에 밝은 글자를 원하는 텍스트 위주 문서에 적합하며, 이미지를 반전하지 않고 밝기나 대비만 바꾸려면 색상 조정을 사용하세요.

반전 후에도 텍스트를 선택하거나 검색할 수 있나요?

아니요. 각 페이지가 이미지로 렌더링되어 반전된 뒤 이미지 전용 PDF로 다시 만들어지므로 텍스트 레이어가 사라집니다. 다시 검색 가능한 텍스트가 필요하면 반전된 파일을 OCR PDF로 처리하세요.

반전된 PDF가 흐릿해 보이나요?

페이지는 1.5배 배율, 대략 108dpi로 렌더링됩니다. 다크 모드로 읽는 일반 화면 확대율에서는 선명하지만, 파일을 인쇄하거나 많이 확대하면 흐릿해 보일 수 있습니다.

결과 파일이 원본보다 큰 이유는 무엇인가요?

반전된 페이지는 텍스트와 벡터 그림이 아니라 전체 페이지 PNG 이미지로 저장되므로 용량이 더 커지는 경우가 많습니다. 더 작은 파일이 필요하면 결과를 PDF 압축으로 처리하세요.

하이퍼링크, 북마크, 양식 필드는 유지되나요?

아니요. 결과물은 새로운 이미지 기반 문서이므로 링크, 양식 필드, 댓글, 북마크 같은 상호작용 요소는 유지되지 않습니다. 필요하면 원본을 보관하세요.

일부 페이지만 반전할 수 있나요?

이 도구로는 할 수 없으며 모든 페이지를 처리합니다. 몇 페이지만 반전하려면 먼저 PDF 분할로 분리하고 해당 부분을 반전한 다음 다시 병합하세요.

스캔한 문서에도 작동하나요?

네. 스캔본은 이미 이미지이므로 깔끔하게 반전되며, 네거티브로 촬영되었거나 노출이 반대로 된 스캔본을 되살릴 수도 있습니다. 회색조 스캔본은 회색 단계가 유지되고 반대로만 바뀝니다.

반전하려면 문서가 업로드되나요?

아니요. 렌더링과 픽셀 반전은 브라우저의 캔버스에서 이루어지고 새 PDF는 로컬에서 만들어집니다. 컴퓨터 밖으로 나가는 것이 없고 서버 대기열도 없으므로 속도는 내 기기에만 좌우됩니다.
