자주 묻는 질문

PDF를 ZIP으로 묶으면 내 파일에 실제로 무슨 일이 일어나나요?

묶는 것 외에는 아무것도 하지 않습니다. PDF는 원래 이름 그대로, 변경 없이, 추가한 순서대로 pdfs_archive.zip 하나에 복사되므로 ZIP에서 나오는 파일은 들어간 파일과 바이트 단위로 같습니다.

ZIP으로 묶으면 PDF가 작아지나요?

아니요. PDF 내용은 이미 내부적으로 압축되어 있어 거의 줄어들지 않으므로 압축 파일은 압축 없이 만들어지며, ZIP의 크기는 파일 크기를 합친 것과 비슷합니다. 크기를 줄이려면 먼저 PDF 압축을 실행한 뒤 결과를 ZIP으로 묶으세요.

PDF를 ZIP으로 묶는 것과 병합하는 것은 어떻게 다른가요?

ZIP은 각 PDF를 받는 사람이 풀어야 하는 하나의 컨테이너 안에 별도의 파일로 보관합니다. 병합은 페이지를 하나의 PDF 문서로 합치며, 파일들을 하나의 문서로 읽어야 할 때 필요합니다. 이 경우 PDF 병합을 사용하세요.

파일 이름이 같은 파일이 둘 있으면 어떻게 되나요?

중복된 이름은 자동으로 처리됩니다. 두 번째 파일은 name (1).pdf, 세 번째는 name (2).pdf가 되어 압축 파일 안에서 아무것도 덮어쓰이지 않습니다. 의미 있는 이름을 원하면 업로드하기 전에 파일 이름을 바꾸세요.

PDF가 아닌 파일도 압축 파일에 추가할 수 있나요?

아니요. .pdf 확장자나 PDF 파일 형식인 파일만 받으며, 그 외의 파일은 무시됩니다. 여러 종류가 섞인 묶음은 운영체제에 내장된 압축 기능을 사용하세요.

받는 사람이 압축 파일을 열려면 특별한 소프트웨어가 필요한가요?

아니요. 결과는 Windows, macOS, iOS, Android에서 별도 소프트웨어 없이 열리는 표준 ZIP 파일이며, 더블클릭하거나 탭하면 PDF를 풀 수 있습니다.

ZIP을 만들기 위해 내 PDF가 업로드되나요?

아니요. 압축 파일은 브라우저에서 만들어지므로 파일은 디스크에서 읽히고 ZIP도 네트워크 전송 없이 디스크에 다시 기록됩니다. 이 방법으로 청구서, 계약서, 진료 기록을 묶으면 내 기기에 그대로 남습니다.
