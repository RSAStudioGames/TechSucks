자주 묻는 질문

PDF를 그레이스케일로 변환하면 용량이 작아지나요?

대체로 그렇습니다. 각 페이지는 품질 90%의 그레이스케일 JPEG로 저장되어 컬러 이미지보다 작으므로, 색이 많은 파일은 보통 용량이 줄어듭니다. 텍스트만 있는 PDF는 컴팩트한 벡터 텍스트가 페이지 전체 이미지가 되어 오히려 커질 수 있습니다.

변환 후에도 텍스트를 선택할 수 있나요?

아니요. 모든 페이지가 2배 배율로 렌더링되고 채도가 제거된 뒤 JPEG 이미지로 다시 삽입되므로, 결과물은 이미지 기반이 되어 텍스트를 선택하거나 검색할 수 없습니다. 검색 가능한 텍스트가 다시 필요하면 결과를 OCR PDF로 처리하세요.

밝기나 대비를 조절하거나 일부 페이지만 컬러로 유지할 수 있나요?

여기서는 안 됩니다. 이 도구에는 옵션이 없으며 표준 휘도 공식으로 모든 페이지를 변환합니다. 밝기, 대비, 채도 조절은 색상 조정을 사용하고, 일부 페이지만 변환하려면 해당 페이지를 먼저 분리한 뒤 나중에 결과를 병합하세요.

그레이스케일과 흑백은 같은 건가요?

아니요. 그레이스케일은 회색 음영을 유지하므로 사진, 음영이 있는 차트, 강조 표시도 읽을 수 있지만, 진짜 흑백은 모든 것을 두 가지 톤으로 줄입니다. 이 도구는 그레이스케일을 만듭니다. 1비트 출력이 필요하면 PDF를 TIFF로 변환에 흑백 모드가 있습니다.

페이지 크기나 인쇄 품질이 바뀌나요?

페이지 크기는 유지됩니다. 페이지는 2배 배율, 약 144dpi로 렌더링되며 화면에서는 문제없고 사무용 인쇄에도 무난하지만, 세밀한 부분은 벡터 원본만큼 선명하지 않습니다.

인쇄하기 전에 PDF를 그레이스케일로 변환하는 이유는 무엇인가요?

그레이스케일 파일은 어떤 프린터에서도 똑같이 인쇄되고 컬러 인쇄 요금이 발생하지 않으며, 일부 인쇄소, 법원, 정부 포털은 그레이스케일 제출을 요구합니다. 먼저 변환해 보면 컬러 차트와 강조 표시가 회색으로 인쇄될 때 어떻게 보일지도 미리 확인할 수 있습니다.

주석, 양식 필드, 링크는 어떻게 되나요?

페이지 이미지에 평탄화됩니다. 양식 필드는 더 이상 입력할 수 없고, 댓글은 그림의 일부가 되며, 클릭 가능한 링크는 작동하지 않습니다.

변환하기 위해 내 PDF가 업로드되나요?

아니요. 렌더링과 그레이스케일 필터는 브라우저 탭의 캔버스에서 실행되고 새 PDF도 그곳에서 만들어집니다. 서버로 전송되는 것은 없습니다.
