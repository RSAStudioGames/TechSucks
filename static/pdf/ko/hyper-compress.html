소개합니다 Hyper Compress

최고의 오픈소스 PDF 압축 엔진입니다. 원본보다 큰 파일을 반환하지 않고, 진정한 무손실 모드를 제공하며, 벤치마크한 모든 엔진 중 가장 낮은 손상률을 기록했습니다.

CLI, Node SDK, C 라이브러리, 자체 호스팅 서비스, WebAssembly 빌드로 제공됩니다.

오픈소스, 자체 호스팅, 내부 사용은 계속 무료입니다. Hyper Compress는 AGPL-3.0으로 라이선스됩니다. 프로젝트가 AGPL과 호환되거나 Hyper Compress를 그대로 직접 실행하는 경우에는 상업용 라이선스가 전혀 필요하지 않습니다. 상업용 라이선스는 Hyper Compress를 비공개 소스 소프트웨어에 포함해 배포할 때만 필요합니다.

제공 방식 & 라이선스 모델

  • 라이선스 키는 필요하지 않으며 제공되지도 않습니다. Hyper Compress는 배포를 간소화하고 운영상의 번거로움을 줄이기 위해 의도적으로 라이선스 키를 사용하지 않습니다.
  • 구매하면 Hyper Compress 전체 소스 코드가 담긴 ZIP 아카이브를 받습니다.
  • Hyper Compress는 오픈소스이므로 모든 릴리스와 업데이트를 언제든지 GitHub 릴리스 페이지에서 다운로드할 수 있습니다.
  • 제공되는 소스 코드는 공개 오픈소스 저장소에 게시된 코드와 동일합니다.
  • 환불 불가. 구매 후에는 어떠한 경우에도 환불되지 않습니다.

라이선스 약관

제품별

라이선스 하나는 배포하는 제품 하나에 적용됩니다. 두 번째 제품에는 두 번째 라이선스가 필요하며, 전체 제품군을 OEM으로 포함하는 방법도 문의하실 수 있습니다.

업데이트 포함

라이선스가 활성인 동안 게시된 모든 릴리스를 사용할 수 있습니다. 라이선스가 만료되더라도 마지막으로 받은 버전에 대한 영구 사용 권리는 유지됩니다.

AGPL 의무 없음

상업용 라이선스는 제품에 대해 AGPL을 대체합니다. 비공개 소스로 배포할 수 있으며 변경 사항이나 애플리케이션을 공개할 의무가 없습니다.

명확한 출처

Hyper Compress는 BentoPDF가 작성하고 소유하며, PDFium, qpdf, jpegli, Leptonica를 포함해 번들된 모든 서드파티 구성 요소가 허용적 라이선스입니다. 공급망에 카피레프트 문제가 생기지 않습니다.

자주 묻는 질문

Hyper Compress를 비공개 소스 소프트웨어에 포함해 배포할 때만 필요합니다. AGPL 호환 라이선스의 오픈소스 프로젝트, 자체 호스팅, 내부 사용은 모두 AGPL-3.0에 따라 무료입니다.

네, 요건을 충족하는 제품에서 BentoPDF 자체 도구를 통해 사용하는 경우 포함됩니다. BentoPDF 상업용 라이선스에는 매출과 투자 유치액 합계가 100만 미국 달러 미만인 기업을 대상으로, 범용 PDF 도구 모음에서 최종 사용자의 기기에서 실행되는 경우 Hyper Compress가 번들 구성 요소로 포함됩니다. API, SDK, 명령줄, 서버 프로세스로 엔진을 직접 사용하거나, 다른 소프트웨어 안에서 사용하거나, 압축 전용 제품에서 사용하거나, 그 규모를 넘는 경우에는 Hyper Compress 라이선스가 필요합니다. Hyper Compress 라이선스는 BentoPDF를 포함하지 않습니다.

다음 갱신 시점에 해당 등급으로 올라갑니다. 소급 적용은 없습니다. 계약 기간 중 기준을 넘어서더라도 현재 라이선스가 무효가 되지 않습니다.
