소개합니다 Kura

PDF 표준 및 프리플라이트 엔진입니다. 모든 PDF를 모든 PDF/A 등급, PDF/UA, PDF/X, PDF/E, PDF/VT로 변환한 뒤 번들된 396개 프로필로 결과를 프리플라이트해 적합성을 확인하세요.

CLI, npm 패키지, 브라우저 WebAssembly 빌드, Docker 이미지, C 라이브러리로 제공됩니다.

오픈소스, 자체 호스팅, 내부 사용은 계속 무료입니다. Kura는 AGPL-3.0으로 라이선스됩니다. 프로젝트가 AGPL과 호환되거나 Kura를 그대로 직접 실행하는 경우에는 상업용 라이선스가 전혀 필요하지 않습니다. 상업용 라이선스는 Kura를 비공개 소스 소프트웨어에 포함해 배포할 때만 필요합니다.

상업용 라이선스 상세 안내

제공 방식 & 라이선스 모델

  • 라이선스 키는 필요하지 않으며 제공되지도 않습니다. Kura는 배포를 간소화하고 운영상의 번거로움을 줄이기 위해 의도적으로 라이선스 키를 사용하지 않습니다.
  • 구매하면 Kura 전체 소스 코드가 담긴 ZIP 아카이브를 받습니다.
  • Kura는 오픈소스이므로 모든 릴리스와 업데이트를 언제든지 GitHub 릴리스 페이지에서 다운로드할 수 있습니다.
  • 제공되는 소스 코드는 공개 오픈소스 저장소에 게시된 코드와 동일합니다.
  • 환불 불가. 구매 후에는 어떠한 경우에도 환불되지 않습니다.

GitHub 저장소: github.com/alam00000/bentopdf-kura

청구서 발행

  • 결제에는 Polar를 사용하며, 구매 후 이메일로 청구서가 자동 발송됩니다.
  • Polar가 해당 지역 기업을 위한 VAT 청구서를 처리합니다.
  • VAT 청구서가 필요하면 결제 시 "I'm purchasing as a business"를 선택하고 청구 주소와 세금/VAT 번호를 입력하세요.

OEM을 다른 등급과 구분하는 것은 재배포, 재판매, 호스팅입니다. Kura를 자체 비공개 소스 제품 안에서만 배포한다면 Solo, Indie, Business 중 선택은 순전히 규모에 따라 결정됩니다.

라이선스 약관

제품별

라이선스 하나는 배포하는 제품 하나에 적용됩니다. 두 번째 제품에는 두 번째 라이선스가 필요하며, 전체 제품군을 OEM으로 포함하는 방법도 문의하실 수 있습니다.

연간 구독

구독이 활성 상태인 동안 모든 릴리스를 받습니다. Kura을(를) 사용, 배포, 호스팅할 권리는 구독이 유지되는 동안만 유효합니다.

AGPL 의무 없음

상업용 라이선스는 제품에 대해 AGPL을 대체합니다. 비공개 소스로 배포할 수 있으며 변경 사항이나 애플리케이션을 공개할 의무가 없습니다.

명확한 출처

Kura는 BentoPDF가 작성하고 소유하며, qpdf, PDFium, FreeType을 포함해 연결된 모든 서드파티 구성 요소가 허용적 라이선스입니다. 공급망에 카피레프트 문제가 생기지 않습니다.

자주 묻는 질문

Kura를 비공개 소스 소프트웨어에 포함해 배포할 때만 필요합니다. AGPL 호환 라이선스의 오픈소스 프로젝트, 자체 호스팅, 내부 사용은 모두 AGPL-3.0에 따라 무료입니다.

아니요. Kura는 별도의 라이선스를 가진 독립된 프로젝트입니다. BentoPDF 앱 라이선스는 Kura에 대한 어떤 권리도 부여하지 않으며, Kura 라이선스도 BentoPDF를 포함하지 않습니다.

다음 갱신 시점에 해당 등급으로 올라갑니다. 소급 적용은 없습니다. 계약 기간 중 기준을 넘어서더라도 현재 라이선스가 무효가 되지 않습니다.

갱신까지 30일의 유예 기간이 있습니다. 그 후에는 Kura이(가) 포함된 제품의 새 버전을 출시하거나, 새 사용자에게 제공하거나, 브라우저에서 불러오는 웹 앱을 포함해 이를 제공하거나 호스팅할 수 없습니다. 최종 사용자가 그 전에 자신의 기기에 설치한 사본은 계속 작동합니다. 그 밖의 모든 사용은 AGPL의 적용을 받으며, 나중에 갱신하면 라이선스가 종료된 이후의 기간도 포함됩니다. 전체 라이선스 조건에서 각 조건을 자세히 확인할 수 있습니다.
