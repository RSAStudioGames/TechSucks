OCR PDF

PDF의 텍스트를 검색하고 복사할 수 있게 만듭니다.

작동 방식:

  • 텍스트 추출: Tesseract OCR을 사용하여 스캔된 이미지나 PDF에서 텍스트를 인식합니다.
  • 검색 가능한 출력: 보이지 않는 텍스트 레이어가 있는 새 PDF를 만들어 원본 모양을 유지하면서 문서를 완전히 검색 가능하게 합니다.
  • 문자 필터링: 화이트리스트를 사용하여 원치 않는 문자를 필터링하고 특정 문서 유형(인보이스, 양식 등)의 정확도를 향상시킵니다.
  • 다국어 지원: 혼합된 언어 콘텐츠가 포함된 문서를 위해 여러 언어를 선택하세요.

자주 묻는 질문

      

        

          내 PDF에 OCR이 필요한지 어떻게 알 수 있나요? 
          
아무 뷰어에서나 파일을 열고 텍스트 한 줄을 선택해 보세요. 아무것도 강조되지 않거나 검색에서 일치하는 항목이 없다면 페이지가 이미지(스캔본이나 사진)일 뿐이며, OCR이 빠진 텍스트를 추가합니다. 이미 선택 가능한 텍스트가 있는 PDF에는 이 도구가 필요 없습니다.

        

        

          어떤 언어를 인식할 수 있나요? 
          
영어, 스페인어부터 아랍어, 힌디어, 일본어, 중국어까지 100개가 넘는 Tesseract 언어 팩이 나열됩니다. 문서에 나오는 모든 언어를 선택하세요. 팩이 함께 로드되므로 여러 언어가 섞인 페이지도 한 번에 인식됩니다. 일부 자체 호스팅 환경은 더 짧은 목록을 번들하며 언어 선택기 위에 그렇게 표시합니다.

        

        

          OCR이 문서의 모양을 바꾸나요? 
          
아니요. 원본 페이지는 그대로 복사되고 그 위에 스캔과 맞도록 단어 단위로 위치를 맞춘 보이지 않는 텍스트 레이어가 그려집니다. 이전과 같은 이미지가 보이지만 이제 텍스트를 검색, 선택, 복사할 수 있습니다.

        

        

          어떤 해상도 설정을 사용해야 하나요? 
          
높음(288 DPI)이 기본값이며 일반적인 사무 문서를 처리합니다. 속도가 중요하거나 파일이 길면 표준(192 DPI)으로 낮추고, 작은 글씨, 각주, 품질이 나쁜 스캔본에는 최고(384 DPI)를 사용하세요. 인식 전에 모든 페이지를 해당 크기로 렌더링하므로 높은 설정은 눈에 띄게 오래 걸립니다.

        

        

          문자 허용 목록은 무엇을 하나요? 
          
출력을 고정된 문자 집합으로 제한해 소문자 l이 1로 읽히는 것 같은 오류를 줄입니다. 청구서 프리셋은 숫자와 $ . , / - # : 기호만 허용하고, 숫자만은 일련번호나 계량기 수치에 적합하며, 사용자 지정은 원하는 문자 집합을 직접 입력할 수 있게 합니다.

        

        

          손글씨도 읽을 수 있나요? 
          
안정적으로는 어렵습니다. Tesseract는 인쇄된 텍스트로 학습되어 있어 단정한 대문자 필기체는 가끔 되지만 흘림체는 대부분 엉뚱한 결과가 나옵니다. 깨끗하고 밝게 인쇄된 페이지에서 결과가 가장 좋으며, 이진화 옵션은 바랜 스캔본이나 대비가 낮은 스캔본에 도움이 되고 PDF 기울기 보정은 기울어진 스캔본을 먼저 바로잡아 줍니다.

        

        

          PDF 대신 인식된 텍스트만 받을 수 있나요? 
          
네. OCR이 끝나면 추출된 텍스트가 상자에 나타나 검토하고, 클립보드에 복사하거나, ocr-text.txt로 다운로드할 수 있습니다. 검색 가능한 PDF 다운로드는 별개이므로 둘 중 하나 또는 둘 다 받을 수 있습니다.

        

        

          OCR이 스캔본을 서버에 업로드하나요? 
          
아니요. Tesseract는 브라우저 안에서 WebAssembly로 실행되며, 다운로드되는 것은 OCR 엔진과 선택한 언어 팩뿐이고 처음 필요할 때 가져옵니다. 스캔한 페이지와 인식된 텍스트는 기기에 남습니다.
