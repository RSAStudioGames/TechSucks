자주 묻는 질문

이 도구는 어떤 종류의 스캔을 위한 것인가요?

단면 스캐너에 한 묶음을 두 번, 즉 앞면용으로 한 번 뒷면용으로 한 번 넣어 만든 PDF를 위한 도구로, 앞면 페이지가 모두 먼저 오고 뒷면 페이지가 그 뒤에 오는 파일 하나가 만들어집니다. 도구는 두 블록을 앞면 1, 뒷면 1, 앞면 2, 뒷면 2 순서로 교차 배치합니다. 앞면과 뒷면이 별도의 PDF에 있다면 페이지 교차 병합 & 섞기를 사용하세요.

나누는 위치를 어디로 설정해야 하는지 어떻게 알 수 있나요?

나누는 위치는 앞면 블록의 마지막 페이지이며, 일반적인 두 번 스캔 방식에서는 정확히 전체의 절반입니다. 자동 감지 나누기(절반)를 클릭해 값을 채운 다음 미리보기 요약을 확인하세요. 확정하기 전에 각 블록의 크기와 결과 페이지 수가 표시됩니다.

그룹별 내보내기 옵션은 무엇을 하나요?

묶음에 두 쪽짜리 양식처럼 짧은 문서가 여러 개 들어 있다면 문서당 페이지 수를 입력하세요. 합쳐진 출력이 그 길이의 조각으로 나뉩니다. 조각이 여러 개면 문서당 PDF 하나가 담긴 ZIP으로 다운로드되고, 조각이 하나면 일반 PDF로 다운로드됩니다.

합쳐진 PDF의 파일 이름은 무엇인가요?

합쳐진 파일 하나는 원래 이름에 _collated가 붙어 scan_collated.pdf 같은 이름으로 다운로드됩니다. 그룹별 출력은 개별 PDF가 담긴 scan_collated_grouped.zip이라는 ZIP입니다.

다운로드하기 전에 결과를 미리 볼 수 있나요?

나누는 위치와 뒷면 순서를 바꾸면 페이지에 앞면과 뒷면 블록의 크기, 출력 페이지 수를 포함한 요약 줄이 표시되며 블록 크기가 다르면 경고합니다. 썸네일 미리보기는 없으므로 다운로드한 파일의 처음 몇 페이지를 확인하고 뒷면이 거꾸로 나오면 뒷면 블록 순서를 바꾸세요.

스캔한 PDF의 북마크가 유지되나요?

출력은 페이지 단위로 다시 만들어지므로 페이지 콘텐츠와 회전은 유지되지만 문서 수준 북마크는 옮겨지지 않습니다. 스캐너 출력에는 북마크가 거의 없지만, 있다면 북마크 편집으로 다시 추가할 수 있습니다.

스캔한 문서가 순서를 바꾸려고 업로드되나요?

아니요. PDF는 브라우저에서 열리고 페이지는 기기에서 새 문서로 복사되며 결과는 바로 다운로드되므로 양식과 기록의 스캔 파일이 컴퓨터를 벗어나지 않습니다.
