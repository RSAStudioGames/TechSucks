자주 묻는 질문

CBZ를 PDF로 변환하면 이미지 품질이 떨어지나요?

JPEG와 PNG 페이지는 다시 인코딩하지 않고 그대로 PDF에 복사되므로 그림이 원본과 똑같이 보이고 파일 크기도 거의 같게 유지됩니다. WebP, GIF, BMP 같은 다른 형식은 디코딩한 뒤 무손실 PNG로 다시 저장하여 삽입합니다.

도구는 페이지 순서를 어떻게 정하나요?

페이지는 자연 정렬 방식으로 파일 이름순으로 정렬되므로 page2.jpg가 page10.jpg보다 앞에 옵니다. 하위 폴더의 파일도 포함되어 전체 경로순으로 정렬되며, ComicInfo.xml 같은 이미지가 아닌 파일은 무시됩니다.

PDF에서 만화 페이지의 크기는 어떻게 되나요?

각 페이지는 이미지의 픽셀 크기에 맞춰 픽셀당 1포인트로 만들어지므로 두 쪽 펼침면은 가로로 넓은 페이지가 되고 한 쪽 페이지는 세로로 유지됩니다. 여기서는 하나의 크기를 강제하는 옵션이 없으며, 페이지 크기를 통일하려면 결과를 페이지 크기 맞추기로 처리하세요.

CBZ뿐 아니라 CBR 파일도 변환할 수 있나요?

.cbr 압축 파일도 지원하며 같은 일괄 작업에서 .cbz 파일과 함께 사용할 수 있습니다. CBR 파일은 처음 사용할 때 다운로드되는 PyMuPDF 엔진을 거치므로 브라우저에서 바로 압축을 푸는 CBZ 파일보다 조금 더 걸립니다.

압축 파일 안의 이미지는 어떤 형식을 지원하나요?

JPEG와 PNG는 그대로 삽입됩니다. GIF, BMP, WebP, AVIF, TIFF, HEIC, JXL은 브라우저가 먼저 PNG로 변환하므로 이런 덜 흔한 형식은 브라우저가 표시할 수 있어야만 작동하며, TIFF, HEIC, JXL은 일부 브라우저에서 실패합니다. 변환기는 확장자가 아니라 실제 이미지 데이터를 확인하므로 이름이 .jpg인 PNG도 정상적으로 처리됩니다.

압축 파일 크기나 페이지 수에 제한이 있나요?

CBZ 하나에는 이미지를 최대 2,000개까지 넣을 수 있으며 이미지당 최대 100MB, 압축 파일당 압축 해제 이미지 데이터 500MB로 제한됩니다. 이 제한은 브라우저의 메모리 부족을 막기 위한 것이며 일반적인 만화책 한 권보다 훨씬 넉넉합니다.

여러 만화를 한꺼번에 변환하면 어떻게 되나요?

각 압축 파일은 원본 파일 이름을 딴 개별 PDF가 됩니다. 파일 하나는 바로 다운로드되고 둘 이상은 comic-converted.zip으로 묶입니다.

만화 파일이 어딘가에 업로드되나요?

아니요. CBZ 압축 파일은 브라우저 안에서 압축이 풀려 PDF로 다시 만들어지며, CBR 파일도 로컬에서 실행되는 엔진이 처리합니다. 컬렉션의 어떤 내용도 기기를 벗어나지 않습니다.
