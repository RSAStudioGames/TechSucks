페이지 레이블 추가

로마 숫자, 접두사, 사용자 지정 시작값으로 PDF 페이지 레이블을 적용합니다.

클릭하여 파일 선택 또는 파일을 끌어다 놓으세요

PDF 파일

파일이 기기 밖으로 나가지 않습니다.

레이블 작동 방식

  • 모든 페이지에 레이블을 적용하려면 페이지 범위를 비워 두세요.
  • 앞부분에는 로마 숫자, 본문에는 십진 번호 같은 스타일을 사용하세요.
  • 시작값 0과 함께 접두사를 사용하면 A-0, A-1, A-2 같은 레이블을 만들 수 있습니다.
  • 하나의 규칙이 1-9,30-40 또는 홀수 페이지 같은 비연속 범위를 사용할 때 진행 옵션을 켜세요.

레이블 규칙

이 도구는 브라우저에서 CoherentPDF를 사용합니다. CoherentPDF가 구성되지 않은 경우 WASM 설정에서 설정하라는 안내가 표시됩니다.

자주 묻는 질문

부록 페이지에 A-1, A-2, A-3 같은 레이블을 붙이려면 어떻게 하나요?

부록 페이지 범위에 대한 규칙을 추가하고 스타일은 십진 아라비아 숫자로 두고 레이블 접두사 입력란에 A-를 입력하세요. 시작 값이 기본값 1이면 페이지는 A-1, A-2, A-3이 되며, 접두사 B-를 가진 두 번째 규칙으로 다음 부록을 처리할 수 있습니다.

페이지 번호를 0이나 1이 아닌 다른 숫자부터 시작할 수 있나요?

각 규칙에는 기본값이 1인 시작 값 입력란이 있습니다. 0부터 번호를 매기려면 0으로, 더 두꺼운 책에서 추출한 챕터가 원래 페이지 번호를 유지하도록 하려면 15 같은 다른 숫자로 설정하세요.

'분리된 범위에 걸쳐 번호 이어서 매기기'는 무엇을 하나요?

한 규칙이 1-9,30-40이나 홀수(odd)처럼 연속되지 않는 페이지를 포함하고, 그 사이를 건너뛰어도 레이블 번호를 순서대로 이어 가고 싶을 때 켜세요. 끄면 분리된 페이지 블록마다 시작 값부터 다시 시작합니다.

PDF에 이미 있는 페이지 레이블은 어떻게 되나요?

'기존 페이지 레이블 제거' 상자가 기본으로 선택되어 있어서 규칙을 적용하기 전에 이전 레이블이 지워집니다. 일부 페이지만 다시 레이블링하고 나머지 페이지의 기존 레이블을 유지하려면 선택을 해제하세요.

어떤 페이지 범위 형식을 입력할 수 있나요?

모든 페이지에 적용하려면 입력란을 비워 두고, 그렇지 않으면 1-4, 7, 홀수(odd), 1-9,30-40 같은 형식을 사용하세요. 페이지 번호는 PDF에 이미 표시된 레이블이 아니라 파일 안의 실제 위치를 가리킵니다.

암호로 보호된 PDF에 레이블을 추가할 수 있나요?

바로는 안 됩니다. 도구가 보호된 PDF 메시지를 표시하며 중단되므로, 먼저 PDF 잠금 해제로 암호를 제거한 다음 암호가 필요 없는 사본을 업로드하세요.

도구가 CoherentPDF를 설정하라고 요청하는 이유는 무엇인가요?

페이지 레이블은 CoherentPDF 엔진이 작성하며, 이 엔진은 도구를 처음 사용할 때 보통 CDN에서 불러옵니다. 직접 호스팅한 빌드에서 이 기본 설정이 꺼져 있다면 WASM 설정에서 라이브러리 사본을 지정하라는 안내가 표시됩니다.

레이블이 적용되었는지 어떻게 확인하나요?

다운로드한 PDF를 Adobe Acrobat이나 Firefox 내장 뷰어처럼 페이지 레이블을 표시하는 뷰어로 열고 도구 모음의 페이지 번호 상자를 확인하세요. 단순한 페이지 순번 대신 iv나 A-1 같은 레이블이 표시됩니다.
