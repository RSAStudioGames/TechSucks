    자주 묻는 질문

    교차 병합은 일반 병합과 무엇이 다른가요?

    일반 병합은 전체 파일을 차례로 이어 붙입니다. 교차 병합은 각 파일에서 1페이지씩 차례로 가져오고, 다음에는 각 파일의 2페이지를 가져오는 식으로 진행하여 둘 이상의 PDF 페이지가 하나의 문서로 교차 배치됩니다. 파일을 그냥 이어 붙이기만 하면 된다면 PDF 병합을 사용하세요.

    앞면과 뒷면이 별도의 PDF에 있는 양면 스캔 문서는 어떻게 정리하나요?

    앞면 PDF를 먼저, 뒷면 PDF를 두 번째로 업로드한 다음 페이지 섞기를 클릭하세요. 출력은 앞면 1, 뒷면 1, 앞면 2, 뒷면 2 순서로 번갈아 이어집니다. 뒷면이 마지막 페이지부터 스캔되었다면 섞기 전에 페이지 순서 뒤집기로 해당 파일을 뒤집으세요.

    앞면과 뒷면이 별도의 파일이 아니라 같은 PDF에 있습니다. 어떤 도구가 필요한가요?

    이 도구는 별도의 파일을 교차 병합합니다. 하나의 PDF에 앞면이 모두 있고 그 뒤에 뒷면이 모두 있다면 양면 합치기가 그 파일을 중간 지점에서 나눠 두 절반을 교차 병합하며, 뒷면 블록을 뒤집는 옵션도 있습니다.

    PDF의 페이지 수가 서로 다르면 어떻게 되나요?

    교차 배치는 더 짧은 파일의 페이지가 다 소진될 때까지 계속되고, 더 긴 파일의 남은 페이지는 순서대로 맨 끝에 붙습니다. 누락되는 페이지는 없습니다.

    PDF를 둘보다 많이 교차 병합할 수 있나요?

    두 개 이상이면 몇 개의 파일이든 가능합니다. 파일이 세 개라면 출력은 A1, B1, C1, A2, B2, C2 순으로 이어지며, 파일 목록에 표시된 순서를 따릅니다. 이 순서는 손잡이를 끌어서 바꿀 수 있습니다.

    출력에 원본 파일의 북마크와 페이지 번호가 유지되나요?

    각 원본 파일의 북마크는 섞은 PDF로 옮겨집니다. 페이지 레이블은 기본적으로 1부터 N까지의 단순한 순서로 초기화되며, 각 파일의 자체 레이블이 필요하면 원래 페이지 레이블 유지 옵션을 켜세요. 이 경우 두 페이지가 모두 1로 표시되는 것처럼 중복이 생길 수 있습니다.

    암호로 보호된 PDF의 페이지도 교차 병합할 수 있나요?

    파일이 암호화되어 있으면 불러올 때 암호를 요청하며, 복호화된 사본이 섞기에 사용됩니다. 출력 파일은 암호화되지 않으므로 다시 암호가 필요하다면 이후에 PDF 보호를 사용하세요.

    PDF를 교차 병합하는 동안 서버로 업로드되나요?

    아니요. 파일은 브라우저에서 읽히고, 기기의 백그라운드 워커에서 실행되는 cpdf의 WebAssembly 빌드가 교차 배치하며, 완성된 alternated-mixed.pdf는 브라우저에서 바로 저장됩니다.
