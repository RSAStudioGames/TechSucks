자주 묻는 질문

배율은 어느 정도로 설정해야 하나요?

배율은 페이지의 원래 크기에 곱해지며 1.0x에서 4.0x까지, 기본값은 2.0x입니다. 2.0x는 휴대폰과 대부분의 태블릿에 적합하고, 3.0x나 4.0x는 고해상도 화면에서 더 선명한 페이지를 제공하지만 파일이 훨씬 커지고 변환 시간이 길어집니다.

CBZ가 원본 PDF보다 왜 더 큰가요?

모든 페이지가 선택한 배율의 비트맵으로 렌더링되므로, PDF의 컴팩트한 벡터 텍스트와 압축이 사라집니다. 배율을 낮추거나, 품질 80% 정도의 JPEG 또는 WebP를 선택하거나, 흑백 콘텐츠에 그레이스케일을 켜면 크기가 줄어듭니다.

만화(Manga) 모드는 무엇을 바꾸나요?

ComicInfo.xml 메타데이터에 오른쪽에서 왼쪽으로 읽는 방향 플래그를 기록하므로, 이 플래그를 따르는 리더는 오른쪽에서 왼쪽으로 페이지를 넘깁니다. 페이지 이미지 자체는 바뀌지 않습니다.

페이지 순서가 올바르게 유지되나요?

네. 이미지는 페이지 수에 따라 01.jpg나 001.jpg처럼 앞에 0을 채운 번호로 이름이 지정되므로, 파일 이름을 알파벳순으로 정렬하는 리더에서도 100페이지가 넘어도 순서가 유지됩니다.

Calibre는 어떤 메타데이터를 읽어 가나요?

Calibre는 아카이브 안의 metadata.opf 파일에서 제목, 저자, 출판사, 연도, 태그, 시리즈와 그 번호를 읽습니다. Komga, Kavita, CDisplayEx, Mylar, ComicRack은 ComicInfo.xml을 사용하며, ZIP 주석의 ComicBookInfo 기록은 오래된 리더를 지원합니다. 라이브러리가 호수를 올바르게 묶을 수 있도록 시리즈와 번호를 입력하세요.

여러 PDF를 한 번에 CBZ로 변환할 수 있나요?

아니요. 이 도구는 한 번에 PDF 하나만 처리하며, 다른 파일을 추가하면 현재 파일이 바뀝니다. 하나씩 변환하세요.

비밀번호로 보호된 PDF도 CBZ로 변환할 수 있나요?

PDF를 열 때 비밀번호가 필요하면 비밀번호를 묻고, 메모리에 보관한 복호화된 사본에서 페이지를 렌더링합니다.

만화 페이지가 서버에서 렌더링되나요?

아니요. 페이지는 브라우저의 PDF.js로 그려지고 로컬에서 압축되므로, 만화가 내 기기 밖으로 나가지 않습니다.
