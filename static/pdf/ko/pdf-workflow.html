PDF 워크플로 빌더는 무엇에 쓰나요?

여러 PDF 작업을 한 번의 실행으로 연결합니다. 단계마다 도구를 열고, 다운로드하고, 결과를 다음 도구에 넣는 대신, 캔버스에서 PDF 입력, 압축, 워터마크, 다운로드 같은 노드를 연결하고 각 노드의 옵션을 설정한 뒤 실행을 클릭하면 모든 작업이 순서대로 처리됩니다.

같은 워크플로를 여러 PDF에 한 번에 실행할 수 있나요?

네. PDF 입력 노드는 여러 파일을 받으며, 병합 노드는 이를 하나의 문서로 합치고 다른 노드는 각 PDF를 따로 처리합니다. 끝에서 파일이 둘 이상 나오면 다운로드 노드가 자동으로 ZIP으로 묶어 줍니다.

두 노드가 연결되지 않는 이유는 무엇인가요?

소켓에는 종류가 있습니다. PDF(문서 하나), MultiPDF(문서 여러 개), 이미지입니다. 단일 PDF를 기대하는 노드는 MultiPDF 출력을 받지 못하므로 사이에 병합 노드를 두어야 하며, 이미지 출력은 이미지를 받는 노드에만 연결됩니다. 연결은 항상 한 노드의 아래쪽에서 다음 노드의 위쪽으로 이어집니다.

암호화가 마지막 단계여야 한다고 나오는 이유는 무엇인가요?

PDF가 암호화되면 이후 노드가 읽을 수 없으므로, 암호화 뒤에 출력 외의 노드가 오는 워크플로는 엔진이 거부합니다. 암호화를 다운로드 바로 앞으로 옮기세요. 비밀번호로 보호된 입력은 반대 경우로, 실행이 멈추고 비밀번호를 묻습니다.

한 단계가 실패하면 어떻게 되나요?

실행이 해당 노드에서 멈추고 노드가 오류 메시지와 함께 빨간색으로 바뀌며, 그 뒤로는 아무것도 만들어지지 않습니다. 설정이나 입력을 고치고 다시 실행하세요. 먼저 노드 두 개짜리 버전을 만들고 그것이 작동하면 단계를 추가하는 것이 가장 쉽습니다.

워크플로를 저장해 두었다가 나중에 다시 사용할 수 있나요?

네. 저장은 이름 붙인 템플릿으로 브라우저의 로컬 저장소에 보관하며, 불러오기는 같은 브라우저의 이후 세션에서 이를 다시 가져옵니다. 내보내기는 레이아웃을 workflow.json 파일로 저장해 백업하거나 동료에게 보낼 수 있고, 가져오기는 그 파일에서 노드, 위치, 연결, 설정을 복원합니다.

저장한 워크플로에 내 문서가 포함되나요?

아니요. 템플릿과 내보낸 JSON 파일에는 노드 종류, 설정, 위치, 연결만 담기며 PDF는 실행할 때마다 새로 선택합니다. 설정은 입력한 그대로 저장되므로, 공유할 계획이라면 암호화 노드에 비밀번호를 입력한 채로 워크플로를 내보내지 마세요.

파일이 서버에서 처리되나요?

아니요. 모든 노드는 개별 도구와 같은 엔진으로 브라우저에서 실행되며, 네트워크 활동은 노드가 처음 필요로 할 때 Ghostscript 같은 처리 모듈을 가져오는 것뿐입니다. 여러 단계로 길게 실행해도 PDF는 내 기기 밖으로 나가지 않습니다.
