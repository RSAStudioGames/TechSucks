사용 방법:

자주 묻는 질문

한 시트에 몇 페이지까지 넣을 수 있나요?

시트당 페이지 메뉴에서 2-up(1x2), 4-up(2x2), 9-up(3x3), 16-up(4x4) 중에서 선택하세요. 페이지는 문서 순서대로 왼쪽에서 오른쪽, 위에서 아래로 배치되며, 페이지 수가 나누어떨어지지 않으면 마지막 시트에 빈 칸이 생깁니다.

결과물의 용지 크기와 방향은 어떻게 되나요?

출력 용지는 Letter, A4, Legal, A3 중에서, 방향은 세로, 가로, 자동 중에서 선택하세요. 자동은 가로 페이지의 2-up 레이아웃에는 가로를, 그 외에는 세로를 사용합니다.

페이지가 늘어나거나 잘리나요?

둘 다 아닙니다. 각 페이지는 비율을 유지한 채 셀에 맞게 축소되어 가운데에 놓이므로, 셀과 모양이 다른 페이지는 왜곡되지 않고 주위에 흰 여백이 생깁니다.

N-up 후에도 텍스트가 선명하게 유지되나요?

원본 페이지는 이미지로 변환되지 않고 벡터 콘텐츠로 포함되므로 텍스트와 선화는 어떤 인쇄 크기에서도 선명합니다. 16-up 같은 빽빽한 레이아웃에서는 종이에서 글자가 여전히 아주 작은데, 이는 품질이 아니라 가독성의 한계입니다.

각 페이지 둘레에 여백이나 테두리를 추가할 수 있나요?

여백 추가는 시트 둘레에 0.5인치 여백을 두고 셀 사이에 작은 간격을 두며, 프린터가 가장자리까지 인쇄하지 못할 때 도움이 됩니다. 테두리 추가는 배치된 각 페이지 둘레에 선택한 색상의 1포인트 윤곽선을 그립니다.

PowerPoint 슬라이드 4장을 한 페이지에 인쇄하려면 어떻게 하나요?

먼저 슬라이드를 PDF로 내보내거나 PowerPoint를 PDF로를 사용한 뒤, 그 PDF를 여기에 업로드하고 4-up을 선택하세요. 세로 시트에 가로 슬라이드는 2x2 격자에 잘 맞습니다.

N-up은 소책자 인쇄와 같은가요?

아니요. N-up은 페이지를 읽는 순서대로 격자에 축소해 넣을 뿐입니다. 소책자는 책으로 접히도록 페이지를 재배열하고 짝지어야 하며, 이것이 PDF 소책자가 하는 일입니다.

N-up 레이아웃을 만들려면 PDF가 업로드되나요?

아니요. 새 시트는 브라우저에서 pdf-lib로 만들어져 원래 파일 이름으로 다운로드되므로 문서가 기기 밖으로 나가지 않습니다.
