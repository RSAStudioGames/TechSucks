자주 묻는 질문

번호를 페이지의 어디에 넣을 수 있나요?

하단 중앙, 하단 왼쪽, 하단 오른쪽, 상단 중앙, 상단 왼쪽, 상단 오른쪽의 여섯 위치를 지원합니다. 여백은 페이지 크기에 맞춰 자동으로 조정되므로(페이지의 약 4퍼센트, 8포인트에서 40포인트 사이), 작은 페이지와 큰 페이지 모두에서 번호가 가장자리와 겹치지 않습니다.

3 / 12처럼 전체 페이지 수도 표시할 수 있나요?

"페이지 X / Y" 형식을 선택하면 각 페이지에 3 / 12처럼 표시되고, 다른 형식은 숫자만 표시합니다. 자유 형식 템플릿은 없으며, "Page 3 of 12" 같은 문구가 필요하면 {page}와 {total} 자리 표시자를 넣은 사용자 지정 텍스트를 지원하는 머리글 및 바닥글을 이용하세요.

첫 페이지가 아닌 다른 페이지부터 번호를 매기거나 표지를 건너뛸 수 있나요?

여기서는 안 됩니다. 번호는 항상 첫 페이지에서 1로 시작해 마지막 페이지까지 이어집니다. 표지에 번호를 넣지 않으려면 표지를 분리하고 나머지에 번호를 매긴 뒤 다시 병합하세요. 앞부분에 로마 숫자를 쓰려면, 페이지에 인쇄하는 대신 뷰어에 표시되는 번호를 지정하는 페이지 레이블 추가를 사용하세요.

어떤 글꼴이 사용되며, 바꿀 수 있나요?

번호는 6포인트에서 72포인트 사이에서 선택한 크기의 Helvetica로 표시되며, 색상 선택기에서 원하는 색을 고를 수 있습니다. 글꼴 자체는 고정되어 있습니다.

번호는 영구적으로 남나요?

번호는 주석으로 추가되는 것이 아니라 페이지 내용에 직접 그려지므로 모든 뷰어에서 표시되고 문서와 함께 인쇄됩니다. 그만큼 나중에 끌 수 없으니, 번호가 없는 원본은 따로 보관하세요.

잘린 페이지나 크기가 섞인 페이지에서도 번호가 올바른 위치에 들어가나요?

각 페이지를 개별적으로 측정하며, 자르기 영역이 설정되어 있으면 그 영역을 기준으로 합니다. 그래서 Letter와 A4, 또는 세로와 가로 페이지가 섞인 문서에서도 번호가 선택한 모서리의 보이는 영역 안에 들어갑니다.

EXHIBIT-A 같은 접두어나 법률용 베이츠 번호를 붙일 수 있나요?

이 도구는 단순한 숫자만 넣습니다. 법률 문서 제출에 쓰이는 ABC000123처럼 접두어와 0 채우기가 필요한 번호는 템플릿, 자릿수 채우기, 여러 파일 처리를 지원하는 베이츠 번호를 사용하세요.

번호를 넣기 위해 이 도구가 내 PDF를 업로드하나요?

아니요. 번호는 브라우저에서 실행되는 PDF 라이브러리가 기록하며 파일은 내 기기 밖으로 나가지 않으므로, 계약서나 기밀 보고서에도 안심하고 사용할 수 있습니다.
