자주 묻는 질문

어떤 출력 형식을 선택해야 하나요?

CSV는 Excel, Google Sheets 또는 모든 데이터베이스 가져오기에서 열 수 있습니다. JSON은 스크립트와 API를 위해 행의 배열을 제공하며 각 행은 셀 문자열의 배열입니다. Markdown은 GitHub, 위키, 문서에 붙여넣을 수 있는 파이프 표를 제공합니다.

PDF에 표가 여러 개 있으면 결과는 어떻게 되나요?

각 표는 table_1_page3.csv처럼 이름 붙은 별도 파일로 저장되고, 모두 filename_tables.zip으로 묶입니다. 표가 하나면 filename_table.csv, .json 또는 .md로 바로 다운로드됩니다. 모든 표를 한 파일로 받고 싶다면 PDF를 CSV로를 사용하세요.

표를 찾을 수 없다고 나오는 이유는 무엇인가요?

감지는 문서의 텍스트 레이어를 기준으로 합니다. 스캔한 PDF에는 이미지만 있으므로 먼저 OCR PDF을 실행하세요. 표 구조 없이 간격 때문에 표처럼 보이기만 하는 텍스트도 감지되지 않을 수 있습니다.

표가 여러 페이지에 이어집니다. 파일 하나로 나오나요?

아니요. 각 페이지를 따로 검사하므로 여러 페이지에 걸친 표는 페이지마다 파일 하나로 내보내지며 파일 이름에 페이지 번호가 들어갑니다. 추출한 후 스프레드시트에서 조각들을 합치세요.

일부 페이지에서만 표를 추출할 수 있나요?

문서 전체를 항상 검사하며, 각 파일 이름의 페이지 번호로 표가 어디서 왔는지 알 수 있습니다. 검사 범위를 제한하려면 먼저 페이지 추출로 필요한 페이지를 저장한 뒤 더 작은 파일에 이 도구를 실행하세요.

CSV는 셀 안의 쉼표와 줄바꿈을 처리하나요?

네. 쉼표, 따옴표, 줄바꿈이 들어 있는 셀은 큰따옴표로 감싸고 내부 따옴표는 두 번 써서 스프레드시트 프로그램이 올바르게 읽도록 합니다. 빈 셀은 빈 필드로 기록됩니다.

비밀번호로 보호된 PDF에서도 표를 추출할 수 있나요?

파일을 열려면 비밀번호가 필요한 경우 추출을 시작하기 전에 비밀번호를 물어보며, 표는 메모리에 있는 암호 해제된 사본에서 읽습니다.

표 감지를 위해 PDF가 업로드되나요?

아니요. 감지 엔진(WebAssembly로 컴파일된 PyMuPDF)은 처음 사용할 때 CDN에서 다운로드된 뒤 브라우저 안에서 실행됩니다. PDF는 기기 밖으로 나가지 않습니다.
