자주 묻는 질문

추출할 페이지를 선택할 수 있나요?

네. 2, 4-6, 9처럼 쉼표로 구분해 페이지 번호와 범위를 입력하면 해당 페이지만 추출됩니다. 번호는 1부터 시작하며, 파일 옆에 전체 페이지 수가 표시되므로 추출하기 전에 범위를 확인할 수 있습니다.

추출된 페이지는 PDF 하나로 나오나요, 개별 파일로 나오나요?

개별 파일입니다. 선택한 각 페이지는 report_page_4.pdf처럼 이름 붙은 한 페이지짜리 PDF가 되며, report_extracted_pages.zip이라는 ZIP으로 함께 다운로드됩니다. 특정 페이지만 담긴 PDF 하나를 만들려면 대신 페이지 삭제로 나머지를 제거하세요.

추출해도 원본 품질이 유지되나요?

네. 페이지는 다시 렌더링되지 않고 복사되므로 텍스트, 이미지, 글꼴, 벡터 그래픽이 원본과 같으며 텍스트도 선택하고 검색할 수 있습니다.

북마크, 링크, 주석은 유지되나요?

페이지의 댓글, 하이라이트 같은 주석은 함께 옮겨집니다. 각 결과물은 복사한 페이지로 만든 새 파일이므로 북마크는 유지되지 않으며, 원본의 다른 페이지로 이동하던 링크는 연결할 대상이 없어집니다.

같은 페이지를 여러 번 추출하거나 다른 순서로 추출할 수 있나요?

ZIP 안에는 여러 번 입력해도 각 페이지가 한 번만 들어가며, 파일 이름은 입력한 순서가 아니라 원래 페이지 번호로 정해집니다. 한 문서 안에서 중복이나 사용자 지정 순서가 필요하면 PDF 정리를 사용하세요.

비밀번호로 보호된 PDF에서도 페이지를 추출할 수 있나요?

파일을 불러올 때 비밀번호를 물어보고, 그 후 정상적으로 추출합니다. 추출된 파일은 비밀번호가 없는 새 PDF입니다.

페이지를 추출할 때 PDF가 업로드되나요?

아니요. 문서를 열고 페이지를 복사하는 모든 작업이 브라우저에서 이루어지고 ZIP도 로컬에서 만들어지므로 아무것도 전송되지 않습니다. 500페이지 파일도 선택한 페이지를 복사하는 데 내 컴퓨터가 필요로 하는 시간만 걸립니다.

수백 페이지를 한 번에 추출할 수 있나요?

엄격한 제한은 없지만 추출된 각 페이지가 ZIP 안에서 별도의 PDF가 되므로, 많이 선택하면 작은 파일이 많아지고 브라우저 탭의 메모리 사용도 늘어납니다. 문서 전체를 여러 조각으로 나누려면 PDF 분할이 더 적합합니다.
