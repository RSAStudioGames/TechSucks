자주 묻는 질문

JSON에는 무엇이 들어 있나요?

cpdf가 읽는 PDF의 전체 객체 구조입니다. 트레일러, 카탈로그, 페이지 트리, 모든 딕셔너리, 그리고 그리기 및 텍스트 연산자 목록으로 파싱한 각 페이지의 콘텐츠 스트림이 포함됩니다. 요약이 아니라 파일 전체를 덤프한 것입니다.

PDF의 텍스트를 JSON으로 꺼내려면 이 도구가 맞나요?

보통은 아닙니다. 여기서 텍스트는 그려진 순서대로 콘텐츠 스트림 연산자에 흩어져 있고, 글꼴과 위치는 있지만 단락은 없습니다. 구조화된 형식으로 읽기 쉬운 페이지 텍스트가 필요하면 AI용 PDF 준비를, 일반 텍스트가 필요하면 PDF를 텍스트로 변환을 사용하세요.

JSON을 다시 PDF로 변환할 수 있나요?

BentoPDF에서는 안 됩니다. 출력은 cpdf 고유의 JSON 형식을 따르며 cpdf 명령줄 도구는 이를 다시 PDF로 읽어 들일 수 있지만, 브라우저 도구는 한 방향으로만 작동합니다.

JSON이 PDF보다 왜 이렇게 훨씬 큰가요?

콘텐츠 스트림은 연산자 배열로 펼쳐지고, 이미지 같은 바이너리 스트림 데이터는 텍스트로 인코딩되며, 모든 객체가 키와 함께 기록되므로 JSON 파일이 원본의 몇 배 크기가 되는 것은 정상입니다. 크거나 이미지가 많은 PDF는 매우 큰 파일을 만듭니다.

여러 PDF를 한 번에 JSON으로 변환할 수 있나요?

원하는 만큼 선택하세요. 각각 백그라운드 워커에서 변환되고 결과는 원본 파일 이름을 딴 PDF당 .json 하나씩 담긴 pdfs-to-json.zip으로 묶입니다. PDF 하나만 변환해도 ZIP으로 제공됩니다.

암호화된 PDF에서도 작동하나요?

변환을 시작하기 전에 비밀번호를 묻고, 복호화된 사본을 직렬화합니다. 비밀번호가 없으면 객체 구조를 읽을 수 없습니다.

어디에 유용한가요?

생성기를 디버깅할 때 PDF 내부를 살펴보거나, 페이지의 콘텐츠 스트림에 무엇이 들어 있는지 확인하거나, 두 버전을 구조적으로 비교하거나, 객체 트리를 스크립트에 넘길 때 유용합니다. 문서 속성만 필요하다면 메타데이터 보기가 더 빠릅니다.

JSON을 만들기 위해 PDF가 업로드되나요?

아니요. cpdf는 브라우저의 웹 워커에서 WebAssembly로 실행되며, JSON은 다운로드 전에 내 기기에서 작성되고 압축됩니다.
