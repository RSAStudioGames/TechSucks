자주 묻는 질문

여러 BMP 파일을 하나의 PDF로 합칠 수 있나요?

네. 추가한 모든 BMP는 파일 목록에 표시된 순서대로 하나의 PDF 안에서 각각 한 페이지가 됩니다. 파일마다 PDF를 따로 만드는 옵션은 없으므로 나누어 만들려면 파일을 따로 변환하세요.

PDF가 BMP 파일보다 작은 이유는 무엇인가요?

BMP는 압축하지 않은 픽셀을 저장하므로 파일이 큽니다. 변환기는 각 이미지를 다시 그려 무손실 PNG로 PDF에 저장하며, 픽셀 하나 바꾸지 않고도 보통 크기가 크게 줄어듭니다.

변환하면 이미지 품질이 떨어지나요?

아니요. 픽셀은 무손실로 저장되며 이 도구에는 품질 설정이 없으므로 출력은 원본과 같은 해상도와 색상을 유지합니다. 이후 더 작은 파일이 필요하면 PDF를 PDF 압축으로 처리하세요.

BMP를 변환하면 PDF의 페이지 크기는 얼마가 되나요?

각 페이지는 이미지의 픽셀 크기에 맞춰 픽셀당 1포인트로 만들어지므로 2480 x 3508 픽셀 스캔은 A4가 아니라 약 34 x 49인치 페이지가 됩니다. 뷰어와 프린터가 맞게 축소하며, 이후 페이지 크기 맞추기로 모든 페이지를 A4나 Letter로 조정할 수 있습니다.

파일 중 하나가 유효하지 않다고 나오는 이유는 무엇인가요?

이미지는 표준 Windows 비트맵을 처리하는 브라우저가 디코딩합니다. OS/2 헤더나 드문 압축 방식 같은 특이한 변형은 실패할 수 있으며, 이미지 편집기에서 파일을 표준 24비트 BMP나 PNG로 다시 저장하면 해결됩니다.

BMP를 JPG나 PNG 파일과 함께 사용할 수 있나요?

이 도구는 .bmp 파일만 받으며 그 밖의 파일은 건너뜁니다. 여러 형식을 하나의 문서로 합치려면 이미지를 PDF로를 사용하세요.

BMP의 DPI 설정이 결과에 영향을 주나요?

아니요. 파일 헤더에 저장된 해상도는 무시되고 페이지 크기는 픽셀 수로만 결정되므로 픽셀 크기가 같은 두 이미지는 DPI와 관계없이 동일한 페이지가 됩니다.

BMP 파일이 어딘가에 업로드되나요?

아니요. 디코딩은 브라우저 자체의 이미지 지원을 사용하고 PDF는 pdf-lib으로 로컬에서 만들어지므로 스캐너나 의료 영상에서 내보낸 파일도 컴퓨터 밖으로 나가지 않습니다.
