자주 묻는 질문

SVG 안의 텍스트를 여전히 선택할 수 있나요?

아니요. 각 페이지는 텍스트가 벡터 윤곽선으로 그려진 채 내보내지므로 깔끔하게 확대되고 글꼴 설치 여부에 의존하지 않지만, 선택하거나 검색할 수 있는 실제 텍스트는 아닙니다. 글자 자체가 필요하면 SVG와 함께 PDF를 텍스트로 변환을 사용하세요.

문서 전체가 SVG 하나로 나오나요, 아니면 페이지마다 하나씩 나오나요?

SVG에는 페이지 개념이 없으므로 페이지당 하나씩 만들어집니다. 한 페이지짜리 PDF는 filename.svg로 다운로드되고, 여러 페이지 PDF는 page_1.svg, page_2.svg 등이 담긴 filename_svg.zip이 되며, 여러 PDF를 한꺼번에 변환하면 pdf_to_svg.zip으로 다운로드됩니다.

결과를 Illustrator나 Inkscape에서 편집할 수 있나요?

결과물은 Inkscape, Illustrator, Figma, 모든 웹 브라우저에서 열리는 표준 SVG입니다. 도형, 경로, 텍스트 윤곽선은 편집 가능한 벡터 객체로 옮겨지고, PDF에 삽입된 사진은 파일 안에서 래스터 이미지로 남습니다.

SVG 파일이 왜 이렇게 큰가요?

스캔본이나 사진이 많은 PDF는 모든 래스터 이미지가 base64 데이터로 파일에 삽입되기 때문에 큰 SVG를 만들고, 작은 벡터 경로가 수천 개 있는 페이지도 용량이 늘어납니다. 이미지 기반 페이지는 PDF를 PNG로 변환이 더 작고 실용적인 결과를 줍니다.

여러 PDF를 한 번에 변환할 수 있나요?

PDF를 원하는 만큼 도구에 끌어다 놓고 변환을 클릭하세요. 각 파일이 차례로 처리되고 결과는 원본 문서 이름을 딴 파일들이 담긴 pdf_to_svg.zip에 모입니다.

페이지 범위나 크기 같은 옵션이 있나요?

아니요. 업로드한 모든 파일의 모든 페이지가 크기 조정이나 범위 선택 없이 원래 페이지 크기로 변환됩니다. 특정 페이지만 변환하려면 먼저 페이지 추출로 분리하세요.

비밀번호로 보호된 PDF도 SVG로 변환할 수 있나요?

업로드 후 비밀번호를 묻고, 승인되면 변환이 진행됩니다. SVG 파일 자체에는 비밀번호가 걸리지 않습니다.

변환을 위해 내 PDF가 업로드되나요?

아니요. PyMuPDF가 브라우저 안에서 WebAssembly로 실행되어 SVG 파일을 로컬에서 작성하므로 PDF가 내 컴퓨터 밖으로 나가지 않습니다. 엔진은 처음 사용할 때 가져오며, 그래서 첫 변환이 조금 더 걸립니다.
