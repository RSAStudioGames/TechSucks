자주 묻는 질문

내 PDF가 A4인지 Letter인지 어떻게 확인하나요?

파일을 업로드하면 분석이 바로 실행됩니다. 요약에는 전체 페이지 수와 서로 다른 크기의 개수가 표시되고, 표에는 각 페이지의 너비와 높이가 일치하는 표준 크기와 함께 나열되므로, 일반적인 A4나 Letter 문서는 모든 페이지에서 한 가지 크기로 나타납니다.

어떤 표준 용지 크기를 인식하나요?

A3, A4, A5, Letter, Legal, Tabloid를 세로 또는 가로 방향 모두 인식하며, 공식 규격과 1포인트 이내로 일치하면 해당 규격으로 판정합니다. 그 외에는 정확한 치수와 함께 사용자 지정으로 표시됩니다.

크기 혼합 경고는 무슨 뜻인가요?

문서에서 너비와 높이 조합이 두 가지 이상 발견되었으며, 요약에 각 크기를 사용하는 페이지 수가 나뉘어 표시됩니다. 회전된 페이지는 똑바로 선 같은 크기의 페이지와 별개의 크기로 계산되므로, 세로 A4 파일 안에 가로 A4 페이지가 있으면 경고가 표시됩니다. 모든 페이지를 통일하려면 페이지 크기 맞추기를 사용하세요.

크기를 포인트 대신 인치나 밀리미터로 볼 수 있나요?

단위 메뉴에서 표 전체를 포인트, 인치, 밀리미터, 픽셀 중 원하는 단위로 바꿀 수 있습니다. 픽셀은 96PPI로 계산되며, 이는 브라우저와 대부분의 화면 도구가 PDF 페이지를 다루는 방식과 같습니다.

회전 열은 무엇을 알려주나요?

페이지에 저장된 회전 속성을 도 단위로 보여줍니다. 뷰어에서는 똑바로 보이는 페이지도 실제로는 90도 또는 270도 회전 값을 가질 수 있어 일부 인쇄 및 변환 작업에서 문제가 되며, PDF 회전으로 이를 바로잡을 수 있습니다.

결과를 내보낼 수 있나요?

CSV로 내보내기를 클릭하면 페이지당 한 행으로 page-dimensions.csv를 내려받습니다. 페이지 번호, 너비, 높이, 표준 크기, 방향, 가로세로 비율, 면적, 회전이 선택한 단위로 담기며, Excel이나 Google 스프레드시트에서 바로 열립니다.

이 도구가 내 PDF를 변경하나요?

아니요. 페이지 트리를 읽고 찾은 내용을 보여줄 뿐 아무것도 다시 쓰지 않으며, 제공되는 다운로드는 선택 사항인 CSV뿐입니다.

분석을 위해 PDF가 업로드되나요?

아니요. 파일은 브라우저에서 분석되고 측정값도 로컬에서 계산되며, 그래서 파일이 로드되자마자 결과가 나타납니다.
