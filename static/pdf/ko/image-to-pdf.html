자주 묻는 질문

어떤 이미지 형식을 PDF로 합칠 수 있나요?

JPG, JPEG, PNG, BMP, GIF, TIFF, PNM, PGM, PBM, PPM, PAM, JXR, JPX, JP2, PSD, SVG, HEIC, HEIF, WebP를 지원합니다. 한 번에 여러 형식을 섞을 수 있으며, 각 이미지는 images_to_pdf.pdf 파일 하나에서 별도의 페이지가 됩니다.

높음, 보통, 낮음 품질 설정은 무엇을 바꾸나요?

고품질은 이미지를 크기 조정이나 재인코딩 없이 그대로 포함합니다. 중간은 각 이미지를 품질 75%의 JPEG로 다시 인코딩하고 긴 변을 2500픽셀로 제한하며, 낮음은 품질 50%에 1500픽셀 제한을 사용해 이메일에 적합한 훨씬 작은 파일을 만듭니다.

투명한 PNG는 투명도가 유지되나요?

파일이 그대로 포함되는 고품질에서만 유지됩니다. 중간과 낮음은 모든 이미지를 알파 채널이 없는 JPEG로 변환하므로 투명한 영역은 유지되지 않고 평탄화됩니다.

페이지 순서는 어떻게 조절하나요?

페이지는 파일 목록의 순서, 즉 이미지를 선택하거나 끌어다 놓은 순서를 따릅니다. 순서를 바꾸려면 휴지통 아이콘으로 이미지를 제거한 뒤 파일 추가로 다시 추가해 맨 끝으로 보내세요.

페이지 크기를 A4나 Letter로 설정할 수 있나요?

이 도구에서는 할 수 없습니다. 각 페이지는 이미지의 크기를 그대로 따르므로 세로로 긴 휴대폰 사진은 세로로 긴 페이지가, 가로 스캔은 가로로 넓은 페이지가 됩니다. 이후 일정한 용지 크기가 필요하면 결과를 페이지 크기 통일로 처리하세요.

iPhone HEIC 사진은 먼저 변환해야 하나요?

아니요. HEIC와 HEIF 파일은 브라우저에서 디코딩되어 PNG로 바뀐 뒤 포함되며, WebP도 같은 방식으로 처리됩니다. 자동으로 이루어지므로 별도 단계가 필요 없습니다.

사진이 어딘가에 업로드되나요?

아니요. 디코딩, 압축, PDF 조립이 모두 브라우저에서 실행되므로 이미지는 기기 밖으로 나가지 않습니다. 그래서 원본 해상도 사진을 대량으로 처리하면 시간이 더 걸리고 컴퓨터의 메모리를 더 많이 사용합니다.

이미지가 모두 JPG라면 별도 도구가 있나요?

JPG를 PDF로는 더 단순한 인터페이스로 같은 결과를 내며, PNG, HEIC, WebP, TIFF 전용 변환기도 있습니다. 파일이 여러 형식이 섞여 있거나 PSD, JXR, PNM 같은 덜 흔한 형식일 때 이 도구를 사용하세요.
