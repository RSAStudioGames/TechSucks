자주 묻는 질문

어떤 종류의 손상된 PDF를 고칠 수 있나요?

파일의 내부 구조를 다시 만들어, 손상되었거나 없어진 상호 참조 테이블, 잘못된 개체 번호와 스트림 길이, 다운로드가 중간에 끊겨 잘린 끝부분, 버그가 있는 PDF 생성기가 남긴 문제를 복구합니다. 실제 콘텐츠 데이터가 파일에 아직 남아 있다면 대개 되살릴 수 있습니다.

PDF 복구로 복구할 수 없는 것은 무엇인가요?

콘텐츠 바이트 대부분이 사라진 파일, 확장자만 PDF일 뿐 실제로는 PDF가 아닌 파일, 암호를 모르는 암호화된 파일입니다. 이미지 데이터도 다시 만들 수 없어서, 다른 부분이 복구된 PDF 안의 손상된 그림은 손상된 채로 남습니다.

복구는 어떻게 작동하나요?

각 파일은 QPDF를 거치며, QPDF는 찾을 수 있는 구조를 모두 읽어 개체 테이블을 재구성하고 깨끗한 새 PDF를 작성합니다. 다시 작성된 파일은 repaired-<원본 이름>.pdf로 다운로드됩니다.

암호로 보호된 PDF도 복구할 수 있나요?

네, 암호를 알고 있다면 가능합니다. 복구를 시작하기 전에 암호를 물어보며, 복구된 사본은 암호화 없이 만들어지므로 여전히 암호가 필요하다면 PDF 보호를 다시 거치세요.

PDF 여러 개를 한 번에 복구할 수 있나요?

네. 복구된 파일이 하나면 바로 다운로드되고, 여러 개면 repaired_pdfs.zip으로 함께 다운로드됩니다. 복구하지 못한 파일은 메시지에 이름이 표시되며 나머지는 그대로 다운로드됩니다.

복구에 실패했습니다. 다른 방법이 있을까요?

Chrome이나 Firefox 같은 웹 브라우저는 자체 복구 로직이 있으니 파일을 브라우저에서 열고, 브라우저의 인쇄 또는 저장 기능으로 새 PDF를 만드세요. 파일이 암호화되어 있다면 먼저 암호 제거 도구로 암호를 제거한 다음 그 결과를 복구하세요.

복구하면 PDF의 모양이 바뀌나요?

아니요. 페이지 콘텐츠, 글꼴, 이미지는 그대로 옮겨지고 주변의 파일 구조만 다시 작성됩니다.

손상된 PDF가 복구를 위해 서버에 업로드되나요?

아니요. QPDF는 브라우저 안에서 WebAssembly로 실행되므로 손상된 파일은 내 기기에서 읽고 다시 작성됩니다. 여기서 복구에 실패한 파일도 어디에 복사된 적이 없습니다.
