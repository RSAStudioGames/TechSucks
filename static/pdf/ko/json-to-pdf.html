자주 묻는 질문

이 도구로 모든 JSON 파일을 PDF로 변환할 수 있나요?

아니요. BentoPDF의 PDF를 JSON으로 도구가 만든 JSON 파일에서만 PDF를 다시 만들 수 있으며, 이 JSON에는 문서의 전체 내부 구조가 저장되어 있습니다. API, 데이터베이스, 설정 파일에서 내보낸 JSON은 오류와 함께 실패합니다.

그렇다면 API 데이터나 설정 파일을 읽기 쉬운 PDF로 만들려면 어떻게 하나요?

JSON을 일반 텍스트로 텍스트를 PDF로에 붙여넣거나 업로드하면 페이지에 서식 있는 텍스트로 배치됩니다. JSON을 PDF로는 처음에 PDF였던 문서를 왕복 변환하는 용도로만 쓰입니다.

다시 만든 PDF는 원본과 같나요?

PDF를 JSON으로 만든 JSON에는 문서의 객체가 담겨 있어, 다시 변환하면 원본의 페이지, 텍스트, 이미지가 재현됩니다. 다시 변환해 비교하는 것은 내보내기가 모든 것을 담았는지 빠르게 확인하는 방법이기도 합니다.

여러 JSON 파일을 변환하면 결과는 어떻게 되나요?

파일이 하나여도 모든 변환 결과는 jsons-to-pdf.zip으로 다운로드됩니다. 안에서 각 PDF는 원본 JSON의 이름을 따르므로 report.json은 report.pdf가 됩니다.

다시 변환하기 전에 JSON을 편집할 수 있나요?

네, 구조가 CPDF 엔진에 유효하게 유지되는 한 가능합니다. 메타데이터나 텍스트 객체 편집 같은 JSON의 프로그램적 변경은 PDF로 다시 만들어지며, 잘못된 편집은 변환 오류를 일으킵니다.

CPDF 엔진을 사용할 수 없다고 나오는 이유는 무엇인가요?

이 변환은 CPDF WebAssembly 빌드에 의존합니다. bentopdf.com에는 포함되어 있지만, 자체 호스팅 사본은 이 도구가 실행되기 전에 WASM 설정에서 CPDF WASM 파일을 구성해야 합니다.

JSON 파일이 서버에 업로드되나요?

아니요. 파일은 브라우저에서 읽히고 CPDF 엔진을 로컬로 실행하는 웹 워커가 PDF로 다시 만들므로 전송되는 것이 없고, 큰 변환 중에도 페이지가 계속 반응합니다.
