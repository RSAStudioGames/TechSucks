자주 묻는 질문

문서 전체가 아니라 한 페이지만 회전할 수 있나요?

네. 모든 페이지가 자체 왼쪽, 오른쪽 버튼이 있는 미리보기로 표시되므로 40페이지 파일에서 옆으로 누운 스캔 한 장만 따로 고칠 수 있습니다. 문서 전체가 거꾸로일 때는 상단의 버튼으로 모든 페이지를 한꺼번에 회전합니다.

페이지를 180도 회전하려면 어떻게 하나요?

같은 방향을 두 번 클릭하세요. 회전은 90도 단위로 누적되므로 두 번 클릭하면 180도, 세 번 클릭하면 270도이며, 반대 방향으로 한 번 클릭한 것과 같습니다. 저장하기 전에 현재 상태를 볼 수 있도록 미리보기가 갱신됩니다.

회전하면 페이지 품질이 떨어지나요?

아니요. 이 도구는 아무것도 다시 렌더링하지 않고 각 페이지의 회전 속성만 바꾸므로 텍스트는 계속 선택할 수 있고, 이미지는 해상도를 유지하며, 파일 크기도 거의 그대로입니다.

다른 앱에서 파일을 열거나 인쇄해도 회전이 그대로 유지되나요?

네. 회전은 PDF 페이지 자체에 기록되므로 모든 뷰어와 프린터가 이를 따릅니다. 파일을 닫으면 초기화되는 뷰어의 임시 회전 버튼과는 다릅니다.

기울어진 스캔본을 바로잡을 때처럼 90도가 아닌 각도로 회전할 수 있나요?

여기서는 안 됩니다. 이 도구는 90도 단위로만 작동합니다. 임의의 각도는 사용자 지정 각도 회전을, 스캔본을 자동으로 바로잡으려면 PDF 기울기 보정을 사용하세요.

홀수 또는 짝수 페이지만 회전할 수 있나요?

이 도구에는 페이지 선택이나 범위 입력란이 없습니다. 버튼으로 페이지를 하나씩 회전하거나 전체를 한꺼번에 회전할 수 있습니다. 여러 페이지를 묶어서 선택하려면 PDF 멀티 도구가 더 적합합니다.

페이지를 회전하려고 내 PDF가 업로드되나요?

아니요. 미리보기는 브라우저에서 렌더링되고 회전된 파일도 로컬에서 만들어지므로 문서가 컴퓨터 밖으로 나가지 않습니다. 회전된 PDF는 원래 파일 이름으로 다운로드됩니다.

회전해도 북마크가 유지되나요?

페이지 콘텐츠, 이미지, 주석은 그대로 유지되지만, 회전된 파일이 복사된 페이지로 만들어지기 때문에 북마크는 옮겨지지 않습니다. 목차 구조에 의존하는 문서는 북마크 도구로 다시 추가해야 합니다.
