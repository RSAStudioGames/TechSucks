자주 묻는 질문

PDF를 Excel로 변환할 때 표를 찾지 못했다고 나오는 이유는 무엇인가요?

감지기는 괘선과 정렬된 셀 같은 표 구조를 찾습니다. 공백으로 열을 맞춘 텍스트나 스캔된 이미지의 일부로만 존재하는 표는 인식되지 않습니다. 스캔본은 먼저 OCR PDF를 실행하고, 서식이 느슨한 텍스트는 PDF를 텍스트로 변환으로 원본 내용을 가져와 직접 정리하세요.

여러 표는 스프레드시트에 어떻게 정리되나요?

감지된 각 표는 표 1 (페이지 3), 표 2 (페이지 5)처럼 이름이 붙은 별도의 워크시트가 되어 어느 페이지에서 왔는지 알 수 있습니다. 표가 하나뿐인 PDF는 Table이라는 시트 하나를 만듭니다. Excel이 31자까지만 허용하므로 시트 이름은 31자에서 잘립니다.

서식, 색상, 병합된 셀이 유지되나요?

아니요. 셀 텍스트만 옮겨지며 글꼴, 채우기, 테두리, 열 너비, 병합된 셀은 재현되지 않습니다. 숫자가 텍스트 셀로 들어올 수 있으므로, 열이 합계되지 않으면 해당 열을 선택하고 Excel의 숫자로 변환 안내를 사용하세요.

특정 페이지만 Excel로 변환할 수 있나요?

페이지 옵션은 없으며 모든 페이지를 스캔해 찾은 모든 표를 내보냅니다. 표 하나만 필요하면 먼저 해당 페이지를 별도의 PDF로 분리하거나, 각 표를 미리 보여주고 하나씩 다운로드할 수 있는 표 추출을 사용하세요.

PDF를 Excel로 변환, PDF를 CSV로 변환, 표 추출은 어떻게 다른가요?

PDF를 Excel로 변환은 모든 표를 표마다 시트가 하나씩 있는 .xlsx 통합 문서 하나에 담습니다. PDF를 CSV로 변환은 단순한 쉼표 구분 파일을 만들고, 표 추출은 각 표를 미리 보여주며 표별로 여러 형식의 다운로드를 제공합니다. 페이지 정보가 포함된 하나의 통합 문서에 모두 담고 싶다면 Excel을 선택하세요.

비밀번호로 보호된 PDF도 처리할 수 있나요?

파일을 열 때 비밀번호가 필요하면 추출을 시작하기 전에 도구가 비밀번호를 묻습니다. 출력된 .xlsx는 비밀번호로 보호되지 않습니다.

변환하는 동안 내 재무 데이터가 업로드되나요?

아니요. 표 감지는 WebAssembly로 브라우저에 로드된 PDF 엔진에서 실행되고 스프레드시트도 JavaScript 라이브러리가 로컬에서 만듭니다. 은행 명세서와 청구서가 내 컴퓨터 밖으로 나가지 않습니다.
