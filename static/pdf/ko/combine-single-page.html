자주 묻는 질문

PDF의 모든 페이지를 하나의 긴 페이지로 합치려면 어떻게 하나요?

PDF를 업로드하고 레이아웃 방향을 세로로 둔 채 처리 버튼을 클릭하세요. 모든 페이지가 위에서 아래로 하나의 연속된 페이지에 배치되며, 출력 너비는 가장 넓은 원본 페이지에 맞춰지고 더 좁은 페이지는 가운데에 정렬됩니다.

페이지를 위아래로 쌓지 않고 나란히 놓을 수 있나요?

레이아웃 방향에서 가로(왼쪽에서 오른쪽)를 선택하세요. 페이지가 하나의 넓은 페이지에 왼쪽에서 오른쪽으로 순서대로 배치되며, 가장 긴 페이지보다 짧은 페이지는 세로 가운데에 정렬됩니다.

페이지 사이에 간격이나 선을 넣을 수 있나요?

간격(기본값 0)은 72가 1인치인 PDF 고유 단위로 측정되는 페이지 사이의 틈을 추가하며, 배경색이 그 틈을 채웁니다. 구분선 추가를 켜면 각 틈의 가운데에 선이 그려지며 두께(0.5 단위 이상, 0.5 단위 간격)와 색상을 따로 지정할 수 있습니다.

배경색은 페이지 전체에 적용되나요, 틈에만 적용되나요?

배경색은 원본 페이지 아래의 출력 페이지 전체를 채우므로 페이지 사이의 간격과 더 좁은 페이지가 가운데 정렬될 때 생기는 여백에 나타납니다. 기본값인 흰색을 선택하면 채우기가 전혀 그려지지 않습니다.

합친 페이지의 텍스트도 선택할 수 있나요?

아니요. 각 원본 페이지는 2배 해상도의 이미지로 렌더링되어 새 페이지에 그려지므로 결과는 실제 텍스트가 아니라 페이지 그림입니다. 나중에 텍스트를 복사하거나 검색해야 한다면 원본 PDF를 보관하세요.

이어 붙일 수 있는 페이지 수에 제한이 있나요?

도구에는 상한이 없지만 페이지를 추가할 때마다 출력이 길어집니다. 100페이지 문서는 높이가 대략 100페이지에 달하는 페이지가 됩니다. 일부 리더는 매우 큰 페이지를 처리하지 못하며, 예를 들어 Adobe Reader는 한 변이 200인치를 넘는 페이지를 표시하지 않습니다.

긴 한 페이지 PDF는 어디에 유용한가요?

웹용 스크롤 미리보기, 디자인 목업, 만화 스트립, 스토리보드처럼 독자가 페이지를 넘기지 않고 스크롤하는 용도에 적합합니다. 한 장에 여러 페이지를 격자로 인쇄하려면 PDF N-Up이 더 알맞습니다.

합쳐진 PDF가 서버로 업로드되나요?

아니요. 페이지 렌더링과 새 한 페이지 PDF 생성 모두 브라우저에서 이루어지며 파일은 내내 기기에 남아 있습니다.
