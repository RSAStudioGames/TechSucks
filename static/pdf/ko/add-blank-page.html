자주 묻는 질문

빈 페이지는 어디에 삽입되나요?

위치 번호는 새 빈 페이지 앞에 기존 페이지가 몇 장 있는지를 뜻합니다. 맨 처음에 넣으려면 0, 3페이지 뒤에 넣으려면 3, 맨 끝에 추가하려면 전체 페이지 수를 입력하세요.

빈 페이지의 크기는 어떻게 되나요?

각 빈 페이지는 문서 첫 페이지의 너비와 높이를 그대로 따르므로 Letter 문서에는 Letter 크기, A4 문서에는 A4 크기의 빈 페이지가 들어갑니다. PDF에 여러 크기의 페이지가 섞여 있어도 빈 페이지는 인접한 페이지가 아니라 1페이지에 맞춰집니다.

한 번에 빈 페이지를 둘 이상 추가할 수 있나요?

1 이상의 수를 입력하면 모두 같은 위치에 함께 삽입됩니다. 여러 위치에 빈 페이지를 추가하려면 출력 파일에 도구를 다시 실행하거나 PDF 멀티 툴로 페이지를 시각적으로 정리하세요.

북마크와 문서 속성이 유지되나요?

페이지의 콘텐츠, 이미지, 텍스트, 주석은 그대로 유지됩니다. 문서를 페이지 단위로 다시 만들기 때문에 북마크(개요 패널)와 제목, 작성자 같은 속성은 새 파일로 옮겨지지 않습니다.

삽입된 페이지는 완전히 비어 있나요?

네. 텍스트도, 페이지 번호도, 인쇄된 메모도 없는 1페이지와 같은 크기의 흰 페이지입니다. 이후 페이지 번호를 넣고 싶다면 결과를 페이지 번호로 처리하세요.

양면 인쇄용으로 모든 챕터를 오른쪽 페이지에서 시작하게 만들 수 있나요?

가능합니다. 한 번에 한 위치씩 실행하면 됩니다. 홀수 페이지로 끝나는 각 챕터 뒤에 빈 페이지를 삽입하고 다운로드한 다음, 새 파일에서 다음 챕터를 위해 반복하세요. 출력 파일은 원래 파일 이름을 유지하므로 헷갈리지 않도록 복사본의 이름을 바꿔 가며 작업하세요.

암호로 보호된 PDF에도 빈 페이지를 추가할 수 있나요?

파일을 열 때 암호가 필요하면 도구가 페이지 수를 읽기 전에 암호를 요청합니다. 새 파일은 암호 없이 저장되므로 필요하다면 이후에 다시 보호하세요.

페이지를 추가하려고 PDF가 업로드되나요?

아니요. 페이지 수 확인과 새 문서 생성은 JavaScript PDF 라이브러리인 pdf-lib을 사용해 브라우저에서 처리되며, 다운로드는 메모리에서 바로 이루어집니다. 서버로는 아무것도 전송되지 않습니다.
