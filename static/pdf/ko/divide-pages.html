자주 묻는 질문

두 쪽씩 스캔한 책을 개별 페이지로 나누려면 어떻게 하나요?

PDF를 업로드하고 나누기 유형으로 세로(왼쪽 & 오른쪽)를 선택한 다음 처리하세요. 각 페이지가 정확히 중앙에서 잘려 왼쪽 페이지 다음에 오른쪽 페이지가 이어지므로, 한 장에 두 페이지씩 스캔한 책이 읽는 순서대로 한 장에 한 페이지가 됩니다.

세로 나누기와 가로 나누기는 어떻게 다른가요?

세로는 각 페이지를 가운데에서 왼쪽 절반과 오른쪽 절반으로 자르며 내용이 좌우로 나란히 있는 가로 방향 페이지에 알맞습니다. 가로는 가운데를 가로질러 위쪽 절반과 아래쪽 절반으로 자르며 위쪽 절반이 먼저 오고, 포스터나 위아래로 쌓인 양식처럼 세로로 긴 페이지에 알맞습니다.

일부 페이지만 나누고 나머지는 그대로 둘 수 있나요?

페이지 범위 입력란에 1-5, 8, 11-13 같은 범위를 입력하세요. 해당 페이지만 나뉘고 다른 페이지는 원래 위치 그대로 변경 없이 출력에 복사됩니다. 모든 페이지를 나누려면 입력란을 비워 두세요.

페이지를 나누면 품질이 떨어지거나 텍스트가 바뀌나요?

아니요. 도구는 다시 렌더링하는 대신 각 페이지를 두 번 복사하고 사본마다 다른 자르기 영역을 설정하므로 텍스트는 선택 가능하고 벡터 그래픽은 선명하며 이미지는 원래 해상도를 유지합니다.

중앙이 아니라 자르는 위치를 직접 정할 수 있나요?

아니요. 나누는 위치는 항상 페이지의 중앙입니다. 콘텐츠가 가운데에 있지 않거나 비대칭으로 잘라야 한다면 PDF 자르기로 각 절반에 원하는 영역을 정확히 지정하세요.

출력은 몇 페이지가 되나요?

나눈 각 페이지는 두 페이지가 되므로 10페이지 문서의 모든 페이지를 나누면 20페이지가 됩니다. 범위 밖의 페이지는 한 번씩만 계산되며 나뉜 절반은 원본과 같은 순서를 유지합니다.

나눈 페이지가 옆으로 누워 나옵니다. 어떻게 해야 하나요?

페이지 나누기는 아무것도 회전하지 않으므로 스캔 방식에 따라 나누기 전이나 나눈 출력에 PDF 회전으로 방향을 바로잡으세요.

페이지를 나눌 때 PDF가 업로드되나요?

아니요. 페이지 복사와 자르기 영역 변경은 브라우저에서 이루어지며 나눈 파일은 업로드 없이 기기에서 작성됩니다.
