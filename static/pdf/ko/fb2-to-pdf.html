자주 묻는 질문

FB2 파일이란 무엇인가요?

FB2는 FictionBook 2 전자책 형식으로, 러시아와 동유럽에서 흔히 쓰이는 XML 기반 형식입니다. 책의 텍스트, 장 구조, 포함된 이미지를 파일 하나에 저장하지만 해당 지역 밖의 많은 리더와 휴대폰에서는 열 수 없어 PDF로 변환하면 도움이 됩니다.

변환 후에도 장, 서식, 이미지가 유지되나요?

FB2 파일에 포함된 장 구분, 기본 텍스트 서식, 이미지가 모두 PDF로 옮겨집니다. PyMuPDF 엔진이 XML 구조를 직접 읽으므로 따로 설정할 것이 없습니다.

.fb2.zip 파일도 변환할 수 있나요?

바로는 안 됩니다. 이 도구는 일반 .fb2 파일만 받으므로 먼저 압축을 풀고 그 안의 .fb2 파일을 업로드하세요.

여러 FB2 책을 한 번에 변환할 수 있나요?

원하는 만큼 파일을 선택하거나 끌어다 놓고 PDF로 변환을 클릭하세요. 책 한 권은 같은 이름의 PDF로 다운로드되고, 여러 권은 책마다 PDF 하나씩 담아 fb2-converted.zip으로 묶입니다.

변환하기 전에 페이지 크기나 글꼴을 바꿀 수 있나요?

아니요. 이 변환기에는 레이아웃 옵션이 없으며 엔진이 기본 페이지 크기와 서체로 책을 페이지로 나눕니다. 나중에 다른 페이지 크기가 필요하면 결과를 페이지 크기 통일에서 처리하세요.

러시아어 등 키릴 문자 텍스트도 올바르게 변환되나요?

FB2 파일은 유니코드 XML이며 변환기가 유니코드 텍스트를 렌더링하므로 키릴 문자로 된 책도 원래 문자 그대로 변환됩니다. 텍스트는 PDF에서도 선택하고 검색할 수 있습니다.

변환하는 동안 전자책이 업로드되나요?

아니요. FB2 파일은 브라우저에서 실행되는 PDF 엔진이 분석하고 배치하며, 완성된 PDF만 기기에 저장됩니다. 서버로 전송되는 것이 없으므로 초안이나 개인 문서도 안심하고 변환할 수 있습니다.

PDF의 페이지 수가 전자책 리더에 표시되는 것과 다른 이유는 무엇인가요?

FB2는 리플로우형 형식이므로 페이지 수는 각 리더의 화면 크기와 글꼴 설정에 따라 달라집니다. PDF는 변환 시점에 레이아웃을 고정하므로 보통 다른 페이지 수가 나오며, 그 수는 이제 고정됩니다.
