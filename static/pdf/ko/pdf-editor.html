100% 개인정보 우선

모든 작업이 브라우저에서 이루어집니다. 파일은 기기 밖으로 나가지 않으며 서버로 업로드되지 않습니다. 완벽한 개인정보 보호를 보장합니다.

무제한 및 무료

모든 도구를 원하는 만큼, 어떤 크기의 파일로도 사용하세요. 파일 제한도, 도구 제한도 없습니다. 영원히 완전 무료입니다.

번개처럼 빠름

브라우저에서 처리하므로 결과를 바로 볼 수 있습니다. 업로드나 다운로드를 기다릴 필요가 없습니다. 페이지를 불러온 뒤에는 오프라인에서도 작동합니다.

회원가입 불필요

바로 도구를 사용해 보세요. 계정 생성, 이메일, 개인 정보가 필요 없습니다. 열기만 하면 바로 쓸 수 있습니다.

자주 묻는 질문

PDF에 있는 기존 텍스트를 수정할 수 있나요?

PDF 텍스트 편집에서는 단락을 클릭해 그 자리에서 바로 수정할 수 있으며, 입력하는 동안 주변 텍스트가 자동으로 재배치되고 글꼴과 스타일을 조절할 수 있습니다. 페이지 위에 새 텍스트 상자, 댓글, 형광펜, 도형, 이미지를 추가하려면 일반 PDF 편집 도구를 사용하세요.

PDF 편집 도구에서는 무엇을 할 수 있나요?

PDF 편집 도구 모음은 형광펜, 밑줄, 취소선, 자유 그리기, 텍스트와 댓글, 도형과 이미지, 영구 교정(가림 처리), 전체 텍스트 검색을 지원합니다. 원래의 PDF 구조를 유지하므로 글꼴, 레이아웃, 양식 필드가 그대로 보존되며, 최대 10개의 문서를 탭으로 열어 두고 전환할 수 있습니다.

PDF 용량을 줄이려면 어떻게 하나요?

PDF 압축은 사용하지 않는 구조를 제거하고, 이미지 해상도를 낮추고, 글꼴을 부분 포함하면서도 텍스트 선택과 링크는 그대로 유지합니다. 보통 수준으로 시작하거나 목표 파일 크기를 입력하고, 파일이 여전히 크면 그때 높음으로 올리세요.

어떤 편집 도구가 텍스트를 선택 가능한 상태로 유지하나요?

회전, 정리, 페이지 삭제, 배경색, 주석 제거 같은 페이지 단위 도구는 PDF 구조에서 작동하므로 텍스트를 계속 검색할 수 있습니다. 색상 반전, 텍스트 색상 변경, PDF를 그레이스케일로 변환은 모든 페이지를 이미지로 다시 렌더링하므로 결과물의 텍스트는 더 이상 선택하거나 검색할 수 없습니다. 이런 도구를 쓴 뒤에도 검색 가능한 텍스트가 필요하면 결과를 OCR PDF로 처리하세요.

페이지 번호나 머리글과 바닥글을 추가할 수 있나요?

페이지 번호는 여섯 가지 위치 중 원하는 곳에 모든 페이지의 번호를 넣으며, 숫자만 또는 "페이지 X / Y" 형식을 고르고 글꼴 크기와 색상도 선택할 수 있습니다. 머리글 및 바닥글은 페이지당 여섯 칸(상단과 하단의 왼쪽, 가운데, 오른쪽)에 텍스트를 넣고, {page}와 {total} 자리 표시자를 인식해 "Page {page} of {total}" 같은 바닥글이 각 페이지에 맞게 채워지며, 페이지 범위로 제한할 수도 있습니다.

모든 페이지에 워터마크를 넣을 수 있나요?

워터마크 추가는 페이지에 텍스트나 이미지를 찍어 넣으며, 실시간 미리보기에서 끌어서 위치를 정한 다음 투명도, 회전, 크기를 설정합니다. 타일 모드는 페이지 전체에 워터마크를 반복해 자르기로 지우기가 훨씬 어렵게 하며, 한 워터마크를 모든 페이지에 적용하거나 페이지 범위로 제한하거나 페이지마다 다른 워터마크를 지정할 수 있습니다.

한 페이지만 회전하거나 살짝 기울어진 스캔본을 바로잡을 수 있나요?

PDF 회전은 모든 페이지의 미리보기를 보여주며 페이지마다 90도 회전용 왼쪽, 오른쪽 버튼이 있고 문서 전체에 적용하는 일괄 컨트롤도 있습니다. 몇 도 정도 기울어진 스캔본은 사용자 지정 각도로 회전에서 페이지별로 또는 전체에 한꺼번에 원하는 각도를 입력할 수 있습니다.

여기서 PDF를 편집하면 어딘가로 업로드되나요?

아니요. 편집기와 이 페이지의 모든 도구는 브라우저 안에서 WebAssembly로 실행되므로, 서버를 거치지 않고 내 기기에서 파일을 열고 수정하고 저장합니다. 아무것도 저장되지 않으므로 작업을 마친 뒤 지울 사본도 없습니다.
