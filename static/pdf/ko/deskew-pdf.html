자주 묻는 질문

도구는 페이지가 기울어진 것을 어떻게 감지하나요?

각 페이지는 선택한 DPI의 이미지로 렌더링된 뒤 OpenCV가 분석합니다. 어두운 픽셀을 둘러싸는 최소 면적 사각형을 맞추고, 보조 수단으로 허프 변환으로 주된 텍스트 줄의 각도를 측정합니다. 이렇게 나온 각도가 결과 패널에 해당 페이지의 값으로 표시됩니다.

기울기 임계값 설정은 무엇을 하나요?

감지된 기울기가 임계값보다 작은 페이지는 그대로 둡니다. 기본값 0.5도는 이미 바른 페이지는 건드리지 않고 눈에 보이는 기울기를 잡아 줍니다. OCR 전에 가장 정밀하게 맞추려면 0.1도로 낮추고, 확연히 삐뚤어진 페이지만 보정하려면 1~2도로 올리세요.

기울기를 보정해도 텍스트를 선택할 수 있나요?

아니요. 보정이 필요 없던 페이지를 포함해 출력의 모든 페이지가 처리 DPI의 이미지로 기록되므로 기존 텍스트 레이어는 사라집니다. 검색 가능한 텍스트가 필요하면 결과를 PDF OCR로 처리하세요. OCR은 바로잡은 페이지에서 어차피 더 잘 작동합니다.

스캔의 기울기를 보정할 때 어떤 DPI를 사용해야 하나요?

150 DPI는 일반 Letter 크기 스캔에서 빠르고 정확합니다. 작은 글씨나 세부 묘사에는 200 또는 300 DPI를, 정밀도보다 속도가 중요하면 100 DPI를 사용하세요. 이 설정은 출력 페이지의 해상도도 결정하므로 값이 높을수록 파일이 커집니다.

회전 후 페이지 크기가 바뀌나요?

출력 페이지는 원래 페이지 크기를 유지합니다. 회전된 이미지는 회전으로 드러난 모서리를 흰색으로 채운 뒤 페이지에 맞춰지므로 콘텐츠가 아주 조금 줄어들 수 있지만 용지 밖으로 밀려나는 것은 없습니다.

모든 종류의 스캔에서 작동하나요?

텍스트의 가로줄이 뚜렷한 페이지에서 가장 잘 작동합니다. 대부분 사진, 도면, 대각선 디자인 요소로 이루어진 페이지는 감지기가 측정할 것이 적어 각도가 틀릴 수 있으므로 결과 패널을 확인하고 그런 페이지는 원본을 보관하세요.

어떤 페이지가 보정되었는지 어떻게 알 수 있나요?

처리가 끝나면 결과 패널에 모든 페이지가 감지된 각도와 함께 나열되고 회전된 페이지에 표시가 붙습니다. 임계값 미만의 페이지는 각도가 표시되지만 변경되지 않았다고 표시됩니다. 여러 PDF를 대기열에 넣었다면 각각 원래 이름으로 다운로드되며 패널에는 마지막으로 처리한 파일이 표시됩니다.

스캔 파일이 처리를 위해 업로드되나요?

아니요. PDF 렌더링과 OpenCV 분석 모두 WebAssembly를 통해 브라우저에서 실행됩니다. 엔진은 처음 사용할 때 다운로드되지만 문서는 컴퓨터를 벗어나지 않습니다.
