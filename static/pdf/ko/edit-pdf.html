자주 묻는 질문

이 편집기로 PDF의 기존 텍스트를 바꿀 수 있나요?

이 편집기는 페이지 위에서 작동합니다. 하이라이트, 댓글, 도형, 이미지, 자유 그리기, 편집 삭제, 새 텍스트 상자를 지원합니다. 문서에 이미 있는 텍스트를 고치려면 단락을 클릭해 그 자리에서 편집할 수 있는 PDF 텍스트 편집을 사용하세요.

내 주석이 Acrobat, 미리보기(Preview), Chrome에서도 표시되나요?

네. 하이라이트, 댓글, 도형, 그림은 표준 PDF 주석으로 저장되므로 다른 뷰어에서도 표시되며 보통 편집하거나 삭제할 수 있습니다. 텍스트 상자는 다운로드할 때 페이지에 일반 텍스트로 기록되므로 어디서나 똑같이 보이지만 이후에는 이동할 수 없습니다.

편집 삭제는 영구적인가요?

네, 적용한 후에는 영구적입니다. 텍스트나 영역을 표시하는 것은 표시만 할 뿐입니다. 편집 삭제(리댁션)를 적용하면 표시한 영역 아래의 콘텐츠가 상자로 덮이는 대신 파일에서 제거되므로 복사나 검색으로 텍스트를 복구할 수 없습니다. 아직 적용하지 않은 표시가 있는 채로 다운로드하면 편집기가 먼저 적용하겠냐고 묻습니다. 선택한 텍스트를 편집 삭제하면 파일이 암호화되어 있지 않은 한 파일 속성, 북마크, 댓글, 첨부 파일에 있는 그 텍스트의 사본도 다운로드할 때 함께 제거됩니다. 공유하기 전에 다운로드한 파일을 열어 확인하세요.

한 번에 PDF를 둘 이상 열 수 있나요?

최대 10개의 문서를 동시에 열 수 있으며 각 문서는 뷰어 위의 별도 탭에 표시됩니다. 파일을 더 추가하면 탭이 늘어나고 목록에서 파일을 제거하면 해당 탭이 닫힙니다.

편집기가 변경 사항을 자동으로 저장하나요?

아니요. 편집된 PDF 다운로드를 클릭하기 전까지 모든 내용은 브라우저 메모리에만 있으며 탭을 닫거나 새로 고치면 변경 사항이 사라집니다. 페이지를 떠나기 전에 다운로드하세요.

스캔한 PDF에서 텍스트를 하이라이트할 수 없는 이유는 무엇인가요?

하이라이트, 밑줄, 취소선은 실제 텍스트에 붙으며 스캔한 페이지는 이미지일 뿐입니다. 먼저 파일을 PDF OCR로 처리해 텍스트 레이어를 추가하거나 펜이나 사각형 도구로 시각적으로 표시하세요.

중국어, 일본어, 아랍어 같은 라틴 문자가 아닌 문자로 텍스트를 추가할 수 있나요?

네. 텍스트 상자에 기본 라틴 문자 범위를 벗어난 문자가 들어 있으면 편집기가 일치하는 Noto 글꼴을 가져와 PDF에 삽입하므로 다른 뷰어에서도 텍스트가 올바르게 표시됩니다.

편집기가 내 PDF를 업로드하나요?

아니요. 편집기는 브라우저 안에서 PDF 엔진(WebAssembly로 컴파일된 PDFium)을 실행합니다. 네트워크 요청은 편집기 코드와 선택적 글꼴 파일뿐이며 문서 자체는 기기를 벗어나지 않습니다.
