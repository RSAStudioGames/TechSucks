자주 묻는 질문

PDF를 평탄화하면 실제로 어떤 일이 일어나나요?

양식 필드, 체크박스, 라디오 버튼, 드롭다운, 서명 필드, 댓글, 하이라이트, 취소선, 스티커 메모, 스탬프, 잉크 표시 같은 상호작용 요소를 페이지 콘텐츠에 합칩니다. 이후에도 페이지는 같아 보이지만 아무것도 편집, 이동, 삭제할 수 없습니다.

평탄화한 후에도 텍스트를 선택하고 검색할 수 있나요?

네, 평탄화는 페이지를 이미지로 바꾸지 않습니다. 일반 텍스트, 이미지, 북마크, 페이지 크기는 그대로이며 양식 필드와 주석만 고정된 페이지 콘텐츠가 됩니다. 모든 페이지를 래스터화하려면 대신 PDF 래스터화를 사용하세요.

양식을 작성했고 답변을 고정하고 싶습니다. 이 도구가 맞나요?

네. 작성을 마친 양식을 평탄화하면 입력한 값이 페이지의 일부가 되어 받는 사람이 바꿀 수 없습니다. 평탄화를 되돌릴 방법은 없으므로 작성이 끝난 뒤에만 하세요.

양식을 찾을 수 없다고 나오는 이유는 무엇인가요?

PDF에 주석은 있지만 양식 필드가 없을 때 표시됩니다. 오류가 아니며 주석은 그대로 평탄화되고 파일은 정상적으로 다운로드됩니다.

평탄화하면 하이퍼링크와 댓글은 유지되나요?

댓글, 하이라이트, 기타 표시는 페이지에 합쳐져 계속 보이지만 팝업 메모는 사라지고 편집할 수 없게 됩니다. 링크도 주석이므로 텍스트는 페이지에 남아 있어도 클릭 가능한 링크가 작동하지 않을 수 있습니다.

여러 PDF를 한 번에 평탄화할 수 있나요?

네. 여러 파일을 업로드하고 PDF 평탄화를 클릭하면 PDF마다 파일 하나씩 담긴 flattened_pdfs.zip을 받습니다. 파일 하나는 이름 앞에 "flattened_"가 붙어 바로 다운로드됩니다.

서명 전에 평탄화해야 하나요, 후에 해야 하나요?

서명 전에 하세요. 먼저 평탄화해야 양식 값과 주석을 바꿀 수 없으며, 그 뒤에 서명하세요. 평탄화는 페이지 콘텐츠를 다시 쓰므로 디지털 서명 후에 하면 리더가 문서가 변경되었다고 알립니다.

PDF를 평탄화하려면 업로드해야 하나요?

아니요. 평탄화는 브라우저 안에서 pdf-lib로 실행되므로 파일과 양식에 입력한 내용은 기기 밖으로 나가지 않습니다.
