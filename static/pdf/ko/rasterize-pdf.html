자주 묻는 질문

PDF를 래스터화하면 실제로 어떻게 되나요?

모든 페이지가 비트맵으로 렌더링되고, 그 비트맵들이 새 PDF로 다시 조립됩니다. 결과물은 똑같아 보이지만 텍스트 개체, 글꼴, 레이어, 양식 필드, 숨겨진 콘텐츠가 없고 복사본처럼 각 페이지의 그림만 남습니다.

래스터화할 때 DPI는 어떤 값을 골라야 하나요?

기본값인 150은 화면에서 읽거나 일반 사무용 인쇄를 하기에 충분합니다. 인쇄 품질이 필요하거나 작은 글씨를 확대해서 볼 때는 300, 보관용이나 전문 인쇄에만 600, 선명도보다 가장 작은 파일 크기가 중요할 때는 72를 사용하세요.

PNG와 JPEG 중 무엇이 좋을까요?

PNG는 무손실이라 글자 가장자리가 선명하지만 파일이 더 큽니다. JPEG(품질 95로 저장)는 눈에 띄게 작고 스캔본이나 사진 페이지에 잘 맞지만, 선명한 글자 주변에 희미한 노이즈가 생길 수 있습니다. 흑백으로 변환은 두 형식 모두에서 쓸 수 있으며, 흑백 문서의 파일 크기를 더 줄여 줍니다.

래스터화한 파일이 원본보다 큰 이유는 무엇인가요?

텍스트 PDF는 페이지당 글꼴과 글리프 데이터를 몇 킬로바이트 정도만 저장하지만, Letter 용지의 300 DPI 이미지는 2550 x 3300 픽셀입니다. 크기가 중요하다면 DPI를 낮추거나 JPEG로 바꾸거나 결과물을 PDF 압축에 거치세요.

나중에 텍스트를 다시 선택할 수 있게 만들 수 있나요?

래스터화된 파일 자체에서는 불가능합니다. 이 작업은 되돌릴 수 없으므로 원본을 보관하세요. OCR PDF로 검색 가능한 텍스트 레이어를 다시 추가할 수는 있지만, 인식된 텍스트는 원본만큼 정확하지 않습니다.

PDF 평탄화와는 무엇이 다른가요?

평탄화는 양식 필드와 주석을 페이지에 합치되 텍스트는 텍스트로 유지합니다. 래스터화는 한 걸음 더 나아가 텍스트를 포함한 모든 것을 픽셀로 바꿉니다. 양식 필드나 댓글만 고정하면 된다면 PDF 평탄화가 파일을 검색 가능한 상태로 유지하고 훨씬 작게 만들어 줍니다.

기밀 문서가 래스터화를 위해 업로드되나요?

아니요. 렌더링은 브라우저에서 실행되는 PyMuPDF WebAssembly 모듈이 수행하므로 페이지는 내 기기에서 그려지고 다시 묶입니다. 그래서 이 도구는 민감한 파일을 공유하기 전에 숨겨진 텍스트와 레이어를 안전하게 제거하는 방법이 됩니다.

PDF 여러 개를 한 번에 래스터화할 수 있나요?

네. 원하는 만큼 추가할 수 있으며, 각 파일은 같은 DPI, 형식, 흑백 설정으로 처리되고 결과는 rasterized-pdfs.zip으로 함께 다운로드됩니다. 파일이 하나면 단독으로 다운로드됩니다.
