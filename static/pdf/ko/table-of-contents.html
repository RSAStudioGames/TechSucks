자주 묻는 질문

PDF에 목차 페이지를 추가하려면 어떻게 하나요?

북마크가 있는 PDF를 업로드하고 제목, 글꼴 크기, 글꼴을 설정한 뒤 목차 생성을 클릭하세요. 모든 북마크와 페이지 번호를 나열한 새 페이지가 문서 맨 앞에 삽입되고, 파일은 원래 이름으로 다운로드됩니다.

PDF에 북마크가 없다고 나오는 이유는 무엇인가요?

목차는 텍스트의 제목이 아니라 PDF의 북마크 개요로만 만들어지므로, 북마크가 없는 문서는 나열할 것이 없습니다. 먼저 북마크 편집으로 만든 다음 저장한 결과에 이 도구를 실행하세요.

목차 항목을 클릭할 수 있나요?

각 항목은 해당 페이지로 연결되므로 링크를 지원하는 모든 뷰어에서 바로 이동할 수 있으며, 종이 출력본을 위해 인쇄된 페이지 번호도 들어 있습니다.

중첩된 북마크도 처리하나요?

하위 북마크는 상위 항목 아래에 들여쓰기되므로 챕터와 섹션 계층이 여러 단계의 목록으로 표시됩니다.

어떤 글꼴과 크기를 쓸 수 있나요?

Times, Helvetica, Courier의 보통, 굵게, 기울임, 굵은 기울임 스타일로 이루어진 12가지 표준 PDF 글꼴 중에서 10pt부터 72pt까지 크기를 고를 수 있으며, 기본값은 Helvetica 12pt입니다. 이 내장 글꼴은 라틴 문자를 지원하므로 다른 문자로 된 북마크 제목은 올바르게 표시되지 않을 수 있습니다.

새 목차 페이지가 기존 북마크나 페이지 번호를 망가뜨리지 않나요?

기존 북마크는 유지되며, 새 페이지가 맨 앞에 들어간 뒤에도 올바른 페이지를 가리킵니다. 페이지에 인쇄된 번호는 바뀌지 않으므로 1이라고 적힌 페이지는 이제 실제로 두 번째 페이지가 됩니다. 목차 페이지 자체를 개요에 표시하려면 목차 페이지 북마크 추가를 선택하세요.

방금 병합한 PDF에 목차를 추가할 수 있나요?

병합된 파일에 북마크가 있다면 다른 PDF와 똑같이 작동합니다. 페이지 번호가 최종 페이지 순서와 맞도록 목차는 마지막 단계에서 생성하세요.

목차를 만들려고 내 PDF가 업로드되나요?

아니요. 북마크 개요를 읽고 목차 페이지를 조판하는 일은 브라우저의 백그라운드 스레드에서 WebAssembly로 실행되는 cpdf 엔진이 처리하며, 업데이트된 파일도 거기서 다운로드됩니다. 문서가 기기 밖으로 나가지 않습니다.
