자주 묻는 질문

BMP 이미지의 해상도는 어떻게 되나요?

페이지는 2배 고정 배율로 렌더링되므로 Letter 페이지(8.5 x 11인치)는 1224 x 1584 픽셀 이미지가 되며, 인치당 약 144픽셀입니다. 이 도구에는 DPI 설정이 없으며, 배율을 조절하려면 PDF를 PNG로 변환을 사용하세요.

여러 페이지 PDF는 어떻게 제공되나요?

한 페이지짜리 PDF는 파일 이름을 딴 .bmp 하나로 다운로드됩니다. 여러 페이지 PDF는 page_1.bmp, page_2.bmp 등 페이지당 이미지 하나가 담긴 filename_bmps.zip이라는 ZIP으로 다운로드됩니다.

BMP 파일은 왜 이렇게 큰가요?

BMP는 압축 없이 원시 픽셀 데이터를 저장하므로, 페이지가 비어 있든 세부 내용으로 가득하든 같은 공간을 차지하며 같은 페이지의 PNG나 JPG보다 파일이 훨씬 큽니다. 대상 소프트웨어가 PNG를 받는다면 PNG도 무손실이면서 크기는 훨씬 작습니다.

여러 PDF를 한 번에 BMP로 변환할 수 있나요?

아니요, 한 번에 PDF 하나씩만 가능하며 여러 파일을 놓으면 첫 번째 파일만 사용됩니다. 차례로 변환하거나, 먼저 페이지 추출로 필요한 페이지만 골라 각 작업의 크기를 작게 유지하세요.

변환하면 투명도나 벡터 품질이 유지되나요?

아니요. 모든 페이지가 흰 배경의 평평한 래스터 이미지가 되고 텍스트도 픽셀이 되므로, BMP는 검색할 수 없고 확대하면 흐려집니다. 편집이 필요하면 원본 PDF를 보관하세요.

비밀번호로 보호된 PDF도 BMP로 변환할 수 있나요?

네, 비밀번호를 알고 있다면 가능합니다. 파일을 불러올 때 도구가 비밀번호를 묻고 이후 페이지를 정상적으로 렌더링합니다. 비밀번호를 모르는 파일은 열 수 없습니다.

BMP로 변환하기 위해 내 PDF가 업로드되나요?

아니요. 렌더링은 브라우저의 캔버스에서 이루어지고 이미지도 로컬에서 ZIP으로 묶이므로 문서가 내 컴퓨터 밖으로 나가지 않습니다. 렌더링을 내 기기가 처리하기 때문에 용량이 큰 PDF는 시간이 더 걸릴 뿐입니다.

BMP가 꼭 필요하지 않다면 어떤 도구를 쓰는 게 좋나요?

파일이 작은 무손실 출력에는 PDF를 PNG로, 사진과 가장 작은 파일에는 PDF를 JPG로, 여러 페이지 팩스나 스캔 시스템에는 PDF를 TIFF로 변환을 쓰세요. BMP는 오래된 애플리케이션이나 장치가 요구할 때 주로 의미가 있습니다.
