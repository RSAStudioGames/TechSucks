자주 묻는 질문

PDF 멀티 도구에서는 단일 기능 도구로 할 수 없는 어떤 작업을 할 수 있나요?

병합, 순서 변경, 회전, 복제, 삭제, 삽입, 분할을 하나의 페이지 그리드에서 처리하므로, 단계마다 다운로드하고 다시 업로드하지 않고도 한 번에 여러 작업을 할 수 있습니다. 모든 동작에 실행 취소와 다시 실행이 적용되므로 내보내기 전에 마음껏 시도해 볼 수 있습니다.

여러 PDF의 페이지를 하나의 문서로 합치려면 어떻게 하나요?

원본 파일을 모두 업로드하면 페이지가 업로드 순서대로 하나의 그리드에 함께 나타납니다. 페이지를 원하는 순서로 끌어다 놓고, 필요 없는 페이지는 삭제한 다음 PDF 내보내기를 클릭해 결과를 파일 하나로 내려받으세요.

이미지를 페이지로 추가할 수 있나요?

JPG, PNG, WebP, HEIC, TIFF, BMP, GIF, SVG 파일을 PDF와 함께 끌어다 놓으면 각 이미지가 다른 페이지처럼 옮기고 회전하고 삭제할 수 있는 페이지가 됩니다. Insert 메뉴에서 빈 페이지를 추가할 수도 있습니다.

PDF 하나를 여러 파일로 나누려면 어떻게 하나요?

Split을 클릭하고 문서를 나눌 방식을 선택합니다. 페이지 범위, 홀수 및 짝수 페이지, 한 페이지씩, 북마크, N페이지마다, 파일 크기 중에서 고를 수 있습니다. 결과가 하나면 PDF로, 여러 개면 한꺼번에 ZIP으로 다운로드됩니다.

여기서 페이지를 회전하면 품질이 떨어지나요?

아니요. 회전은 내용을 다시 렌더링하지 않고 90도 단위의 페이지 속성으로 저장되므로 텍스트, 벡터, 이미지는 그대로입니다. 90, 180, 270도가 아닌 각도는 사용자 지정 각도로 회전을 사용하세요.

일부 페이지만 내보낼 수 있나요?

원하는 페이지의 체크박스를 선택하고 선택 항목 다운로드를 사용하면 해당 페이지만 selected-pages.pdf로 받을 수 있습니다. 작업 공간은 그대로 유지되므로 계속 작업하다가 나머지는 나중에 내보낼 수 있습니다.

내보낼 때 북마크는 어떻게 되나요?

내보내기는 문서를 페이지별로 다시 구성하므로 원본 파일의 북마크는 새 PDF로 옮겨지지 않습니다. 텍스트와 이미지를 포함한 페이지 내용은 그대로 복사됩니다.

멀티 도구를 사용할 때 내 PDF가 업로드되나요?

아니요. 페이지 미리보기 렌더링과 최종 PDF 또는 ZIP 생성이 브라우저에서 이루어지며, 손상된 파일도 불러오기 전에 로컬에서 복구됩니다. 그리드에 올린 어떤 파일도 내 컴퓨터 밖으로 나가지 않습니다.
