자주 묻는 질문

파일을 업로드하는 대신 텍스트를 직접 입력할 수 있나요?

네. 토글을 텍스트 입력으로 바꾸고 편집기에 붙여 넣거나 입력한 뒤 PDF 만들기를 클릭하세요. .txt 파일을 먼저 저장하지 않고 클립보드 내용을 PDF로 만드는 가장 빠른 방법입니다.

어떤 글꼴과 페이지 크기를 사용할 수 있나요?

Helvetica(산세리프), Tiro와 Times(세리프), Courier(고정폭)의 네 가지 글꼴을 6~72포인트 크기로 쓸 수 있습니다. 페이지 크기는 A0부터 C10까지의 ISO A, B, C 시리즈와 US Letter, Legal, Tabloid, Ledger, 11 x 17을 지원하며 기본값은 A4입니다.

.txt 파일을 여러 개 업로드하면 어떻게 되나요?

내용은 나열된 순서대로 하나의 PDF로 합쳐지며 파일 사이에 빈 줄이 들어갑니다. 파일 사이에 페이지 나누기는 없으므로 각 파일이 별도 페이지에 있어야 한다면 하나씩 변환하세요.

아랍어나 히브리어 같은 오른쪽에서 왼쪽으로 쓰는 언어도 처리하나요?

네. 텍스트에 아랍어, 히브리어, 페르시아어, 우르두어 문자가 있으면 편집기와 PDF 모두에서 방향이 오른쪽에서 왼쪽으로 바뀌고 텍스트가 오른쪽 정렬됩니다.

여백을 바꿀 수 있나요?

아니요. 여백은 모든 면에서 1인치(72포인트)로 고정되며, 텍스트는 선택한 글꼴 크기로 그 안에 맞게 줄 바꿈됩니다. 한 페이지에 더 많은 텍스트가 필요하면 더 큰 페이지 크기를 고르세요.

긴 줄은 줄 바꿈되나요, 아니면 잘리나요?

줄은 오른쪽 여백에서 자동으로 줄 바꿈되며, 원본의 줄 바꿈은 유지됩니다. Courier는 모든 글자의 너비가 같아 코드와 로그에 적합합니다.

텍스트 파일로 만든 PDF의 파일 이름은 무엇인가요?

입력 파일 이름과 관계없이 다운로드 파일 이름은 항상 text_to_pdf.pdf입니다. 여러 개를 만든다면 다운로드한 뒤 이름을 바꾸세요.

입력한 텍스트가 서버로 전송되나요?

아니요. PDF는 브라우저에서 실행되는 PDF 엔진이 만들므로 편집기에 붙여 넣은 메모, 로그, 인증 정보가 기기 밖으로 나가지 않습니다. 엔진 자체는 처음 사용할 때 다운로드되므로 첫 변환은 잠시 멈춘 것처럼 보입니다.
