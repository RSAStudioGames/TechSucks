자주 묻는 질문

PDF의 페이지 순서를 뒤집어야 하는 때는 언제인가요?

스캐너나 PDF로 인쇄한 작업이 시트를 마지막 페이지부터 읽어 들였거나, 이미지로 만든 문서가 거꾸로 되었을 때가 가장 흔합니다. 이 도구는 전체 순서를 뒤집어 마지막 페이지가 1페이지가 되게 합니다.

페이지의 내용이나 회전이 바뀌나요?

아니요. 각 페이지는 크기, 회전, 페이지에 있는 주석을 포함해 그대로 복사되며 순서만 바뀝니다.

북마크가 유지되나요?

페이지 콘텐츠와 페이지 수준 주석은 유지되지만, 결과물이 페이지 단위로 다시 만들어지므로 문서 수준 북마크는 옮겨지지 않습니다. 필요하면 북마크 편집으로 다시 추가하세요.

뒤집은 PDF의 파일 이름은 무엇인가요?

PDF 하나는 원래 파일 이름으로 다운로드되므로 같은 폴더에 저장하면 원본을 덮어씁니다. 여러 파일은 각각 따로 뒤집혀 reversed_pdfs.zip으로 함께 다운로드됩니다.

문서 전체를 뒤집지 않고 몇 페이지만 옮길 수 있나요?

페이지를 원하는 순서로 끌어다 놓거나 복제, 삭제하려면 복제 및 정리를 사용하세요. 페이지 뒤집기는 페이지별 설정 없이 한 번의 클릭으로 전체를 뒤집습니다.

암호로 보호된 PDF의 페이지도 뒤집을 수 있나요?

처리를 시작할 때 암호를 물어보며, 복호화된 사본이 뒤집힙니다. 결과물은 암호화되지 않습니다.

뒤집으려고 PDF가 업로드되나요?

아니요. 페이지는 브라우저에서 실행되는 pdf-lib가 새 문서로 복사하고 파일도 거기서 다운로드되며, 전송되는 것은 없습니다.
