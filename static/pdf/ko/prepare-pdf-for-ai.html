RAG/LLM 파이프라인을 위해 PDF를 LlamaIndex JSON으로 추출합니다.

PDF 파일 1개 이상

파일이 기기 밖으로 나가지 않습니다.

출력 형식:

각 PDF는 다음 항목이 포함된 LlamaIndex Document 객체 배열을 담은 JSON 파일로 추출됩니다.

  • text - 페이지별 추출 텍스트
  • metadata - 페이지 번호, 제목, 문서 정보
  • extra_info - RAG 시스템을 위한 추가 컨텍스트

자주 묻는 질문

JSON 출력에는 무엇이 들어 있나요?

LlamaIndex 문서 스키마를 따릅니다. 페이지마다 문서 하나가 만들어지며 해당 페이지의 텍스트와 메타데이터 필드가 담깁니다. PyMuPDF의 LlamaIndex 통합으로 생성되므로 LlamaIndex나 페이지별 텍스트와 메타데이터를 받는 어떤 파이프라인에도 바로 불러올 수 있습니다.

PDF를 텍스트로 변환이나 PDF를 Markdown으로 변환과는 어떻게 다른가요?

PDF를 텍스트로 변환은 하나의 일반 텍스트 스트림을 만들고, PDF를 Markdown으로 변환은 읽기 좋게 제목과 구조를 유지합니다. 이 도구는 내용을 페이지별로 나누고 메타데이터와 함께 구조화된 JSON으로 감싸 줍니다. 검색 파이프라인에서 청크 분할과 출처 인용에 필요한 형식입니다.

스캔한 PDF에도 작동하나요?

텍스트 레이어가 이미 있는 경우에만 가능합니다. 스캔 이미지는 출력이 비어 있거나 거의 비어 있으므로, 먼저 OCR PDF로 처리한 다음 추출하세요.

여러 PDF를 한꺼번에 처리할 수 있나요?

네. 여러 파일을 업로드하면 PDF마다 yourfile_llm.json 하나씩을 담은 pdf-for-ai.zip을 받게 되며, 파일이 하나면 yourfile_llm.json으로 바로 다운로드됩니다. 일괄 작업 중 한 파일이 실패해도 나머지는 계속 처리되고, 요약에 실패한 개수가 표시됩니다.

추출할 페이지를 선택하거나 청크 크기를 조절할 수 있나요?

아니요. 옵션이 없으며 모든 페이지가 전체 텍스트와 메타데이터와 함께 추출됩니다. 청크 분할은 임베딩 모델에 맞는 크기를 고를 수 있는 자체 파이프라인에서 하고, 필요 없는 페이지도 그곳에서 제외하세요.

비밀번호로 보호된 PDF도 AI 도구용으로 준비할 수 있나요?

네. 파일이 암호화되어 있으면 추출을 시작하기 전에 비밀번호를 묻고, 복호화된 사본에서 텍스트를 가져옵니다.

내 문서가 AI 서비스로 전송되나요?

아니요. 이름과 달리 AI 제공업체나 어떤 서버로도 아무것도 전송되지 않으며, 추출은 브라우저 안에서 WebAssembly로 컴파일된 PyMuPDF로 실행됩니다. JSON을 어디에 보낼지는 이후에 직접 결정합니다.

JSON 파일로 무엇을 할 수 있나요?

RAG 파이프라인에 넣거나, 챗봇용 지식 베이스를 만들거나, 보고서에 LLM 분석을 실행하거나, PDF 모음을 학습 데이터로 바꿀 수 있습니다. 내용이 메타데이터와 함께 페이지별로 나뉘므로 답변이 어느 페이지에서 나왔는지 가리킬 수 있습니다.
