자주 묻는 질문

PNG 이미지에서 품질 설정은 무엇을 하나요?

높음은 각 PNG를 원본 크기 그대로 무손실로 삽입합니다. 보통은 이미지를 품질 75%의 JPEG로 다시 인코딩하고 긴 변이 2500픽셀을 넘으면 줄이며, 낮음은 품질 50%의 JPEG에 1500픽셀 제한을 사용합니다.

스크린샷에는 어떤 설정을 써야 하나요?

높음입니다. 스크린샷과 도표는 가장자리가 날카롭고 글자가 작아서, 보통이나 낮음의 JPEG 압축은 눈에 띄는 흐림과 노이즈를 만듭니다. 보통이나 낮음은 파일 크기가 더 중요한 사진에 주로 적합합니다.

투명한 영역은 어떻게 되나요?

높음에서는 PNG의 알파 채널이 유지되어 투명한 영역 뒤로 페이지가 비치며, 뷰어에서는 흰색으로 표시됩니다. 보통과 낮음은 투명도가 없는 JPEG로 변환하므로, 배경이 투명한 이미지에는 높음을 사용하세요.

각 페이지의 크기는 어떻게 되나요?

페이지는 픽셀당 1포인트로 이미지의 픽셀 크기와 같아지므로, 1920 x 1080 스크린샷은 약 26.7 x 15인치 페이지가 되고, 보통이나 낮음에서는 축소된 이미지에 비례해 더 작은 페이지가 됩니다. A4나 Letter가 필요하면 나중에 페이지 크기 맞추기를 사용하세요.

여러 PNG를 PDF 하나에 넣고 순서를 정할 수 있나요?

네. 추가한 파일마다 목록에 표시된 순서대로 한 페이지가 되며, 순서를 바꾸려면 파일을 제거했다가 다시 추가하세요. 결과는 이미지마다 파일 하나가 아니라 항상 PDF 하나입니다.

PDF 크기가 PNG 크기와 비슷한 이유는 무엇인가요?

높음에서는 PNG 데이터가 그대로 저장되므로 PDF는 대략 이미지 크기의 합에 약간의 추가 용량이 더해진 크기가 됩니다. 너무 크면 보통이나 낮음을 선택하거나 PDF를 PDF 압축으로 처리하세요.

PNG를 삽입할 수 없으면 어떻게 되나요?

PDF 라이브러리가 거부하는 특이한 색상 프로필이나 비트 심도의 PNG는 다시 그려 품질 90%의 JPEG로 저장하므로, 약간의 품질 손실이 있더라도 변환은 끝까지 진행됩니다.

이미지가 업로드되나요?

아니요. 각 PNG는 브라우저 안에서 pdf-lib로 읽고, 필요하면 다시 압축하고, 삽입하므로 사내 도구의 스크린샷이나 개인 대화가 기기 밖으로 나가지 않습니다.
