자주 묻는 질문

어떤 PDF/A 버전을 선택해야 하나요?

기본값인 PDF/A-2b는 대부분의 보관 용도에 적합하며 투명도와 JPEG 2000 이미지를 허용합니다. PDF/A-1b는 받는 쪽이 요구할 때만 선택하세요. 가장 엄격한 수준으로 투명도와 레이어를 금지합니다. PDF/A-3b는 전자 청구서 형식에 쓰는 XML 데이터처럼 보관 파일에 첨부 파일을 담아야 할 때 선택하세요.

변환하면 내 파일에서 실제로 무엇이 바뀌나요?

Ghostscript가 표준을 충족하도록 PDF를 다시 작성합니다. 모든 글꼴은 부분 집합으로 포함되고, 색상은 sRGB 출력 의도를 가진 장치 독립 색상으로 변환되며, 선택한 수준이 금지하는 기능은 전체 작업을 실패시키지 않고 제거됩니다. 페이지 내용은 그대로 유지되고 텍스트도 계속 선택할 수 있습니다.

PDF/A 파일이 원본보다 왜 더 큰가요?

PDF/A는 모든 글꼴의 포함을 요구하므로, 원본이 참조만 하고 포함하지 않았던 글꼴이 이제 파일 안에 저장되며 sRGB 색상 프로필도 추가됩니다. PDF 압축으로 크기를 줄일 수 있으며, 엄격한 준수가 중요하다면 이후에 다시 검증하세요.

사전 평탄화는 언제 켜야 하나요?

일반 변환이 실패할 때만 사용하세요. 사전 평탄화는 Ghostscript를 실행하기 전에 모든 페이지를 300 DPI 이미지로 렌더링해 깨진 글꼴이나 특이한 투명도 문제를 피하지만 선택 가능한 텍스트가 남지 않으므로, 먼저 사용하지 않고 시도해 보세요. PyMuPDF 모듈도 필요하며 처음 사용할 때 로드됩니다.

결과물이 PDF/A 검증기를 반드시 통과하나요?

보장되지는 않습니다. Ghostscript는 대부분의 파일에서 규격에 맞는 결과를 만들지만 검증기는 아니므로, 법원, 저장소, 감사 담당자가 증빙을 요구한다면 veraPDF 같은 전용 PDF/A 검증기로 결과를 확인하세요.

여러 PDF를 한 번에 PDF/A로 변환할 수 있나요?

네. 여러 파일을 추가하면 같은 설정으로 차례로 변환되며, 파일 하나는 바로 다운로드되고 여러 개는 pdfa-converted.zip으로 함께 다운로드됩니다.

PDF/A 변환을 위해 내 문서가 서버로 업로드되나요?

아니요. Ghostscript는 브라우저 안에서 WebAssembly 모듈로 실행되므로 변환은 내 컴퓨터에서 이루어지고 파일은 밖으로 나가지 않습니다. 모듈 자체는 도구를 처음 사용할 때 CDN에서 가져오며, 그래서 첫 실행이 조금 더 걸립니다.

비밀번호로 보호된 PDF도 PDF/A로 변환할 수 있나요?

도구가 먼저 열기 비밀번호를 묻고 복호화된 파일을 변환합니다. PDF/A 자체가 암호화를 금지하므로 결과는 항상 보호되지 않으며, 비밀번호로 보호된 PDF/A는 만들 수 없습니다.
