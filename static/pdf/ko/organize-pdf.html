자주 묻는 질문

페이지를 다른 위치로 옮기려면 어떻게 하나요?

미리보기를 그리드의 새 위치로 끌어다 놓으세요. 페이지 번호 표시는 바로 업데이트됩니다. 문서 전체를 재배열하려면 페이지 순서 입력란에 새 순서(예: 3, 1, 2, 4)를 입력하고 적용을 클릭하세요.

페이지 순서 입력란에는 무엇을 입력해야 하나요?

원하는 순서대로 원본 페이지 번호를 쉼표로 구분해 입력하며, 모든 페이지가 정확히 한 번씩 들어가야 합니다. 3페이지 파일이라면 3, 1, 2는 가능하지만 3, 1(페이지 누락)이나 1, 1, 2(중복)는 거부됩니다. 복사와 삭제는 복제 및 삭제 버튼을 사용하세요.

한 페이지를 여러 번 복제할 수 있나요?

네. 초록색 복제 버튼을 클릭할 때마다 해당 페이지 바로 뒤에 복사본이 하나씩 추가되며, 각 복사본은 따로 원하는 위치로 끌어다 놓을 수 있습니다. 양식 페이지의 빈 사본을 한 파일에 여러 장 넣을 때 편리합니다.

여기서 페이지를 삭제할 수도 있나요?

네. 미리보기의 빨간색 삭제 버튼을 클릭하면 결과에서 제외됩니다. 마지막 남은 한 페이지는 삭제할 수 없다는 규칙만 있습니다. 범위로 많은 페이지를 지우려면 페이지 삭제가 더 빠릅니다.

페이지 순서를 바꿔도 북마크가 유지되나요?

각 페이지의 내용, 이미지, 주석은 유지됩니다. 하지만 북마크는 유지되지 않습니다. 재정리된 파일은 복사한 페이지로 새로 조립되기 때문에 탐색용 목차가 있는 문서는 목차가 사라집니다. 필요하면 나중에 북마크 도구로 다시 만드세요.

페이지 품질에 영향이 있나요?

아니요. 페이지는 다시 렌더링하지 않고 그대로 복사되므로 텍스트는 계속 선택할 수 있고 이미지는 원래 해상도를 유지합니다. 결과 파일은 원본 파일과 같은 이름으로 저장됩니다.

페이지를 재배열하는 동안 내 PDF가 업로드되나요?

아니요. 미리보기는 브라우저에서 만들고 새 파일도 로컬에서 조립하므로, 용량이 큰 문서라도 어디로도 전송되지 않습니다.

여러 PDF의 페이지를 한꺼번에 정리할 수 있나요?

아니요, 이 도구는 파일 하나에서 작동합니다. 여러 문서의 페이지를 하나의 순서로 모으려면, 모든 파일의 미리보기를 한 그리드에 보여주는 PDF 병합의 페이지 모드를 사용하세요.
