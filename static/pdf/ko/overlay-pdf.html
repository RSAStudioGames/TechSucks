이용 방법

1

두 개의 PDF 업로드

기본 PDF와 오버레이 또는 언더레이할 PDF를 업로드하세요.

2

모드 선택

오버레이(위) 또는 언더레이(뒤)를 선택하세요. 선택적으로 페이지 범위와 반복을 설정할 수 있습니다.

3

다운로드

오버레이 또는 언더레이가 적용된 PDF를 다운로드하세요.

자주 묻는 질문

오버레이를 일부 페이지에만 적용하려면 어떻게 하나요?

페이지 적용 범위 입력란에 기본 문서의 페이지 번호로 범위를 입력하세요. 예: 1-5, 8, 10-z (z는 마지막 페이지). 비워 두면 모든 페이지에 적용됩니다.

두 PDF의 페이지 수가 다르면 어떻게 되나요?

반복 옵션을 켜면 모든 기본 페이지가 채워질 때까지 오버레이의 페이지가 순서대로 반복되므로, 5페이지 문서에 2페이지 오버레이를 적용하면 1, 2, 1, 2, 1 순으로 적용됩니다. 끄면 페이지가 일대일로 대응되며, 오버레이 길이를 넘어서는 기본 페이지는 그대로 남습니다.

페이지 크기가 서로 같아야 하나요?

아니요. 기본 페이지보다 큰 오버레이 페이지는 맞게 축소되고, 작은 페이지는 확대하지 않고 가운데에 놓입니다. 위치, 배율, 투명도를 조절하는 설정은 없으므로, 합치기 전에 원하는 크기와 투명도로 오버레이 PDF를 만들어 두세요.

기본 PDF는 계속 검색하고 편집할 수 있나요?

네. 기본 문서의 텍스트, 링크, 양식 필드, 북마크는 그대로 유지됩니다. 오버레이는 각 페이지에 추가 그리기 레이어로 얹히며, 그 안의 텍스트도 선택할 수 있습니다.

오버레이 PDF의 링크, 양식 필드, 댓글도 함께 복사되나요?

아니요. 오버레이의 눈에 보이는 페이지 내용만 사용됩니다. 링크, 양식 필드, 댓글을 비롯한 오버레이 페이지의 주석은 결과로 옮겨지지 않습니다.

레터헤드에는 어떤 모드를 사용해야 하나요?

언더레이를 사용하세요. 레터헤드가 페이지 내용 뒤에 놓이며, 레터헤드가 한 페이지짜리라면 반복 옵션을 켜세요. 투명도, 회전, 위치를 조절할 수 있는 텍스트나 이미지 워터마크는 워터마크 추가에서 더 세밀하게 설정할 수 있습니다.

비밀번호로 보호된 PDF에서는 왜 실패하나요?

이 도구는 비밀번호를 묻지 않습니다. 두 파일 중 하나라도 열 때 비밀번호가 필요하면, 먼저 비밀번호 제거 도구로 제거한 다음 비밀번호가 없는 사본에 오버레이를 적용하세요.

두 PDF 모두 업로드되나요?

아니요. 오버레이는 WebAssembly로 컴파일된 qpdf가 브라우저 안에서만 적용하므로, 기본 문서와 오버레이 파일 모두 내 기기 밖으로 나가지 않습니다. 합쳐진 PDF는 기본 문서의 파일 이름으로 다운로드됩니다.
