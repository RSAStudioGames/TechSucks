자주 묻는 질문

PNG의 해상도는 어떻게 되나요?

배율 1.0x는 페이지 1인치당 72픽셀로 렌더링하므로 Letter 페이지는 612 x 792 픽셀이 됩니다. 기본값인 2.0x는 이를 1224 x 1584로 두 배로 늘리고, 3.0x는 1836 x 2376(인치당 216픽셀)이 됩니다.

인쇄용으로 300 DPI로 내보낼 수 있나요?

직접은 안 됩니다. 슬라이더는 3.0x까지, 표준 페이지에서 약 216 DPI이며, 이 도구에는 DPI를 직접 입력하는 칸이 없습니다.

배경이 투명한가요?

아니요. 페이지는 흰 배경에 그려지므로 PNG가 투명도를 지원하더라도 내용이 없는 영역은 투명이 아니라 흰색으로 나옵니다.

특정 페이지만 PNG로 변환할 수 있나요?

모든 페이지가 변환되며 페이지 범위 입력란은 없습니다. 먼저 페이지 추출로 필요한 페이지를 분리한 다음 그 작은 파일을 변환하세요.

파일 이름은 어떻게 정해지나요?

한 페이지짜리 PDF는 filename.png로 다운로드됩니다. 여러 페이지 문서는 page_1.png, page_2.png 등이 문서 순서대로 담긴 filename_pngs.zip으로 다운로드됩니다.

PNG 파일은 왜 이렇게 큰가요?

PNG는 무손실이므로 2.0x 배율의 한 페이지가 특히 스캔본과 사진의 경우 수 메가바이트가 되는 경우가 많습니다. 어느 정도 압축이 허용된다면 PDF를 JPG로 변환이나 PDF를 WebP로 변환이 같은 페이지로 훨씬 작은 이미지를 만듭니다.

주석과 작성된 양식 필드가 이미지에 나타나나요?

형광펜, 스탬프, 작성된 양식 필드 같은 보이는 마크업은 페이지에 보이는 모습 그대로 렌더링됩니다. 팝업 댓글 안의 텍스트는 그려지지 않고 메모 아이콘만 표시됩니다.

PDF가 서버에서 렌더링되나요?

아니요. 렌더링은 브라우저 안의 PDF.js가 처리하고 ZIP도 로컬에서 만들어지므로 문서가 내 컴퓨터 밖으로 나가지 않습니다. PDF에 비밀번호가 필요하면 먼저 비밀번호를 묻습니다.
