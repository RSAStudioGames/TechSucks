자주 묻는 질문

PDF를 비밀번호로 보호하는 것과 권한을 제한하는 것은 어떻게 다른가요?

PDF 보호로 설정하는 사용자 비밀번호는 파일을 여는 데 반드시 필요합니다. 권한은 암호화 안에 저장되는 플래그로, 파일을 연 뒤 인쇄, 복사, 편집, 주석, 양식 작성 같은 작업을 할 수 있는지를 제어하며 소유자 비밀번호가 설정된 경우에만 효력이 있습니다. 권한 변경에서는 작업별로 허용하거나 거부할 수 있고, PDF 보호는 소유자 비밀번호를 추가하는 즉시 가장 엄격한 권한 세트를 적용합니다.

비밀번호 보호는 얼마나 강력한가요?

PDF 보호와 권한 변경은 브라우저에서 실행되는 QPDF가 적용하는 PDF 2.0 표준의 256비트 AES 암호화를 사용합니다. 암호화 자체는 무차별 대입으로 뚫기가 현실적으로 어려우므로 약점은 비밀번호입니다. 긴 암호문을 사용하고 파일과는 다른 경로로 전달하세요. 권한 플래그는 별개의 문제로, 뷰어가 이를 지켜야만 효력이 있으며 일부 서드파티 도구는 이를 무시합니다.

비밀번호를 모르는 PDF의 비밀번호를 제거할 수 있나요?

아니요. PDF 잠금 해제는 비밀번호가 필요하며, 암호화와 제한이 없는 사본을 저장합니다. 비밀번호를 해독하거나 무차별 대입하는 도구는 없습니다. 열리기는 하지만 인쇄나 복사가 막힌 파일은 제한 제거를 사용하세요. 파일에 소유자 비밀번호가 있으면 그 비밀번호를 묻습니다.

PDF 서명과 디지털 서명은 어떻게 다른가요?

PDF 서명은 직접 그리거나 입력하거나 업로드한 서명 이미지를 페이지에 넣으며, 나중에 아무도 옮기거나 삭제하지 못하도록 평탄화하는 옵션이 있습니다. 디지털 서명은 자신의 X.509 인증서(.pfx, .p12 또는 .pem)로 암호화 서명을 적용해 누가 서명했는지와 이후 파일이 변경되지 않았음을 증명하며, 서명 검증은 파일에 이미 있는 서명을 확인합니다. 인증서 서명은 인증서 체인을 가져오기 위해 인터넷 연결이 필요할 수 있으며, 자체 서명 인증서는 Adobe Reader에서 경고가 표시됩니다.

텍스트를 완전히 사라지게 교정하려면 어떻게 하나요?

PDF 편집기의 교정(가림 처리) 도구를 사용하세요. 텍스트나 영역을 표시하는 것만으로는 표시만 될 뿐입니다. 교정을 적용하면 표시한 내용이 상자로 가려지는 데 그치지 않고 페이지에서 영구적으로 제거되며, 아직 적용하지 않은 표시가 있는 상태로 다운로드하면 편집기가 먼저 적용할지 묻습니다. 선택한 텍스트를 교정하면 파일 속성, 북마크, 댓글, 첨부 파일에 있는 같은 텍스트도 파일이 암호화되어 있지 않은 한 다운로드할 때 함께 제거됩니다. 영역 교정은 검색할 텍스트가 없으므로, 파일 속성, 댓글, 첨부 파일에 같은 정보가 드러날 수 있다면 결과에 메타데이터 제거나 PDF 정리도 실행하세요.

메타데이터 제거와 PDF 정리는 어떻게 다른가요?

메타데이터 제거는 제목, 작성자, 날짜, 생성 프로그램, XMP 데이터, 문서 ID, 애플리케이션별 데이터 같은 문서 속성만 지우고 페이지, 양식, 링크, 북마크는 그대로 둡니다. PDF 정리는 한 걸음 더 나아가 양식 평탄화, 주석, 삽입된 JavaScript, 첨부 파일, 레이어, 링크, 구조 태그 삭제까지 할 수 있으며 항목별로 선택할 수 있습니다. 둘 다 되돌릴 수 없으니 원본 파일을 보관하세요.

PDF 평탄화는 무엇을 하며 언제 사용해야 하나요?

PDF 평탄화은 양식 필드와 주석(댓글, 형광펜, 스탬프, 메모, 서명 필드)을 페이지 내용에 굽기 때문에 모양은 같지만 더 이상 편집하거나 옮기거나 삭제할 수 없습니다. 양식을 작성했거나 서명을 넣은 뒤 파일을 보내기 전에 사용하세요. 평탄화를 되돌릴 방법은 없습니다. 텍스트는 계속 선택하고 검색할 수 있으며 북마크도 유지됩니다.

내 비밀번호, 인증서, 파일이 서버로 전송되나요?

아니요. 암호화, 잠금 해제, 정리(새니타이즈), 서명이 모두 브라우저에서 WebAssembly로 실행되므로 문서, 입력한 비밀번호, 인증서의 개인 키가 내 기기에 그대로 남습니다. 유일한 네트워크 예외는 디지털 서명으로, 인증서 체인을 가져오기 위해 인증 기관 서버에 접속할 수 있지만 문서 자체는 전송되지 않습니다.
