자주 묻는 질문

자르면 영역 밖 페이지 부분이 영구적으로 삭제되나요?

기본 모드에서는 아닙니다. 도구는 각 페이지의 자르기 영역을 설정하므로 뷰어와 프린터에는 선택한 영역만 표시되지만 전체 페이지 콘텐츠는 파일에 남아 있으며 PDF 편집기에서 자르기 영역을 초기화하면 복원할 수 있습니다. 잘라낸 영역이 완전히 사라져야 한다면(예: 발췌본을 공유하기 전) 평면화 자르기를 켜세요.

자른 후에도 텍스트를 선택할 수 있나요?

기본 모드에서는 가능합니다. 다시 렌더링하지 않으므로 텍스트, 링크, 벡터 그래픽이 그대로 유지됩니다. 평면화 자르기는 잘라낸 각 페이지를 이미지로 렌더링하므로 선택 가능한 텍스트가 사라지고 파일이 보통 더 커집니다.

페이지마다 다른 크기로 자를 수 있나요?

네. 페이지 탐색으로 문서를 이동하며 각 페이지에 별도의 영역을 그리세요. 도구는 설정한 모든 영역을 기억하며 영역을 그리지 않은 페이지는 원래 크기를 유지합니다. 하나의 영역을 모든 페이지에 쓰려면 모든 페이지에 적용을 선택하세요. 현재 페이지의 영역이 모든 페이지에 복사됩니다.

자른 PDF의 페이지 크기는 어떻게 되나요?

잘라낸 각 페이지는 영역의 크기를 따르므로 Letter 페이지의 사방에서 1인치 여백을 잘라내면 6.5 x 9인치 페이지가 됩니다. 이후 A4나 Letter 같은 표준 크기가 필요하다면 결과를 페이지 크기 맞추기로 처리하세요.

정확한 자르기 치수를 입력할 방법이 있나요?

아니요. 자르기는 페이지 미리보기에서 오버레이의 모서리나 가장자리를 끌어서 하며, 이 도구에는 여백이나 크기를 입력하는 숫자 입력란이 없습니다. 여백이 몇 밀리미터뿐일 때는 브라우저를 확대하면 도움이 됩니다.

자르면 이미지 품질이나 파일 크기가 줄어드나요?

기본 모드는 둘 다 바꾸지 않습니다. 콘텐츠는 건드리지 않으므로 품질이 동일하고, 숨겨진 여백 데이터가 여전히 안에 있으므로 파일 크기도 거의 같습니다. 평면화 자르기는 잘라낸 페이지를 이미지로 바꾸므로 보통 파일이 작아지기보다 커집니다.

자르는 동안 문서가 업로드되나요?

아니요. 페이지 미리보기는 브라우저에서 렌더링되고 자르기는 로컬에서 적용되므로 파일이 컴퓨터를 벗어나지 않으며, 잘라낸 사본은 원래 파일 이름으로 저장됩니다.

스캔한 PDF를 잘라 검은 가장자리를 제거할 수 있나요?

네. 각 페이지의 어두운 테두리 안쪽에 영역을 그리거나, 모든 스캔의 테두리가 같다면 한 번 설정하고 모든 페이지에 적용을 사용하세요. 기본 자르기는 가장자리를 숨길 뿐이므로 테두리를 물리적으로 제거해야 한다면 평면화 자르기를 사용하고, 기울어진 스캔은 먼저 PDF 기울기 보정으로 바로잡으세요.
