자주 묻는 질문

여러 PDF를 하나의 파일로 합치려면 어떻게 하나요?

PDF 병합에 파일을 두 개 이상 추가하고 원하는 순서로 끌어다 놓으세요. 파일 모드는 문서 전체를 합치며 1-3, 5처럼 파일별 페이지 범위를 지정할 수 있고, 페이지 모드는 모든 페이지를 미리보기로 펼쳐 정확한 순서를 만들 수 있게 해줍니다. 파일 수나 전체 페이지 수에 제한이 없으며, 페이지는 다시 인코딩하지 않고 복사되므로 품질이 변하지 않습니다.

PDF를 분할하는 방법에는 어떤 것이 있나요?

PDF 분할에는 여섯 가지 모드가 있습니다. 페이지 범위, 미리보기에서 시각적으로 선택, 짝수 또는 홀수 페이지만, 페이지당 파일 하나, 북마크 수준을 선택해 북마크 경계에서 분할, N페이지마다 고정 단위로 분할입니다. 범위 하나는 PDF 하나로 다운로드되고, 여러 범위나 페이지별 출력은 ZIP으로 제공됩니다. 북마크 모드를 쓰려면 북마크가 실제로 있는 PDF가 필요합니다.

분할, 페이지 추출, 페이지 삭제는 어떻게 다른가요?

페이지 추출은 지정한 페이지만 남겨 새 파일로 저장하고, 페이지 삭제는 지정한 페이지를 제거하고 나머지를 모두 유지하며, 분할은 문서 하나를 여러 파일로 나눕니다. 추출과 삭제는 서로 반대이므로 페이지 번호 목록이 더 짧은 쪽을 고르세요.

페이지 순서를 바꾸거나 페이지를 복제할 수 있나요?

PDF 정리는 모든 페이지를 끌어서 옮길 수 있는 미리보기로 보여주며, 각 페이지에 복제와 삭제 버튼이 있습니다. 3, 1, 2, 4처럼 전체 페이지 순서를 입력해 한 번에 재배열할 수도 있고, 페이지 뒤집기는 문서 전체 또는 여러 문서를 한 번의 클릭으로 뒤집습니다.

스캐너가 앞면 페이지를 모두 먼저, 뒷면 페이지를 그 뒤에 스캔했습니다. 순서는 어떻게 바로잡나요?

양면 스캔 병합이 바로 그 작업을 처리합니다. 두 묶음을 앞면 1, 뒷면 1, 앞면 2, 뒷면 2 순서로 교차 배치하며, 두 번째 스캔 전에 뒤집어 놓은 묶음이라면 뒷면 묶음을 거꾸로 뒤집는 옵션도 있습니다. 앞면과 뒷면이 서로 다른 두 파일에 있다면 교차 병합이 여러 PDF의 페이지를 같은 방식으로 교차 배치합니다.

PDF를 접는 소책자로 인쇄하려면 어떻게 하나요?

PDF 소책자는 페이지를 중철 제본 순서로 재배열하며, 다운로드하기 전에 각 장의 미리보기를 보여줍니다. "짧은 변 기준으로 넘기기"로 양면 인쇄한 뒤 반으로 접어 가운데를 스테이플러로 고정하세요. 페이지 수가 4의 배수가 아니면 마지막 장을 채우도록 빈 페이지가 자동으로 추가됩니다.

PDF 두 버전 사이에서 무엇이 바뀌었는지 볼 수 있나요?

PDF 비교는 두 문서의 페이지를 짝지어 텍스트, 이미지, 주석, 머리글과 바닥글, 서식의 차이를 나란히 보기 또는 오버레이 보기로 강조 표시합니다. 필터로 신경 쓰지 않는 변경 유형을 숨길 수 있고, 스캔 문서에는 OCR을 켤 수 있으며, 비교 결과를 PDF 보고서로 내보낼 수 있습니다.

병합하거나 분할할 때 내 파일이 업로드되나요?

아니요. 병합, 분할, 순서 변경은 브라우저 안에서 WebAssembly로 실행되므로, 파일은 디스크에서 읽히고 결과도 서버를 거치지 않고 디스크에 다시 저장됩니다. 용량이 큰 스캔본이나 여러 파일을 한꺼번에 처리할 때도 마찬가지입니다.
