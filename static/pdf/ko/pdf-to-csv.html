자주 묻는 질문

도구가 PDF에서 표를 어떻게 찾나요?

모든 페이지에서 PyMuPDF의 표 감지를 실행해, 표를 이루는 괘선과 정렬된 텍스트를 찾습니다. 찾은 각 표는 CSV에 행 단위로 기록되며 모든 페이지가 한 번에 스캔됩니다.

PDF에 표가 여러 개 있으면 어떻게 되나요?

모든 표가 페이지 순서대로 하나의 .csv 파일에 기록되며, 한 표의 행이 이전 표의 행 뒤에 구분 없이 이어집니다. 표마다 별도 파일이나 별도 시트가 필요하면 대신 PDF를 Excel로 변환을 사용하세요.

PDF를 CSV로 변환할 때 표를 찾지 못했다고 나오는 이유는 무엇인가요?

대개 PDF가 표처럼 보이기만 하는 공백과 탭으로 데이터를 배치해 감지에 필요한 구조가 없거나, 페이지가 텍스트 레이어가 전혀 없는 스캔본이기 때문입니다. 스캔본은 감지할 텍스트가 생기도록 먼저 OCR PDF를 실행하세요.

셀 안의 쉼표, 따옴표, 줄바꿈은 어떻게 처리되나요?

쉼표, 큰따옴표, 줄바꿈이 들어 있는 셀은 큰따옴표로 감싸고 그 안의 따옴표는 두 번 써서 RFC 4180을 따릅니다. 파일은 UTF-8로 저장되므로 악센트 문자와 라틴 문자가 아닌 문자도 스프레드시트로 그대로 옮겨집니다.

CSV에 PDF의 서식이 유지되나요?

아니요. CSV는 일반 텍스트이므로 굵은 글씨, 색상, 병합된 셀, 열 너비는 사라지고 셀 값만 남습니다. 숫자는 통화 기호나 천 단위 구분 기호를 포함해 PDF에 표시된 텍스트 그대로 내보내집니다.

비밀번호로 보호된 PDF에서도 표를 추출할 수 있나요?

업로드 후 비밀번호를 묻고, 입력하면 추출이 이어집니다. 비밀번호는 브라우저에서 파일을 여는 용도로만 사용됩니다.

표를 추출하기 위해 PDF가 업로드되나요?

아니요. 표 감지 엔진은 WebAssembly로 브라우저에 로드되고 CSV도 로컬에서 생성되므로 문서가 내 기기 밖으로 나가지 않습니다. 엔진을 불러오는 동안 첫 실행은 조금 더 걸립니다.

열이 깨지지 않게 CSV를 Excel에서 열려면 어떻게 하나요?

이 도구는 표준 쉼표 구분자를 사용하므로 대부분의 환경에서 파일을 더블클릭하면 열립니다. Excel이 세미콜론을 기대하는 지역 설정이라면 데이터 > 텍스트/CSV 가져오기를 사용하고 구분자로 쉼표를 선택하세요.
