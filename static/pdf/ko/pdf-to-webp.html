자주 묻는 질문

PDF 페이지에 JPG 대신 WebP를 선택하는 이유는 무엇인가요?

WebP 파일은 같은 화질에서 보통 JPG보다 25~35% 작으며, 파일 크기가 중요한 웹 페이지와 소셜 게시물에서 의미가 큽니다. 오래된 소프트웨어나 이메일 클라이언트용 이미지가 필요하다면 PDF를 JPG로 변환이 더 안전합니다.

WebP 품질 설정은 어느 정도로 해야 하나요?

슬라이더는 10%에서 100%까지이며 기본값은 85%입니다. 80~85% 사이의 값은 화면에서 보통 원본과 똑같아 보이며, 더 높이면 주로 파일 크기만 커집니다.

WebP 이미지의 해상도는 어떻게 되나요?

각 페이지는 PDF 크기의 2배로 렌더링되므로 Letter 크기 페이지는 대략 1,224 x 1,584 픽셀로 나옵니다. 별도의 DPI나 크기 설정은 없습니다.

모든 페이지가 변환되나요, 아니면 일부만 고를 수 있나요?

모든 페이지가 변환됩니다. 한 페이지짜리 PDF는 filename.webp로 다운로드되고, 더 긴 문서는 page_1.webp, page_2.webp 등이 담긴 filename_webps.zip으로 다운로드됩니다. 특정 페이지만 변환하려면 먼저 페이지 추출로 분리하세요.

WebP 이미지가 어디서나 열리나요?

최신 버전의 Chrome, Firefox, Safari, Edge는 WebP를 표시하며 대부분의 최신 이미지 편집기도 마찬가지입니다. 일부 오래된 데스크톱 프로그램과 이메일 클라이언트는 지원하지 않으므로, 그런 경우에는 JPG나 PNG를 사용하세요.

WebP 결과물은 손실 압축인가요?

품질 슬라이더는 손실 압축을 조절하므로, 낮은 설정에서는 텍스트 가장자리의 세부 표현이 조금 줄어듭니다. 페이지를 정확히 복제하려면 무손실인 PDF를 PNG로 변환을 사용하세요.

WebP로 변환할 때 내 PDF 페이지가 업로드되나요?

아니요. 렌더링과 WebP 인코딩은 브라우저에서 이루어지고, 결과 이미지나 ZIP도 내 기기에서 만들어집니다.
