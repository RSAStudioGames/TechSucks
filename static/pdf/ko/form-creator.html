자주 묻는 질문

이미 가지고 있는 PDF에 입력 가능한 필드를 추가할 수 있나요?

PDF를 업로드하면 페이지가 편집기에 나타납니다. 도구 모음에서 필드 유형을 고르고 페이지를 클릭해 배치한 다음 필요에 따라 끌거나 크기를 조절하세요. PDF에 이미 양식 필드가 있으면 감지해 불러오므로 새 필드와 함께 이동, 편집, 삭제할 수 있습니다.

기존 PDF 없이 처음부터 양식을 만들 수 있나요?

빈 PDF 만들기를 클릭하고 Letter, A4, A5, Legal, Tabloid, A3 또는 포인트 단위의 사용자 지정 크기를 선택하세요. 여러 페이지 양식에는 페이지 추가를 사용하세요.

어떤 필드 유형을 사용할 수 있나요?

텍스트(한 줄, 여러 줄, 칸으로 나뉜 콤브 상자), 체크박스, 라디오 버튼 그룹, 드롭다운, 목록 상자, 누름 버튼, 서명, 날짜, 이미지, 바코드를 지원합니다. 각 필드에는 이름, 기본값, 글꼴 크기, 텍스트 색상, 정렬, 툴팁, 필수 또는 읽기 전용 플래그를 위한 속성 패널이 있습니다. 서명 필드는 표준 AcroForm 서명 필드이며 서명을 지원하는 뷰어에서만 표시됩니다.

하나만 선택되도록 라디오 버튼은 어떻게 그룹으로 묶나요?

모든 라디오 필드에는 그룹 이름이 있으며 기본값은 RadioGroup1입니다. 그룹 이름이 같은 필드는 하나만 선택할 수 있는 묶음이 되므로, 질문마다 별도의 그룹 이름을 지정하고 각 옵션에 서로 다른 내보내기 값을 설정하세요.

버튼으로 다른 필드를 표시하거나 숨기거나 양식을 초기화할 수 있나요?

버튼 동작에는 양식 초기화, 양식 인쇄, URL 열기, JavaScript 실행, 필드 표시/숨기기가 있으며, 필드 표시/숨기기는 다른 필드를 대상으로 지정해 표시, 숨기기 또는 전환할 수 있습니다. 표준 PDF 동작으로 저장되므로 Acrobat과 양식 스크립트를 지원하는 다른 뷰어에서 실행됩니다.

날짜 필드는 어떻게 작동하나요?

날짜 형식이 적용된 텍스트 필드로, 기본값은 mm/dd/yyyy이며 dd/mm/yyyy 같은 사용자 지정 패턴도 쓸 수 있습니다. AcroForm JavaScript를 지원하는 뷰어는 입력값을 검증하고 서식을 맞추며, 단순한 뷰어는 일반 텍스트로 처리합니다.

바코드와 이미지도 실제 양식 필드인가요?

바코드(QR 코드, Code 128, Code 39, EAN-13, UPC-A, DataMatrix, PDF417)는 입력한 값으로 생성되어 고정 이미지로 페이지에 그려지므로 양식을 작성하는 사람이 바꿀 수 없습니다. 이미지 필드는 사용자가 컴퓨터에서 그림을 고를 수 있는 버튼이며 Acrobat과 이미지 가져오기를 지원하는 다른 뷰어에서 작동합니다.

양식이나 업로드한 PDF가 서버에 저장되나요?

아니요. 편집기는 브라우저에서 실행되고, 필드는 기기에서 pdf-lib로 PDF에 기록되며, PDF 양식 다운로드는 결과를 원래 파일 이름으로 로컬에 저장합니다. 결과는 PDF 양식 작성에서 테스트할 수 있습니다.
