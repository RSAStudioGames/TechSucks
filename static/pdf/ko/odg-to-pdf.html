자주 묻는 질문

ODG 파일을 변환하려면 LibreOffice가 설치되어 있어야 하나요?

아니요. WebAssembly로 컴파일된 LibreOffice 엔진이 브라우저 안에서 실행되므로 컴퓨터에 LibreOffice, OpenOffice, 플러그인이 필요 없고 어떤 운영체제에서도 작동합니다.

그림은 벡터로 유지되나요, 이미지로 바뀌나요?

도형, 커넥터, 선, 텍스트 상자는 PDF에서 벡터로 유지되므로 그림은 어떤 인쇄 크기로도 깔끔하게 확대되고 텍스트는 선택할 수 있습니다.

PDF가 원래 페이지 크기를 유지하나요?

네. 가로 방향과 사용자 지정 크기를 포함해 ODG 파일의 페이지 크기가 유지되므로 A3나 Tabloid용으로 만든 도면은 그 크기로 인쇄됩니다.

여러 ODG 파일을 한 번에 변환할 수 있나요?

네. 여러 파일을 추가하면 결과가 그림마다 PDF 하나씩 담긴 odg-to-pdf.zip으로 다운로드됩니다. 파일 하나는 같은 기본 이름에 .pdf 확장자로 바로 다운로드됩니다.

첫 번째 ODG 변환이 이후 변환보다 오래 걸리는 이유는 무엇인가요?

처음 사용할 때 브라우저가 압축 상태 약 75MB의 LibreOffice 엔진을 다운로드하고 시작합니다. 같은 세션의 이후 변환은 이 단계를 건너뛰어 훨씬 빨리 끝납니다.

글꼴이 LibreOffice Draw와 똑같이 보이나요?

엔진은 컴퓨터에 설치된 글꼴이 아니라 엔진에 내장된 글꼴로 렌더링하므로 특이한 글꼴은 비슷한 글꼴로 바뀔 수 있습니다. 그림이 특정 서체에 의존한다면 결과를 확인하세요.

Apache OpenOffice Draw의 파일도 작동하나요?

네. 두 프로그램이 같은 OpenDocument Graphics 형식을 사용하므로 OpenOffice Draw에서 저장한 파일을 포함해 모든 .odg 파일이 작동합니다.

내 그림이 어딘가에 업로드되나요?

아니요. 변환은 브라우저 탭 안에서 완전히 실행되며, 다운로드되는 것은 엔진뿐이고 ODG 파일은 기기 밖으로 나가지 않습니다.
