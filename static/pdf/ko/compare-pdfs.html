자주 묻는 질문

PDF의 두 버전 사이에서 무엇이 바뀌었는지 어떻게 확인하나요?

원본을 첫 번째 PDF로, 수정본을 두 번째 PDF로 업로드하세요. 도구가 일치하는 페이지를 짝짓고 각 페이지 쌍에서 추가, 삭제, 수정, 이동된 콘텐츠를 강조 표시하며, 종류별로 몇 건의 변경이 발견되었는지 카운터로 보여 줍니다.

나란히 보기 모드와 오버레이 모드는 어떻게 다른가요?

나란히 보기는 동기화된 스크롤로 두 페이지를 옆에 나란히 보여 주어 텍스트 변경을 읽기에 가장 편합니다. 오버레이는 불투명도 슬라이더로 수정된 페이지를 원본 위에 겹쳐서 이동되거나 크기가 바뀐 요소를 두드러지게 하며, 깜박임 버튼은 위쪽 페이지를 켜고 꺼서 작은 이동도 눈에 띄게 합니다.

텍스트 레이어가 없는 스캔 PDF도 비교할 수 있나요?

OCR을 켜면 페이지 이미지가 브라우저에서 Tesseract로 처리되고 인식된 텍스트를 비교하므로 스캔 문서도 확인할 수 있습니다. OCR은 현재 영어 언어 모델을 사용하며, 이미 텍스트가 들어 있는 PDF를 비교할 때보다 느립니다.

서식 변경은 제외하고 텍스트 차이만 볼 수 있나요?

변경 사항은 텍스트, 이미지, 머리글/바닥글, 주석, 서식, 배경 범주로 묶이며 각각 켜고 끌 수 있습니다. 신경 쓰지 않는 범주는 끄고, 텍스트 검색 상자로 변경된 특정 단어나 구문을 찾을 수 있습니다.

버전 사이에 페이지가 추가, 삭제, 재배열되면 어떻게 되나요?

페이지는 페이지 번호가 아니라 콘텐츠 유사도로 짝지어지므로 삽입된 페이지 하나가 그 뒤의 모든 페이지를 어긋나게 하지 않습니다. 짝이 없는 페이지는 추가 또는 삭제로 표시되며, 페이지 탐색은 도구가 만든 쌍을 차례로 이동합니다.

댓글과 주석의 변경도 감지하나요?

주석 변경은 별도의 범주이므로 추가되거나 삭제된 댓글, 하이라이트, 마크업이 본문 텍스트와 따로 표시되며 주석 필터로 보이거나 숨길 수 있습니다.

비교 결과를 보고서로 저장할 수 있나요?

PDF로 내보내기 메뉴는 비교 결과를 PDF로 만듭니다. 나란히 보기 모드에서는 분할 보기, 페이지 번갈아 보기, 또는 강조 표시가 포함된 왼쪽이나 오른쪽 문서만 선택할 수 있으며, 오버레이 모드에서는 오버레이 보기를 내보냅니다.

비교하려고 두 PDF가 어딘가로 전송되나요?

아니요. 렌더링, 페이지 짝짓기, OCR, 변경 감지가 모두 WebAssembly와 웹 워커로 브라우저에서 실행되고 아무것도 전송되지 않으므로 계약서 같은 기밀 초안도 내 컴퓨터에 그대로 남습니다.
