자주 묻는 질문

텍스트를 잃지 않고 PDF의 배경색을 바꾸려면 어떻게 하나요?

PDF를 업로드하고 색상을 고르면 도구가 각 페이지 뒤에 단색 사각형을 그리고 그 위에 원래 페이지 콘텐츠를 올립니다. 텍스트는 실제 텍스트로 유지되어 선택하고 검색할 수 있으며 페이지 크기도 바뀌지 않습니다.

일부 페이지에 배경색이 나타나지 않는 이유는 무엇인가요?

색상은 기존 콘텐츠 아래에 깔리기 때문에 이미 불투명한 배경이 있는 페이지는 색상이 가려집니다. 보통 전체 페이지가 한 장의 이미지인 스캔 페이지와 흰색 배경이 그려진 페이지가 가장 흔한 경우입니다.

색상이 모든 페이지에 적용되나요, 아니면 특정 페이지를 고를 수 있나요?

페이지 범위 옵션이 없으므로 같은 색상이 문서의 모든 페이지에 적용됩니다. 특정 페이지에만 색을 입히려면 PDF 분할로 해당 페이지를 따로 빼내 색을 적용한 다음 다시 병합하세요.

PDF 배경에는 어떤 색상이 가장 좋나요?

크림색, 아이보리, 연한 노란색 같은 밝고 차분한 색조는 검은색 텍스트를 읽기 쉽게 유지하므로 기본값이 연한 노란색(#FFFFCC)입니다. 텍스트 색상은 바뀌지 않기 때문에 어두운 배경에서는 기본 검은색 텍스트를 읽기 어렵습니다. 어두운 페이지에 밝은 텍스트를 쓰려면 결과물에 텍스트 색상 변경을 사용하세요.

링크, 양식 필드, 북마크는 색상을 바꾼 후에도 유지되나요?

아니요. 각 페이지는 색상 레이어 위에 그림으로 다시 삽입되어 새 파일로 작성되므로 링크 주석, 양식 필드, 댓글, 북마크는 옮겨지지 않습니다. 먼저 배경을 바꾸고 그다음에 해당 요소를 추가하세요.

배경을 바꾸면 페이지가 이미지로 바뀌거나 파일이 커지나요?

페이지는 래스터화되지 않습니다. 이 도구는 PDF 객체 수준에서 작동하며 페이지마다 채워진 사각형 하나만 추가하므로 글꼴과 벡터 그래픽은 그대로 유지되고 파일 크기도 원본과 비슷하게 유지됩니다.

배경색을 바꿀 때 PDF가 업로드되나요?

아니요. 색상 레이어는 브라우저에서 실행되는 코드가 추가하며 완성된 파일은 페이지에서 바로 기기에 저장됩니다. 문서는 어느 단계에서도 서버로 전송되지 않습니다.

암호로 보호된 PDF의 배경색을 바꿀 수 있나요?

PDF를 열 때 암호가 필요하면 도구가 암호를 요청한 다음 평소처럼 파일을 처리합니다. 출력 파일은 해당 암호 없이 저장되므로 계속 잠가 두어야 한다면 PDF 보호로 다시 보호하세요.
