자주 묻는 질문

PDF에 어떤 종류의 파일을 삽입할 수 있나요?

모든 파일 형식을 첨부할 수 있습니다. 스프레드시트, 이미지, ZIP 압축 파일, CAD 도면, 실행 파일까지 가능합니다. 이 도구는 파일을 검사하거나 변환하지 않고 원래 파일 이름 그대로 PDF 안에 데이터를 저장하며, 한 번에 여러 파일을 삽입할 수 있습니다.

문서 수준 첨부 파일과 페이지 수준 첨부 파일은 어떻게 다른가요?

문서 수준 첨부 파일은 PDF 전체에 속하며 뷰어의 첨부 파일 패널에 표시됩니다. 페이지 수준 첨부 파일은 페이지 범위 입력란에 적은 페이지(예: 1,3,5-7)에 연결되며, 같은 파일이 해당 범위의 모든 페이지에 첨부됩니다. 일부 뷰어는 페이지 수준 첨부 파일을 전혀 표시하지 않으므로 문서 수준이 더 안전합니다.

PDF를 열면 첨부 파일은 어디에 표시되나요?

Adobe Acrobat Reader나 Firefox 내장 뷰어처럼 첨부 파일 패널이 있는 뷰어에서는 파일 이름 목록으로 표시되며 거기서 열거나 저장할 수 있습니다. 해당 패널이 없는 뷰어에서는 파일이 PDF 안에 있어도 표시되지 않습니다.

파일을 삽입하면 PDF 크기가 커지나요?

네. 파일 데이터가 PDF 안에 저장되므로 첨부 파일 크기만큼 커집니다. 1MB 보고서에 40MB 스프레드시트를 첨부하면 약 41MB의 PDF가 되므로, 결과물을 이메일로 보내기 전에 첨부 파일 크기를 확인하세요.

삽입할 때 첨부한 파일이 어딘가에 업로드되나요?

아니요. PDF와 첨부 파일은 CoherentPDF WebAssembly 모듈이 브라우저에서 읽고 결합하며, 결과는 페이지에서 바로 다운로드됩니다. 서버로는 아무것도 전송되지 않습니다.

고급 처리 모듈이 필요하다는 메시지가 나오는 이유는 무엇인가요?

삽입에는 CoherentPDF(cpdf) 모듈을 사용합니다. 이 모듈은 메인 사이트에 포함되어 있지 않고 처음 사용할 때 CDN에서 필요한 만큼 불러옵니다. BentoPDF를 직접 호스팅하거나 폐쇄망 환경에서 사용한다면 고급 기능 설정 페이지에서 도구가 자체 모듈 사본을 사용하도록 지정할 수 있습니다.

나중에 첨부 파일을 제거할 수 있나요?

네. 첨부 파일 편집은 삽입된 모든 파일을 보여 주며 개별 파일 또는 전체를 제거할 수 있고, 첨부 파일 추출은 파일을 각각 다운로드할 수 있게 저장합니다.

파일을 첨부하면 PDF의 디지털 서명이 깨지나요?

네. 첨부 파일을 추가하면 파일이 다시 작성되어 기존 디지털 서명이 무효가 됩니다. 먼저 파일을 첨부한 다음 완성된 PDF에 PDF 디지털 서명으로 서명하세요.
