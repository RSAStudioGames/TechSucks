자주 묻는 질문

어떤 픽셀이 텍스트인지 어떻게 아나요?

텍스트를 읽는 것이 아닙니다. 각 페이지를 이미지로 렌더링하고, 어두운 픽셀(0~255 범위에서 빨강, 초록, 파랑이 모두 120 미만)을 모두 선택한 색으로 다시 칠합니다. 검은색과 짙은 회색 글자는 해당되고, 옅은 회색 텍스트, 색이 있는 텍스트, 사진은 그대로 둡니다.

선, 테두리, 로고의 색도 바뀐 이유는 무엇인가요?

이 도구는 텍스트 개체가 아니라 어두운 픽셀을 대상으로 하므로, 표의 선, 밑줄, 검은색 그림을 포함한 모든 어두운 요소가 텍스트와 함께 색이 바뀝니다. 이 도구에서는 특정 영역을 제외할 수 없습니다.

특정 단어나 문단만 색을 바꿀 수 있나요?

아니요. 모든 페이지의 어두운 콘텐츠 전체에 한 가지 색이 적용됩니다. 나머지는 그대로 두고 특정 단어나 제목만 바꾸려면 PDF 편집기에서 텍스트를 직접 편집하세요.

텍스트를 계속 선택하고 검색할 수 있나요?

아니요. 결과물은 이미지 기반이며 각 페이지가 2배 크기로 렌더링되어 PNG로 삽입되므로 텍스트를 더 이상 선택, 검색, 복사할 수 없습니다. 편집 가능한 버전이 필요하면 원본을 보관하거나, 결과물에 OCR PDF를 실행해 텍스트 레이어를 다시 추가하세요.

파일이 훨씬 커진 이유는 무엇인가요?

텍스트 한 페이지는 텍스트일 때 몇 킬로바이트지만, 색을 바꾸면 전체 페이지 PNG 이미지가 되므로 여러 페이지 문서는 몇 배로 커질 수 있습니다. PDF 압축으로 선명도를 약간 희생하고 결과물을 줄일 수 있습니다.

어두운 배경에 맞게 검은 글자를 흰색으로 바꿀 수 있나요?

네, 흰색을 포함해 어떤 색이든 가능합니다. 다만 페이지 배경은 바뀌지 않으므로 원래 흰 페이지의 흰색 텍스트는 보이지 않게 됩니다. 페이지의 기존 배경과 대비되는 색을 고르세요.

텍스트 색을 바꾸려고 내 문서가 업로드되나요?

아니요. 각 페이지는 브라우저의 캔버스에서 렌더링되어 색이 바뀌고 새 PDF도 그곳에서 만들어지므로 파일이 기기 밖으로 나가지 않습니다. 진행 표시기가 처리 중인 페이지를 보여 줍니다.

색이 있거나 옅은 회색 텍스트가 바뀌지 않는 이유는 무엇인가요?

기준을 넘을 만큼 충분히 어두운 픽셀만 다시 칠해집니다. 빨간 제목, 파란 링크, 중간 회색 캡션, 기준보다 밝은 안티앨리어싱 가장자리는 원래 색을 유지하므로, 색을 바꾼 글자 주변에 옅은 테두리가 남을 수 있습니다.
