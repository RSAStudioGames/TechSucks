자주 묻는 질문

Markdown 파일을 PDF로 변환하려면 어떻게 하나요?

업로드를 클릭해 .md, .markdown, .txt 파일을 고르거나 왼쪽 창에 텍스트를 붙여넣으면 렌더링된 미리보기가 오른쪽에 나타납니다. PDF 내보내기를 클릭하거나 Ctrl+S(Mac에서는 Cmd+S)를 누른 뒤, 열리는 인쇄 대화상자에서 대상으로 PDF로 저장을 선택하세요.

PDF의 페이지 크기나 여백을 바꿀 수 있나요?

인쇄 대화상자에서 설정하세요. Letter, A4 등 용지 크기를 선택하고 여백을 조정하며, 넓은 표가 잘리면 배율을 낮추세요. 각 페이지에 날짜와 URL이 인쇄되는 것이 싫다면 거기서 머리글과 바닥글도 끄세요.

코드 블록, 표, 다이어그램을 지원하나요?

코드 블록은 JavaScript, TypeScript, Python, Go, Rust, Java, C#, C++, SQL, Bash, YAML, JSON, HTML, CSS에 구문 강조가 적용되고, 표준 파이프 표는 표로 렌더링됩니다. Mermaid 코드 블록은 미리보기와 PDF 모두에서 순서도, 시퀀스 다이어그램 등 여러 차트로 그려집니다.

기본 문법 외에 어떤 Markdown 확장이 작동하나요?

작업 목록, 각주, 정의 목록, 약어, 아래 첨자와 위 첨자, ==highlight== 및 ++insert++ 표시, :smile: 같은 이모지 단축 코드, 일반 URL 자동 링크를 지원합니다. 설정 대화상자에는 원시 HTML, 줄바꿈, 자동 링크, 타이포그래피 따옴표 스위치가 있습니다.

다크 테마가 내보낸 PDF에 영향을 주나요?

아니요. 테마 전환은 화면의 편집기 색상만 바꾸며, 인쇄 스타일시트가 흰 배경과 어두운 글자를 강제하므로 PDF는 어느 쪽이든 똑같이 보입니다.

PDF에 목차를 추가할 수 있나요?

목차를 넣고 싶은 위치에 ${toc}를 한 줄로 입력하면 문서가 렌더링될 때 제목으로 목차가 생성됩니다. 제목에는 앵커 ID도 붙으므로 문서 내 제목 링크가 미리보기에서 작동합니다.

PDF에 이미지를 넣을 수 있나요?

전체 이미지 URL이나 데이터 URI와 함께 표준 Markdown 이미지 구문을 사용하면 이미지가 미리보기에 렌더링되고 PDF에 인쇄됩니다. 편집기는 로컬 폴더에 접근할 수 없으므로 디스크에 있는 파일의 상대 경로는 불러오지 못합니다.

PDF를 만들려면 Markdown 텍스트가 서버에 업로드되나요?

아니요. Markdown은 브라우저에서 markdown-it으로 HTML로 렌더링되고 PDF는 브라우저의 인쇄 기능으로 만들어지므로 텍스트도 완성된 PDF도 서버에 닿지 않습니다. 메모, 초안, 내부 문서는 내 컴퓨터에만 남습니다.
