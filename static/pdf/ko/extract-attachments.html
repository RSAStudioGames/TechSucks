자주 묻는 질문

PDF에서 무엇이 첨부 파일로 간주되나요?

PDF 안에 포함된 파일로, 문서 수준(Acrobat의 클립 패널) 또는 파일 첨부 주석으로 특정 페이지에 연결된 것을 말합니다. 페이지에 그려진 이미지, 글꼴, 양식 데이터는 첨부 파일이 아니며, 그림은 이미지 추출을 사용하세요.

PDF에 첨부 파일이 없다고 나오는 이유는 무엇인가요?

cpdf가 문서 수준이나 페이지 수준 어디에서도 포함된 파일을 찾지 못했다는 뜻입니다. 페이지 위의 그림, 외부 파일로 연결되는 하이퍼링크, 양식 필드 데이터는 뷰어에서 첨부 파일처럼 보일 수 있지만 포함된 파일로 저장된 것이 아니므로 추출할 항목이 없습니다.

추출된 파일의 이름은 어떻게 정해지나요?

각 파일은 포함될 때의 이름을 그대로 유지합니다. 특정 페이지에 연결된 첨부 파일은 PDF 이름과 페이지 번호가 접두어로 붙으며, 이름이 같은 첨부 파일이 둘이면 두 번째에는 _1 접미사가 붙어 ZIP 안에서 덮어쓰이는 일이 없습니다.

여러 PDF에서 첨부 파일을 한 번에 추출할 수 있나요?

PDF를 원하는 만큼 업로드하고 첨부파일 추출을 한 번만 클릭하세요. 모든 파일에서 찾은 항목이 extracted-attachments.zip 하나에 담기며, 상태 메시지에 전체 개수와 합계 크기가 표시됩니다.

어떤 파일 형식을 추출할 수 있나요?

스프레드시트, XML 데이터 파일, 이미지, ZIP 아카이브, 다른 PDF 등 포함된 것은 무엇이든 가능합니다. 이 도구는 저장된 바이트를 그대로 복사해 내며 변환하거나 열지 않습니다.

비밀번호로 보호된 PDF에서도 첨부 파일을 추출할 수 있나요?

암호화된 PDF는 불러올 때 비밀번호를 물어보며, 이후 추출은 메모리에 있는 암호 해제된 사본에서 이루어집니다. 올바른 비밀번호가 없으면 포함된 파일을 읽을 수 없습니다.

전체를 추출하지 않고 첨부 파일을 하나씩 보거나 삭제할 수 있나요?

이 도구는 모든 항목을 한 번에 추출합니다. PDF 안의 첨부 파일을 개별적으로 확인, 삭제, 교체하려면 첨부파일 편집을, 새 파일을 포함하려면 첨부파일 추가를 사용하세요.

추출하는 동안 포함된 파일이 업로드되나요?

아니요. PDF는 브라우저의 백그라운드 워커에서 cpdf의 WebAssembly 빌드로 분석되고, ZIP은 로컬에서 만들어지며, 다운로드는 기기에서 바로 이루어집니다. 첨부 파일에는 원본 데이터가 들어 있는 경우가 많은데, 이 방식은 그것이 어떤 서버에도 올라가지 않게 합니다.
