자주 묻는 질문

PDF를 Markdown으로 변환하면 문서 구조가 얼마나 잘 유지되나요?

제목, 단락, 목록, 기본적인 굵게 및 기울임 서식이 변환되며, 각 페이지는 결과에서 가로줄(---)로 구분됩니다. 제목 수준은 글꼴 크기로 추정하므로, 스타일이 일관되지 않은 문서는 일부 제목의 수준이 잘못 나올 수 있습니다.

이미지 포함 옵션은 무엇을 하나요?

체크하면 PDF의 그림이 base64 데이터로 Markdown에 직접 삽입되므로, .md 파일 하나로 완결되지만 크기가 커질 수 있습니다. 텍스트 위주 문서는 끄면 결과가 작아지고 일반 편집기에서도 읽기 쉽습니다.

Markdown이 왜 비어 있거나 거의 비어 있나요?

변환기는 PDF의 텍스트 레이어를 읽으므로, 이미지뿐인 스캔 문서는 변환할 내용이 없습니다. 먼저 OCR PDF로 텍스트 레이어를 추가한 다음 결과를 변환하세요.

여러 단 레이아웃, 각주, 사이드바는 어떻게 처리하나요?

복잡한 레이아웃이 약점입니다. 여러 단의 텍스트가 뒤섞이거나 사이드바와 각주가 엉뚱한 위치에 들어갈 수 있습니다. 잡지 형식의 페이지는 결과를 검토하고 다듬어야 하며, 한 단짜리 문서는 정리할 것이 거의 없습니다.

여러 PDF를 한 번에 Markdown으로 변환할 수 있나요?

PDF를 여러 개 업로드하고 변환을 한 번 클릭하세요. 파일 하나는 filename.md로 다운로드되고, 여러 개는 PDF당 .md 하나씩 담긴 markdown-files.zip으로 받으며, 중복된 이름에는 번호가 붙습니다.

PDF를 텍스트로 변환과 같은 건가요?

아니요. PDF를 텍스트로 변환은 구조 없는 원시 텍스트를 제공하므로 스크립트에 넘기기에 더 좋습니다. PDF를 Markdown으로 변환은 제목, 목록, 강조를 유지하므로 결과를 Obsidian, 위키, 정적 사이트 생성기에 바로 붙여 넣을 수 있습니다.

비밀번호로 보호된 PDF도 변환할 수 있나요?

파일을 열 때 비밀번호가 필요하면 변환을 시작하기 전에 비밀번호를 묻고 평소처럼 텍스트를 추출합니다. 비밀번호는 어디에도 저장되지 않으며, Markdown 결과물 자체에는 보호 기능이 없습니다.

Markdown으로 변환하기 위해 내 PDF가 업로드되나요?

아니요. 변환은 WebAssembly로 브라우저에 로드된 PyMuPDF 엔진에서 실행되고, .md 파일이나 ZIP도 내 컴퓨터에서 만들어집니다. 연구 논문, 계약서, 내부 문서가 비공개로 유지됩니다.
