자주 묻는 질문

PDF의 특정 페이지에만 워터마크를 넣을 수 있나요?

네. 페이지 범위 입력란에 1-3, 5, 7-9 같은 범위를 입력하거나 "all"로 두세요. 페이지마다 다른 텍스트나 위치를 쓰려면 "모든 페이지에 적용" 선택을 해제하고 미리보기 위의 페이지 화살표로 각 페이지를 따로 설정하세요.

페이지에 대각선 CONFIDENTIAL이나 DRAFT 워터마크를 넣으려면 어떻게 하나요?

텍스트 모드에서 단어를 입력하고 글꼴 크기(10~200pt, 기본값 72)를 페이지 전체에 걸칠 만큼 키우세요. 각도 슬라이더는 이미 기본값이 클래식한 대각선 모양인 -45도라서, 보통은 텍스트를 키워 미리보기 중앙으로 끌어다 놓기만 하면 됩니다.

로고 이미지를 워터마크로 사용할 수 있나요?

이미지 모드로 전환해 PNG나 JPG를 업로드하세요. 다른 이미지 형식은 지원되지 않습니다. 배경이 투명한 PNG가 페이지와 가장 잘 어울립니다. 크기를 10%에서 200%까지 조절하고 불투명도와 각도를 설정한 다음 미리보기에서 원하는 위치로 끌어다 놓을 수 있습니다.

바둑판식 레이아웃은 무엇을 하나요?

바둑판식은 회전 각도를 따르는 대각선 격자로 페이지 전체에 워터마크를 반복해서 표시하므로 표시가 가장자리까지 이어집니다. 가로 및 세로 간격 슬라이더는 워터마크 크기에 대한 백분율로 타일 사이 간격을 조절합니다. 바둑판식을 쓸 때는 아래 문서가 읽히도록 불투명도를 낮추세요.

나중에 누군가 워터마크를 제거할 수 있나요?

워터마크는 별도의 주석이 아니라 페이지 콘텐츠에 그려지므로 PDF 뷰어에서 클릭 한 번으로 삭제할 수 없습니다. 하지만 변조가 불가능한 것은 아닙니다. 더 제거하기 어렵게 하려면 바둑판식 모드를 사용하거나 "워터마크 평면화"를 선택해 모든 페이지를 픽셀로 합치세요. 이 경우 문서의 텍스트도 선택할 수 없게 됩니다.

워터마크를 추가하면 원본 텍스트나 이미지 품질이 바뀌나요?

아니요. 페이지는 원래의 텍스트, 이미지, 크기를 그대로 유지하고 워터마크가 그 위에 얹히므로 텍스트를 계속 선택하고 검색할 수 있습니다. 단, "워터마크 평면화" 옵션은 예외로, 모든 페이지를 2.5배 배율의 이미지로 다시 렌더링하여 선택 가능한 텍스트가 사라집니다.

워터마크에는 어느 정도의 불투명도가 좋은가요?

슬라이더 범위는 0.05에서 1까지이며 기본값은 0.3입니다. 0.2에서 0.4 사이의 값은 아래 콘텐츠를 가리지 않으면서 표시가 보이도록 유지합니다. 여백이나 모서리에 놓는 작은 표시에만 더 높은 값을 사용하세요.

워터마크를 추가할 때 PDF가 업로드되나요?

아니요. 실시간 미리보기, 끌어다 놓기 편집기, 최종 렌더링이 모두 pdf-lib으로 브라우저 안에서 실행되므로 PDF도 추가한 로고 이미지도 기기 밖으로 나가지 않습니다.
