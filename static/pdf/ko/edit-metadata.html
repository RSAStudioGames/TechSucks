자주 묻는 질문

어떤 메타데이터 필드를 바꿀 수 있나요?

제목, 작성자, 주제, 키워드, 작성 프로그램, 생성 프로그램, 생성 날짜, 수정 날짜와 추가한 사용자 지정 키-값 쌍입니다. 양식은 파일의 현재 값으로 채워져 열리므로 바꿀 부분만 편집하면 됩니다.

작성자 같은 필드를 완전히 삭제하려면 어떻게 하나요?

입력란을 지우고 저장하세요. 양식에 있는 내용이 그대로 기록되므로 비운 필드는 빈 값으로 저장됩니다. 숨겨진 필드를 포함해 모든 필드를 한 번에 제거하려면 메타데이터 제거를 사용하세요.

건드리지 않았는데도 수정 날짜가 바뀌는 이유는 무엇인가요?

수정 날짜 입력란을 비워 두면 도구가 저장할 때 현재 날짜와 시간을 기록합니다. 특정 값을 유지해야 한다면 선택기에서 날짜를 직접 지정하세요.

부서나 프로젝트 ID 같은 나만의 필드를 추가할 수 있나요?

네. 추가 버튼을 클릭하고 키와 값을 입력하면 표준 필드와 함께 PDF의 정보 사전에 기록됩니다. 모든 리더가 사용자 지정 항목을 표시하지는 않지만 파일에는 남아 있으며 메타데이터 보기처럼 전체 정보 사전을 읽는 도구에는 표시됩니다.

제목을 바꿨는데 Acrobat에는 여전히 이전 제목이 표시됩니다. 왜 그런가요?

도구는 문서 정보 사전에 기록합니다. 일부 PDF에는 XMP 메타데이터 스트림도 있으며 Acrobat 같은 리더는 둘 다 있을 때 XMP를 우선하므로 이전 제목이 거기서 계속 표시될 수 있습니다. 충돌을 피하려면 먼저 메타데이터 제거를 실행한 다음 편집하세요.

키워드는 어떻게 입력해야 하나요?

invoice, 2026, Q3처럼 쉼표로 구분하세요. 문서 관리 시스템과 데스크톱 검색이 색인할 수 있는 키워드 목록으로 저장됩니다.

메타데이터를 편집하면 페이지가 바뀌거나 파일이 어딘가로 전송되나요?

아니요. 정보 사전만 다시 쓰이며 페이지, 글꼴, 링크, 북마크는 그대로이고 모든 편집이 브라우저에서 이루어지므로 문서가 기기를 벗어나지 않습니다.

암호로 보호된 PDF의 메타데이터를 편집할 수 있나요?

파일을 열 때 암호가 필요하면 도구가 암호를 요청한 다음 문서를 정상적으로 불러옵니다. 암호가 없으면 여기서 파일을 열 수 없습니다.
