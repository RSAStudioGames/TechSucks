PDF 분할

원하는 페이지 범위를 새 PDF로 추출합니다.

클릭하여 파일 선택 또는 파일을 끌어다 놓으세요

PDF 파일 1개

파일이 기기 밖으로 나가지 않습니다.

사용 방법:

  • 쉼표로 구분해 페이지 번호를 입력하세요(예: 2, 8, 14).
  • 하이픈으로 페이지 범위를 입력하세요(예: 5-10).
  • 복잡한 선택은 조합해서 사용하세요(예: 1-3, 7, 12-15).

사용 방법:

  • 모든 짝수 페이지(2, 4, 6...) 또는 모든 홀수 페이지(1, 3, 5...)를 새 PDF로 추출합니다.

사용 방법:

  • PDF의 모든 페이지가 각각 별도의 PDF 파일로 저장됩니다.
  • 결과는 모든 페이지가 담긴 ZIP 파일로 다운로드됩니다.

사용 방법:

  • 아래 페이지 미리보기를 클릭해 추출할 페이지를 선택하세요.
  • 선택한 페이지가 강조 표시됩니다.

사용 방법:

  • 북마크(목차)를 기준으로 PDF를 분할합니다.
  • 분할할 북마크 수준을 선택하세요.

사용 방법:

  • PDF를 각각 N페이지를 담은 여러 파일로 분할합니다.

출력

여러 파일은 ZIP으로 함께 다운로드됩니다.

자주 묻는 질문

PDF에서 페이지 범위를 추출하려면 어떻게 하나요?

페이지 범위로 추출을 선택하고 1-5, 8, 11-13처럼 원하는 페이지를 입력하세요. 기본적으로 선택한 페이지는 PDF 하나로 합쳐지며, 출력을 범위당 PDF 하나로 바꾸면 쉼표로 구분한 각 범위가 split-pages.zip 안의 개별 파일이 됩니다.

PDF를 페이지당 파일 하나로 분할할 수 있나요?

네. 모든 페이지를 개별 파일로 분할을 선택하면 모든 페이지가 page-1.pdf, page-2.pdf 등의 이름으로 각각의 PDF로 만들어져 split-pages.zip에 담깁니다.

PDF를 N페이지마다 나누려면 어떻게 하나요?

N페이지마다 분할을 선택하고 청크 크기를 입력하세요. 23페이지 파일을 5페이지마다 나누면 PDF 다섯 개가 만들어지며, 마지막 파일은 3페이지뿐이라는 경고가 미리 표시됩니다. 파일은 split-n-times.zip으로 다운로드됩니다.

PDF를 챕터나 북마크 기준으로 분할할 수 있나요?

네, PDF에 북마크가 있다면 가능합니다. 북마크로 분할과 수준(전체 또는 수준 0~3)을 선택하면 각 북마크의 페이지에서 새 파일이 시작되며, split-by-bookmarks.zip 안에 split-1.pdf, split-2.pdf 등으로 만들어집니다. 선택한 수준에 북마크가 없는 PDF는 오류가 표시됩니다.

홀수 페이지와 짝수 페이지는 어떻게 나누나요?

짝수/홀수 페이지로 분할을 선택하고 짝수 또는 홀수를 고르면, 해당 페이지가 원래 순서대로 PDF 하나에 추출됩니다. 단면 프린터로 양면 인쇄를 할 때 흔히 쓰는 단계입니다.

숫자를 입력하는 대신 페이지를 시각적으로 고를 수 있나요?

네. 페이지를 시각적으로 선택은 모든 페이지의 미리보기를 보여 주며, 원하는 페이지를 클릭하면 페이지 순서대로 추출됩니다. 합친 출력은 PDF 하나를 만들고, 별도 출력 옵션은 페이지당 파일 하나를 ZIP으로 만듭니다.

분할하면 페이지 품질이 떨어지나요?

아니요. 페이지는 QPDF가 다시 렌더링하지 않고 복사하므로 텍스트, 이미지, 글꼴, 벡터 그래픽이 원본과 완전히 똑같이 유지됩니다.

분할할 때 내 PDF가 업로드되나요?

아니요. 페이지 추출과 ZIP 압축은 브라우저에서 실행되며, 결과 파일은 기기에서 바로 저장됩니다.
