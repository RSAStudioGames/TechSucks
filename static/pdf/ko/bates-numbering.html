자주 묻는 질문

페이지에 베이츠 번호는 어떤 모양으로 표시되나요?

기본값은 바닥글 가운데에 10pt Helvetica로 들어가는 000001 같은 여섯 자리 0 채움 번호입니다. 프리셋으로 증거 번호, 사건 레이블, 페이지 번호를 추가할 수 있으며(예: 증거 1 사건 XYZ 000001 페이지 1), 처리하기 전에 미리보기 상자에서 정확한 텍스트를 확인할 수 있습니다.

프리셋 대신 내 접두사나 사건 번호를 쓸 수 있나요?

네. 사용자 지정 스타일을 선택하고 자리 표시자로 템플릿을 작성하세요. [BATES]는 순차 번호, [PAGE]는 파일 내 페이지 번호, [FILE]은 파일 카운터, [FILENAME]은 원본 파일 이름입니다. SMITH-[BATES] 같은 템플릿은 SMITH-000001, SMITH-000002 같은 결과를 만듭니다.

여러 PDF에 걸쳐 번호가 이어지나요, 파일마다 다시 시작하나요?

이어집니다. 첫 번째 파일이 30페이지이고 번호가 1부터 시작하면 두 번째 파일은 파일 목록 순서(끌어서 바꿀 수 있음)에 따라 000031부터 시작합니다. 파일마다 번호를 다시 시작하는 옵션은 없으므로 그렇게 하려면 파일을 따로 처리하세요.

번호는 몇 자리까지 쓸 수 있나요?

0 채우기 자릿수는 3, 4, 5, 6자리 중에서 고르거나 끄면 1, 2, 3처럼 앞에 0 없이 인쇄됩니다. 숫자 자체에는 상한이 없으며 채우기 자릿수를 넘어가면 추가 자릿수도 그대로 인쇄됩니다.

스탬프는 어디에 찍히며 내용을 가리나요?

머리글 또는 바닥글의 왼쪽, 가운데, 오른쪽 중 여섯 곳에서 하나를 고릅니다. 여백은 페이지에 비례하여 너비나 높이의 약 4%이며 최소 8pt, 최대 40pt입니다. 그래서 Letter, A4, 대형 증거 자료에서도 스탬프가 같은 상대 위치에 놓입니다. 기존 콘텐츠는 이동하지 않으므로 가장자리까지 인쇄된 페이지에서는 스탬프가 콘텐츠와 겹칠 수 있습니다.

베이츠 번호는 검색 가능한 텍스트인가요, 이미지인가요?

Helvetica, Times New Roman, Courier로 그려진 실제 텍스트이므로 OCR 없이도 선택하고 검색할 수 있으며 검토 소프트웨어도 읽을 수 있습니다. 이 글꼴들은 라틴 문자만 지원하는 PDF 기본 표준 글꼴이므로 다른 문자가 포함된 템플릿은 실패합니다.

증거 개시(디스커버리) 문서가 스탬프를 찍으려고 서버에 업로드되나요?

아니요. 스탬프는 브라우저 안에서 찍히고 번호가 매겨진 파일은 다운로드 폴더에 바로 저장됩니다. 문서, 사건 이름, 번호 매기기에 관한 어떤 정보도 기기를 벗어나지 않으므로 비밀 유지 대상 자료에도 안심하고 사용할 수 있습니다.

여러 파일에 한꺼번에 스탬프를 찍으면 결과는 어떻게 되나요?

각 PDF는 개별 파일로 번호가 매겨지고 원래 이름을 유지합니다. 파일 하나는 바로 다운로드되고 둘 이상은 bates_numbered.zip으로 함께 다운로드됩니다. 파일은 병합되지 않으므로 각 문서의 페이지 수와 순서는 그대로 유지됩니다.
