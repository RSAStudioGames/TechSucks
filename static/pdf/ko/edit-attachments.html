자주 묻는 질문

PDF에 어떤 파일이 첨부되어 있는지 어떻게 확인하나요?

PDF를 업로드하면 도구가 스캔하여 삽입된 모든 파일을 이름순으로 나열하고, 각각 문서 수준 첨부 파일인지 페이지 번호가 있는 페이지 첨부 파일인지 표시합니다. 삽입된 파일이 없으면 빈 목록 대신 그렇다고 알려 줍니다.

모든 첨부 파일이 아니라 하나만 제거할 수 있나요?

첨부 파일 옆의 휴지통 아이콘을 클릭해 표시하고, 저장하기 전에 다시 클릭하면 표시가 해제됩니다. 모든 첨부 파일 제거는 한 번에 전체를 선택하며, 새 PDF는 표시한 파일만 빠진 상태로 작성됩니다.

첨부 파일을 제거하면 PDF의 나머지 부분이 바뀌나요?

페이지, 텍스트, 이미지는 그대로입니다. 유지하는 첨부 파일은 원래 이름으로 다시 삽입되며 페이지 첨부 파일은 원래 페이지에 삽입되지만, 첨부 파일에 저장된 설명 텍스트는 옮겨지지 않습니다.

첨부 파일을 삭제하면 PDF가 작아지나요?

보통 작아지며 크게 줄어드는 경우도 많습니다. 삽입된 파일은 PDF 안에 통째로 저장되기 때문입니다. 큰 스프레드시트나 이미지 첨부 파일이 있는 문서는 해당 파일을 제거하면 크기가 몇 분의 일로 줄어들 수 있습니다.

문서 수준 첨부 파일과 페이지 수준 첨부 파일은 어떻게 다른가요?

문서 수준 첨부 파일은 PDF의 삽입 파일 목록에 있으며 뷰어의 첨부 파일 패널에 표시됩니다. 페이지 수준 첨부 파일은 한 페이지의 특정 위치에 고정된 파일 첨부 주석으로, 보통 클립이나 압정 아이콘으로 표시됩니다. 도구는 두 종류를 모두 나열하고 제거합니다.

삭제하기 전에 첨부 파일을 다운로드할 수 있나요?

이 도구는 첨부 파일을 나열하고 제거하기만 합니다. 삽입된 파일을 먼저 컴퓨터에 저장하려면 PDF를 첨부 파일 추출로 처리한 다음 여기로 돌아와 제거하세요.

여기서 첨부 파일을 추가하거나 교체할 수 있나요?

아니요. 이 도구는 첨부 파일을 제거하기만 합니다. 새 파일을 삽입하려면 첨부 파일 추가를 사용하세요. 오래된 첨부 파일을 새 버전으로 교체하려면 두 단계를 함께 사용하세요.

첨부 파일을 편집할 때 어딘가에 업로드되나요?

아니요. PDF는 브라우저에서 WebAssembly로 실행되는 cpdf 엔진이 분석하고, 첨부 파일 목록은 로컬에서 만들어지며, 정리된 파일은 브라우저에서 바로 저장됩니다. 문서도 첨부 파일도 서버로 전송되지 않으므로 첨부 파일이 민감한 부분일 때 안심할 수 있습니다.
