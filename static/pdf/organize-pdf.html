Frequently Asked Questions

How do I move a page to a different position?

Drag its thumbnail to the new spot in the grid; the page number labels update as you go. For a whole-document rearrangement, type the new order in the page order box, for example 3, 1, 2, 4, and click Apply.

What does the page order box expect?

A comma-separated list of the original page numbers in the order you want them, and it must mention every page exactly once. 3, 1, 2 for a three-page file works; 3, 1 (a page missing) or 1, 1, 2 (a repeat) is rejected. Use the duplicate and delete buttons for copies and removals.

Can I duplicate a page more than once?

Yes. Each click on the green duplicate button adds another copy right after the page, and every copy can then be dragged anywhere independently. This is handy for putting several blank copies of a form page in one file.

Can I delete pages here too?

Yes. Click the red delete button on a thumbnail to drop it from the output; the only rule is that the last remaining page can't be deleted. For removing many pages by range, Delete Pages is quicker.

Does reordering pages keep my bookmarks?

Page content, images, and annotations on each page are kept. Bookmarks aren't, because the reorganized file is assembled fresh from copied pages, so a document with a navigation outline will lose it. Recreate it afterward with the Bookmark tool if needed.

Is the quality of the pages affected?

No. Pages are copied as-is rather than re-rendered, so text stays selectable and images keep their original resolution. The output is saved under the same name as the original file.

Is my PDF uploaded while I rearrange its pages?

No. The thumbnails are rendered by your browser and the new file is assembled locally, so nothing is sent anywhere, even for large documents.

Can I organize pages from more than one PDF at once?

No, this tool works on a single file. To pull pages from several documents into one sequence, use Merge PDF in Page Mode, which shows thumbnails from every file in one grid.
