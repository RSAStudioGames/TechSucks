Frequently Asked Questions

How do I see what files are attached to a PDF?

Upload the PDF and the tool scans it and lists every embedded file by name, marking each one as a document-level attachment or as a page attachment with its page number. If nothing is embedded, it tells you so instead of showing an empty list.

Can I remove just one attachment instead of all of them?

Click the trash icon next to any attachment to mark it, and click again to unmark it before saving. Remove All Attachments selects everything at once, and the new PDF is written with only the marked files taken out.

Does removing attachments change the rest of the PDF?

The pages, text, and images are untouched. The attachments you keep are re-embedded under their original names and, for page attachments, on their original pages, but any description text stored with them isn't carried over.

Will deleting attachments make my PDF smaller?

Usually, and often by a lot, because embedded files are stored in full inside the PDF. A document carrying a large spreadsheet or image attachment can drop to a fraction of its size once that file is removed.

What is the difference between a document-level and a page-level attachment?

Document-level attachments live in the PDF's embedded files list and show up in a viewer's attachments panel. Page-level attachments are file attachment annotations pinned to a spot on one page, usually shown as a paperclip or pushpin icon. The tool lists and removes both kinds.

Can I download the attachments before deleting them?

This tool only lists and removes them. To save the embedded files to your computer first, run the PDF through Extract Attachments, then come back here to strip them.

Can I add or replace an attachment here?

No, this tool only removes attachments. Use Add Attachments to embed new files, and combine the two steps when you want to swap an outdated attachment for a newer version.

Are the attachments uploaded anywhere when I edit them?

No. The PDF is parsed by a cpdf engine running as WebAssembly in your browser, the attachment list is built locally, and the cleaned file is saved straight from your browser. Neither the document nor its attachments is sent to a server, which matters when the attachments are the sensitive part.
