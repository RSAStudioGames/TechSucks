Frequently Asked Questions

Does cropping permanently delete the part of the page outside the box?

Not in the default mode. The tool sets each page's crop box, so viewers and printers show only the selected area while the full page content stays in the file and can be restored by resetting the crop box in a PDF editor. Turn on Flattening Crop if the trimmed area has to be gone for good, for example before sharing an excerpt.

Will my text still be selectable after cropping?

In the default mode, yes: nothing is re-rendered, so text, links, and vector graphics stay exactly as they were. Flattening Crop renders each cropped page as an image, which removes selectable text and usually makes the file larger.

Can I crop different pages by different amounts?

Yes. Use the page navigation to move through the document and draw a separate box on each page; the tool remembers every box you set, and pages you never drew on keep their original size. To use one box everywhere, check Apply to all pages and the box on the current page is copied to every page.

What page size will the cropped PDF have?

Each cropped page takes on the size of its box, so trimming a 1-inch margin from every side of a Letter page leaves a 6.5 x 9 inch page. If you need a standard size like A4 or Letter afterward, run the result through Fix Page Size.

Is there a way to type exact crop measurements?

No. Cropping is done by dragging the corners or edges of the overlay on the page preview; there's no numeric input for margins or dimensions in this tool. Zooming the browser in helps when a margin is only a few millimeters wide.

Does cropping reduce image quality or file size?

The default mode changes neither: the content is untouched, so quality is identical, and the file stays about the same size because the hidden margin data is still inside. Flattening Crop replaces cropped pages with images, which typically makes the file bigger rather than smaller.

Is my document uploaded while I crop it?

No. The page previews are rendered in your browser and the crop is applied locally, so the file never leaves your computer; the cropped copy is saved under the original file name.

Can I crop a scanned PDF to remove black edges?

Yes. Draw the box inside the dark border on each page, or set it once and use Apply to all pages if every scan has the same border. Because the default crop only hides the edges, use Flattening Crop if the border must be physically removed, and straighten tilted scans first with Deskew PDF.
