Często Zadawane Pytania

Czy mogę przekonwertować dowolny plik JSON na PDF za pomocą tego narzędzia?

Nie. Odtwarza tylko pliki PDF z plików JSON utworzonych przez narzędzie PDF na JSON w BentoPDF, które przechowuje pełną wewnętrzną strukturę dokumentu. Eksport JSON z API, bazy danych lub pliku konfiguracyjnego zakończy się błędem.

Jak zamiast tego zamienić dane z API lub plik konfiguracyjny w czytelny PDF?

Wklej lub prześlij JSON jako zwykły tekst w Tekst na PDF, który układa go jako sformatowany tekst na stronach. JSON na PDF służy tylko do odtwarzania dokumentów, które początkowo były plikami PDF.

Czy odtworzony PDF będzie zgodny z oryginałem?

JSON utworzony przez PDF na JSON zawiera obiekty dokumentu, więc konwersja z powrotem odtwarza strony, tekst i obrazy źródła. Konwersja z powrotem i porównanie to też szybki sposób, by potwierdzić, że eksport uchwycił wszystko.

Co otrzymam, konwertując wiele plików JSON?

Każda konwersja jest pobierana jako jsons-to-pdf.zip, nawet dla jednego pliku. W środku każdy PDF nosi nazwę swojego źródłowego JSON, więc report.json staje się report.pdf.

Czy mogę edytować JSON przed ponowną konwersją?

Tak, o ile struktura pozostaje poprawna dla silnika CPDF. Programowe zmiany w JSON, takie jak edytowane metadane lub obiekty tekstowe, są odtwarzane w PDF; błędna edycja powoduje błąd konwersji.

Dlaczego narzędzie mówi, że silnik CPDF jest niedostępny?

Konwersja zależy od kompilacji CPDF WebAssembly. Na bentopdf.com jest ona dołączona, ale kopia na własnym serwerze wymaga skonfigurowania plików CPDF WASM w ustawieniach WASM, zanim to narzędzie zadziała.

Czy mój plik JSON jest wysyłany na serwer?

Nie. Pliki są odczytywane w Twojej przeglądarce i odtwarzane jako PDF przez Web Worker uruchamiający silnik CPDF lokalnie, więc nic nie jest przesyłane, a strona pozostaje responsywna podczas dużych konwersji.
