Często Zadawane Pytania

Co zawiera JSON?

Pełna struktura obiektów pliku PDF tak, jak odczytuje ją cpdf: trailer, katalog, drzewo stron, każdy słownik oraz strumień zawartości każdej strony sparsowany do listy operatorów rysowania i tekstu. To kompletny zrzut pliku, a nie podsumowanie.

Czy to właściwe narzędzie, aby wyciągnąć tekst z pliku PDF jako JSON?

Zwykle nie. Tekst jest tu rozrzucony po operatorach strumienia zawartości w kolejności rysowania, z czcionkami i pozycjami, ale bez akapitów. Dla czytelnego tekstu stron w ustrukturyzowanym formacie użyj Przygotuj PDF dla AI, a dla zwykłego tekstu PDF na tekst.

Czy mogę zamienić JSON z powrotem na PDF?

Nie w BentoPDF. Wynik ma własny format JSON cpdf, który narzędzie wiersza poleceń cpdf może odczytać z powrotem do pliku PDF, ale narzędzie w przeglądarce działa tylko w jednym kierunku.

Dlaczego JSON jest o wiele większy niż PDF?

Strumienie zawartości są rozwijane do tablic operatorów, dane binarne strumieni, takie jak obrazy, są kodowane jako tekst, a każdy obiekt jest zapisywany ze wszystkimi kluczami, więc plik JSON kilka razy większy od źródła jest normalny. Duże pliki PDF lub z dużą ilością obrazów dają bardzo duże pliki.

Czy mogę przekonwertować kilka plików PDF na JSON naraz?

Wybierz ich tyle, ile chcesz. Każdy jest konwertowany w roboczym wątku w tle, a wyniki są pakowane do pdfs-to-json.zip z jednym plikiem .json na PDF, nazwanym według pliku źródłowego. Pojedynczy PDF również trafia do archiwum ZIP.

Czy działa na zaszyfrowanych plikach PDF?

Przed rozpoczęciem konwersji pojawia się prośba o hasło, a serializowana jest odszyfrowana kopia. Bez hasła nie można odczytać struktury obiektów.

Do czego to się przydaje?

Do sprawdzania wnętrza pliku PDF przy debugowaniu generatora, sprawdzania zawartości strumienia strony, porównywania dwóch wersji strukturalnie lub przekazywania drzewa obiektów do skryptu. Dla samych właściwości dokumentu szybsze jest Wyświetl metadane.

Czy plik PDF jest wysyłany, aby utworzyć JSON?

Nie. cpdf działa jako WebAssembly w web workerze w przeglądarce, a JSON jest zapisywany i pakowany do ZIP na Twoim urządzeniu przed pobraniem.
