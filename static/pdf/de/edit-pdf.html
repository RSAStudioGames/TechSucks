Häufig gestellte Fragen

Kann ich mit diesem Editor den vorhandenen Text in meiner PDF ändern?

Dieser Editor arbeitet auf der Seite: Hervorhebungen, Kommentare, Formen, Bilder, freihändiges Zeichnen, Schwärzung und neue Textfelder. Um Text umzuschreiben, der bereits im Dokument steht, nutzen Sie PDF-Text bearbeiten, womit Sie auf einen Absatz klicken und ihn direkt bearbeiten können.

Erscheinen meine Anmerkungen in Acrobat, Vorschau oder Chrome?

Ja. Hervorhebungen, Kommentare, Formen und Zeichnungen werden als standardmäßige PDF-Anmerkungen gespeichert, sodass andere Viewer sie anzeigen und meist bearbeiten oder löschen können. Textfelder werden beim Herunterladen als normaler Text in die Seite geschrieben, sodass sie überall identisch aussehen, danach aber nicht mehr verschoben werden können.

Ist die Schwärzung dauerhaft?

Ja, sobald sie angewendet wurde. Das Markieren von Text oder einem Bereich setzt nur eine Markierung. Beim Anwenden einer Schwärzung wird der Inhalt unter dem markierten Bereich aus der Datei entfernt, statt ihn mit einem Kasten zu verdecken, sodass der Text weder durch Kopieren noch durch Suchen wiederhergestellt werden kann. Wenn Sie mit noch nicht angewendeten Markierungen herunterladen, bietet der Editor an, sie zuerst anzuwenden. Wenn Sie ausgewählten Text schwärzen, werden Kopien davon in den Eigenschaften, Lesezeichen, Kommentaren und Anhängen der Datei beim Herunterladen ebenfalls entfernt, sofern die Datei nicht verschlüsselt ist. Öffnen Sie die heruntergeladene Datei und prüfen Sie sie, bevor Sie sie weitergeben.

Kann ich mehr als eine PDF gleichzeitig öffnen?

Bis zu 10 Dokumente können gleichzeitig geöffnet sein, jedes in einem eigenen Tab über dem Viewer. Weitere Dateien öffnen weitere Tabs, und das Entfernen einer Datei aus der Liste schließt ihren Tab.

Speichert der Editor meine Änderungen automatisch?

Nein. Alles bleibt im Speicher Ihres Browsers, bis Sie auf Bearbeitete PDF herunterladen klicken, und das Schließen oder Neuladen des Tabs verwirft die Änderungen. Laden Sie herunter, bevor Sie die Seite verlassen.

Warum kann ich in meiner gescannten PDF keinen Text markieren?

Hervorheben, Unterstreichen und Durchstreichen haften an echtem Text, und eine gescannte Seite ist nur ein Bild. Lassen Sie die Datei zuerst durch PDF mit OCR laufen, um eine Textebene hinzuzufügen, oder markieren Sie sie visuell mit den Stift- oder Rechteck-Werkzeugen.

Kann ich Text auf Chinesisch, Japanisch, Arabisch oder in anderen nicht-lateinischen Schriften hinzufügen?

Ja. Wenn ein Textfeld Zeichen außerhalb des einfachen lateinischen Zeichensatzes enthält, lädt der Editor eine passende Noto-Schrift und bettet sie in die PDF ein, damit der Text in anderen Viewern korrekt dargestellt wird.

Lädt der Editor meine PDF hoch?

Nein. Der Editor führt eine PDF-Engine (PDFium, kompiliert zu WebAssembly) in Ihrem Browser aus. Die einzigen Netzwerkanfragen betreffen den Code des Editors und optionale Schriftdateien; das Dokument selbst verlässt nie Ihr Gerät.
