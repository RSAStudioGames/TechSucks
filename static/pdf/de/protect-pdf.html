Häufig gestellte Fragen

Was ist der Unterschied zwischen Benutzerpasswort und Eigentümerpasswort?

Das Benutzerpasswort ist erforderlich, und jeder muss es eingeben, um die Datei zu öffnen. Das Eigentümerpasswort ist optional. Wenn Sie ein anderes festlegen, erhält die PDF außerdem Nutzungsbeschränkungen, sodass jemand, der sie nur mit dem Benutzerpasswort öffnet, nicht drucken, kopieren, bearbeiten, kommentieren, Formulare ausfüllen oder Seiten neu anordnen kann.

Welche Verschlüsselung verwendet PDF schützen?

256-Bit-AES, angewendet mit der QPDF-Implementierung des PDF-2.0-Verschlüsselungsstandards. Es gibt keine Möglichkeit, eine schwächere Verschlüsselung zu wählen, die Stärke des Schutzes hängt also davon ab, wie sicher Ihr Passwort ist.

Was passiert, wenn ich das Passwort vergesse?

Es gibt keine Wiederherstellung. AES-256 lässt sich in praktisch keiner Zeit per Brute Force knacken, und BentoPDF speichert weder eine Kopie der Datei noch des Passworts. Bewahren Sie das Passwort an einem sicheren Ort auf und behalten Sie selbst ein ungeschütztes Original.

Bekomme ich trotzdem Beschränkungen, wenn ich nur ein Benutzerpasswort eingebe?

Nein. Mit nur einem Benutzerpasswort braucht die Datei zum Öffnen das Passwort, aber nach dem Öffnen gibt es keine Grenzen beim Drucken, Kopieren oder Bearbeiten. Fügen Sie ein separates Eigentümerpasswort hinzu, wenn Sie diese Beschränkungen möchten.

Kann ich Drucken oder Kopieren einschränken, ohne dass zum Öffnen der Datei ein Passwort nötig ist?

Nicht mit diesem Werkzeug, denn das Benutzerpasswort ist hier Pflicht. Verwenden Sie stattdessen Berechtigungen ändern, das Beschränkungen anwendet und die Datei ohne Passwort öffnbar lässt.

Wie entferne ich das Passwort später wieder?

Öffnen Sie die geschützte Datei im Werkzeug zum Entfernen des Passworts, geben Sie das Passwort ein und laden Sie eine Kopie ohne Verschlüsselung herunter. Dafür brauchen Sie das Passwort, es gibt keine Umgehung.

Lässt sich die geschützte PDF in jedem Reader öffnen?

Jeder aktuelle PDF-Reader, darunter Adobe Reader, Vorschau, Chrome, Firefox und Edge, öffnet mit AES-256 verschlüsselte Dateien. Sehr alte Reader, die vor der Unterstützung von AES-256 erschienen sind, lehnen die Datei möglicherweise ab.

Wird meine PDF oder mein Passwort irgendwohin gesendet?

Nein. QPDF läuft als WebAssembly in Ihrem Browser, die Datei wird also auf Ihrem Gerät verschlüsselt, und weder das Dokument noch die Passwörter werden übertragen. Geben Sie das Passwort über einen anderen Kanal an Ihren Empfänger weiter als die Datei selbst.
