Häufig gestellte Fragen

Was bewirkt das Rastern einer PDF eigentlich?

Jede Seite wird in eine Bitmap gerendert, und die Bitmaps werden zu einer neuen PDF zusammengesetzt. Das Ergebnis sieht gleich aus, enthält aber keine Textobjekte, Schriften, Ebenen, Formularfelder oder versteckten Inhalte, nur ein Bild jeder Seite, ähnlich wie eine Fotokopie.

Welche DPI sollte ich beim Rastern wählen?

150, der Standard, reicht zum Lesen am Bildschirm und für normales Drucken im Büro. Verwenden Sie 300 für Ausgaben in Druckqualität oder wenn jemand ins Kleingedruckte hineinzoomt, 600 nur für Archivierung oder professionellen Druck und 72, wenn eine möglichst kleine Datei wichtiger ist als Schärfe.

PNG oder JPEG?

PNG ist verlustfrei, Textkanten bleiben also scharf, die Dateien sind aber größer. JPEG (mit Qualität 95 gespeichert) ist deutlich kleiner und eignet sich gut für gescannte oder fotografische Seiten, kann aber schwache Artefakte um scharfen Text hinterlassen. Graustufen sind mit beiden möglich und verkleinern Dateien bei Schwarzweiß-Dokumenten weiter.

Warum ist die gerasterte Datei größer als das Original?

Eine Text-PDF speichert pro Seite einige Kilobyte an Schrift- und Glyphendaten, ein 300-DPI-Bild einer Letter-Seite hat dagegen 2550 x 3300 Pixel. Senken Sie die DPI, wechseln Sie zu JPEG oder lassen Sie das Ergebnis durch PDF komprimieren laufen, wenn die Größe wichtig ist.

Kann ich den Text danach wieder auswählbar machen?

Nicht aus der gerasterten Datei selbst. Der Vorgang ist nicht umkehrbar, behalten Sie also das Original. Mit OCR PDF können Sie wieder eine durchsuchbare Textebene hinzufügen, erkannter Text ist aber nie so exakt wie das Original.

Worin unterscheidet sich das vom Reduzieren einer PDF?

Beim Reduzieren werden Formularfelder und Annotationen in die Seite eingebunden, Text bleibt aber Text. Beim Rastern wird alles, auch Text, in Pixel umgewandelt. Wenn Sie nur Formularfelder oder Kommentare fixieren möchten, hält PDF reduzieren die Datei durchsuchbar und viel kleiner.

Werden meine vertraulichen Dokumente zum Rastern hochgeladen?

Nein. Das Rendern übernimmt das PyMuPDF-WebAssembly-Modul in Ihrem Browser, die Seiten werden also auf Ihrem eigenen Rechner gezeichnet und neu zusammengesetzt. Deshalb ist das Werkzeug ein sicherer Weg, versteckten Text und Ebenen aus einer sensiblen Datei zu entfernen, bevor Sie sie teilen.

Kann ich mehrere PDFs auf einmal rastern?

Ja. Fügen Sie beliebig viele hinzu. Jede wird mit denselben DPI-, Format- und Graustufen-Einstellungen verarbeitet, und die Ergebnisse werden gemeinsam als rasterized-pdfs.zip heruntergeladen. Eine einzelne Datei wird für sich heruntergeladen.
