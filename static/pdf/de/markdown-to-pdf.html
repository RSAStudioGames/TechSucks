Häufig gestellte Fragen

Wie konvertiere ich eine Markdown-Datei in PDF?

Klicken Sie auf Hochladen und wählen Sie eine .md-, .markdown- oder .txt-Datei, oder fügen Sie den Text im linken Bereich ein, dann erscheint rechts die gerenderte Vorschau. Klicken Sie auf PDF exportieren oder drücken Sie Strg+S (Cmd+S auf dem Mac) und wählen Sie im sich öffnenden Druckdialog als Ziel Als PDF speichern.

Kann ich Seitengröße oder Ränder der PDF ändern?

Legen Sie das im Druckdialog fest: Wählen Sie Letter, A4 oder ein anderes Papierformat, passen Sie die Ränder an und verringern Sie die Skalierung, wenn eine breite Tabelle abgeschnitten wird. Schalten Sie dort auch Kopf- und Fußzeilen aus, wenn Datum und URL nicht auf jeder Seite gedruckt werden sollen.

Werden Codeblöcke, Tabellen und Diagramme unterstützt?

Eingezäunte Codeblöcke erhalten Syntaxhervorhebung für JavaScript, TypeScript, Python, Go, Rust, Java, C#, C++, SQL, Bash, YAML, JSON, HTML und CSS, und standardmäßige Tabellen mit senkrechten Strichen werden als Tabellen dargestellt. Mermaid-Codeblöcke werden als Flussdiagramme, Sequenzdiagramme und andere Diagrammtypen gezeichnet, sowohl in der Vorschau als auch in der PDF.

Welche Markdown-Erweiterungen funktionieren über die Grundlagen hinaus?

Aufgabenlisten, Fußnoten, Definitionslisten, Abkürzungen, tiefgestellter und hochgestellter Text, ==Hervorhebungs==- und ++Einfüge++-Markierungen, Emoji-Kürzel wie :smile: und automatische Verlinkung bloßer URLs. Der Einstellungsdialog hat Schalter für rohes HTML, Zeilenumbrüche, automatische Verlinkung und typografische Anführungszeichen.

Wirkt sich das dunkle Design auf die exportierte PDF aus?

Nein. Der Design-Schalter ändert nur die Editorfarben auf dem Bildschirm; das Druck-Stylesheet erzwingt einen weißen Hintergrund und dunklen Text, die PDF sieht also in beiden Fällen gleich aus.

Kann ich der PDF ein Inhaltsverzeichnis hinzufügen?

Setzen Sie ${toc} in eine eigene Zeile an die gewünschte Stelle, dann wird beim Rendern des Dokuments aus Ihren Überschriften ein Inhaltsverzeichnis erzeugt. Überschriften erhalten außerdem Anker-IDs, sodass Links im Dokument zu einer Überschrift in der Vorschau funktionieren.

Kann ich Bilder in die PDF einfügen?

Verwenden Sie die Standard-Markdown-Bildsyntax mit einer vollständigen Bild-URL oder einem Data-URI, dann wird das Bild in der Vorschau dargestellt und in die PDF gedruckt. Relative Pfade zu Dateien auf Ihrer Festplatte werden nicht geladen, da der Editor keinen Zugriff auf Ihre lokalen Ordner hat.

Wird mein Markdown-Text zum Erstellen der PDF auf einen Server hochgeladen?

Nein. Das Markdown wird von markdown-it in Ihrem Browser zu HTML gerendert, und die PDF wird von der Druckfunktion des Browsers erstellt, weder der Text noch die fertige PDF berühren also einen Server. Notizen, Entwürfe und interne Dokumente bleiben auf Ihrem Rechner.
