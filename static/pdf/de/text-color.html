Häufig gestellte Fragen

Woher weiß es, welche Pixel Text sind?

Es liest den Text nicht. Jede Seite wird zu einem Bild gerendert, und jedes dunkle Pixel (Rot, Grün und Blau alle unter 120 auf einer Skala von 0 bis 255) wird in der gewählten Farbe neu gemalt. Schwarze und dunkelgraue Schrift wird erfasst, hellgrauer Text, farbiger Text und Fotos bleiben unberührt.

Warum haben auch Linien, Rahmen und mein Logo die Farbe gewechselt?

Da das Werkzeug mit dunklen Pixeln statt mit Textobjekten arbeitet, wird jedes dunkle Element, auch Tabellenlinien, Unterstreichungen und schwarze Grafiken, zusammen mit dem Text umgefärbt. In diesem Werkzeug lassen sich keine Bereiche ausschließen.

Kann ich nur bestimmte Wörter oder Absätze umfärben?

Nein. Eine Farbe wird auf alle dunklen Inhalte auf jeder Seite angewendet. Um einzelne Wörter oder Überschriften zu ändern und den Rest unberührt zu lassen, bearbeiten Sie den Text direkt im PDF-Editor.

Bleibt der Text auswählbar und durchsuchbar?

Nein. Die Ausgabe ist bildbasiert: Jede Seite wird mit 2-facher Auflösung gerendert und als PNG eingebettet, sodass Text nicht mehr ausgewählt, durchsucht oder kopiert werden kann. Behalten Sie das Original, wenn Sie eine bearbeitbare Version brauchen, oder führen Sie OCR PDF mit dem Ergebnis aus, um wieder eine Textebene hinzuzufügen.

Warum ist die Datei so viel größer geworden?

Eine Textseite wiegt als Text einige Kilobyte, wird beim Umfärben aber zu einem ganzseitigen PNG-Bild, sodass mehrseitige Dokumente um ein Vielfaches wachsen können. PDF komprimieren kann das Ergebnis auf Kosten etwas Schärfe verkleinern.

Kann ich schwarzen Text für einen dunklen Hintergrund weiß machen?

Ja, jede Farbe funktioniert, auch Weiß, der Seitenhintergrund wird aber nicht geändert, weißer Text auf der ursprünglich weißen Seite verschwindet also. Wählen Sie eine Farbe, die sich vom bereits vorhandenen Hintergrund der Seite abhebt.

Wird mein Dokument zum Ändern der Textfarbe hochgeladen?

Nein. Jede Seite wird auf einem Canvas in Ihrem Browser gerendert und umgefärbt, und auch die neue PDF wird dort zusammengesetzt, die Datei verlässt Ihr Gerät also nie. Eine Fortschrittsanzeige zeigt, welche Seite gerade verarbeitet wird.

Warum bleibt farbiger oder hellgrauer Text unverändert?

Nur Pixel, die dunkel genug sind, um den Schwellenwert zu erreichen, werden neu gemalt. Rote Überschriften, blaue Links, mittelgraue Bildunterschriften und geglättete Kanten, die heller als der Grenzwert sind, behalten ihre ursprüngliche Farbe, was einen schwachen Schimmer um umgefärbte Buchstaben hinterlassen kann.
