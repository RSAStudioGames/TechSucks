Häufig gestellte Fragen

Was enthält die JSON?

Die vollständige Objektstruktur der PDF, wie cpdf sie liest: Trailer, Katalog, Seitenbaum, jedes Wörterbuch und der Inhaltsstrom jeder Seite, zerlegt in eine Liste von Zeichen- und Textoperatoren. Es ist ein kompletter Dump der Datei, keine Zusammenfassung.

Ist das das richtige Werkzeug, um den Text einer PDF als JSON auszulesen?

Meistens nicht. Der Text ist hier in der Reihenfolge, in der er gezeichnet wurde, über Inhaltsstrom-Operatoren verstreut, mit Schriftarten und Positionen, aber ohne Absätze. Für lesbaren Seitentext in strukturiertem Format nutzen Sie PDF für KI vorbereiten, für reinen Text PDF in Text.

Kann ich die JSON wieder in eine PDF zurückwandeln?

Nicht mit BentoPDF. Die Ausgabe folgt dem eigenen JSON-Format von cpdf, das das cpdf-Kommandozeilenwerkzeug wieder in eine PDF einlesen kann, das Browser-Werkzeug geht aber nur in eine Richtung.

Warum ist die JSON so viel größer als die PDF?

Inhaltsströme werden in Operator-Arrays aufgelöst, binäre Streamdaten wie Bilder werden als Text kodiert, und jedes Objekt wird mit seinen Schlüsseln ausgeschrieben, eine JSON-Datei, die mehrfach so groß ist wie die Quelle, ist also normal. Große oder bildlastige PDFs erzeugen sehr große Dateien.

Kann ich mehrere PDFs auf einmal in JSON umwandeln?

Wählen Sie beliebig viele aus. Jede wird in einem Hintergrund-Worker umgewandelt, und die Ergebnisse werden in pdfs-to-json.zip mit einer .json pro PDF verpackt, benannt nach der Quelldatei. Auch eine einzelne PDF kommt als ZIP.

Funktioniert es bei verschlüsselten PDFs?

Sie werden vor Beginn der Umwandlung nach dem Passwort gefragt, und die entschlüsselte Kopie wird serialisiert. Ohne das Passwort lässt sich die Objektstruktur nicht lesen.

Wofür ist das nützlich?

Um die Interna einer PDF beim Debuggen eines Generators zu untersuchen, zu prüfen, was der Inhaltsstrom einer Seite enthält, zwei Versionen strukturell zu vergleichen oder den Objektbaum in ein Skript einzuspeisen. Für Dokumenteigenschaften allein geht Metadaten anzeigen schneller.

Wird die PDF hochgeladen, um die JSON zu erzeugen?

Nein. cpdf läuft als WebAssembly in einem Web Worker in Ihrem Browser, und die JSON wird auf Ihrem Gerät geschrieben und gezippt, bevor sie heruntergeladen wird.
