Häufig gestellte Fragen

Wie sehe ich, welche Dateien an eine PDF angehängt sind?

Laden Sie die PDF hoch, und das Werkzeug durchsucht sie und listet jede eingebettete Datei mit Namen auf, wobei jede als Anhang auf Dokumentebene oder als Seitenanhang mit Seitenzahl gekennzeichnet ist. Ist nichts eingebettet, teilt es Ihnen das mit, statt eine leere Liste zu zeigen.

Kann ich nur einen Anhang entfernen statt alle?

Klicken Sie auf das Papierkorb-Symbol neben einem Anhang, um ihn zu markieren, und klicken Sie vor dem Speichern erneut, um die Markierung aufzuheben. Alle Anhänge entfernen wählt alles auf einmal aus, und die neue PDF wird nur ohne die markierten Dateien geschrieben.

Verändert das Entfernen von Anhängen den Rest der PDF?

Seiten, Text und Bilder bleiben unberührt. Die Anhänge, die Sie behalten, werden unter ihren ursprünglichen Namen und, bei Seitenanhängen, auf ihren ursprünglichen Seiten neu eingebettet, aber mit ihnen gespeicherte Beschreibungstexte werden nicht übernommen.

Wird meine PDF kleiner, wenn ich Anhänge lösche?

Meistens, und oft deutlich, denn eingebettete Dateien werden vollständig in der PDF gespeichert. Ein Dokument mit einer großen Tabellen- oder Bildanlage kann auf einen Bruchteil seiner Größe schrumpfen, sobald diese Datei entfernt ist.

Was ist der Unterschied zwischen einem Anhang auf Dokumentebene und einem auf Seitenebene?

Anhänge auf Dokumentebene liegen in der Liste der eingebetteten Dateien der PDF und erscheinen im Anhangsbereich eines Viewers. Seitenanhänge sind Dateianhang-Anmerkungen, die an einer Stelle einer Seite fixiert sind und meist als Büroklammer- oder Stecknadel-Symbol angezeigt werden. Das Werkzeug listet und entfernt beide Arten.

Kann ich die Anhänge vor dem Löschen herunterladen?

Dieses Werkzeug listet sie nur auf und entfernt sie. Um die eingebetteten Dateien zuerst auf Ihrem Computer zu speichern, lassen Sie die PDF durch Anhänge extrahieren laufen und kommen Sie dann hierher zurück, um sie zu entfernen.

Kann ich hier einen Anhang hinzufügen oder ersetzen?

Nein, dieses Werkzeug entfernt nur Anhänge. Nutzen Sie Anhänge hinzufügen, um neue Dateien einzubetten, und kombinieren Sie beide Schritte, wenn Sie einen veralteten Anhang durch eine neuere Version ersetzen möchten.

Werden die Anhänge beim Bearbeiten irgendwohin hochgeladen?

Nein. Die PDF wird von einer cpdf-Engine geparst, die als WebAssembly in Ihrem Browser läuft, die Anhangsliste wird lokal erstellt, und die bereinigte Datei wird direkt aus Ihrem Browser gespeichert. Weder das Dokument noch seine Anhänge werden an einen Server gesendet, was wichtig ist, wenn die Anhänge der sensible Teil sind.
