Häufig gestellte Fragen

Was bewirkt das Umwandeln von Schriften in Konturen bei einer PDF?

Jedes Textzeichen wird durch einen Vektorpfad ersetzt, der dieselbe Form zeichnet, und die Ausgabe verweist auf keine Schrift mehr. Sie wird auf jedem Gerät und Drucker gleich dargestellt, auch auf solchen ohne die Originalschrift.

Wann sollte ich Schriften vor dem Drucken in Konturen umwandeln?

Druckereien verlangen oft Schriften in Konturen, um Schriftersetzung oder Lizenzprobleme auf ihren Geräten zu vermeiden. Tun Sie es als letzten Schritt, nachdem alle Textänderungen abgeschlossen sind, denn der Text lässt sich danach nicht mehr bearbeiten.

Kann ich nach dem Umwandeln noch Text auswählen, durchsuchen oder kopieren?

Nein. Konturierter Text besteht nur aus Formen, Auswahl, Suche mit Strg+F, Kopieren und Einfügen sowie der Zugriff per Screenreader funktionieren daher nicht mehr. Behalten Sie die Original-PDF für alles, was Live-Text braucht.

Kann ich Konturen wieder in bearbeitbaren Text umwandeln?

Nein, die Konvertierung ist eine Einbahnstraße. Wenn Sie das Original verloren haben, fügt OCR auf der konturierten Datei eine erkannte Textebene zum Suchen hinzu, stellt aber weder die Originalschriften noch bearbeitbaren Text wieder her.

Warum ist meine PDF nach dem Umwandeln der Schriften in Konturen größer?

Jedes Zeichen wird als Bézier-Pfad gespeichert statt als kurzer Verweis in ein Schriftprogramm, und eine Seite Fließtext kann Tausende davon enthalten. Die Datei wächst oft spürbar; führen Sie sie danach durch PDF komprimieren, wenn die Größe wichtig ist.

Verändert das Umwandeln das Aussehen des Dokuments?

In der PDF eingebettete Schriften werden exakt nachgezeichnet, das Aussehen bleibt also gleich. Ist eine Schrift nicht eingebettet, ersetzt Ghostscript sie vor dem Umwandeln durch eine ähnliche, prüfen Sie das Ergebnis daher, wenn ein Dokument auf Systemschriften angewiesen ist.

Kann ich Schriften in mehreren PDFs auf einmal in Konturen umwandeln?

Ja. Laden Sie mehrere PDFs hoch und konvertieren Sie sie zusammen; eine Datei wird als PDF heruntergeladen, mehrere als outlined_pdfs.zip mit einem Eintrag pro Eingabe.

Wird meine PDF bei der Schriftkonvertierung hochgeladen?

Nein. Ghostscript läuft als WebAssembly in Ihrem Browser, die Datei wird also auf Ihrem Gerät verarbeitet und die konturierte Kopie lokal ohne Upload geschrieben.
