Häufig gestellte Fragen

Kann ich mit diesem Werkzeug jede beliebige JSON-Datei in eine PDF umwandeln?

Nein. Es baut nur PDFs aus JSON-Dateien zurück, die mit dem Werkzeug PDF zu JSON von BentoPDF erstellt wurden und die vollständige interne Struktur des Dokuments speichern. Ein JSON-Export aus einer API, einer Datenbank oder einer Konfigurationsdatei schlägt mit einem Fehler fehl.

Wie mache ich stattdessen API-Daten oder eine Konfigurationsdatei zu einer lesbaren PDF?

Fügen Sie die JSON als einfachen Text in Text zu PDF ein oder laden Sie sie dort hoch, wo sie als formatierter Text auf Seiten gesetzt wird. JSON zu PDF dient nur dem Hin-und-zurück-Umwandeln von Dokumenten, die ursprünglich PDFs waren.

Entspricht die zurückgebaute PDF dem Original?

Die von PDF zu JSON erzeugte JSON erfasst die Objekte des Dokuments, die Rückumwandlung gibt daher Seiten, Text und Bilder der Quelle wieder. Zurückkonvertieren und Vergleichen ist außerdem ein schneller Weg, um zu prüfen, ob ein Export alles erfasst hat.

Was ist die Ausgabe, wenn ich mehrere JSON-Dateien konvertiere?

Jede Konvertierung wird als jsons-to-pdf.zip heruntergeladen, auch bei einer einzelnen Datei. Darin trägt jede PDF den Namen ihrer JSON-Quelle, aus report.json wird also report.pdf.

Kann ich die JSON bearbeiten, bevor ich sie zurückkonvertiere?

Ja, solange die Struktur für die CPDF-Engine gültig bleibt. Programmatische Änderungen an der JSON, etwa bearbeitete Metadaten oder Textobjekte, werden in die PDF übernommen; eine fehlerhafte Änderung führt zu einem Konvertierungsfehler.

Warum meldet das Werkzeug, die CPDF-Engine sei nicht verfügbar?

Die Konvertierung hängt vom CPDF-WebAssembly-Build ab. Auf bentopdf.com ist er enthalten, bei einer selbst gehosteten Kopie müssen die CPDF-WASM-Dateien jedoch in den WASM-Einstellungen konfiguriert sein, bevor dieses Werkzeug läuft.

Wird meine JSON-Datei auf einen Server hochgeladen?

Nein. Die Dateien werden in Ihrem Browser gelesen und von einem Web Worker, der die CPDF-Engine lokal ausführt, in PDFs zurückgebaut, es wird also nichts übertragen, und die Seite bleibt auch bei großen Konvertierungen reaktionsfähig.
