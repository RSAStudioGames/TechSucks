Häufig gestellte Fragen

Was enthält die JSON-Ausgabe?

Es folgt dem LlamaIndex-Dokumentschema: ein Dokument pro Seite mit dem Text der Seite und Metadatenfeldern. Es wird von der LlamaIndex-Integration von PyMuPDF erzeugt und lässt sich daher direkt in LlamaIndex oder in jede Pipeline laden, die seitenweisen Text mit Metadaten akzeptiert.

Wie unterscheidet sich das von PDF in Text oder PDF in Markdown?

PDF zu Text liefert einen einzigen reinen Textstrom, und PDF zu Markdown behält Überschriften und Struktur zum Lesen bei. Dieses Werkzeug teilt den Inhalt seitenweise auf und verpackt ihn in strukturiertes JSON mit Metadaten, was Retrieval-Pipelines für das Chunking und das Zitieren von Quellen brauchen.

Funktioniert es bei gescannten PDFs?

Nur wenn sie bereits eine Textebene haben. Gescannte Bilder liefern leere oder fast leere Ergebnisse. Lassen Sie sie daher zuerst durch OCR PDF laufen und extrahieren Sie danach.

Kann ich einen ganzen Stapel PDFs verarbeiten?

Ja. Laden Sie mehrere Dateien hoch, und Sie erhalten pdf-for-ai.zip mit je einer yourfile_llm.json pro PDF. Eine einzelne Datei wird direkt als yourfile_llm.json heruntergeladen. Schlägt eine Datei im Stapel fehl, werden die übrigen trotzdem verarbeitet, und die Zusammenfassung zeigt Ihnen, wie viele fehlgeschlagen sind.

Kann ich auswählen, welche Seiten extrahiert werden, oder die Chunk-Größe steuern?

Nein. Es gibt keine Optionen, jede Seite wird mit vollständigem Text und Metadaten extrahiert. Das Chunking erledigen Sie in Ihrer eigenen Pipeline, wo Sie Größen passend zu Ihrem Embedding-Modell wählen und nicht benötigte Seiten aussortieren können.

Kann ich eine passwortgeschützte PDF für KI-Werkzeuge vorbereiten?

Ja. Ist eine Datei verschlüsselt, werden Sie vor Beginn der Extraktion nach dem Passwort gefragt, und der Text wird aus der entschlüsselten Kopie gezogen.

Wird mein Dokument an einen KI-Dienst gesendet?

Nein. Trotz des Namens wird nichts an einen KI-Anbieter oder Server gesendet, die Extraktion läuft mit PyMuPDF, kompiliert nach WebAssembly, in Ihrem Browser. Wohin die JSON danach geht, entscheiden Sie.

Was kann ich mit der JSON-Datei tun?

Speisen Sie sie in eine RAG-Pipeline ein, bauen Sie eine Wissensdatenbank für einen Chatbot auf, führen Sie LLM-Analysen über Berichte aus oder machen Sie aus einer PDF-Sammlung Trainingsdaten. Da der Inhalt seitenweise mit Metadaten aufgeteilt ist, können Antworten auf die Seite verweisen, aus der sie stammen.
