Häufig gestellte Fragen

Welche Arten von Stempeln kann ich mit diesem Tool hinzufügen?

Dieses Tool platziert Bildstempel: Sie wählen eine Bilddatei wie PNG oder JPG (ein Firmensiegel, eine Genehmigt-Grafik, einen eingescannten Notarstempel) und setzen sie auf die Seite. Für reine Textmarkierungen wie einen diagonalen Entwurf-Hinweis ist Wasserzeichen hinzufügen besser geeignet.

Was bewirkt das Feld Stempel-Benutzername?

Der eingegebene Name wird bei jedem von Ihnen erstellten Stempel als Autor gespeichert, damit Prüfende sehen können, wer ihn platziert hat. Legen Sie ihn fest, bevor Sie die PDF hochladen. Die Angabe ist optional, und wenn Sie das Feld leer lassen, entstehen Stempel ohne Namen.

Kann ich denselben Stempel auf einmal auf jede Seite setzen?

Nein. Stempel werden einzeln auf der Seite platziert, die Sie gerade ansehen, und Sie können jeden vor dem Speichern verschieben und in der Größe ändern. Wenn Sie auf allen Seiten dieselbe Markierung brauchen, nutzen Sie den Bildmodus in Wasserzeichen hinzufügen, der ein Bild in einem Schritt auf jede Seite anwenden kann.

Sind die Stempel dauerhaft, oder lassen sie sich später wieder entfernen?

Stempel werden als PDF-Stempelannotationen gespeichert, daher kann ein PDF-Editor sie weiterhin auswählen, verschieben oder löschen. Wenn sie in den Seiteninhalt eingebunden werden sollen, damit sie sich nicht abheben lassen, führen Sie die gespeicherte Datei durch PDF reduzieren.

Wie verschiebe ich einen Stempel oder ändere seine Größe, nachdem ich ihn platziert habe?

Klicken Sie im Viewer auf den Stempel, um ihn auszuwählen, und ziehen Sie ihn dann an eine neue Position oder an den Eckgriffen, um die Größe zu ändern. Erst wenn Sie auf Gestempelte PDF speichern klicken, ist etwas endgültig, Sie können also vorher beliebig nachjustieren.

Was ist der Unterschied zu PDF unterschreiben?

PDF unterschreiben ist für Unterschriften gedacht: Sie zeichnen eine, tippen eine oder laden eine hoch und platzieren sie auf der Seite. Stempel hinzufügen ist für wiederverwendbare Bildmarkierungen wie Siegel, Eingangsstempel oder Prüfstempel, wobei Ihr Name als Autor jedes Stempels gespeichert wird.

Funktioniert das Stempel-Tool bei passwortgeschützten PDFs?

Wenn die Datei zum Öffnen ein Passwort braucht, fragt das Tool danach, bevor der Viewer geladen wird. Sie benötigen das Öffnungspasswort, das Tool umgeht keine Verschlüsselung.

Wird mein Dokument beim Stempeln hochgeladen?

Nein. Der Viewer, der Stempel-Editor und der Export laufen alle in Ihrem Browser, und die gestempelte PDF wird auf Ihrem Gerät erstellt. Es wird nichts an einen Server gesendet, was wichtig ist, wenn Sie Verträge, Prüfberichte oder notariell beglaubigte Dokumente stempeln.
