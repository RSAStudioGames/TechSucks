Häufig gestellte Fragen

Kann PDF entsperren ein Passwort entfernen, das ich nicht kenne?

Nein. Es braucht das aktuelle Passwort und knackt, errät oder erzwingt nichts. Öffnet sich die PDF ohne Passwort, blockiert aber Drucken oder Kopieren, nutzen Sie stattdessen Beschränkungen entfernen.

Funktioniert es mit dem Eigentümerpasswort oder nur mit dem Öffnungspasswort?

Beides. Geben Sie das Passwort ein, das Sie haben. Das Werkzeug authentifiziert sich damit und speichert eine Kopie, bei der die Verschlüsselung vollständig entfernt ist, sodass keine Restbeschränkungen bleiben.

Kann ich das Passwort aus mehreren PDFs auf einmal entfernen?

Ja, solange sie dasselbe Passwort haben. Laden Sie alle hoch, geben Sie das Passwort einmal ein, und Sie erhalten decrypted-pdfs.zip mit den Dateien unter ihren ursprünglichen Namen. PDFs mit unterschiedlichen Passwörtern brauchen getrennte Stapel. Jede Datei, die fehlschlägt, wird in der Zusammenfassung gezählt, während die übrigen trotzdem heruntergeladen werden.

Warum erhalte ich einen Passwortfehler?

Das Passwort passte nicht zur Datei. Prüfen Sie die Feststelltaste und Leerzeichen am Ende, und achten Sie darauf, das Passwort dieser Datei zu verwenden und nicht das eines ähnlichen Dokuments. Eine beschädigte Datei zeigt stattdessen die Meldung Entschlüsselung fehlgeschlagen. Dabei kann PDF reparieren helfen.

Verändert das Entfernen des Passworts das Dokument?

Nein. Seiten, Text, Bilder, Formulare und Lesezeichen bleiben erhalten, nur die Verschlüsselungsebene wird entfernt, und die Datei behält ihren Namen. Die Ausgabe hat überhaupt keinen Schutz, schützen Sie sie daher mit PDF schützen erneut, wenn sie ein neues Passwort braucht.

Warum sollte ich das Passwort aus meiner eigenen PDF entfernen?

Häufige Gründe: ein Dokumentenmanagementsystem, das verschlüsselte Dateien ablehnt, das Zusammenführen mit anderen PDFs (viele Zusammenführungswerkzeuge können verschlüsselte Eingaben nicht lesen), Langzeitarchivierung oder ein Passwort, das nicht mehr gebraucht wird.

Werden mein Passwort oder meine Datei irgendwohin gesendet?

Nein. Die Entschlüsselung läuft in Ihrem Browser mit WebAssembly-PDF-Engines (CoherentPDF, mit PyMuPDF als Fallback), die Datei und das Passwort bleiben also auf Ihrem Gerät.

Ist das dasselbe Werkzeug, das früher PDF entschlüsseln hieß?

Ja. PDF entschlüsseln wurde in PDF entsperren umbenannt. Es ist dasselbe Werkzeug mit demselben Verhalten.
