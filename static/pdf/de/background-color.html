Häufig gestellte Fragen

Wie ändere ich die Hintergrundfarbe einer PDF, ohne den Text zu verlieren?

Laden Sie die PDF hoch, wählen Sie eine Farbe, und das Tool zeichnet hinter jede Seite ein einfarbiges Rechteck und legt den ursprünglichen Seiteninhalt darüber. Der Text bleibt echter Text, ist also weiterhin auswählbar und durchsuchbar, und die Seitenmaße ändern sich nicht.

Warum wurde die Hintergrundfarbe auf manchen Seiten nicht angezeigt?

Die Farbe liegt unter dem vorhandenen Inhalt, daher verdeckt jede Seite mit einem bereits deckenden Hintergrund sie. Am häufigsten sind das gescannte Seiten, die meist aus einem ganzseitigen Bild bestehen, und Seiten mit gezeichnetem weißem Hintergrund.

Gilt die Farbe für jede Seite, oder kann ich bestimmte Seiten wählen?

Es gibt keine Option für einen Seitenbereich, daher wird dieselbe Farbe auf jede Seite des Dokuments angewendet. Um nur bestimmte Seiten einzufärben, lösen Sie sie mit PDF teilen heraus, färben Sie diese Datei ein und führen Sie sie wieder zusammen.

Welche Farben eignen sich am besten als PDF-Hintergrund?

Helle, gedämpfte Töne wie Creme, Elfenbein oder Hellgelb halten schwarzen Text lesbar, weshalb der Standard ein helles Gelb (#FFFFCC) ist. Ein dunkler Hintergrund macht normalen schwarzen Text schwer lesbar, da die Textfarbe nicht geändert wird. Nutzen Sie Textfarbe ändern auf dem Ergebnis, wenn Sie hellen Text auf einer dunklen Seite möchten.

Bleiben Links, Formularfelder oder Lesezeichen nach der Farbänderung erhalten?

Nein. Jede Seite wird als Zeichnung über der Farbebene neu eingebettet und in eine neue Datei geschrieben, daher werden Link-Annotationen, Formularfelder, Kommentare und Lesezeichen nicht übernommen. Ändern Sie zuerst den Hintergrund und fügen Sie diese Elemente danach hinzu.

Macht das Ändern des Hintergrunds meine Seiten zu Bildern oder die Datei größer?

Seiten werden nicht gerastert. Das Tool arbeitet auf PDF-Objektebene und fügt nur ein gefülltes Rechteck pro Seite hinzu, daher bleiben Schriften und Vektorgrafiken erhalten, und die Dateigröße bleibt nah am Original.

Wird meine PDF hochgeladen, wenn ich ihre Hintergrundfarbe ändere?

Nein. Die Farbebene wird von Code hinzugefügt, der in Ihrem Browser läuft, und die fertige Datei wird direkt von der Seite auf Ihr Gerät gespeichert. Das Dokument wird zu keinem Zeitpunkt an einen Server gesendet.

Kann ich die Hintergrundfarbe einer passwortgeschützten PDF ändern?

Wenn die PDF zum Öffnen ein Passwort braucht, fragt das Tool danach und verarbeitet die Datei dann wie gewohnt. Die Ausgabe wird ohne dieses Passwort gespeichert, schützen Sie sie daher mit PDF schützen erneut, wenn sie weiterhin gesperrt sein soll.
