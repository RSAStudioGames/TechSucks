Häufig gestellte Fragen

Wie öffne ich eine .pub-Datei ohne Microsoft Publisher?

Laden Sie die .pub-Datei hier hoch und klicken Sie auf In PDF konvertieren. Eine LibreOffice-Engine, kompiliert zu WebAssembly, läuft in Ihrem Browser, liest die Publisher-Datei und schreibt eine PDF, die Sie auf jedem Gerät öffnen können. Sie brauchen also weder Publisher noch andere Microsoft-Software.

Sieht das Layout genauso aus wie in Publisher?

Text, Bilder und Textfelder werden entsprechend dem ursprünglichen Layout platziert, und die meisten Flyer und Newsletter lassen sich gut konvertieren. Überlagerte Textfelder und eng positionierte Elemente können leicht verrutschen, und Schriften, die keine Standard-Systemschriften sind, werden unter Umständen ersetzt. Prüfen Sie das Ergebnis also, wenn es auf exakte Positionierung ankommt.

Warum dauert die erste Publisher-Datei länger?

Die Konvertierungs-Engine ist komprimiert etwa 75 MB groß und wird beim ersten Konvertieren in einer Sitzung heruntergeladen und gestartet, wobei eine Fortschrittsanzeige zeigt, wie weit sie ist. Danach werden weitere Dateien deutlich schneller konvertiert.

Kann ich mehrere Publisher-Dateien auf einmal konvertieren?

Fügen Sie mehrere .pub-Dateien hinzu, entfernen Sie nicht gewünschte und konvertieren Sie sie zusammen. Eine einzelne Datei wird als PDF mit demselben Basisnamen heruntergeladen, mehrere werden in pub-to-pdf.zip verpackt, wobei doppelte Namen ein nummeriertes Suffix erhalten.

Kann ich eine PDF wieder in eine Publisher-Datei umwandeln?

Nein, die Konvertierung geht nur in eine Richtung, von .pub zu PDF. Wenn Sie ein bearbeitbares Ergebnis brauchen, konvertieren Sie die PDF anschließend mit PDF zu Word und bauen Sie das Layout dort neu auf.

Ist der Text in der konvertierten PDF auswählbar?

Die PDF wird aus den Textobjekten des Dokuments erzeugt, der Text bleibt also auswählbar und durchsuchbar, statt zu einem Bild verflacht zu werden. Text, der im Original als Bild eingefügt war, bleibt ein Bild.

Wird meine Publisher-Datei auf einen Server hochgeladen?

Nein. Die gesamte Konvertierung läuft in Ihrem Browser, die .pub-Datei und die entstandene PDF verlassen also nie Ihren Computer. Kundengrafiken, unveröffentlichte Newsletter und Veranstaltungsprogramme bleiben privat.
