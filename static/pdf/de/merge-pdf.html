PDF zusammenführen

Mehrere PDFs zu einer Datei kombinieren. Lesezeichen werden beibehalten.

Klicken Sie hier, um eine Datei auszuwählen oder per Drag & Drop reinziehen

PDFs oder Bilder

Ihre Dateien verlassen nie Ihr Gerät.

So funktioniert es:

  • Klicken Sie auf das Symbol und ziehen Sie es, um die Reihenfolge der Dateien zu ändern.
  • Im Feld "Seiten" für jede Datei können Sie Bereiche angeben (z. B. "1-3, 5"), um nur diese Seiten zusammenzuführen.
  • Lassen Sie das Feld "Seiten" leer, um alle Seiten dieser Datei aufzunehmen.

    So funktioniert es:

    • Alle Seiten Ihrer hochgeladenen PDFs werden unten angezeigt.
    • Ziehen Sie einfach die einzelnen Seitenminiaturen, um genau die gewünschte Reihenfolge für Ihre neue Datei zu erstellen.

    Häufig gestellte Fragen

    Bleiben beim Zusammenführen Lesezeichen erhalten?

    Ja. Das Zusammenführen erfolgt mit der CoherentPDF-Engine, die die Lesezeichen jeder Datei in das kombinierte Dokument übernimmt, sodass die Gliederung navigierbar bleibt. Seiteninhalt und Annotationen werden unverändert kopiert.

    Kann ich nur einige Seiten aus jeder Datei zusammenführen?

    Ja. Geben Sie im Dateimodus neben einer Datei im Feld Seiten einen Bereich wie 1-3, 5 ein, um nur diese Seiten aufzunehmen, oder lassen Sie es leer für die ganze Datei. Im Seitenmodus erscheint jede Seite aus jeder Datei als Miniatur, die Sie in beliebige Reihenfolge ziehen können, einschließlich abwechselnder Seiten aus verschiedenen Dokumenten.

    In welcher Reihenfolge stehen die Dateien?

    Die in der Liste gezeigte Reihenfolge, von oben nach unten. Ziehen Sie Einträge vor dem Zusammenführen an eine andere Stelle, und nutzen Sie Weitere Dateien hinzufügen, um Dokumente anzuhängen, ohne die bestehende Anordnung zu verlieren.

    Warum sehen die Seitenzahlen in der zusammengeführten PDF falsch aus?

    Standardmäßig verwendet die zusammengeführte Datei eine einfache Nummerierung von 1 bis N. Wenn die Originale Seitenbeschriftungen wie i, ii, iii oder A-1 nutzten, aktivieren Sie Ursprüngliche Seitenbeschriftungen beibehalten, um sie zu erhalten, und bedenken Sie, dass zwei Dateien mit denselben Beschriftungen Duplikate erzeugen. Um sichtbare Zahlen auf die Seiten selbst zu drucken, nutzen Sie Seitenzahlen.

    Warum ist die zusammengeführte Datei so groß?

    Schriften und Bilder jeder Datei werden unverändert kopiert, das Ergebnis hat daher ungefähr die kombinierte Größe der Eingaben, und wenn mehrere Dateien dieselbe Schrift einbetten, bleibt jede Kopie erhalten. Aktivieren Sie Doppelte Schriften entfernen, um identische Schriften zu einer zusammenzufassen; für mehr Einsparung führen Sie das Ergebnis durch PDF komprimieren.

    Kann ich PDFs mit unterschiedlichen Seitengrößen oder Ausrichtungen zusammenführen?

    Ja. Seiten behalten ihre eigene Größe und Drehung, eine A3-Zeichnung im Querformat kann also auf eine Letter-Seite im Hochformat folgen, ohne skaliert zu werden. Für eine einheitliche Größe führen Sie die zusammengeführte Datei anschließend durch Seitengröße reparieren.

    Werden die PDFs zum Zusammenführen auf einen Server hochgeladen?

    Nein. Die Dateien werden in Ihrem Browser vom CoherentPDF-WebAssembly-Modul kombiniert, und die zusammengeführte PDF wird in Ihren Download-Ordner geschrieben, Verträge und Kontoauszüge verlassen Ihren Rechner also nie.

    Kann ich passwortgeschützte PDFs zusammenführen?

    Wenn eine Datei zum Öffnen ein Passwort braucht, fragt das Werkzeug beim Hinzufügen der Datei danach und führt dann die entschlüsselten Seiten zusammen. Die zusammengeführte Ausgabe hat kein Passwort; fügen Sie bei Bedarf danach eines mit PDF schützen hinzu.
