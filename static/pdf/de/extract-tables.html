Häufig gestellte Fragen

Welches Ausgabeformat sollte ich wählen?

CSV lässt sich in Excel, Google Sheets oder jedem Datenbank-Import öffnen. JSON liefert ein Array von Zeilen, jeweils ein Array von Zell-Strings, für Skripte und APIs. Markdown liefert eine Tabelle mit senkrechten Strichen, die Sie in GitHub, ein Wiki oder eine Dokumentation einfügen können.

Was erhalte ich, wenn die PDF mehrere Tabellen enthält?

Jede Tabelle wird als eigene Datei gespeichert, mit einem Namen wie table_1_page3.csv, und alle werden in filename_tables.zip gebündelt. Eine einzelne Tabelle wird direkt als filename_table.csv, .json oder .md heruntergeladen. Wenn Sie lieber alle Tabellen in einer Datei möchten, nutzen Sie PDF zu CSV.

Warum heißt es, es seien keine Tabellen gefunden worden?

Die Erkennung arbeitet auf der Textebene des Dokuments. Gescannte PDFs enthalten nur ein Bild, führen Sie sie daher zuerst durch OCR PDF. Text, der nur durch Abstände wie eine Tabelle aussieht, aber keine Tabellenstruktur hat, wird möglicherweise ebenfalls nicht erkannt.

Eine Tabelle geht über mehrere Seiten. Kommt sie als eine Datei heraus?

Nein. Jede Seite wird einzeln gescannt, eine Tabelle über mehrere Seiten wird daher als eine Datei pro Seite exportiert, jeweils mit der Seitenzahl im Namen. Fügen Sie die Teile nach der Extraktion in einer Tabellenkalkulation zusammen.

Kann ich Tabellen nur aus einigen Seiten extrahieren?

Es wird immer das gesamte Dokument gescannt, die Seitenzahl im Dateinamen verrät aber, woher eine Tabelle stammt. Um den Scan einzugrenzen, speichern Sie zuerst die benötigten Seiten mit Seiten extrahieren und führen dieses Werkzeug mit der kleineren Datei aus.

Kommt die CSV mit Kommas und Zeilenumbrüchen in Zellen zurecht?

Ja. Zellen mit Kommas, Anführungszeichen oder Zeilenumbrüchen werden in doppelte Anführungszeichen gesetzt, wobei innere Anführungszeichen verdoppelt werden, damit Tabellenkalkulationen sie korrekt lesen. Leere Zellen werden als leere Felder geschrieben.

Lassen sich Tabellen aus einer passwortgeschützten PDF extrahieren?

Wenn die Datei zum Öffnen ein Passwort braucht, werden Sie vor Beginn der Extraktion danach gefragt, und die Tabellen werden aus einer entschlüsselten Kopie im Arbeitsspeicher gelesen.

Wird die PDF zur Tabellenerkennung hochgeladen?

Nein. Die Erkennungs-Engine (PyMuPDF, kompiliert zu WebAssembly) wird beim ersten Mal von einem CDN heruntergeladen und läuft dann in Ihrem Browser. Ihre PDF bleibt auf Ihrem Gerät.
