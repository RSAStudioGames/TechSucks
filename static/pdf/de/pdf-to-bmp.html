Häufig gestellte Fragen

Welche Auflösung haben die BMP-Bilder?

Seiten werden mit festem Faktor 2x gerendert, eine Seite im Format Letter (8,5 x 11 Zoll) wird also zu einem Bild von 1224 x 1584 Pixeln, etwa 144 Pixel pro Zoll. Dieses Werkzeug hat keine DPI-Einstellung. Für einen einstellbaren Faktor nutzen Sie PDF in PNG.

Wie wird eine mehrseitige PDF geliefert?

Eine einseitige PDF wird als einzelne .bmp mit dem Namen der Datei heruntergeladen. Eine mehrseitige PDF wird als ZIP namens filename_bmps.zip heruntergeladen, die page_1.bmp, page_2.bmp und so weiter enthält, ein Bild pro Seite.

Warum sind die BMP-Dateien so groß?

BMP speichert rohe Pixeldaten ohne Komprimierung, eine Seite belegt also gleich viel Platz, ob sie leer oder voller Details ist, und die Dateien sind weit größer als eine PNG oder JPG derselben Seite. Wenn Ihre Zielsoftware PNG akzeptiert, ist dieses Format ebenfalls verlustfrei und deutlich kleiner.

Kann ich mehrere PDFs in einem Stapel in BMP umwandeln?

Nein, eine PDF pro Durchlauf. Wenn Sie mehrere Dateien hineinziehen, wird nur die erste verwendet. Wandeln Sie sie nacheinander um oder wählen Sie die benötigten Seiten vorab mit Seiten extrahieren aus, damit jeder Durchlauf klein bleibt.

Bleiben bei der Umwandlung Transparenz oder Vektorqualität erhalten?

Nein. Jede Seite wird zu einem flachen Rasterbild auf weißem Hintergrund, und Text wird zu Pixeln. Die BMP lässt sich daher weder durchsuchen noch ohne Unschärfe vergrößern. Behalten Sie die Original-PDF zum Bearbeiten.

Kann ich eine passwortgeschützte PDF in BMP umwandeln?

Ja, wenn Sie das Passwort kennen: Das Werkzeug fragt beim Laden der Datei danach und rendert die Seiten dann normal. Eine Datei mit unbekanntem Passwort lässt sich nicht öffnen.

Wird meine PDF hochgeladen, um sie in BMP umzuwandeln?

Nein. Das Rendern läuft auf einem Canvas in Ihrem Browser, und die Bilder werden lokal in die ZIP gepackt, das Dokument verlässt also nie Ihren Computer. Große PDFs dauern nur länger, weil Ihr eigenes Gerät rendert.

Welches Werkzeug sollte ich stattdessen nutzen, wenn BMP nicht erforderlich ist?

Für verlustfreie Ausgabe mit kleinen Dateien nutzen Sie PDF in PNG, für Fotos und die kleinsten Dateien PDF in JPG, für mehrseitige Fax- oder Scansysteme PDF in TIFF. BMP ist hauptsächlich sinnvoll, wenn eine ältere Anwendung oder ein Gerät darauf besteht.
