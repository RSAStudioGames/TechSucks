Häufig gestellte Fragen

Kann ich den vorhandenen Text in einer PDF ändern?

Mit PDF-Text bearbeiten klicken Sie auf einen beliebigen Absatz und schreiben ihn direkt um, wobei der umgebende Text beim Tippen umbricht, mit Einstellungen für Schriftarten und Formatierung. Zum Hinzufügen neuer Textfelder, Kommentare, Markierungen, Formen oder Bilder auf der Seite nutzen Sie stattdessen das allgemeine Werkzeug PDF bearbeiten.

Was kann ich im Werkzeug PDF bearbeiten tun?

Die Werkzeugleiste von PDF bearbeiten bietet Hervorheben, Unterstreichen, Durchstreichen, Freihandzeichnen, Text und Kommentare, Formen und Bilder, dauerhaftes Schwärzen und Volltextsuche. Sie erhält die ursprüngliche PDF-Struktur, sodass Schriftarten, Layouts und Formularfelder intakt bleiben, und Sie können bis zu 10 Dokumente in Tabs geöffnet halten und zwischen ihnen wechseln.

Wie mache ich eine PDF kleiner?

PDF komprimieren entfernt ungenutzte Struktur, verkleinert Bilder und bettet nur benötigte Schriftzeichen ein, wobei Text markierbar bleibt und Links funktionieren. Beginnen Sie mit der Stufe Mittel oder geben Sie eine Zielgröße ein, und gehen Sie nur auf Hoch, wenn die Datei immer noch zu groß ist.

Welche Bearbeitungswerkzeuge lassen meinen Text markierbar?

Werkzeuge auf Seitenebene wie Drehen, Organisieren, Seiten löschen, Hintergrundfarbe und Anmerkungen entfernen arbeiten an der PDF-Struktur und lassen den Text durchsuchbar. Farben umkehren, Textfarbe ändern und PDF in Graustufen rendern jede Seite als Bild neu, sodass Text in ihrer Ausgabe nicht mehr markiert oder durchsucht werden kann. Brauchen Sie nach einem dieser Werkzeuge durchsuchbaren Text, schicken Sie das Ergebnis durch OCR PDF.

Kann ich Seitenzahlen oder eine Kopf- und Fußzeile hinzufügen?

Seitenzahlen setzt auf jeder Seite eine Nummer an eine von sechs Positionen, schlicht oder im Stil Seite X von Y, mit frei wählbarer Schriftgröße und Farbe. Kopf- und Fußzeile fügt pro Seite Text in sechs Feldern hinzu (links, Mitte und rechts oben und unten), versteht die Platzhalter {page} und {total}, sodass eine Fußzeile wie Seite {page} von {total} auf jeder Seite korrekt ausgefüllt wird, und lässt sich auf einen Seitenbereich beschränken.

Kann ich auf jede Seite ein Wasserzeichen setzen?

Wasserzeichen hinzufügen stempelt Text oder ein Bild auf Ihre Seiten. Sie positionieren es per Ziehen in einer Live-Vorschau und stellen dann Deckkraft, Drehung und Größe ein. Ein Kachelmodus wiederholt das Zeichen über die ganze Seite, sodass es sich viel schwerer abschneiden lässt, und Sie können ein Wasserzeichen auf alle Seiten anwenden, auf einen Seitenbereich beschränken oder auf jeder Seite ein anderes setzen.

Kann ich eine einzelne Seite drehen oder einen leicht schiefen Scan geraderichten?

PDF drehen zeigt ein Vorschaubild jeder Seite mit eigenen Schaltflächen für Drehungen um 90 Grad nach links und rechts sowie einer Sammelsteuerung für das ganze Dokument. Für einen Scan, der um ein paar Grad schief liegt, akzeptiert Um beliebige Grad drehen jeden Winkel, pro Seite oder für alle Seiten auf einmal.

Wird eine PDF beim Bearbeiten hier irgendwohin hochgeladen?

Nein. Der Editor und jedes andere Werkzeug auf dieser Seite läuft als WebAssembly in Ihrem Browser, die Datei wird also auf Ihrem eigenen Gerät geöffnet, geändert und gespeichert, ohne Server dazwischen. Es wird nichts gespeichert, Sie müssen am Ende also keine Kopie löschen.
