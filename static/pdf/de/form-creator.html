Häufig gestellte Fragen

Kann ich einer bereits vorhandenen PDF ausfüllbare Felder hinzufügen?

Laden Sie die PDF hoch, und ihre Seiten erscheinen im Editor; wählen Sie in der Symbolleiste einen Feldtyp und klicken Sie auf die Seite, um es zu platzieren, und ziehen Sie es dann bei Bedarf oder ändern Sie die Größe. Hat die PDF bereits Formularfelder, werden sie erkannt und geladen, sodass Sie sie neben den neuen verschieben, bearbeiten oder löschen können.

Kann ich ein Formular von Grund auf ohne vorhandene PDF erstellen?

Klicken Sie auf Leere PDF erstellen und wählen Sie Letter, A4, A5, Legal, Tabloid, A3 oder eigene Abmessungen in Punkt. Mit Seite hinzufügen erstellen Sie mehrseitige Formulare.

Welche Feldtypen gibt es?

Text (einzeilig, mehrzeilig oder in Kammfelder unterteilt), Kontrollkästchen, Optionsfeldgruppen, Dropdown, Listenfeld, Schaltfläche, Signatur, Datum, Bild und Barcode. Jedes Feld hat ein Eigenschaftenfenster für Name, Standardwert, Schriftgröße, Textfarbe, Ausrichtung, Tooltip sowie Pflicht- oder Schreibschutz-Markierungen. Signaturfelder sind standardmäßige AcroForm-Signaturfelder, die nur in Viewern erscheinen, die das Signieren unterstützen.

Wie werden Optionsfelder gruppiert, sodass nur eines ausgewählt werden kann?

Jedes Optionsfeld hat einen Gruppennamen, standardmäßig RadioGroup1. Felder mit demselben Gruppennamen bilden eine Gruppe, in der nur eine Auswahl möglich ist. Geben Sie daher jeder Frage einen eigenen Gruppennamen und jeder Option einen eigenen Exportwert.

Kann eine Schaltfläche ein anderes Feld ein- oder ausblenden oder das Formular zurücksetzen?

Zu den Schaltflächenaktionen gehören Formular zurücksetzen, Formular drucken, URL öffnen, JavaScript ausführen und Feld ein-/ausblenden, wobei Letzteres ein anderes Feld anspricht und es ein-, ausblenden oder umschalten kann. Sie werden als standardmäßige PDF-Aktionen gespeichert und laufen daher in Acrobat und anderen Viewern, die Formularskripte unterstützen.

Wie funktioniert das Datumsfeld?

Es ist ein Textfeld mit angehängtem Datumsformat, standardmäßig mm/dd/yyyy oder ein eigenes Muster wie dd/mm/yyyy. Viewer mit Unterstützung für AcroForm-JavaScript prüfen den eingegebenen Wert und formatieren ihn; einfachere Viewer behandeln es als normalen Text.

Sind Barcodes und Bilder echte Formularfelder?

Ein Barcode (QR-Code, Code 128, Code 39, EAN-13, UPC-A, DataMatrix oder PDF417) wird aus dem eingegebenen Wert erzeugt und als festes Bild auf die Seite gezeichnet, sodass die ausfüllende Person ihn nicht ändern kann. Das Bildfeld ist eine Schaltfläche, über die Benutzer ein Bild von ihrem Computer auswählen können, was in Acrobat und anderen Viewern mit Bildimport funktioniert.

Werden das Formular oder die hochgeladene PDF auf einem Server gespeichert?

Nein. Der Editor läuft in Ihrem Browser, die Felder werden mit pdf-lib auf Ihrem Gerät in die PDF geschrieben, und PDF-Formular herunterladen speichert das Ergebnis lokal unter dem ursprünglichen Dateinamen. Sie können das Ergebnis im PDF-Formular ausfüllen testen.
