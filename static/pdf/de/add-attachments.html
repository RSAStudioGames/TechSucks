Häufig gestellte Fragen

Welche Arten von Dateien kann ich in eine PDF-Datei einbetten?

Jeder Dateityp: Tabellen, Bilder, ZIP-Archive, CAD-Zeichnungen, sogar ausführbare Dateien. Das Werkzeug prüft oder konvertiert die Datei nicht, sondern speichert ihre Bytes unter dem ursprünglichen Dateinamen in der PDF-Datei. Sie können mehrere Dateien in einem Durchgang einbetten.

Was ist der Unterschied zwischen Anhängen auf Dokumentebene und auf Seitenebene?

Anhänge auf Dokumentebene gehören zur gesamten PDF-Datei und erscheinen im Anhangsbereich des Readers. Anhänge auf Seitenebene sind an die Seiten gebunden, die Sie im Feld für den Seitenbereich angeben (zum Beispiel 1,3,5-7), und dieselbe Datei wird an jede Seite in diesem Bereich angehängt. Die Dokumentebene ist die sicherere Wahl, da manche Viewer Anhänge auf Seitenebene gar nicht anzeigen.

Wo erscheinen die angehängten Dateien, wenn jemand die PDF-Datei öffnet?

In Readern mit Anhangsbereich, etwa dem Adobe Acrobat Reader oder dem integrierten Viewer von Firefox, werden sie mit ihrem Dateinamen aufgelistet und lassen sich dort öffnen oder speichern. Viewer ohne diesen Bereich zeigen sie gar nicht an, obwohl die Dateien weiterhin in der PDF enthalten sind.

Wird die PDF durch eingebettete Dateien größer?

Ja, ungefähr um die Größe jedes Anhangs, da die Bytes der Datei in der PDF-Datei gespeichert werden. Eine Tabelle mit 40 MB, die an einen Bericht mit 1 MB angehängt wird, ergibt eine PDF-Datei mit etwa 41 MB. Behalten Sie die Größe der Anhänge also im Blick, bevor Sie das Ergebnis per E-Mail verschicken.

Wird die Datei, die ich anhänge, beim Einbetten irgendwohin hochgeladen?

Nein. Die PDF-Datei und die Anhänge werden in Ihrem Browser vom CoherentPDF-WebAssembly-Modul gelesen und kombiniert, und das Ergebnis wird direkt von der Seite heruntergeladen. Es wird nichts an einen Server gesendet.

Warum meldet das Werkzeug, dass ein erweitertes Verarbeitungsmodul erforderlich ist?

Das Einbetten nutzt das CoherentPDF-Modul (cpdf), das beim ersten Einsatz bei Bedarf von einem CDN geladen wird, statt mit der Hauptseite ausgeliefert zu werden. Wenn Sie BentoPDF selbst hosten oder in einer netzwerkisolierten Umgebung arbeiten, können Sie das Tool auf der Seite Einstellungen für erweiterte Funktionen auf Ihre eigene Kopie des Moduls verweisen.

Kann ich einen Anhang später wieder entfernen?

Ja. Anhänge bearbeiten listet jede eingebettete Datei auf und lässt Sie einzelne oder alle entfernen, und mit Anhänge extrahieren speichern Sie sie wieder als separate Downloads.

Macht das Anhängen von Dateien eine digitale Signatur in der PDF-Datei ungültig?

Ja. Beim Hinzufügen von Anhängen wird die Datei neu geschrieben, wodurch jede vorhandene digitale Signatur ungültig wird. Fügen Sie zuerst die Anhänge hinzu und signieren Sie dann die fertige PDF-Datei mit Digitale PDF-Signatur.
