Veelgestelde vragen

Kan ik met deze tool elk JSON-bestand naar een PDF converteren?

Nee. Het bouwt alleen PDF's opnieuw op uit JSON-bestanden die zijn gemaakt met de tool PDF naar JSON van BentoPDF, die de volledige interne structuur van het document opslaat. Een JSON-export uit een API, database of configuratiebestand geeft een foutmelding.

Hoe maak ik van API-gegevens of een configuratiebestand in plaats daarvan een leesbare PDF?

Plak of upload de JSON als platte tekst in Tekst naar PDF, dat hem als opgemaakte tekst op pagina's zet. JSON naar PDF is alleen bedoeld voor het heen en weer converteren van documenten die als PDF zijn begonnen.

Komt de opnieuw opgebouwde PDF overeen met het origineel?

De JSON die PDF naar JSON maakt, bevat de objecten van het document, dus terug converteren reproduceert de pagina's, tekst en afbeeldingen van het origineel. Terug converteren en vergelijken is ook een snelle manier om te bevestigen dat een export alles heeft vastgelegd.

Wat is de uitvoer als ik meerdere JSON-bestanden converteer?

Elke conversie wordt gedownload als jsons-to-pdf.zip, ook voor één bestand. Daarin draagt elke PDF de naam van de bijbehorende JSON, dus report.json wordt report.pdf.

Kan ik de JSON bewerken voordat ik hem terug converteer?

Ja, zolang de structuur geldig blijft voor de CPDF-engine. Programmatische wijzigingen in de JSON, zoals bewerkte metadata of tekstobjecten, worden in de PDF herbouwd; een foutieve bewerking geeft een conversiefout.

Waarom meldt de tool dat de CPDF-engine niet beschikbaar is?

De conversie is afhankelijk van de CPDF WebAssembly-build. Op bentopdf.com is die inbegrepen, maar een zelf gehoste kopie heeft de CPDF WASM-bestanden nodig, geconfigureerd in de WASM-instellingen, voordat deze tool werkt.

Wordt mijn JSON-bestand naar een server geüpload?

Nee. De bestanden worden in je browser gelezen en door een Web Worker met de CPDF-engine lokaal opnieuw tot PDF's opgebouwd, dus er wordt niets verzonden en de pagina blijft responsief tijdens grote conversies.
