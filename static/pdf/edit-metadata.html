Frequently Asked Questions

Which metadata fields can I change?

Title, Author, Subject, Keywords, Creator, Producer, Creation Date, and Modification Date, plus any custom key-value pairs you add. The form loads with the file's current values, so you only edit what needs changing.

How do I delete a field like Author completely?

Clear the box and save. Whatever is in the form is written back, so an emptied field is stored as empty. To strip every field at once, including hidden ones, use Remove Metadata instead.

Why does the modification date change even though I didn't touch it?

If the Modification Date box is left empty, the tool stamps the current date and time when it saves. Set a specific date in the picker if a particular value needs to be kept.

Can I add my own fields such as Department or Project ID?

Yes. Click the add button, enter a key and a value, and the pair is written into the PDF's info dictionary alongside the standard fields. Not every reader lists custom entries, but they stay in the file and show up in tools that read the full info dictionary, such as View Metadata.

I changed the title but Acrobat still shows the old one. Why?

The tool writes to the document info dictionary. Some PDFs also carry an XMP metadata stream, and readers like Acrobat prefer XMP when both exist, so the old title can still appear there. Run Remove Metadata first, then edit, to avoid the conflict.

How should I enter keywords?

Separate them with commas, for example invoice, 2026, Q3. They're saved as a keyword list that document management systems and desktop search can index.

Does editing metadata alter the pages or send my file anywhere?

No. Only the info dictionary is rewritten; pages, fonts, links, and bookmarks are untouched, and the whole edit happens in your browser, so the document never leaves your device.

Can I edit metadata on a password-protected PDF?

If the file needs a password to open, the tool asks for it and then loads the document normally. Without the password the file can't be opened here.
