    Questions fréquemment posées

    Comment ajouter des signets à un PDF qui n'en a pas ?

    Importez le PDF, allez à une page, saisissez un titre et cliquez sur Ajouter à la page ; faites glisser les entrées pour les imbriquer ou les réordonner. Cliquez sur Enregistrer le PDF avec les signets pour télécharger le résultat. Pour une page de sommaire imprimée dans le document plutôt qu'une navigation dans la barre latérale, utilisez plutôt Table des matières.

    Mes signets existants seront-ils conservés ?

    Seulement si vous cochez l'extraction automatique des signets existants avant l'import, ou si vous utilisez ensuite le bouton d'extraction, pour les charger dans le panneau. À l'enregistrement, le contenu du panneau remplace entièrement l'arborescence de signets du PDF : tout ce qui n'a pas été chargé dans l'éditeur est supprimé.

    Quel est le format CSV pour importer des signets ?

    Une ligne d'en-tête suivie d'une ligne par signet, avec trois colonnes : title,page,level. Les titres contenant des virgules vont entre guillemets doubles, page est le numéro de page à partir de 1, et level indique l'imbrication, avec le plus petit nombre pour les entrées de premier niveau et un niveau de plus pour chaque sous-niveau.

    Un signet peut-il pointer vers un endroit précis d'une page plutôt que le haut ?

    Ouvrez la fenêtre de modification du signet, activez Définir une destination personnalisée, puis saisissez les coordonnées X et Y avec un pourcentage de zoom, ou cliquez sur le bouton de sélection puis sur l'endroit exact dans l'aperçu de la page. Le signet est enregistré comme destination XYZ, que la plupart des lecteurs respectent.

    Puis-je colorer ou mettre des signets en gras ?

    Chaque signet peut être rouge, bleu, vert, jaune, violet ou d'une couleur hexadécimale personnalisée, en gras, en italique ou en gras italique. Activez le mode par lot pour sélectionner plusieurs signets et leur appliquer une couleur ou un style en une fois.

    Comment extraire les signets d'un PDF pour les modifier dans un tableur ?

    Chargez-les avec l'extraction automatique, puis utilisez Exporter en CSV ou Exporter en JSON ; le fichier porte le nom de votre PDF avec le suffixe -bookmarks. Le CSV s'ouvre dans Excel ou Google Sheets et, une fois modifié, vous pouvez le réimporter et enregistrer un nouveau PDF.

    L'éditeur fonctionne-t-il sur les PDF protégés par mot de passe ?

    Le mot de passe vous est demandé à l'import du fichier, et l'éditeur s'ouvre une fois qu'il est saisi. Le PDF enregistré est écrit sans le mot de passe : protégez-le à nouveau ensuite si nécessaire.

    Mon PDF est-il envoyé quelque part pendant que je modifie les signets ?

    Non. L'aperçu des pages, l'arborescence des signets et l'enregistrement final se font dans votre navigateur avec PDF.js et pdf-lib : le fichier ne quitte jamais votre ordinateur.
