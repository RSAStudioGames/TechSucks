Questions fréquemment posées

Quel format de sortie dois-je choisir ?

Le CSV s’ouvre dans Excel, Google Sheets ou n’importe quel import de base de données. Le JSON fournit un tableau de lignes, chacune étant un tableau de chaînes de cellules, pour les scripts et les API. Le Markdown fournit un tableau avec barres verticales que vous pouvez coller dans GitHub, un wiki ou une documentation.

Qu’obtient-on quand le PDF contient plusieurs tableaux ?

Chaque tableau est enregistré dans son propre fichier, nommé par exemple table_1_page3.csv, et tous sont regroupés dans filename_tables.zip. Un tableau unique est téléchargé directement sous la forme filename_table.csv, .json ou .md. Si vous préférez avoir tous les tableaux dans un seul fichier, utilisez PDF vers CSV.

Pourquoi l’outil indique-t-il qu’aucun tableau n’a été trouvé ?

La détection s’appuie sur la couche de texte du document. Les PDF numérisés ne contiennent qu’une image : passez-les donc d’abord par OCR PDF. Un texte qui ressemble à un tableau uniquement à cause des espaces, sans structure de tableau, peut aussi ne pas être détecté.

Un tableau se poursuit sur plusieurs pages. Sera-t-il extrait en un seul fichier ?

Non. Chaque page est analysée séparément : un tableau qui s’étend sur plusieurs pages est donc exporté en un fichier par page, avec le numéro de page dans son nom. Assemblez les morceaux dans un tableur après l’extraction.

Puis-je extraire les tableaux de certaines pages seulement ?

Le document entier est toujours analysé, mais le numéro de page dans chaque nom de fichier indique d’où provient un tableau. Pour limiter l’analyse, enregistrez d’abord les pages dont vous avez besoin avec Extraire des pages et utilisez cet outil sur le fichier réduit.

Le CSV gère-t-il les virgules et les sauts de ligne dans les cellules ?

Oui. Les cellules contenant des virgules, des guillemets ou des sauts de ligne sont placées entre guillemets doubles, les guillemets internes étant doublés, afin que les tableurs les lisent correctement. Les cellules vides sont écrites comme des champs vides.

Peut-on extraire des tableaux d’un PDF protégé par mot de passe ?

Si le fichier nécessite un mot de passe pour s’ouvrir, il vous est demandé avant le début de l’extraction, et les tableaux sont lus à partir d’une copie déchiffrée conservée en mémoire.

Le PDF est-il envoyé pour la détection des tableaux ?

Non. Le moteur de détection (PyMuPDF compilé en WebAssembly) est téléchargé depuis un CDN à la première utilisation, puis s’exécute dans votre navigateur. Votre PDF reste sur votre appareil.
