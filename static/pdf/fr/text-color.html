Questions fréquemment posées

Comment sait-il quels pixels sont du texte ?

Il ne lit pas le texte ; chaque page est rendue en image et chaque pixel sombre (rouge, vert et bleu tous inférieurs à 120 sur une échelle de 0 à 255) est repeint dans la couleur choisie. Le texte noir et gris foncé est pris en compte, tandis que le texte gris clair, le texte coloré et les photos sont laissés tels quels.

Pourquoi les lignes, les bordures et mon logo ont-ils aussi changé de couleur ?

Comme l’outil travaille sur des pixels sombres et non sur des objets texte, tout élément sombre, y compris les filets de tableau, les soulignements et les illustrations noires, est recoloré avec le texte. Cet outil ne permet pas d’exclure des zones.

Puis-je recolorer seulement certains mots ou paragraphes ?

Non. Une seule couleur est appliquée à tout le contenu sombre de chaque page. Pour modifier des mots ou des titres individuels sans toucher au reste, modifiez directement le texte dans l’Éditeur PDF.

Le texte restera-t-il sélectionnable et consultable par recherche ?

Non. Le fichier de sortie est basé sur des images : chaque page est rendue en 2x et intégrée sous forme de PNG, le texte ne peut donc plus être sélectionné, recherché ni copié. Conservez l’original si vous avez besoin d’une version modifiable, ou passez le résultat dans OCR PDF pour rajouter une couche de texte.

Pourquoi le fichier est-il devenu beaucoup plus gros ?

Une page de texte pèse quelques kilo-octets sous forme de texte, mais devient une image PNG pleine page une fois recolorée ; les documents de plusieurs pages peuvent donc être plusieurs fois plus lourds. Compresser un PDF peut réduire le résultat au prix d’un peu de netteté.

Puis-je mettre le texte noir en blanc pour un fond sombre ?

Oui, n’importe quelle couleur convient, y compris le blanc, mais l’arrière-plan de la page n’est pas modifié : le texte blanc sur la page blanche d’origine disparaît donc. Choisissez une couleur qui contraste avec l’arrière-plan déjà présent sur la page.

Mon document est-il envoyé pour changer la couleur du texte ?

Non. Chaque page est rendue et recolorée sur un canevas dans votre navigateur, et le nouveau PDF y est aussi assemblé, le fichier ne quitte donc jamais votre appareil. Un indicateur de progression montre quelle page est en cours de traitement.

Pourquoi le texte coloré ou gris clair reste-t-il inchangé ?

Seuls les pixels assez sombres pour passer le seuil sont repeints. Les titres rouges, les liens bleus, les légendes gris moyen et les bords anticrénelés plus clairs que le seuil gardent leur couleur d’origine, ce qui peut laisser un léger halo autour des lettres recolorées.
