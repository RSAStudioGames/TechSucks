Questions fréquemment posées

Le PDF est-il vectoriel ou une image ?

Une image. Chaque SVG est rendu par votre navigateur sur un canevas et l’image bitmap est placée sur une page PDF, le résultat ne peut donc pas être agrandi sans perte et le texte n’est pas sélectionnable. Si vous avez besoin d’une vraie sortie vectorielle, exportez plutôt le PDF depuis un éditeur vectoriel comme Inkscape.

Quelle sera la taille de la page ?

La page correspond aux attributs width et height du SVG en pixels, un pixel par point PDF. Un SVG sans width ni height (seulement un viewBox) est rendu en 800 par 600 ; définissez donc des dimensions explicites dans le fichier pour des résultats prévisibles.

Que changent les réglages de qualité pour la conversion SVG ?

Élevée conserve le PNG sans perte à sa taille complète. Moyenne le réencode en JPEG à 75 % de qualité et limite le plus grand côté à 2500 pixels ; Faible utilise 50 % et 1500 pixels, ce qui réduit aussi la page. Pour les dessins au trait et le texte, Élevée évite les artefacts JPEG.

Puis-je contrôler la résolution de sortie, par exemple 300 DPI ?

Il n’y a pas de réglage DPI ; le rendu utilise les dimensions en pixels propres au SVG. Pour obtenir plus de pixels, augmentez les attributs width et height dans le code source du SVG en conservant le viewBox, puis convertissez.

Pourquoi mon SVG est-il sorti avec du texte, des polices ou des images manquants ?

Le SVG est rendu à partir de son propre balisage : les références à des fichiers externes (images liées, polices importées, CSS externe) ne peuvent pas être chargées dans ce contexte et sont remplacées ou disparaissent. Intégrez les images sous forme d’URI de données et convertissez le texte en tracés avant la conversion.

La transparence est-elle conservée ?

Non. Le canevas est rempli de blanc avant le dessin du SVG, les zones transparentes deviennent donc blanches dans le PDF.

Puis-je mettre plusieurs SVG dans un seul PDF ?

Importez plusieurs fichiers et ils deviennent des pages consécutives d’un seul fichier from_svgs.pdf, dans l’ordre affiché dans la liste. Chaque page prend la taille de son propre SVG.

Le SVG est-il envoyé pour être converti ?

Non. Le rendu se fait sur un canevas dans votre navigateur et le PDF est construit avec pdf-lib sur votre appareil ; rien n’est envoyé ailleurs.
