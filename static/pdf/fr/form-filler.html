Remplir un formulaire PDF

Téléversez un PDF avec des champs de formulaire. Remplissez-les directement dans la visionneuse ci-dessous, puis cliquez sur le bouton pour enregistrer et télécharger le formulaire rempli. Prend également en charge les formulaires XFA.

Remarque sur les formulaires XFA : XFA (XML Forms Architecture) est un format hérité uniquement pris en charge par certaines visionneuses PDF telles que BentoPDF et Firefox. Si vous ouvrez un PDF XFA dans un autre logiciel et voyez des pages blanches ou aucun champ de formulaire, cela signifie que la visionneuse ne prend pas en charge XFA. Pour afficher et remplir correctement les formulaires XFA, utilisez Firefox ou le remplisseur de formulaires de BentoPDF.

Questions fréquemment posées

Comment remplir un formulaire PDF dans lequel je ne peux pas écrire ?

Importez le PDF et il s’ouvre dans une visionneuse intégrée qui transforme les champs de formulaire en zones de saisie actives : vous pouvez écrire dans les zones de texte, cocher des cases et choisir dans les listes déroulantes et les boutons radio. Si rien ne devient modifiable, le document n’a pas de vrais champs de formulaire ; ajoutez-en d’abord avec Créer un formulaire PDF.

Qu’est-ce qu’un formulaire XFA et puis-je en remplir un ici ?

XFA est un ancien format de formulaire basé sur XML que Chrome et la plupart des outils en ligne ne savent pas afficher, ce qui explique pourquoi ces formulaires apparaissent comme des pages vides ailleurs. Cet outil de remplissage et Firefox prennent tous deux en charge XFA : vous pouvez donc remplir et enregistrer ces formulaires ici.

Comment enregistrer le formulaire rempli ?

Cliquez sur Enregistrer et télécharger le formulaire rempli : la visionneuse écrit vos saisies dans les champs du PDF et télécharge le fichier. Les valeurs sont stockées dans les champs eux-mêmes, elles apparaissent donc aussi dans les autres lecteurs PDF, pas seulement celui-ci.

Puis-je signer le formulaire après l’avoir rempli ?

Cet outil ne remplit que les champs. Téléchargez le PDF rempli, puis ouvrez-le dans Signer un PDF pour ajouter votre signature à l’endroit prévu par le formulaire.

Quelqu’un d’autre peut-il modifier mes réponses après l’envoi du formulaire rempli ?

Les champs restent modifiables dans le fichier téléchargé : un destinataire pourrait donc les changer. Pour verrouiller les réponses, passez le PDF rempli dans Aplatir le PDF, qui transforme les champs en contenu de page fixe.

Puis-je enregistrer un formulaire partiellement rempli et le terminer plus tard ?

Téléchargez le formulaire avec ce que vous avez déjà rempli ; les valeurs sont conservées dans les champs. Importez ensuite ce même fichier plus tard et la visionneuse affiche vos saisies précédentes, prêtes à être poursuivies.

L’outil de remplissage fonctionne-t-il avec les formulaires protégés par mot de passe ?

Si le PDF nécessite un mot de passe pour s’ouvrir, l’outil le demande avant de charger le formulaire. La copie téléchargée est enregistrée sans ce mot de passe : protégez-la de nouveau avec Protéger un PDF si le formulaire doit rester verrouillé.

Les informations que je saisis dans le formulaire sont-elles envoyées quelque part ?

Non. Le formulaire est affiché par une visionneuse PDF.js intégrée à la page, vos saisies sont conservées dans la mémoire de cette visionneuse, et le PDF rempli est généré et téléchargé sur votre appareil. Rien de ce que vous saisissez n’est transmis, ce qui est essentiel quand le formulaire contient des données fiscales, médicales ou d’identité.
