Questions fréquemment posées

Puis-je ajouter des champs remplissables à un PDF que j’ai déjà ?

Importez le PDF et ses pages apparaissent dans l’éditeur ; choisissez un type de champ dans la barre d’outils et cliquez sur la page pour le placer, puis faites-le glisser ou redimensionnez-le selon vos besoins. Si le PDF contient déjà des champs de formulaire, ils sont détectés et chargés pour que vous puissiez les déplacer, les modifier ou les supprimer avec les nouveaux.

Puis-je créer un formulaire de zéro, sans PDF existant ?

Cliquez sur Créer un PDF vierge et choisissez Letter, A4, A5, Legal, Tabloid, A3 ou des dimensions personnalisées en points. Utilisez Ajouter une page pour les formulaires de plusieurs pages.

Quels types de champs sont disponibles ?

Texte (une ligne, plusieurs lignes ou réparti en cases), case à cocher, groupes de boutons radio, liste déroulante, zone de liste, bouton, signature, date, image et code-barres. Chaque champ dispose d’un panneau de propriétés pour le nom, la valeur par défaut, la taille de police, la couleur du texte, l’alignement, l’info-bulle et les options obligatoire ou lecture seule. Les champs de signature sont des champs de signature AcroForm standard, qui n’apparaissent que dans les lecteurs prenant en charge la signature.

Comment regrouper les boutons radio pour qu’un seul puisse être sélectionné ?

Chaque champ radio a un nom de groupe, RadioGroup1 par défaut. Les champs qui partagent le même nom de groupe forment un ensemble à choix exclusif : donnez donc à chaque question son propre nom de groupe et définissez une valeur d’export distincte pour chaque option.

Un bouton peut-il afficher ou masquer un autre champ, ou réinitialiser le formulaire ?

Les actions de bouton comprennent Réinitialiser le formulaire, Imprimer le formulaire, Ouvrir une URL, Exécuter du JavaScript et Afficher/masquer un champ, qui cible un autre champ et peut l’afficher, le masquer ou basculer son état. Elles sont stockées comme des actions PDF standard : elles s’exécutent donc dans Acrobat et les autres lecteurs prenant en charge les scripts de formulaire.

Comment fonctionne le champ de date ?

C’est un champ de texte auquel un format de date est associé, mm/jj/aaaa par défaut ou un modèle personnalisé comme jj/mm/aaaa. Les lecteurs qui prennent en charge le JavaScript AcroForm valident la valeur saisie et la mettent en forme ; les lecteurs plus simples la traitent comme du texte ordinaire.

Les codes-barres et les images sont-ils de vrais champs de formulaire ?

Un code-barres (QR Code, Code 128, Code 39, EAN-13, UPC-A, DataMatrix ou PDF417) est généré à partir de la valeur saisie et dessiné sur la page sous forme d’image fixe : la personne qui remplit le formulaire ne peut donc pas le modifier. Le champ image est un bouton qui permet à l’utilisateur de choisir une image sur son ordinateur, ce qui fonctionne dans Acrobat et les autres lecteurs prenant en charge l’import d’images.

Le formulaire ou le PDF importé est-il stocké sur un serveur ?

Non. L’éditeur s’exécute dans votre navigateur, les champs sont écrits dans le PDF avec pdf-lib sur votre appareil, et Télécharger le formulaire PDF enregistre le résultat localement sous le nom de fichier d’origine. Vous pouvez tester le résultat dans Remplir un formulaire PDF.
