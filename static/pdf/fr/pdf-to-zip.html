Questions fréquemment posées

Que fait réellement PDF vers ZIP à mes fichiers ?

Rien de plus que l’empaquetage. Les PDF sont copiés dans un seul pdfs_archive.zip avec leurs noms d’origine, inchangés, dans l’ordre où vous les avez ajoutés : ce qui sort du ZIP est donc identique, octet pour octet, à ce qui y est entré.

Zipper rend-il les PDF plus légers ?

Non. L’archive est écrite sans compression, car le contenu d’un PDF est déjà compressé en interne et ne rétrécirait guère de toute façon : attendez-vous donc à ce que le ZIP ait environ la taille cumulée des fichiers. Pour réduire la taille, passez-les d’abord dans Compresser le PDF, puis zippez les résultats.

Quelle est la différence entre compresser des PDF en ZIP et les fusionner ?

Un ZIP garde chaque PDF comme un fichier distinct dans un même conteneur que le destinataire décompresse. La fusion réunit les pages en un seul document PDF, ce qui convient quand les fichiers doivent se lire comme un seul document ; utilisez Fusionner des PDF pour cela.

Et si deux de mes fichiers portent le même nom ?

Les noms en double sont gérés automatiquement : le deuxième fichier devient name (1).pdf, le troisième name (2).pdf, et ainsi de suite, pour que rien ne soit écrasé dans l’archive. Renommez les fichiers avant l’import si vous préférez des noms parlants.

Puis-je ajouter des fichiers qui ne sont pas des PDF à l’archive ?

Non. Seuls les fichiers avec l’extension .pdf ou un type de fichier PDF sont acceptés ; tout le reste que vous déposez est ignoré. Pour un lot mixte, utilisez plutôt la fonction zip intégrée à votre système d’exploitation.

Le destinataire aura-t-il besoin d’un logiciel particulier pour ouvrir l’archive ?

Non. Le résultat est un fichier ZIP standard que Windows, macOS, iOS et Android ouvrent sans logiciel supplémentaire ; double-cliquez ou touchez-le pour extraire les PDF.

Mes PDF sont-ils envoyés pour créer le ZIP ?

Non. L’archive est assemblée dans votre navigateur : les fichiers sont lus depuis votre disque et le ZIP y est réécrit sans aucun transfert réseau. Regrouper ainsi des factures, des contrats ou des dossiers médicaux les garde sur votre appareil.
