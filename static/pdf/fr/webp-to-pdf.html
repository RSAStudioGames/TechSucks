Questions fréquemment posées

Chaque image WebP devient-elle sa propre page ?

Oui. Chaque image est placée sur une page distincte à la taille de l’image elle-même, dans l’ordre d’apparition des fichiers dans la liste, et l’ensemble est téléchargé sous la forme d’un seul fichier nommé from_webps.pdf.

Quelle taille de page auront mes images WebP dans le PDF ?

La page a les dimensions en pixels de l’image à raison d’un point par pixel : une image de 1600 x 1200 produit donc une page de 1600 x 1200 points, soit environ 22 x 17 pouces. Pour obtenir des pages A4 ou Letter standard, passez le résultat dans Uniformiser la taille des pages.

Que changent les réglages de qualité pour les images WebP ?

Élevée conserve les dimensions complètes en pixels avec la compression la plus légère. Moyenne, la valeur par défaut, réencode en JPEG à environ 75 % et réduit les images pour que le plus grand côté fasse au plus 2500 pixels ; Faible utilise environ 50 % et un plafond de 1500 pixels, ce qui donne les plus petits fichiers.

Les zones transparentes resteront-elles transparentes ?

Non. Les images sont réencodées en JPEG via le canevas du navigateur lors de leur intégration, et le JPEG n’a pas de canal alpha ; les zones transparentes deviennent donc un fond uni. Aplatissez d’abord l’image sur un fond blanc dans un éditeur d’images si cela compte.

Puis-je convertir un WebP animé ?

Seule la première image est utilisée, car le navigateur décode le fichier comme une image fixe avant de le placer sur la page. Chaque animation devient une seule page statique.

Puis-je mélanger WebP avec des fichiers JPG ou PNG dans le même PDF ?

Pas sur cette page ; le sélecteur de fichiers n’accepte que .webp. Utilisez Images en PDF, qui accepte WebP, JPG, PNG et d’autres formats ensemble dans une seule conversion.

Mes images sont-elles envoyées pour créer le PDF ?

Non. Chaque WebP est décodé par le moteur d’images de votre navigateur et écrit dans le PDF localement, les images ne quittent donc jamais votre appareil.

Puis-je réordonner ou supprimer des images avant la conversion ?

Vous pouvez retirer n’importe quel fichier de la liste avec son icône de suppression, mais il n’y a pas de réordonnancement par glisser-déposer sur cette page : les pages suivent donc l’ordre dans lequel vous avez sélectionné les fichiers. Sélectionnez-les dans l’ordre où vous voulez qu’ils apparaissent.
