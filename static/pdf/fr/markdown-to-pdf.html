Questions fréquemment posées

Comment convertir un fichier Markdown vers PDF ?

Cliquez sur Importer et choisissez un fichier .md, .markdown ou .txt, ou collez le texte dans le volet de gauche, et l’aperçu rendu apparaît à droite. Cliquez sur Exporter en PDF ou appuyez sur Ctrl+S (Cmd+S sur Mac), puis choisissez Enregistrer au format PDF comme destination dans la boîte de dialogue d’impression qui s’ouvre.

Puis-je changer le format de page ou les marges du PDF ?

Réglez cela dans la boîte de dialogue d’impression : choisissez Letter, A4 ou un autre format de papier, ajustez les marges et réduisez l’échelle si un tableau large est coupé. Désactivez aussi En-têtes et pieds de page à cet endroit si vous ne voulez pas que la date et l’URL soient imprimées sur chaque page.

Prend-il en charge les blocs de code, les tableaux et les diagrammes ?

Les blocs de code délimités bénéficient de la coloration syntaxique pour JavaScript, TypeScript, Python, Go, Rust, Java, C#, C++, SQL, Bash, YAML, JSON, HTML et CSS, et les tableaux standard avec barres verticales sont rendus comme des tableaux. Les blocs de code Mermaid sont dessinés sous forme d’organigrammes, de diagrammes de séquence et d’autres types de graphiques, dans l’aperçu comme dans le PDF.

Quelles extensions Markdown fonctionnent au-delà des bases ?

Listes de tâches, notes de bas de page, listes de définitions, abréviations, indices et exposants, marques ==surlignage== et ++insertion++, codes courts d’emoji comme :smile: et liens automatiques pour les URL brutes. La boîte de dialogue des paramètres propose des options pour le HTML brut, les sauts de ligne, les liens automatiques et les guillemets typographiques.

Le thème sombre affecte-t-il le PDF exporté ?

Non. Le bouton de thème ne change que les couleurs de l’éditeur à l’écran ; la feuille de style d’impression impose un fond blanc et un texte sombre : le PDF est donc identique dans les deux cas.

Puis-je ajouter une table des matières au PDF ?

Placez ${toc} sur sa propre ligne à l’endroit voulu et une table des matières est générée à partir de vos titres lors du rendu du document. Les titres reçoivent aussi des identifiants d’ancre : les liens internes vers un titre fonctionnent donc dans l’aperçu.

Puis-je inclure des images dans le PDF ?

Utilisez la syntaxe Markdown standard pour les images avec une URL d’image complète ou un URI de données, et l’image s’affiche dans l’aperçu et s’imprime dans le PDF. Les chemins relatifs vers des fichiers de votre disque ne se chargeront pas, car l’éditeur n’a pas accès à vos dossiers locaux.

Mon texte Markdown est-il envoyé à un serveur pour créer le PDF ?

Non. Le Markdown est converti en HTML par markdown-it dans votre navigateur et le PDF est créé par la fonction d’impression du navigateur : ni le texte ni le PDF final ne passent par un serveur. Vos notes, brouillons et documents internes restent sur votre machine.
