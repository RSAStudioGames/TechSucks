Questions fréquemment posées

Quels types de tampons puis-je ajouter avec cet outil ?

Cet outil place des tampons image : vous choisissez un fichier image comme un PNG ou un JPG (un sceau d'entreprise, un visuel APPROUVÉ, un tampon de notaire numérisé) et vous le déposez sur la page. Pour des marques en texte seul comme une mention BROUILLON en diagonale, Ajouter un filigrane est mieux adapté.

À quoi sert le champ Nom du tampon ?

Le nom que vous saisissez est enregistré sur chaque tampon que vous créez comme son auteur, ce qui permet aux relecteurs de voir qui l'a placé. Définissez-le avant d'importer le PDF. Il est facultatif, et si vous le laissez vide, les tampons sont créés sans nom associé.

Puis-je mettre le même tampon sur toutes les pages en une seule fois ?

Non. Les tampons sont placés un par un sur la page que vous consultez, et vous pouvez déplacer et redimensionner chacun d'eux avant d'enregistrer. Si vous avez besoin d'une marque identique sur toutes les pages, utilisez le mode image de Ajouter un filigrane, qui peut appliquer une image à chaque page en une seule étape.

Les tampons sont-ils permanents, ou peuvent-ils être retirés ensuite ?

Les tampons sont enregistrés sous forme d'annotations de tampon PDF, un éditeur PDF peut donc toujours les sélectionner, les déplacer ou les supprimer. Si vous voulez les fusionner dans le contenu de la page pour qu'ils ne puissent pas être retirés, passez le fichier enregistré dans Aplatir le PDF.

Comment déplacer ou redimensionner un tampon après l'avoir placé ?

Cliquez sur le tampon dans la visionneuse pour le sélectionner, puis faites-le glisser vers une nouvelle position ou tirez ses poignées d'angle pour changer sa taille. Rien n'est définitif tant que vous n'avez pas cliqué sur Enregistrer le PDF tamponné, vous pouvez donc ajuster autant que vous le souhaitez au préalable.

Quelle est la différence avec Signer un PDF ?

Signer un PDF est conçu pour les signatures : vous en dessinez une, en saisissez une ou en importez une et la placez sur la page. Ajouter des tampons sert aux marques image réutilisables comme les sceaux, les tampons REÇU ou les tampons de contrôle qualité, avec votre nom enregistré comme auteur de chacun.

L'outil de tampon fonctionne-t-il sur les PDF protégés par mot de passe ?

Si le fichier nécessite un mot de passe pour s'ouvrir, l'outil le demande avant de charger la visionneuse. Vous devez disposer du mot de passe d'ouverture, l'outil ne contourne pas le chiffrement.

Mon document est-il envoyé quand je le tamponne ?

Non. La visionneuse, l'éditeur de tampons et l'export s'exécutent tous dans votre navigateur, et le PDF tamponné est écrit sur votre appareil. Rien n'est envoyé à un serveur, ce qui compte quand vous tamponnez des contrats, des rapports d'inspection ou des documents notariés.
