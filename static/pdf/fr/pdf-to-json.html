Questions fréquemment posées

Que contient le JSON ?

La structure complète des objets du PDF telle que cpdf la lit : le trailer, le catalogue, l’arbre des pages, chaque dictionnaire, et le flux de contenu de chaque page analysé en une liste d’opérateurs de dessin et de texte. C’est un vidage complet du fichier, pas un résumé.

Est-ce le bon outil pour obtenir le texte d’un PDF au format JSON ?

En général non. Ici, le texte est éparpillé entre les opérateurs du flux de contenu dans l’ordre où il a été dessiné, avec polices et positions mais sans paragraphes. Pour un texte de page lisible dans un format structuré, utilisez Préparer le PDF pour l’IA, et pour du texte brut, PDF vers texte.

Puis-je reconvertir le JSON en PDF ?

Pas avec BentoPDF. Le résultat suit le format JSON propre à cpdf, que l’outil en ligne de commande cpdf peut relire pour reconstituer un PDF, mais l’outil du navigateur ne fonctionne que dans un sens.

Pourquoi le JSON est-il tellement plus gros que le PDF ?

Les flux de contenu sont développés en tableaux d’opérateurs, les données de flux binaires comme les images sont encodées en texte, et chaque objet est écrit avec toutes ses clés : un fichier JSON plusieurs fois plus gros que la source est donc normal. Les PDF volumineux ou riches en images produisent des fichiers très gros.

Puis-je convertir plusieurs PDF en JSON à la fois ?

Sélectionnez-en autant que vous voulez ; chacun est converti dans un worker en arrière-plan et les résultats sont regroupés dans pdfs-to-json.zip, avec un .json par PDF, nommé d’après le fichier source. Un PDF seul arrive aussi dans un ZIP.

Fonctionne-t-il sur les PDF chiffrés ?

Le mot de passe vous est demandé avant le début de la conversion et la copie déchiffrée est sérialisée. Sans le mot de passe, la structure des objets ne peut pas être lue.

À quoi cela sert-il ?

Examiner l’intérieur d’un PDF pour déboguer un générateur, vérifier ce que contient le flux de contenu d’une page, comparer deux versions structurellement, ou fournir l’arbre des objets à un script. Pour les seules propriétés du document, Afficher les métadonnées est plus rapide.

Le PDF est-il envoyé pour produire le JSON ?

Non. cpdf s’exécute en WebAssembly dans un web worker de votre navigateur, et le JSON est écrit et compressé en ZIP sur votre appareil avant le téléchargement.
