Questions fréquemment posées

Puis-je convertir n’importe quel fichier JSON en PDF avec cet outil ?

Non. Il ne reconstruit que des PDF à partir de fichiers JSON créés par l’outil PDF vers JSON de BentoPDF, qui stocke la structure interne complète du document. Un export JSON provenant d’une API, d’une base de données ou d’un fichier de configuration échouera avec une erreur.

Comment transformer à la place des données d’API ou un fichier de configuration en PDF lisible ?

Collez ou importez le JSON comme texte brut dans Texte vers PDF, qui le met en page sous forme de texte formaté. JSON vers PDF ne sert qu’à faire des allers-retours avec des documents qui étaient à l’origine des PDF.

Le PDF reconstruit sera-t-il identique à l’original ?

Le JSON produit par PDF vers JSON capture les objets du document : le reconvertir reproduit donc les pages, le texte et les images de la source. Reconvertir puis comparer est aussi un moyen rapide de vérifier qu’un export a tout capturé.

Qu’obtient-on en convertissant plusieurs fichiers JSON ?

Chaque conversion est téléchargée sous la forme jsons-to-pdf.zip, même pour un seul fichier. À l’intérieur, chaque PDF porte le nom de son JSON source : report.json devient donc report.pdf.

Puis-je modifier le JSON avant de le reconvertir ?

Oui, tant que la structure reste valide pour le moteur CPDF. Les modifications programmatiques du JSON, comme des métadonnées ou des objets texte modifiés, sont reconstruites dans le PDF ; une modification mal formée provoque une erreur de conversion.

Pourquoi l’outil indique-t-il que le moteur CPDF n’est pas disponible ?

La conversion dépend du build WebAssembly de CPDF. Il est inclus sur bentopdf.com, mais une copie auto-hébergée nécessite de configurer les fichiers WASM de CPDF dans les paramètres WASM avant que cet outil puisse fonctionner.

Mon fichier JSON est-il envoyé à un serveur ?

Non. Les fichiers sont lus dans votre navigateur et reconstruits en PDF par un Web Worker exécutant le moteur CPDF en local : rien n’est transmis et la page reste réactive pendant les grosses conversions.
