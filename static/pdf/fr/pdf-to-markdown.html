Questions fréquemment posées

Dans quelle mesure PDF vers Markdown préserve-t-il la structure du document ?

Les titres, paragraphes, listes et la mise en forme de base en gras et en italique sont convertis, et chaque page est séparée par un trait horizontal (---) dans le résultat. Les niveaux de titre sont déduits des tailles de police : un document au style incohérent peut donc ressortir avec certains titres au mauvais niveau.

Que fait l’option Inclure les images ?

Lorsque l’option est cochée, les images du PDF sont intégrées directement dans le Markdown sous forme de données base64 : le fichier .md unique est donc autonome, mais peut devenir volumineux. Laissez-la désactivée pour les documents surtout textuels afin de garder un résultat léger et lisible dans un éditeur simple.

Pourquoi le Markdown est-il vide ou presque vide ?

Le convertisseur lit la couche de texte du PDF : un document numérisé composé uniquement d’images n’a donc rien à convertir. Passez-le d’abord dans OCR PDF pour ajouter une couche de texte, puis convertissez le résultat.

Comment gère-t-il les mises en page à plusieurs colonnes, les notes de bas de page et les encadrés ?

Les mises en page complexes sont le point faible : le texte sur plusieurs colonnes peut être entremêlé, et les encadrés ou notes de bas de page peuvent atterrir au mauvais endroit. Prévoyez de relire et de retoucher le résultat pour les pages de style magazine, alors que les documents à une seule colonne demandent peu de nettoyage.

Puis-je convertir plusieurs PDF en Markdown à la fois ?

Importez plusieurs PDF et cliquez une seule fois sur Convertir. Un fichier est téléchargé sous la forme filename.md ; plusieurs reviennent dans markdown-files.zip, avec un .md par PDF, et les noms en double reçoivent un suffixe numéroté.

Est-ce la même chose que PDF vers texte ?

Non. PDF vers texte donne du texte brut sans structure, ce qui convient mieux pour alimenter des scripts. PDF vers Markdown conserve les titres, les listes et les mises en valeur, de sorte que le résultat est prêt à être collé dans Obsidian, un wiki ou un générateur de site statique.

Puis-je convertir un PDF protégé par mot de passe ?

Si le fichier nécessite un mot de passe pour s’ouvrir, il vous est demandé avant le début de la conversion et le texte est extrait normalement. Le mot de passe n’est stocké nulle part, et le résultat Markdown n’a aucune protection propre.

Mon PDF est-il envoyé pour le convertir en Markdown ?

Non. La conversion s’exécute sur un moteur PyMuPDF chargé dans votre navigateur en WebAssembly, et le fichier .md ou le ZIP est généré sur votre machine. Vos articles de recherche, contrats et documents internes restent privés.
