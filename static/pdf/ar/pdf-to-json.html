الأسئلة الشائعة

ماذا يحتوي JSON؟

بنية كائنات PDF الكاملة كما يقرؤها cpdf: المقطورة (trailer) والفهرس وشجرة الصفحات وكل قاموس، ومحتوى كل صفحة مُحلَّلًا إلى قائمة من عوامل الرسم والنص. إنها نسخة كاملة من الملف وليست ملخصًا.

هل هذه هي الأداة المناسبة لاستخراج النص من PDF بصيغة JSON؟

عادةً لا. يتناثر النص هنا عبر عوامل تدفق المحتوى بالترتيب الذي رُسم به، مع الخطوط والمواضع لكن دون فقرات. للحصول على نص صفحة مقروء بصيغة منظمة استخدم تجهيز PDF للذكاء الاصطناعي، وللنص العادي استخدم PDF إلى نص.

هل يمكنني تحويل JSON إلى PDF مرة أخرى؟

ليس مع BentoPDF. يتبع الناتج صيغة JSON الخاصة بـ cpdf، ويمكن لأداة سطر الأوامر cpdf قراءتها وإعادتها إلى PDF، لكن أداة المتصفح تعمل في اتجاه واحد فقط.

لماذا JSON أكبر بكثير من PDF؟

تُوسَّع تدفقات المحتوى إلى مصفوفات عوامل، وتُرمَّز بيانات التدفق الثنائية مثل الصور كنص، ويُكتب كل كائن بمفاتيحه، لذلك من الطبيعي أن يكون ملف JSON أكبر من المصدر بعدة أضعاف. تنتج ملفات PDF الكبيرة أو الغنية بالصور ملفات كبيرة جدًا.

هل يمكنني تحويل عدة ملفات PDF إلى JSON دفعة واحدة؟

اختر ما تشاء من الملفات، وتُحوَّل كل منها في عامل (worker) في الخلفية وتُحزَّم النتائج في pdfs-to-json.zip مع ملف .json لكل PDF باسم الملف المصدر. ويصل ملف PDF واحد أيضًا في ملف ZIP.

هل يعمل مع ملفات PDF المشفّرة؟

تُطلب منك كلمة المرور قبل بدء التحويل وتُسلسَل النسخة المفكوكة التشفير. بدون كلمة المرور لا يمكن قراءة بنية الكائنات.

ما فائدة هذا؟

فحص البنية الداخلية لملف PDF عند تصحيح أخطاء مولّد، أو التحقق مما يحتويه تدفق محتوى صفحة، أو مقارنة نسختين بنيويًا، أو تغذية شجرة الكائنات إلى سكربت. لخصائص المستند فقط، عرض البيانات الوصفية أسرع.

هل يُرفع ملف PDF لإنتاج JSON؟

لا. يعمل cpdf كـ WebAssembly في عامل ويب (web worker) داخل متصفحك، ويُكتب JSON ويُضغط على جهازك قبل التنزيل.
