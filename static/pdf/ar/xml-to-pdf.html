الأسئلة الشائعة

كيف تقرر الأداة شكل PDF؟

تحلل الأداة XML وتجمّع العناصر الشقيقة المتكررة حسب اسم الوسم، وتعرض كل مجموعة كجدول بعمود لكل عنصر فرعي، مستخدمةً أسماء العناصر كرؤوس. إذا لم يكن للجذر أبناء متكررون، تحصل على جدول من عمودين: الخاصية والقيمة. الناتج A4 أفقي واسم العنصر الجذر هو العنوان.

ما نوع XML الذي يعمل أفضل؟

XML بأسلوب البيانات: سجلات لها المجموعة نفسها من العناصر الفرعية متكررة تحت أب واحد، مثل تصديرات قواعد البيانات وبنود الفواتير وخلاصات المنتجات وخلاصات RSS وخرائط المواقع. يُسطَّح XML العميق التداخل أو بأسلوب المستندات، فتُدمج القيم المتداخلة في خلية واحدة وتفقد تسلسلها الهرمي.

لماذا يظهر لي خطأ XML غير صالح؟

الملف غير سليم البنية: وسم غير مغلق، أو عنصر جذر مفقود، أو حرف & أو < غير مهرَّب، أو ترميز سيئ. تتضمن الرسالة سبب المحلل، فأصلح الملف في محرر أو أداة تحقق وأعد المحاولة.

هل تُضمَّن سمات XML في PDF؟

جزئيًا. في عرض الجدول تصبح العناصر الفرعية فقط أعمدة، فلا تظهر السمات في السجلات المتكررة. في عرض الخاصية والقيمة للجذر غير المتكرر، تُسرد السمات بعد قيم العناصر الفرعية.

هل يمكنني تحويل عدة ملفات XML دفعة واحدة؟

نعم. أضف عدة ملفات فتُحوَّل في دفعة واحدة إلى xml-to-pdf.zip مع PDF لكل ملف. يُنزَّل الملف الواحد مباشرة بالاسم الأساسي نفسه وبالامتداد .pdf.

هل يطبّق ورقة أنماط XSLT أو CSS الخاصة بي؟

لا. تُزال تعليمات ورقة الأنماط وتصريحات DOCTYPE قبل التحليل، ويُولَّد التخطيط من بنية البيانات وحدها. إذا احتجت إلى العرض المنسَّق، فافتح XML في متصفح يطبّق ورقة الأنماط واطبعه إلى PDF من هناك.

هل سيُعرض النص الصيني أو العربي أو السيريلي أو غير اللاتيني الآخر؟

ليس بشكل موثوق. يُبنى PDF بخط Helvetica القياسي في jsPDF الذي يغطي الأحرف اللاتينية، لذا قد يظهر النص بأبجديات أخرى بأحرف خاطئة أو مفقودة.

هل يُرفع ملف XML لتحويله؟

لا. يستخدم التحليل محلل XML بـ JavaScript ويُنشأ PDF بواسطة jsPDF، وكلاهما داخل متصفحك، فلا تغادر الفواتير وسجلات المعاملات وغيرها من البيانات الحساسة في الملف جهازك.
