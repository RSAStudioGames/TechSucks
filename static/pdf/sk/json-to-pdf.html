Často kladené otázky

Môžem týmto nástrojom konvertovať ľubovoľný súbor JSON na PDF?

Nie. Znova zostavuje PDF iba zo súborov JSON vytvorených nástrojom PDF do JSON v BentoPDF, ktorý ukladá celú internú štruktúru dokumentu. Export JSON z API, databázy alebo konfiguračného súboru zlyhá s chybou.

Ako zmením údaje z API alebo konfiguračný súbor na čitateľné PDF?

Vložte alebo nahrajte JSON ako obyčajný text v nástroji Text do PDF, ktorý ho rozloží ako formátovaný text na stranách. JSON do PDF slúži len na spätnú konverziu dokumentov, ktoré pôvodne boli PDF.

Bude znova zostavené PDF zodpovedať originálu?

JSON vytvorený nástrojom PDF do JSON zachytáva objekty dokumentu, takže spätná konverzia reprodukuje strany, text a obrázky zdroja. Spätná konverzia a porovnanie je tiež rýchly spôsob, ako overiť, že export zachytil všetko.

Aký je výstup pri konverzii viacerých súborov JSON?

Každá konverzia sa stiahne ako jsons-to-pdf.zip, aj pri jednom súbore. Vnútri každé PDF nesie názov svojho zdrojového JSON, takže report.json sa stane report.pdf.

Môžem JSON pred konverziou späť upraviť?

Áno, pokiaľ štruktúra zostane platná pre engine CPDF. Programové zmeny JSON, ako upravené metadáta alebo textové objekty, sa znova zostavia do PDF. Chybná úprava spôsobí chybu konverzie.

Prečo nástroj hlási, že engine CPDF nie je k dispozícii?

Konverzia závisí od zostavy CPDF WebAssembly. Na bentopdf.com je zahrnutá, ale samostatne hostovaná kópia vyžaduje nastavenie súborov CPDF WASM v nastaveniach WASM, kým tento nástroj bude fungovať.

Nahráva sa môj súbor JSON na server?

Nie. Súbory sa čítajú vo vašom prehliadači a do PDF ich znova zostavuje Web Worker s enginom CPDF lokálne, takže sa nič neprenáša a stránka zostáva responzívna aj pri veľkých konverziách.
