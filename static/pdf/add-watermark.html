Frequently Asked Questions

Can I watermark only certain pages of a PDF?

Yes. Type a range such as 1-3, 5, 7-9 in the Page Range field, or leave it set to "all". If you want different text or a different position on individual pages, uncheck "Apply to all pages" and use the page arrows above the preview to set each page separately.

How do I add a diagonal CONFIDENTIAL or DRAFT watermark across the page?

Stay in Text mode, type the word, and raise the font size (10 to 200 points, default 72) until it spans the page. The angle slider already defaults to -45 degrees for the classic diagonal look, so usually you only need to enlarge the text and drag it to the center of the preview.

Can I use a logo image as the watermark?

Switch to Image mode and upload a PNG or JPG; other image formats aren't accepted. A PNG with a transparent background blends best with the page. You can scale it from 10% to 200%, set its opacity and angle, and drag it into position on the preview.

What does the Tiled layout do?

Tiled repeats the watermark across the whole page in a diagonal grid that follows the rotation angle, so the mark runs edge to edge. The horizontal and vertical gap sliders control the spacing between tiles as a percentage of the watermark size. Lower the opacity when tiling so the document underneath stays readable.

Can someone remove the watermark afterward?

The watermark is drawn into the page content rather than added as a separate annotation, so it can't be deleted with one click in a PDF viewer. It isn't tamper-proof though. For a harder-to-strip result, use Tiled mode, or check "Flatten watermark" to bake every page into pixels, which also makes the document's text unselectable.

Does adding a watermark change the original text or image quality?

No. The pages keep their original text, images, and dimensions, and the watermark is placed on top, so text stays selectable and searchable. The exception is the "Flatten watermark" option, which re-renders every page as an image at 2.5x scale and removes selectable text.

What opacity should I use for a watermark?

The slider runs from 0.05 to 1 and defaults to 0.3. Values between 0.2 and 0.4 keep the mark visible without hiding the content beneath it; go higher only for small marks placed in a margin or corner.

Is my PDF uploaded when I add a watermark?

No. The live preview, the drag-and-drop editor, and the final rendering all run inside your browser with pdf-lib, so neither the PDF nor a logo image you add leaves your device.
