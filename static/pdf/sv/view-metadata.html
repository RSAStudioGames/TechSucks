Vanliga frågor och svar

Vad kan en PDF avslöja om mig?

Info-dictionaryn innehåller ofta författarens namn (vanligtvis operativsystemets eller Office-användarnamnet), programvaran som använts samt tidsstämplar för skapande och ändring. XMP-metadata kan lägga till dokument-ID:n, versionshistorik och programinformation, och ifyllda formulärfältsvärden visas också. Om du ska publicera eller dela filen, kör Ta bort metadata efteråt.

Vad är skillnaden mellan Info-dictionaryn och XMP-metadata?

Info-dictionaryn är den äldre uppsättningen fasta fält: Title, Author, Subject, Keywords, Creator, Producer och datum. XMP är ett XML-block med namnrymder som Dublin Core, xmp och pdf, och det kan rymma mycket mer. De två är tänkta att stämma överens men gör ofta inte det, vilket är varför verktyget visar båda.

Varför visas datumen annorlunda än i Acrobat?

PDF-datum lagras som strängar som D:20240101120000Z. Verktyget konverterar dem till ett läsbart datum i din lokala tidszon, så timmen kan skilja sig från en läsare som visar råvärdet eller använder en annan tidszon.

Hur kan jag se vilket program som skapade PDF-filen?

Titta på fältet Creator (programmet som skapade originaldokumentet, till exempel Word eller InDesign) och fältet Producer (biblioteket som skrev PDF-filen, till exempel Acrobat Distiller eller en PDF-motor). XMP-avsnittet upprepar dem oftast som xmp:CreatorTool och pdf:Producer.

Visar det värdena som fyllts i formulärfält?

Avsnittet Interaktiva formulärfält listar varje fältnamn med sitt aktuella värde, eller Inte angivet när det är tomt, vilket är ett snabbt sätt att kontrollera vilka data ett ifyllt formulär innehåller innan du skickar det.

Kan jag kopiera eller exportera metadatan?

Knappen Kopiera metadata som JSON lägger Info-dictionaryns fält på urklipp som ett JSON-objekt. XMP-trädet och formulärfältsvärdena visas på sidan men ingår inte i den kopierade JSON-filen.

Kan jag ändra det jag ser här?

Det här verktyget är skrivskyddat. Använd Redigera metadata för att ändra titel, författare, nyckelord och datum, eller Ta bort metadata för att ta bort allt innan publicering.

Laddas PDF-filen upp för att läsa dess metadata?

Nej. Filen tolkas av pdf.js i din webbläsare så fort du väljer den och ingenting skickas, så du kan granska ett känsligt dokument innan du bestämmer vart det ska.
