Frequently Asked Questions

Do I need WordPerfect installed to convert WPD files?

No. The tool loads a LibreOffice engine into your browser, and LibreOffice's WordPerfect filter reads the file directly, so nothing needs to be installed on your computer.

Which WordPerfect versions are supported?

All major WordPerfect versions that use the .wpd extension, including files from the DOS and early Windows era that current software often refuses to open. The file must actually end in .wpd; other extensions aren't accepted by the picker.

Why is the first WordPerfect conversion slow?

The LibreOffice engine is around 75 MB compressed and is downloaded the first time you convert, with a progress percentage shown while it loads. Later conversions in the same session skip that step and are much faster.

What is preserved from the original document?

Text, page layout, and basic formatting such as fonts, bold and italic, and indents carry over to the PDF. WordPerfect macros and reveal codes are not preserved, since they have no equivalent in a PDF.

Can I convert several WPD files in one go?

Select or drop multiple files and click Convert to PDF. One file downloads as a PDF with the same name; several are packed into wpd-to-pdf.zip with a PDF for each document.

Can I turn a WordPerfect file into a Word document instead?

Not from this tool. Convert to PDF here first, then run the result through PDF to Word if you need an editable .docx.

Are my old legal or government documents uploaded?

No. The conversion engine runs entirely in your browser, so the WPD files and the resulting PDFs stay on your device. Only the engine itself is downloaded, not your documents.

Why did a file fail to convert?

Damaged files and files that aren't really WordPerfect despite the .wpd extension are the usual causes. If the file opens in desktop LibreOffice, it should convert here as well, since the same import filter is used.
