常見問題

用密碼保護 PDF 與限制其權限有什麼差別？

使用保護 PDF設定的使用者密碼，是開啟檔案的必要條件。權限則是儲存在加密內的旗標，用來控制讀者開啟後能做什麼，例如列印、複製、編輯、註解或填寫表單，且只有在設定了擁有者密碼時才會生效。變更權限可讓您逐項允許或拒絕每個動作，而保護 PDF 在您加入擁有者密碼時會立即套用最嚴格的設定。

密碼保護的強度如何？

保護 PDF 和變更權限使用 256 位元 AES 加密（PDF 2.0 標準），由在您瀏覽器中執行的 QPDF 套用。加密本身不可能用暴力方式破解，因此弱點在於密碼：請使用較長的通關密語，並透過與檔案不同的管道傳送。權限旗標是另一回事，因為它們仰賴讀者軟體遵守，而部分第三方工具會忽略它們。

如果不知道密碼，可以移除 PDF 的密碼嗎？

不可以。解鎖 PDF 需要密碼，然後儲存一份不含加密或限制的副本，所有工具都不會破解或暴力猜測密碼。若檔案可以正常開啟，但禁止列印或複製，請改用「移除限制」，如果檔案設有擁有者密碼，它會要求輸入。

簽署 PDF 和數位簽章有什麼差別？

簽署 PDF 會在頁面上放置手繪、輸入或上傳的簽名圖片，並可選擇將其攤平，讓任何人之後都無法移動或刪除。數位簽章 則使用您自己的 X.509 憑證（.pfx、.p12 或 .pem）套用加密簽章，能證明簽署者是誰，以及檔案自簽署後未被更改；驗證簽章則會檢查檔案中既有的簽章。憑證簽署可能需要網路連線以取得憑證鏈，自簽憑證在 Adobe Reader 中會顯示警告。

如何遮蓋文字才能確實移除？

請使用 PDF 編輯器中的遮蓋工具。標記文字或區域只是做記號，一旦套用遮蓋，被標記的內容就會從頁面上永久移除，而不是只用方框蓋住；如果在尚未套用標記的情況下下載，編輯器會提示您先套用。遮蓋所選文字時，檔案屬性、書籤、註解和附件中的副本也會在下載時一併移除，除非檔案已加密。區域遮蓋沒有可搜尋的文字，因此若檔案的屬性、註解或附件可能洩漏相同資訊，請對結果再執行移除中繼資料或清理 PDF。

移除中繼資料和清理 PDF 有什麼差別？

移除中繼資料 只會清除文件屬性：標題、作者、日期、製作程式、XMP 資料、文件 ID 和應用程式專屬資料，頁面、表單、連結和書籤都不會受影響。清理 PDF 的範圍更廣，還可以攤平表單，並刪除註解、內嵌 JavaScript、附件、圖層、連結和結構標籤，每個項目都可以個別選擇。兩者都無法復原，請保留您的原始檔案。

攤平 PDF 有什麼作用？何時該使用？

攤平 PDF 會將表單欄位和註解（註解文字、螢光標示、印章、便利貼、簽名欄位）燒錄到頁面內容中，外觀不變，但無法再編輯、移動或移除。請在表單填寫完畢或簽名放置之後、傳送檔案之前使用，因為無法還原攤平。文字仍可選取和搜尋，書籤也會保留。

我的密碼、憑證或檔案會被傳送到伺服器嗎？

不會。加密、解鎖、清理和簽署都以 WebAssembly 的形式在您的瀏覽器中執行，因此文件、您輸入的密碼和憑證的私密金鑰都會留在您的裝置上。唯一的網路例外是數位簽章，它可能會連線到您的憑證授權單位的伺服器以取得憑證鏈；文件本身仍然絕不會被傳送。
