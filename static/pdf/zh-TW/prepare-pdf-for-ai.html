常見問題

JSON 輸出包含哪些內容？

它遵循 LlamaIndex 的文件結構：每頁一份文件，包含該頁的文字與中繼資料欄位。內容由 PyMuPDF 的 LlamaIndex 整合功能產生，因此可直接載入 LlamaIndex，或任何接受逐頁文字與中繼資料的流程。

這和 PDF 轉文字或 PDF 轉 Markdown 有什麼不同？

PDF 轉文字只會輸出單一的純文字串流，PDF 轉 Markdown 則保留標題與結構以方便閱讀。本工具會逐頁分割內容，並連同中繼資料包裝成結構化的 JSON，這正是檢索流程在分段與標註來源時所需要的。

對掃描的 PDF 有用嗎？

只有在檔案已含文字圖層時才行。掃描影像只會產生空白或近乎空白的輸出，所以請先用 OCR PDF 處理，再進行擷取。

我可以一次處理一整批 PDF 嗎？

可以。上傳多個檔案後，您會得到 pdf-for-ai.zip，內含每個 PDF 對應的一個 yourfile_llm.json；單一檔案則直接下載為 yourfile_llm.json。若批次中有檔案失敗，其餘檔案仍會完成，摘要會告訴您有幾個失敗。

我可以選擇要擷取哪些頁面，或控制分段大小嗎？

不會。沒有任何選項；每一頁都會連同完整文字和中繼資料一起擷取。請在您自己的流程中進行分塊，這樣可以挑選適合您嵌入模型的大小，也可以在那裡捨棄不需要的頁面。

可以為 AI 工具準備受密碼保護的 PDF 嗎？

可以。如果檔案已加密，擷取開始前會提示您輸入密碼，文字則從解密後的副本取出。

我的文件會被傳送到 AI 服務嗎？

不會。儘管名稱如此，不會有任何內容傳送給 AI 供應商或任何伺服器；擷取由編譯為 WebAssembly 的 PyMuPDF 在您的瀏覽器內執行。JSON 之後要送到哪裡，由您決定。

我可以用 JSON 檔案做什麼？

可以餵給 RAG 流程、為聊天機器人建立知識庫、對報告進行 LLM 分析，或把一批 PDF 轉成訓練資料。由於內容是連同中繼資料逐頁分割的，答案可以標示出自哪一頁。
