常見問題

如何將 Markdown 檔案轉換為 PDF？

點選「上傳」並選擇 .md、.markdown 或 .txt 檔案，或將文字貼到左側窗格，右側就會顯示呈現後的預覽。點選「匯出 PDF」或按 Ctrl+S（Mac 上為 Cmd+S），然後在開啟的列印對話方塊中選擇「另存為 PDF」作為目的地。

可以更改 PDF 的頁面大小或邊界嗎？

請在列印對話方塊中設定：選擇 Letter、A4 或其他紙張大小，調整邊界，若寬表格被截斷則降低縮放比例。如果不想在每頁印出日期和網址，也請在那裡關閉「頁首與頁尾」。

支援程式碼區塊、表格和圖表嗎？

圍欄式程式碼區塊支援 JavaScript、TypeScript、Python、Go、Rust、Java、C#、C++、SQL、Bash、YAML、JSON、HTML 和 CSS 的語法醒目提示，標準的直線分隔表格也會呈現為表格。Mermaid 程式碼區塊在預覽和 PDF 中都會繪製成流程圖、循序圖和其他圖表類型。

除了基本語法，還支援哪些 Markdown 擴充功能？

工作清單、註腳、定義清單、縮寫、下標與上標、==highlight== 和 ++insert++ 標記、:smile: 這類表情符號簡碼，以及自動連結純網址。設定對話方塊中有原始 HTML、換行、自動連結和排版引號的開關。

深色主題會影響匯出的 PDF 嗎？

不會。主題切換只會改變螢幕上的編輯器顏色；列印樣式表會強制使用白色背景和深色文字，因此無論哪種主題，PDF 看起來都一樣。

可以在 PDF 中加入目錄嗎？

將 ${toc} 單獨放在您想要的那一行，文件呈現時就會根據您的標題產生目錄。標題也會有錨點 ID，因此文件內指向標題的連結在預覽中可以運作。

可以在 PDF 中加入圖片嗎？

使用標準的 Markdown 圖片語法，搭配完整的圖片網址或資料 URI，圖片就會顯示在預覽中並列印到 PDF 裡。指向您磁碟上檔案的相對路徑無法載入，因為編輯器無法存取您的本機資料夾。

製作 PDF 時我的 Markdown 文字會被上傳到伺服器嗎？

不會。Markdown 由 markdown-it 在您的瀏覽器中轉譯為 HTML，PDF 則由瀏覽器的列印功能建立，因此文字和完成的 PDF 都不會經過伺服器。筆記、草稿和內部文件都會留在您的電腦上。
