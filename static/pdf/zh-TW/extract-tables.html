常見問題

我該選擇哪種輸出格式？

CSV 可在 Excel、Google Sheets 或任何資料庫匯入功能中開啟。JSON 會提供列的陣列，每列是儲存格字串的陣列，適合指令碼和 API 使用。Markdown 則提供直線分隔的表格，可貼到 GitHub、wiki 或文件中。

PDF 包含多個表格時會得到什麼？

每個表格都會儲存為獨立檔案，名稱類似 table_1_page3.csv，並全部打包成 filename_tables.zip。單一表格則直接下載為 filename_table.csv、.json 或 .md。若您希望所有表格放在同一個檔案中，請使用PDF 轉 CSV。

為什麼顯示找不到表格？

偵測是以文件的文字圖層為基礎。掃描版 PDF 只包含圖片，因此請先使用OCR PDF處理。僅因間距而看起來像表格、但沒有表格結構的文字，也可能偵測不到。

表格跨越多個頁面。它會輸出成一個檔案嗎？

不會。每一頁都是分別掃描的，因此跨頁的表格會輸出為每頁一個檔案，檔名中帶有頁碼。擷取後請在試算表中自行合併。

可以只擷取部分頁面的表格嗎？

整份文件一律會被掃描，不過每個檔名中的頁碼會告訴您表格來自哪裡。若要限縮掃描範圍，請先用擷取頁面儲存所需的頁面，再對較小的檔案執行此工具。

CSV 能處理儲存格內的逗號和換行嗎？

會。包含逗號、引號或換行的儲存格會以雙引號包住，內部的引號則重複一次，讓試算表軟體能正確讀取。空白儲存格會寫成空欄位。

可以從受密碼保護的 PDF 擷取表格嗎？

如果檔案需要密碼才能開啟，擷取開始前會先要求您輸入密碼，表格則是從記憶體中的解密副本讀取。

偵測表格時 PDF 會被上傳嗎？

不會。偵測引擎（編譯為 WebAssembly 的 PyMuPDF）會在您第一次使用時從 CDN 下載，之後便在您的瀏覽器內執行。您的 PDF 會留在您的裝置上。
