常見問題

可以編輯掃描版 PDF 中的文字嗎？

此工具無法做到。掃描頁面是一張圖片，即使經過 OCR，文字也只是覆蓋在圖片上的隱形圖層，因此沒有可編輯的字元。編輯器會偵測到這種情況，並顯示提示說明該頁的文字區塊是 OCR 圖層，可搜尋、可選取，但無法編輯。

新增或刪除文字時，內容會重新排版嗎？

在您正在編輯的段落內，文字行會隨輸入即時換行，區塊也會自動放大或縮小以符合內容。其他段落與頁面則維持原位，因此請留意過長的段落是否會壓到下方的內容。

可以使用我電腦上的字型嗎？

開啟「字型」選單並選擇「系統字型」，即可列出您電腦上安裝的字型。此功能依賴 Local Font Access API，目前僅 Chrome 和 Edge 支援；在其他瀏覽器中，您仍可使用文件中已內嵌的字型。

可以在整份文件中尋找與取代嗎？

「尋找與取代」列提供下一個、取代和全部取代，並有區分大小寫、全字拼寫須相符及忽略重音符號等選項。「全部取代」會處理文件的每一頁，而不只是畫面上顯示的那一頁。

除了文字，我也能編輯圖片和圖形嗎？

使用「編輯」選單選擇文字、圖片、圖形或全部編輯，以控制在內容密集的頁面上可選取的項目。圖片可以移動、以 90 度為單位旋轉、翻轉，或在保留位置的情況下替換；您也可以新增圖片和文字方塊，而圖形則可調整其路徑線條設定。

如果 PDF 有數位簽章或是 PDF/A，會發生什麼事？

編輯已簽署的文件會使其簽章失效，因此編輯器會提出警告，並將您的變更以附加修訂版本的方式儲存，讓原始已簽署的版本仍可驗證。若是 PDF/A 檔案，則會警告編輯可能破壞其合規性。

編輯器能開啟受密碼保護的 PDF 嗎？

它會先要求輸入密碼，然後開啟文件進行編輯。儲存的副本是由解密後的文件產生，因此如果您仍需要保護，請使用加密 PDF重新加上。

這與 PDF 編輯器工具有何不同？

此工具用於修改頁面上既有的文字、圖片與圖形，並支援字型、間距、對齊、清單及由右至左的書寫方向。PDF 編輯器則用於註解：在頁面上方加入螢光標示、註解、繪圖及其他標記。
