常見問題

我可以把多個 BMP 檔案合併成一份 PDF 嗎？

可以。您加入的每個 BMP 都會成為單一 PDF 中的一頁，順序依檔案清單所示。沒有每個檔案各產生一份 PDF 的選項，如果需要分開，請分別轉換檔案。

為什麼 PDF 比我的 BMP 檔案小？

BMP 儲存的是未壓縮的像素，所以檔案很大。轉換器會重繪每張圖片，並以無損 PNG 存入 PDF，通常能大幅縮小檔案，而且不會改變任何一個像素。

轉換時會損失任何圖片品質嗎？

不會。像素以無損方式儲存，這個工具也沒有品質設定，所以輸出的解析度與色彩和來源相同。如果之後需要更小的檔案，請將 PDF 交給壓縮 PDF處理。

轉換 BMP 時，PDF 的頁面尺寸是多少？

每一頁的尺寸依圖片的像素尺寸，以每像素一點計算，所以 2480 x 3508 像素的掃描檔會產生約 34 x 49 英寸的頁面，而不是 A4。檢視器與印表機會縮放以符合頁面，之後也可以用統一頁面尺寸把每一頁調整為 A4 或 Letter。

為什麼顯示我的其中一個檔案無效？

圖片由您的瀏覽器解碼，可處理標準的 Windows 點陣圖。OS/2 標頭或罕見壓縮模式等特殊變體可能會失敗；用任何圖片編輯器將檔案重新儲存為標準 24 位元 BMP 或 PNG 即可解決。

我可以把 BMP 與 JPG 或 PNG 檔案混在一起嗎？

這個工具只接受 .bmp 檔案，並會略過您加入的其他檔案。如果需要把多種格式合併成一份文件，請使用圖片轉 PDF。

BMP 的 DPI 設定會影響結果嗎？

不會。檔案標頭中儲存的解析度會被忽略，頁面尺寸完全由像素數量決定，所以兩張像素尺寸相同的圖片會產生完全相同的頁面，不論 DPI 為何。

我的 BMP 檔案會被上傳到任何地方嗎？

不會。解碼使用的是您瀏覽器本身的圖片支援，PDF 則透過 pdf-lib 在本機組合，所以掃描器或醫療影像匯出檔絕不會離開您的電腦。
