常見問題

SVG 中的文字還能選取嗎？

不能。每一頁匯出時，文字都以向量外框繪製，因此縮放清晰，也不依賴已安裝的字型，但它不是可以選取或搜尋的即時文字。如果您需要文字內容本身，請搭配 SVG 使用 PDF 轉文字。

整份文件得到一個 SVG，還是每頁一個？

每頁一個，因為 SVG 沒有頁面的概念。單頁 PDF 會下載為 filename.svg，多頁 PDF 則成為 filename_svg.zip，內含 page_1.svg、page_2.svg 等，一次轉換多個 PDF 則會下載為 pdf_to_svg.zip。

可以在 Illustrator 或 Inkscape 中編輯結果嗎？

輸出為標準 SVG，可在 Inkscape、Illustrator、Figma 和任何網頁瀏覽器中開啟。圖形、路徑和文字外框會以可編輯的向量物件呈現，而嵌入 PDF 的照片則在檔案內保持為點陣圖。

為什麼我的 SVG 檔案這麼大？

掃描或照片較多的 PDF 會產生很大的 SVG，因為每張點陣圖都以 base64 資料嵌入檔案，而包含數千個細小向量路徑的頁面也會累積體積。對於以圖片為主的頁面，PDF 轉 PNG 能提供更小、更實用的結果。

可以一次轉換多個 PDF 嗎？

將任意數量的 PDF 拖放到工具中，然後按一下「轉換」。每個檔案會依序處理，結果會收集在 pdf_to_svg.zip 中，並以來源文件命名。

有頁面範圍或大小之類的選項嗎？

沒有。每個上傳檔案的每一頁都會以原始頁面大小轉換，沒有縮放或範圍選擇。若只想轉換特定頁面，請先用擷取頁面將它們分出來。

可以將受密碼保護的 PDF 轉換為 SVG 嗎？

上傳後會提示您輸入密碼，通過後就會繼續轉換。SVG 檔案本身不帶密碼。

轉換時我的 PDF 會被上傳嗎？

不會。PyMuPDF 以 WebAssembly 的形式在您的瀏覽器內執行，並在本機寫入 SVG 檔案，因此 PDF 絕不會離開您的機器。引擎在第一次使用時才會下載，所以第一次轉換會稍微久一點。
