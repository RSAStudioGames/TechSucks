常見問題

可以用這個工具將任何 JSON 檔案轉換成 PDF 嗎？

不行。它只會從 BentoPDF 的 PDF 轉 JSON 工具所建立的 JSON 檔案重新建立 PDF，該工具會儲存文件完整的內部結構。來自 API、資料庫或設定檔的 JSON 匯出檔會因錯誤而失敗。

如何將 API 資料或設定檔轉換成可閱讀的 PDF？

請在文字轉 PDF中貼上或上傳純文字形式的 JSON，它會將 JSON 排版為頁面上的格式化文字。JSON 轉 PDF 僅用於來回轉換原本就是 PDF 的文件。

重新建立的 PDF 會與原始檔案相符嗎？

PDF 轉 JSON 所產生的 JSON 會記錄文件的物件，因此轉換回來時會重現來源的頁面、文字和圖片。轉換回來再比對，也是確認匯出是否完整擷取所有內容的快速方法。

轉換多個 JSON 檔案時輸出的是什麼？

每次轉換都會下載為 jsons-to-pdf.zip，即使只有一個檔案也一樣。其中每個 PDF 都沿用來源 JSON 的名稱，因此 report.json 會變成 report.pdf。

轉換回 PDF 之前可以編輯 JSON 嗎？

可以，只要結構對 CPDF 引擎而言仍然有效。以程式方式對 JSON 所做的變更（例如編輯後的中繼資料或文字物件）會重新建立到 PDF 中；格式錯誤的編輯則會產生轉換錯誤。

為什麼工具顯示 CPDF 引擎無法使用？

此轉換依賴 CPDF 的 WebAssembly 版本。bentopdf.com 上已內建，但自行託管的副本需要先在 WASM 設定中設定 CPDF WASM 檔案，此工具才能執行。

我的 JSON 檔案會被上傳到伺服器嗎？

不會。檔案在您的瀏覽器中讀取，並由在本機執行 CPDF 引擎的 Web Worker 重新建立為 PDF，因此不會傳送任何資料，大型轉換期間頁面也能保持回應。
