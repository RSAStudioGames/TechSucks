常見問題

究竟會移除哪些中繼資料？

文件資訊欄位（標題、作者、主旨、關鍵字、建立者、產生者，以及建立與修改日期）、XMP 中繼資料串流、檔尾的文件 ID 配對，以及 Illustrator 或 InDesign 等工具留下的應用程式專屬 PieceInfo。沒有任何選項；它一律會清除以上所有內容。

檔案中會保留什麼？

所有可見內容，加上表單欄位、註解、書籤、連結與任何檔案附件。這些元素內儲存的名稱，例如便利貼註解上的作者，則不會被動到。若要連註解、指令碼與附件一併清除，請使用清理 PDF。

它會移除 PDF 內影像的中繼資料嗎？

不會。影像資料維持原樣，所以照片放入 PDF 時帶有的任何 EXIF 或 XMP 資訊都會留在該影像中。如果這點很重要，點陣化 PDF會把每一頁重新轉譯為全新的影像，代價是失去可選取的文字。

我要如何確認中繼資料已經消失？

在檢視中繼資料中開啟清理後的檔案，確認欄位都是空白的。先對原始檔執行同樣的檢查，就能清楚看到即將被移除的內容。

可以復原嗎？

不行。清理後的檔案不會保留被移除數值的任何紀錄。如果日後可能需要作者、日期或其他細節，請保留您的原始檔。

移除中繼資料會縮小檔案大小嗎？

會稍微縮小，因為 XMP 區塊與資訊欄位被移除了，通常只有幾 KB。若要真正縮小，請接著使用壓縮 PDF。

它會移除註解、標記或隱藏文字嗎？

不會，它只針對中繼資料。註解與標記屬於註解物件，會保留；這部分請用移除註解處理。隱藏或白色的文字仍是頁面內容的一部分，所以若文件經過多次修訂，請檢查文件本身。

移除中繼資料時，我的 PDF 會被上傳嗎？

不會。檔案是由瀏覽器中的 PDF 函式庫開啟並重新寫入，當目標是匿名時這正是重點：文件完全不會接觸伺服器，也沒有伺服器記錄會留下您清理了什麼。
