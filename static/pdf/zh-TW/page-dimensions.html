常見問題

如何確認我的 PDF 是 A4 還是 Letter？

上傳檔案後會立即進行分析。摘要會顯示總頁數和出現的不同尺寸數量，表格則列出每一頁的寬度和高度，以及比對到的標準尺寸，因此一般的 A4 或 Letter 文件所有頁面都會顯示同一種尺寸。

可以辨識哪些標準紙張大小？

A3、A4、A5、Letter、Legal 和 Tabloid，不論直向或橫向，只要與官方尺寸相差在一點以內就會比對成功。其他尺寸則會顯示為「自訂」並附上精確的測量值。

「混合尺寸」警告是什麼意思？

文件中發現不只一種寬高組合，摘要會列出每種尺寸各有多少頁。旋轉過的頁面會被視為與其直立版本不同的尺寸，因此直向 A4 檔案中的橫向 A4 頁面就會觸發此警告。若要讓所有頁面一致，請使用修正頁面大小。

可以用英吋或公釐來顯示尺寸，而不是點嗎？

使用單位選單，可將整個表格切換為點、英吋、公釐和像素。像素以 96 PPI 計算，與瀏覽器及大多數螢幕工具處理 PDF 頁面的方式一致。

「旋轉」欄位代表什麼？

它會顯示頁面上儲存的旋轉屬性，以度數表示。頁面在檢視器中看起來可能是正的，卻帶有 90 或 270 度的旋轉，這會讓某些列印和轉換流程出錯，而旋轉 PDF可以將它標準化。

可以匯出結果嗎？

按一下「匯出為 CSV」即可下載 page-dimensions.csv，每頁一列，包含頁碼、寬度、高度、標準尺寸、方向、長寬比、面積和旋轉，單位為目前選取的單位。可直接用 Excel 或 Google 試算表開啟。

此工具會更改我的 PDF 嗎？

不會。它只讀取頁面樹並回報找到的內容，不會改寫任何內容，唯一提供的下載是選用的 CSV。

分析時 PDF 會被上傳嗎？

不會。檔案在您的瀏覽器中解析，測量值也在本機計算，這也是檔案載入後結果立刻出現的原因。
