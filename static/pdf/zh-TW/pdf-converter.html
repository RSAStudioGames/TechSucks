常見問題

可以將哪些檔案格式轉換為 PDF？

Word、Excel 和 PowerPoint 檔案（包含較舊的 DOC、XLS 和 PPT 格式）、OpenDocument 文字、試算表、簡報和繪圖、RTF、純文字、Markdown、CSV、XML、EPUB、MOBI、FB2 和 CBZ 格式的電子書、XPS、Publisher、Visio、WordPerfect、Microsoft Works、Apple Pages，以及 JPG、PNG、HEIC、WebP、TIFF、BMP、SVG 和 PSD 格式的圖片。如果您有一個資料夾裝著各種不同類型的圖片，圖片轉 PDF 可以一次接受全部，並讓每張圖片各佔一頁。

PDF 可以轉換成什麼格式？

可轉為 Word（DOCX）、Excel（XLSX）、CSV、純文字、Markdown、SVG，以及 JPG、PNG、WebP、TIFF 或 BMP 格式的頁面圖片，多頁 PDF 會以 ZIP 提供，每頁一張圖片。若要長期封存，PDF 轉 PDF/A 可輸出 PDF/A-1b、2b 或 3b，另有獨立工具可將彩色 PDF 轉為灰階。

PDF 轉 Word 會保留版面嗎？

PDF 轉 Word 會重建文件的文字、基本格式和整體版面，也可以一次轉換多個檔案。包含多欄、內嵌表單或大量圖形的頁面可能無法完美轉換，請預期需要在文書處理軟體中做些整理。

為什麼轉換後的 Word 或文字檔是空的？

這個 PDF 幾乎可以確定是掃描檔，每一頁都以圖片儲存而沒有文字圖層，因此 PDF 轉 Word、PDF 轉文字和表格轉換器都沒有東西可以擷取。請先用 OCR PDF 加入可搜尋的文字圖層，再轉換結果。

可以將 PDF 中的表格匯出到 Excel 嗎？

PDF 轉 Excel 會掃描每一頁的表格，並將每個表格寫入各自的工作表，工作表名稱依來源頁面命名。如果顯示找不到表格，表示該 PDF 的資料是以零散文字排列，而不是真正的表格結構；PDF 轉 CSV 和擷取表格採用相同的偵測方式，因此請改試 PDF 轉文字來取得原始內容。

轉換 Word、Excel 或 PowerPoint 檔案需要安裝 Microsoft Office 嗎？

不需要。這些檔案，以及 Publisher、Visio、RTF 和 WordPerfect，都由在您瀏覽器內執行的 LibreOffice 引擎轉換，因此不必安裝任何東西；例如 Word 轉 PDF 也可以直接處理 DOC、ODT 和 RTF。引擎每次使用時只會下載一次，所以第一次轉換會比之後的轉換多花幾秒鐘。

將 PDF 轉為 JPG 或 PNG 會損失品質嗎？

頁面會以原始大小的兩倍繪製，因此 Letter 大小的頁面會變成約 1,224 x 1,584 像素的圖片。PDF 轉 JPG 為有損壓縮，附有品質滑桿，預設為 90%，可在清晰度和檔案大小之間取得良好平衡；PDF 轉 PNG 和 PDF 轉 TIFF 為無損，PNG 另有 1x 到 3x 的縮放控制，可輸出適合列印的品質。

轉換時我的檔案會被上傳到伺服器嗎？

不會。此頁面上的每個轉換器，包括 Office、電子書和圖片轉換器，都以 WebAssembly 的形式在您的瀏覽器分頁中執行，檔案從您的裝置讀取，結果也直接寫回裝置。沒有上傳佇列，沒有伺服器副本，事後也不需要刪除任何東西。
