常見問題

每張 WebP 圖片都會成為各自的一頁嗎？

可以。每張圖片都會放在依圖片本身大小建立的獨立頁面上，依檔案在清單中的順序排列，整組檔案會下載為名為 from_webps.pdf 的單一檔案。

我的 WebP 圖片在 PDF 中會是什麼頁面大小？

頁面依圖片的像素尺寸決定，每個像素對應一點，所以 1600 x 1200 的圖片會產生 1600 x 1200 點的頁面，約 22 x 17 英寸。若要標準的 A4 或 Letter 頁面，請用修正頁面大小處理結果。

品質設定對 WebP 圖片有什麼影響？

「高」保留完整的像素尺寸與最輕的壓縮。「中」是預設值，以約 75% 品質重新編碼為 JPEG，並縮小圖片使最長邊不超過 2500 像素；「低」使用約 50% 與 1500 像素的上限，可得到最小的檔案。

透明區域會維持透明嗎？

不會。圖片嵌入時會透過瀏覽器的畫布重新編碼為 JPEG，而 JPEG 沒有 Alpha 通道，所以透明區域會變成純色背景。如果這很重要，請先在影像編輯器中將圖片平面化到白色背景上。

我可以轉換動態 WebP 嗎？

只會使用第一個影格，因為瀏覽器在將檔案放到頁面上之前，是把它當成靜態圖片解碼。每個動畫都會成為單一的靜態頁面。

我可以在同一個 PDF 中混用 WebP 與 JPG 或 PNG 檔案嗎？

此頁面不行；檔案選擇器只接受 .webp。請使用圖片轉 PDF，它能在單次轉換中同時接受 WebP、JPG、PNG 與其他格式。

我的圖片會為了製作 PDF 而被上傳嗎？

不會。每張 WebP 由您瀏覽器自己的影像引擎解碼，並在本機寫入 PDF，所以圖片不會離開您的裝置。

轉換前我可以重新排序或移除圖片嗎？

您可以用刪除圖示將任何檔案從清單中移除，但此頁面沒有拖曳重新排序，所以頁面會依您選取檔案的順序排列。請依您希望出現的順序來挑選。
