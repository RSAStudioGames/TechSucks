常見問題

JSON 包含什麼內容？

cpdf 所讀取的 PDF 完整物件結構：trailer、catalog、頁面樹、每個字典，以及每一頁解析為繪圖和文字運算子清單的內容串流。這是檔案的完整傾印，而不是摘要。

要將 PDF 的文字取出為 JSON，這是正確的工具嗎？

通常不是。這裡的文字依繪製順序散落在內容串流運算子中，有字型和位置，但沒有段落。若要以結構化格式取得可閱讀的頁面文字，請使用為 AI 準備 PDF，純文字則使用 PDF 轉文字。

可以將 JSON 轉回 PDF 嗎？

BentoPDF 無法做到。輸出遵循 cpdf 自己的 JSON 格式，cpdf 命令列工具可以將它讀回 PDF，但瀏覽器工具只支援單向轉換。

為什麼 JSON 比 PDF 大這麼多？

內容串流會展開為運算子陣列，影像等二進位串流資料會編碼為文字，每個物件也會連同其鍵值一併寫出，因此 JSON 檔案的大小是來源檔案的數倍是正常的。大型或圖片較多的 PDF 會產生非常大的檔案。

可以一次將多個 PDF 轉換為 JSON 嗎？

可選擇任意數量的檔案，每個檔案都在背景 worker 中轉換，結果會打包成 pdfs-to-json.zip，每個 PDF 對應一個以來源檔名命名的 .json。即使只有一個 PDF，也會以 ZIP 提供。

適用於加密的 PDF 嗎？

轉換開始前會要求您輸入密碼，然後序列化解密後的副本。沒有密碼就無法讀取物件結構。

這有什麼用途？

用於除錯產生器時檢查 PDF 內部、查看頁面內容串流包含什麼、比較兩個版本的結構差異，或將物件樹餵給腳本。若只需要文件屬性，檢視中繼資料會更快。

產生 JSON 時 PDF 會被上傳嗎？

不會。cpdf 以 WebAssembly 的形式在您瀏覽器的 web worker 中執行，JSON 也在您的裝置上寫入並壓縮後才下載。
