常見問題

空白頁會插入在哪裡？

位置數字代表新空白頁之前有多少張既有頁面。輸入 0 會放在最前面，輸入 3 會插入在第 3 頁之後，輸入總頁數則會附加在最後面。

空白頁的尺寸是多少？

每張空白頁都會複製文件第一頁的寬度與高度，所以 Letter 文件會得到 Letter 空白頁，A4 文件則得到 A4 空白頁。如果您的 PDF 混用多種頁面尺寸，空白頁仍會與第 1 頁一致，而不是與相鄰的頁面一致。

我可以一次新增多張空白頁嗎？

輸入 1 以上的任何數量，全部會一起插入在同一個位置。若要在多個不同位置加入空白頁，請對輸出檔再執行一次工具，或使用 PDF 多功能工具以視覺方式排列頁面。

會保留書籤與文件屬性嗎？

頁面上的內容、圖片、文字與註解都會原樣保留。文件是逐頁重新建立的，所以書籤（大綱面板）以及標題、作者等屬性不會帶到新檔案。

插入的頁面是完全空白的嗎？

是的。它沒有文字、沒有頁碼，也沒有任何列印的註記，就是一張與第 1 頁尺寸相同的白紙。如果之後想在上面加頁碼，請將結果交給頁碼處理。

我可以用這個讓每一章都從右側頁面開始，方便雙面列印嗎？

可以，但每次執行只能設定一個位置。在每個結束於奇數頁的章節後插入一張空白頁，下載後，再對新檔案重複操作以處理下一章。輸出會保留原始檔名，所以請邊做邊重新命名副本，避免混淆。

我可以為受密碼保護的 PDF 新增空白頁嗎？

如果檔案需要密碼才能開啟，工具會在讀取頁數之前先詢問密碼。新檔案儲存時不含密碼，如有需要，請之後再重新保護。

新增頁面時我的 PDF 會被上傳嗎？

不會。頁數的讀取與新文件的組合都是在您的瀏覽器中，用 JavaScript PDF 函式庫 pdf-lib 完成，下載則直接從記憶體產生。不會傳送任何內容到伺服器。
