常見問題

PDF 多功能工具能做到哪些單一用途工具做不到的事？

它將合併、重新排序、旋轉、複製、刪除、插入和分割整合在同一個頁面格線中，因此您可以一次完成多項操作，不必在各步驟之間下載再重新上傳。每個動作都支援復原和重做，您可以在匯出前放心嘗試。

如何將多個 PDF 的頁面合併成一份文件？

上傳所有來源檔案後，它們的頁面會依上傳順序一起顯示在同一個格線中。將頁面拖曳成您想要的順序，刪除不需要的頁面，再按一下「匯出 PDF」，即可將結果下載為單一檔案。

可以將圖片加入為頁面嗎？

將 JPG、PNG、WebP、HEIC、TIFF、BMP、GIF 或 SVG 檔案與 PDF 一起拖放進來，每張圖片都會變成一頁，可以像其他頁面一樣移動、旋轉或刪除。也可以從「Insert」選單新增空白頁面。

如何將一個 PDF 分割成多個檔案？

按一下「Split」，再選擇文件的分割方式：依頁面範圍、奇數頁與偶數頁、每一頁、書籤、每 N 頁或檔案大小。只有一個部分時會下載為 PDF；有多個部分時會一起打包成 ZIP 下載。

在這裡旋轉頁面會降低品質嗎？

不會。旋轉是以 90 度為單位儲存為頁面屬性，而不是重新繪製內容，因此文字、向量和圖片都不會受影響。若要使用 90、180 或 270 度以外的角度，請使用依自訂角度旋轉。

可以只匯出部分頁面嗎？

勾選您想要的頁面，再使用「下載所選頁面」，即可取得僅含這些頁面的 selected-pages.pdf。工作區會保持原樣，因此您可以繼續作業，之後再匯出其餘頁面。

匯出時書籤會如何處理？

匯出會逐頁重建文件，因此來源檔案中的書籤不會帶入新的 PDF。頁面內容，包括文字和圖片，會原樣複製。

使用多功能工具時，我的 PDF 會被上傳嗎？

不會。頁面縮圖在您的瀏覽器中繪製，最終的 PDF 或 ZIP 也在瀏覽器中組合，損壞的檔案也會在載入前於本機修復。您放入格線的任何內容都不會離開您的電腦。
