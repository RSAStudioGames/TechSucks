頁面標籤的運作方式

  • 將頁面範圍留空即可為所有頁面套用標籤。
  • 前置頁可使用羅馬數字，正文則可使用十進位編號等樣式。
  • 將前綴搭配起始值 0，可建立像 A-0、A-1、A-2 這樣的標籤。
  • 當規則使用 1-9,30-40 或 odd 等不連續範圍時，請啟用持續編號。

常見問題

如何將附錄頁面標示為 A-1、A-2、A-3？

為附錄頁面範圍新增一條規則，樣式維持為十進位阿拉伯數字，並在標籤前綴欄位輸入 A-。使用預設起始值 1，頁面就會變成 A-1、A-2、A-3，再以前綴 B- 新增第二條規則即可處理下一個附錄。

頁碼可以從 0 或 1 以外的數字開始嗎？

每條規則都有「起始值」欄位，預設為 1。設為 0 即為從零開始編號，也可以設為其他數字，例如 15，讓從長篇書籍中擷取出來的章節保留原本的頁碼。

「跨不連續範圍延續編號」有什麼作用？

當一條規則涵蓋的頁面不連續（例如 1-9,30-40 或 odd），而您希望標籤跨越間隔持續依序計數時，請開啟此選項。關閉時，每個獨立的頁面區塊都會從起始值重新開始。

PDF 原本就有的頁面標籤會怎麼處理？

「移除現有頁面標籤」核取方塊預設為勾選，所以在套用您的規則之前，舊標籤會先被清除。如果您只想為部分頁面重新加上標籤，並保留其餘頁面的現有標籤，請取消勾選。

我可以輸入哪些頁碼範圍格式？

留空代表涵蓋所有頁面，也可以使用 1-4, 7, odd 或 1-9,30-40 這類格式。頁碼指的是檔案中的實際位置，而不是 PDF 可能已顯示的標籤。

我可以為受密碼保護的 PDF 新增標籤嗎？

不能直接加。工具會停下並顯示「受保護的 PDF」訊息，請先用解除鎖定 PDF移除密碼，再上傳不再需要密碼的副本。

為什麼工具要我設定 CoherentPDF？

頁面標籤是由 CoherentPDF 引擎寫入，通常會在您第一次使用工具時從 CDN 載入。如果自行代管的版本已關閉該預設，系統會提示您將 WASM 設定指向函式庫的副本。

如何確認標籤已套用？

用能顯示頁面標籤的閱讀器（例如 Adobe Acrobat 或 Firefox 內建檢視器）開啟下載的 PDF，並查看工具列中的頁碼方塊。它會顯示標籤，例如 iv 或 A-1，而不是單純的頁面索引。
