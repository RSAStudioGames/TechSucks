分割 PDF

將指定範圍的頁面擷取為新的 PDF。

點選以選擇檔案 或將檔案拖曳至此處

單一 PDF 檔案

您的檔案絕不會離開您的裝置。

運作方式：

  • 輸入以逗號分隔的頁碼（例如 2, 8, 14）。
  • 請用連字號輸入頁面範圍（例如 5-10）。
  • 可組合使用以進行複雜的選取（例如 1-3, 7, 12-15）。

運作方式：

  • 將所有偶數頁（2、4、6...）或所有奇數頁（1、3、5...）擷取到新的 PDF。

運作方式：

  • PDF 的每一頁都會儲存為獨立的 PDF 檔案。
  • 結果會下載為包含所有頁面的 ZIP 檔案。

運作方式：

  • 按一下下方的頁面縮圖，選取您要擷取的頁面。
  • 選取的頁面會被醒目標示。

運作方式：

  • 依書籤（大綱）分割 PDF。
  • 選擇要分割的書籤層級。

運作方式：

  • 將 PDF 分割成多個檔案，每個檔案包含 N 頁。

輸出

多個檔案會一起下載為 ZIP。

常見問題

我要如何從 PDF 擷取一段頁面範圍？

選擇「依頁面範圍擷取」並輸入您要的頁面，例如 1-5, 8, 11-13。預設會把選取的頁面合併成一個 PDF；把輸出切換為「每個範圍一個 PDF」，每個以逗號分隔的範圍就會成為 split-pages.zip 內的獨立檔案。

我可以把 PDF 分割成每頁一個檔案嗎？

可以。選擇「將所有頁面分割成獨立檔案」，每一頁都會寫成各自的 PDF，命名為 page-1.pdf、page-2.pdf 等，並打包在 split-pages.zip 中。

我要如何每 N 頁分割一次 PDF？

選擇「每 N 頁分割」並輸入分段大小。23 頁的檔案每 5 頁分割一次會產生五個 PDF，工具會事先警告最後一個只有 3 頁。檔案會以 split-n-times.zip 下載。

我可以依章節或書籤分割 PDF 嗎？

可以，只要 PDF 有書籤。選擇「依書籤分割」與層級（全部，或第 0 到第 3 層），每個書籤所在頁面都會開始一個新檔案，在 split-by-bookmarks.zip 中得到 split-1.pdf、split-2.pdf 等檔案。如果 PDF 在所選層級沒有書籤，則會顯示錯誤。

我要如何分開奇數頁與偶數頁？

選擇「依偶數/奇數頁分割」並挑選偶數或奇數；符合的頁面會依原始順序擷取到同一個 PDF。這是在單面印表機上進行雙面列印的常見步驟。

我可以用視覺方式挑選頁面，而不是輸入數字嗎？

可以。「以視覺方式選取頁面」會顯示每一頁的縮圖；按一下您要的頁面，它們會依頁面順序被擷取。合併輸出會產生一個 PDF，分開輸出則在 ZIP 中每頁一個檔案。

分割會降低頁面品質嗎？

不會。頁面由 QPDF 直接複製而不重新轉譯，所以文字、圖片、字型與向量圖形都和原始檔完全相同。

分割時我的 PDF 會被上傳嗎？

不會。頁面擷取與 ZIP 封裝都在您的瀏覽器中執行，產生的檔案直接從您的裝置儲存。
