常見問題

PDF 轉 ZIP 實際上對我的檔案做了什麼？

除了打包之外什麼都沒做。PDF 會以原始檔名、不更動地依您加入的順序複製到單一 pdfs_archive.zip 中，因此從 ZIP 取出的內容與放進去的完全一致。

壓縮成 ZIP 會讓 PDF 變小嗎？

不會。封存檔以不壓縮的方式寫入，因為 PDF 內容內部已經過壓縮，幾乎無法再縮小，所以 ZIP 的大小會約等於所有檔案加總的大小。若要縮小，請先用壓縮 PDF處理，再將結果打包成 ZIP。

壓縮 PDF 成 ZIP 和合併 PDF 有什麼差別？

ZIP 會將每個 PDF 以獨立檔案的形式放在同一個容器中，由收件者解壓縮。合併則是將頁面接成同一份 PDF 文件，適用於這些檔案應被視為單一文件閱讀的情況，請使用合併 PDF。

如果我有兩個檔案同名怎麼辦？

重複的名稱會自動處理：第二個檔案會變成 name (1).pdf，第三個變成 name (2).pdf，依此類推，因此封存檔內不會有任何檔案被覆蓋。如果您想要有意義的名稱，請在上傳前先重新命名檔案。

可以將非 PDF 檔案加入封存檔嗎？

不可以。只接受副檔名為 .pdf 或檔案類型為 PDF 的檔案，其他拖放進來的內容都會被忽略。若要打包混合檔案，請改用作業系統內建的壓縮功能。

收件者需要特殊軟體才能開啟封存檔嗎？

不需要。輸出是標準的 ZIP 檔案，Windows、macOS、iOS 和 Android 無須額外軟體就能開啟，按兩下或點一下即可解開 PDF。

建立 ZIP 時我的 PDF 會被上傳嗎？

不會。封存檔在您的瀏覽器中組合，檔案從您的磁碟讀取，ZIP 也寫回磁碟，沒有任何網路傳輸。以這種方式打包發票、合約或病歷，可讓它們留在您的裝置上。
