常見問題

PDF 轉 Markdown 能保留多少文件結構？

標題、段落、清單和基本的粗體與斜體格式都會轉換，每一頁在輸出中以水平線（---）分隔。標題層級是依字型大小推斷，因此樣式不一致的文件可能會有些標題層級錯誤。

「包含圖片」選項有什麼作用？

勾選時，PDF 中的圖片會以 base64 資料直接嵌入 Markdown，因此單一 .md 檔案是自給自足的，但可能變得很大。對以文字為主的文件請保持關閉，讓輸出保持小巧，並能在純文字編輯器中閱讀。

為什麼 Markdown 是空的或幾乎是空的？

轉換器讀取的是 PDF 的文字圖層，因此只有圖片的掃描文件沒有可轉換的內容。請先用 OCR PDF 加入文字圖層，再轉換結果。

如何處理多欄版面、註腳和側欄？

複雜版面是弱項：多欄文字可能會交錯，側欄或註腳可能放錯位置。雜誌風格的頁面需要檢查並整理輸出，而單欄文件則幾乎不用整理。

可以一次將多個 PDF 轉換為 Markdown 嗎？

上傳多個 PDF 並按一次「轉換」。單一檔案會下載為 filename.md；多個檔案則以 markdown-files.zip 提供，每個 PDF 對應一個 .md，名稱重複時會加上編號後綴。

這和 PDF 轉文字一樣嗎？

不一樣。PDF 轉文字 提供沒有結構的原始文字，更適合餵給腳本。PDF 轉 Markdown 則保留標題、清單和強調，結果可直接貼到 Obsidian、wiki 或靜態網站產生器。

可以轉換受密碼保護的 PDF 嗎？

如果檔案需要密碼才能開啟，轉換開始前會提示您輸入，之後照常擷取文字。密碼不會儲存在任何地方，Markdown 輸出本身也沒有任何保護。

轉換為 Markdown 時我的 PDF 會被上傳嗎？

不會。轉換在以 WebAssembly 載入您瀏覽器的 PyMuPDF 引擎上執行，.md 檔案或 ZIP 也在您的機器上產生。研究論文、合約和內部文件都能保持私密。
