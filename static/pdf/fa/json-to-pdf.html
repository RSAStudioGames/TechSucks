JSON به PDF

فایل‌های JSON را به قالب PDF تبدیل کنید.

نکته: تنها فایل‌های JSON ساخته‌شده با ابزار تبدیل PDF به JSON پشتیبانی می‌شوند. فایل‌های JSON استاندارد از ابزارهای دیگر کار نخواهند کرد.

سؤالات متداول

آیا می‌توانم هر فایل JSON را با این ابزار به PDF تبدیل کنم؟

خیر. فقط PDFها را از فایل‌های JSON ساخته‌شده با ابزار PDF به JSON در BentoPDF بازسازی می‌کند که ساختار داخلی کامل سند را ذخیره می‌کند. خروجی JSON از یک API، پایگاه‌داده یا فایل پیکربندی با خطا مواجه می‌شود.

چطور داده‌های API یا فایل پیکربندی را به‌جای آن به PDF خوانا تبدیل کنم؟

JSON را به‌صورت متن ساده در متن به PDF بچسبانید یا بارگذاری کنید تا به‌صورت متن قالب‌بندی‌شده روی صفحه‌ها چیده شود. JSON به PDF فقط برای رفت‌وبرگشت اسنادی است که از ابتدا PDF بوده‌اند.

آیا PDF بازسازی‌شده با اصلی یکسان است؟

JSON تولیدشده با PDF به JSON اشیای سند را ثبت می‌کند، پس تبدیل دوباره صفحه‌ها، متن و تصاویر منبع را بازسازی می‌کند. تبدیل برگشتی و مقایسه همچنین راهی سریع برای اطمینان از ثبت کامل خروجی است.

اگر چند فایل JSON را تبدیل کنم خروجی چیست؟

هر تبدیل حتی برای یک فایل هم به‌صورت jsons-to-pdf.zip دانلود می‌شود. درون آن، هر PDF نام JSON منبع خود را دارد، پس report.json به report.pdf تبدیل می‌شود.

آیا می‌توانم JSON را پیش از تبدیل دوباره ویرایش کنم؟

بله، به شرط اینکه ساختار برای موتور CPDF معتبر بماند. تغییرات برنامه‌نویسی‌شده در JSON، مثل فراداده یا اشیای متن ویرایش‌شده، دوباره در PDF ساخته می‌شوند؛ ویرایش نادرست خطای تبدیل می‌دهد.

چرا ابزار می‌گوید موتور CPDF در دسترس نیست؟

این تبدیل به نسخهٔ WebAssembly از CPDF وابسته است. در bentopdf.com گنجانده شده است، اما نسخهٔ خودمیزبان پیش از اجرای این ابزار نیاز دارد فایل‌های WASM مربوط به CPDF در تنظیمات WASM پیکربندی شوند.

آیا فایل JSON من روی سرور بارگذاری می‌شود؟

خیر. فایل‌ها در مرورگر شما خوانده و با Web Workerی که موتور CPDF را به‌صورت محلی اجرا می‌کند به PDF بازسازی می‌شوند، پس چیزی ارسال نمی‌شود و صفحه هنگام تبدیل‌های بزرگ پاسخگو می‌ماند.
