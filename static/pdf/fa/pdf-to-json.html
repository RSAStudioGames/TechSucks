سؤالات متداول

JSON شامل چه چیزی است؟

ساختار کامل اشیاء PDF آن‌گونه که cpdf می‌خواند: trailer، کاتالوگ، درخت صفحه‌ها، هر دیکشنری، و جریان محتوای هر صفحه که به فهرستی از عملگرهای ترسیم و متن تجزیه شده است. این یک تخلیهٔ کامل فایل است، نه خلاصه.

آیا این ابزار مناسب گرفتن متن PDF به‌صورت JSON است؟

معمولاً نه. متن اینجا به ترتیب رسم در میان عملگرهای جریان محتوا پراکنده است، با فونت‌ها و موقعیت‌ها ولی بدون پاراگراف. برای متن خوانای صفحه در قالب ساختاریافته از آماده‌سازی PDF برای هوش مصنوعی و برای متن ساده از PDF به متن استفاده کنید.

آیا می‌توانم JSON را دوباره به PDF تبدیل کنم؟

با BentoPDF نه. خروجی از قالب JSON خود cpdf پیروی می‌کند که ابزار خط فرمان cpdf می‌تواند آن را دوباره به PDF بخواند، ولی ابزار مرورگر فقط یک جهت را انجام می‌دهد.

چرا JSON این‌قدر از PDF بزرگ‌تر است؟

جریان‌های محتوا به آرایه‌های عملگر باز می‌شوند، داده‌های جریان دودویی مانند تصاویر به متن کدگذاری می‌شوند و هر شیء با کلیدهایش نوشته می‌شود، پس فایل JSON چند برابر منبع طبیعی است. PDFهای بزرگ یا پر از تصویر فایل‌های بسیار بزرگ تولید می‌کنند.

آیا می‌توانم چند PDF را همزمان به JSON تبدیل کنم؟

هر تعداد که می‌خواهید انتخاب کنید؛ هر کدام در worker پس‌زمینه تبدیل می‌شود و نتایج در pdfs-to-json.zip با یک .json برای هر PDF و به نام فایل مبدأ بسته‌بندی می‌شود. یک PDF تکی هم به‌صورت ZIP می‌رسد.

آیا روی PDFهای رمزگذاری‌شده کار می‌کند؟

پیش از شروع تبدیل گذرواژه از شما پرسیده می‌شود و نسخهٔ رمزگشایی‌شده سریالایز می‌شود. بدون گذرواژه ساختار اشیاء خوانده نمی‌شود.

این به چه کاری می‌آید؟

بررسی درونیات PDF هنگام اشکال‌زدایی یک تولیدکننده، بررسی محتوای جریان محتوای یک صفحه، مقایسهٔ ساختاری دو نسخه، یا دادن درخت اشیاء به یک اسکریپت. برای ویژگی‌های سند به‌تنهایی، مشاهدهٔ فراداده سریع‌تر است.

آیا PDF برای تولید JSON بارگذاری می‌شود؟

خیر. cpdf به‌صورت WebAssembly در یک web worker در مرورگر شما اجرا می‌شود و JSON پیش از دانلود روی دستگاه شما نوشته و فشرده می‌شود.
