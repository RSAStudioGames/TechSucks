Frequently Asked Questions

How does it know which pixels are text?

It doesn't read the text; each page is rendered to an image and every dark pixel (red, green, and blue all below 120 on a 0 to 255 scale) is repainted in your chosen color. Black and dark gray type is caught, while light gray text, colored text, and photos are left alone.

Why did lines, borders, and my logo change color too?

Because the tool works on dark pixels rather than text objects, any dark element, including table rules, underlines, and black artwork, is recolored along with the text. There's no way to exclude regions in this tool.

Can I recolor only certain words or paragraphs?

No. One color is applied to all dark content on every page. To change individual words or headings while leaving the rest alone, edit the text directly in the PDF Editor.

Will the text still be selectable and searchable?

No. The output is image-based: each page is rendered at 2x and embedded as a PNG, so text can no longer be selected, searched, or copied. Keep the original if you need an editable version, or run OCR PDF on the result to add a text layer back.

Why did the file get much bigger?

A page of text weighs a few kilobytes as text but becomes a full-page PNG image when recolored, so multi-page documents can grow many times over. Compress PDF can shrink the result at the cost of some sharpness.

Can I turn black text white for a dark background?

Yes, any color works, including white, but the page background isn't changed, so white text on the original white page disappears. Choose a color that contrasts with the background the page already has.

Is my document uploaded to change the text color?

No. Each page is rendered and recolored on a canvas in your browser, and the new PDF is assembled there too, so the file never leaves your device. A progress indicator shows which page is being processed.

Why is colored or light gray text unchanged?

Only pixels dark enough to pass the threshold are repainted. Red headings, blue links, mid-gray captions, and anti-aliased edges lighter than the cutoff keep their original color, which can leave a faint halo around recolored letters.
