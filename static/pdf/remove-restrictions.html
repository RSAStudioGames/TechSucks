Frequently Asked Questions

What is the difference between Remove Restrictions and Unlock PDF?

Use Unlock PDF when a PDF asks for a password before it will open. Use this tool when the PDF opens but blocks printing, copying, editing, or commenting; it strips those restrictions and writes a copy with no encryption at all.

Do I need the owner password?

If the PDF opens without asking for a password, leave the field empty and the restrictions are removed as is. If a password is required, enter it in the Owner Password field. The tool doesn't crack, guess, or brute-force passwords.

What restrictions exactly get removed?

Password protection, printing limits, editing locks, text and image copying restrictions, annotation and commenting limits, and the usage restrictions attached to some digitally signed PDFs. The output has zero encryption, so anyone who receives it can open it freely.

Is it legal to remove restrictions from a PDF?

That depends on your rights to the document and on local law. Removing restrictions from files you own or are licensed to use, for example to run accessibility tools or copy quotes for notes, is the intended use. Don't use it to get around someone else's copyright or licensing terms.

Will the content of the PDF change?

No. QPDF rewrites only the encryption layer; pages, text, images, bookmarks, and form fields are untouched, and the output keeps the original file name.

Why does it say the PDF may require the correct owner password?

That error appears when QPDF can't open the file with the password you entered, or with no password. Check for typos and caps lock, and if the file needs a password to open, enter that one.

Can I keep the PDF encrypted but allow printing?

Not with this tool, which removes all security. To keep a password and adjust individual permissions such as printing or copying, use Change Permissions instead.

Does removing restrictions upload my PDF or password?

No. QPDF runs as WebAssembly inside your browser tab, so the file and any password you enter stay on your device.
