A Simple Guide to Debloating Windows

Windows comes with with a bunch of extra apps, background tracking that is effectively spyware, and features nobody wants or asked for (like copilot). I’ll show you how to remove a majority of the junk Windows comes with to reduce data collection, remove clutter, and very likely speed up your computer.

I always run this on any new installation of Windows 10/11, but that isn’t required for this process to work. If you want to stay on Windows 10, you can use 0Patch to stay up to date with security updates even after Microsoft kills off W10 on October 14th, 2025.

WinUtil quick start

Step 1 - Opening WinUtil#

We’ll start by using a free, trusted tool called WinUtil by Chris Titus Tech. This safely automates most of the cleanup.
Here’s the documentation if you want to read further.

  1. Press the Windows key, type powershell.

  2. Right-click Windows PowerShell and select Run as administrator.

    Any of these three options (should you have them) will launch PowerShell.

  3. Copy and paste the command below

    irm "https://christitus.com/win" | iex

    It may take a moment to load the application.

Step 2 - Applying Tweaks#

Once WinUtil opens, select the ‘Tweaks’ tab at the top.

If you’re new to this tool and don’t know what most of the options mean, select ‘Standard’ from the recommended selections at the top and then click ‘Run Tweaks’
Once it’s done processing, restart your computer for the changes to take effect.

Advanced Configuration#

If you want to be more detailed, here are the options I’d recommend for the average user:

Restore point#

  • Enable: Create Restore Point Note: This creates a restore point in case something ever goes wrong on your PC, you have a good point to restore.

Privacy and tracking#

  • Enable: Disable Telemetry Note: Blocks a lot of the built-in features microsoft has to spy on its users.
  • Enable: Disable Activity History Note: It’s my personal preference to keep this off.
  • Enable: Disable Location Tracking Note: Self-explanatory. Recommended option.
  • Enable: Disable Recall Note: Highly recommended option. Major safety concern created by microsoft.
  • Enable: Disable Microsoft Copilot Note: My opinion is that Copilot is garbage. Do what you wish.

Apps and disk cleanup#

  • Enable: Delete Temporary Files Note: Usually doesn’t hurt to run this and possibly free up some space.
  • Enable: Run Disk Cleanup Note: Usually doesn’t hurt to run this and possibly free up some space. Will also remove old unneeded windows update files.
  • Enable: Disable Storage Sense Note: Personal preference to leave off
  • Enable: Disable ConsumerFeatures Note: Disables the automatic installation of random games and third-party apps that microsoft forces on it’s users after installation or updates. It could potentially disable the Phone Link feature.
  • Enable: Disable Background Apps
  • Disable: Remove ALL MS Store Apps Note: This will remove ALL microsoft store apps besides the essentials required to make WinGet work.
  • Enable: Remove OneDrive Note: Moves OneDrive files to Default Home Folders and Uninstalls it. Do not select if you use OneDrive.
  • Enable: Block Razer Software Installs Note: If you have a Razer device (my condolences to your wallet), don’t use this option.
  • Enable: Debloat Brave Note: I recommend if you use Brave browser.
  • Enable: Debloat Edge Note: I recommend if you use MS Edge.
  • Disable: Adobe Debloat

Desktop and File Explorer#

  • Enable: Disable Explorer Automatic Folder Discovery Note: It’s my personal preference to keep this off. Stops Windows Explorer from automatically changing the folder settings based on the content inside, such as, changing a folder to be optimized for music if music files are detected in the folder.
  • Enable: Enable End Task With Right Click Note: Allows you to end the task when right-clicking an application from the taskbar.
  • Disable: Disable Notification Tray/Calendar
  • Enable: Set Classic Right-Click Menu Note: Windows 11 only option. I prefer this as it gives you the full-featured context menu back instead of the half-useless version microsoft pushes on you.
  • Enable: Remove Home from explorer Note: Personal preference
  • Enable: Remove Gallery from explorer Note: Personal preference

Power and gaming#

  • Enable: Disable GameDVR Note: Disables the Xbox app screen recording function and some other game features. Not needed whatsoever and can even lower your performance in games.
  • Disable: Disable Fullscreen Optimizations Note: Fullscreen optimizations run games in an optimized borderless windowed mode. I usually leave this option deselected.
  • Enable: Disable Hibernation Note: Disables hibernation. I recommend leaving this on if you’re on a laptop.
  • Disable: Set Hibernation as default Note: Select if you are using a laptop.
  • Disable: Set Display to Performance

Networking#

  • Enable: Disable Homegroup Note: Not really needed on the average user’s computer. Leave on if you know you need it.
  • Enable: Disable Wifi-Sense Note: Used to spy on you and all the wifi networks around your device.
  • Disable: Adobe Network Block
  • Disable: Disable IPv6
  • Disable: Prefer IPv4 over IPv6
  • Disable: Disable Teredo

System settings#

  • Disable: Change Windows Terminal default: PowerShell 5 → PowerShell 7 Note: Personal preference. If you don’t know what it is, don’t worry about it.
  • Disable: Disable PowerShell 7 Telemetry Note: Only if you used the above option. Stops microsoft from spying on your usage of PowerShell.
  • Enable: Set Services to Manual Note: Sets a lot of useless, bloat, and telemetry services to manual that don’t need to be running all the time.
  • Enable: Disable Intel MM (vPro LMS) Note: Recommended unless you know what this is and need it for something.
  • Enable: Disable Windows Platform Binary Table (WPBT)
  • Disable: Set Time to UTC

Customize Preferences#

Then, under “Customize Preferences” (the right bar of WinUtil in the tweaks tab), I usually change the following:

Appearance, Start menu, and taskbar#

  • Enable: Dark Theme for Windows Note: Personal preference. Enables Dark Mode system-wide
  • Disable: Bing Search in Start Menu Note: Personal preference. I don’t like my start menu to send all my search results to bing’s servers.
  • Disable: Recommendations In Start Menu Note: Personal preference. Be aware disabling this will disable Windows Spotlight in the lock screen.
  • Disable: Remove Settings Home Page
  • Disable: Search Button in Taskbar Note: Personal preference.
  • Disable: Task View Button in Taskbar Note: Personal preference.
  • Disable: Center Taskbar Items Note: Windows 11 only. Personal preference.
  • Disable: Widgets Button in Taskbar Note: Personal preference.

Window snapping and File Explorer#

  • Enable: Snap Window
  • Enable: Snap Assist Flyout
  • Enable: Snap Assist Suggestion
  • Enable: Show Hidden Files
  • Enable: Show File Extensions

Keyboard and mouse#

  • Disable: NumLock on Startup Note: Personal preference.
  • Disable: Mouse Acceleration Note: Disables mouse acceleration so your mouse cursor will move around the screen at a consistent speed based on your settings. Recommended if you game on that device.
  • Disable: Sticky Keys Note: Disables Sticky Keys so it will no longer activate upon pressing the “Shift” key 5 times rapidly. Recommended if you game on that device.

Startup, diagnostics, and power#

  • Disable: Verbose Messages During Logon Note: Personal preference. Not really needed for the average user.
  • Enable: Detailed BSoD Note: Gives you more detailed crash reports should you encounter a Blue Screen of Death which is helpful for debugging.
  • Enable: S3 Sleep Note: Recommended if you use a laptop. S3 Sleep prevents unwanted wake-ups and battery drain, unlike Modern Standby which wakes your device more often.
  • Enable: Add and Activate Ultimate Performance Profile Note: Not recommended if you are on a laptop as it will use more power and drain your battery life significantly faster.
    I believe this also changes the execution policy to Restricted. You can check this using Get-ExecutionPolicy

O&O ShutUp10++#

I then like to run OO Shutup 10. Go to “Actions” in the top bar then select “Apply only recommended settings” you’ll be good. This will block a lot of background spying/telemetry by microsoft and some general annoyances. Read the descriptions of what the other options do if you’re unfamiliar with them as they can lead to some significant changes.
