Quantization#

Model quantization is a method of reducing the size of an existing AI model (LLM, diffusion, video gen, etc) while maintaining accuracy. It works by reducing the precision of the weights and activations with a loss in quality proportional to the quantization level and method. Quantizing a model allows for larger models to be used with less of a computing requirment. For example, Llama 3.3 70B FP16 is about 140GB in size and would require a similar amount of memory to run. Quantizing it to 4 bit precision would only require about 40GB of memory to run. The preicision size is directly proportional to the memory required to run a model. To measure the change in quality from a quantized model compared to its unquantized form, you can measure its perplexity (PPL).

In the table, the lower the precision is, the higher the perplexity. Perplexity values can be different depending on the model, its architecture, quantization method used, etc. I personally would not go lower than 4 bits per weight (about Q4 or Q4_K_M within Llama.cpp quantization). I prefer using ExLlama quantization as it tends to be more performant and accurate than Llama.cpp. The trade-off is that llama.cpp allows you to use both your VRAM and RAM together whereas ExLlama is fixed to the VRAM. EXL3 is the latest version of the Exllama quantization method and has fairly good quality even at low precision.

Tools#

Here are a few different AI tools I’ve found that are (relatively) simple to use and have lots of strong features.

GPT4ALL#

https://www.nomic.ai/gpt4all

GPT4ALL is an easy to use application with minimal setup required to hop right into using LLMs personally. It also offers text embedding, to read documents you give it, and the ability to use an on-device AI model or connect to an API provider (ChatGPT/Claude/Vertex/etc).

Supports Nvidia, AMD, and Intel GPUs as well as CPU.

Ollama#

https://ollama.com/

Ollama is another easy way of serving LLMs. You can download the install package for Windows, Mac OS, or Linux, install it, and quickly download LLMs on your device with a single command. Ollama is based on llama.cpp which allows you to offload the AI model onto your CPU/RAM to fit larger models, or if you dont have a GPU, run solely on a CPU/RAM.

Text Generation Web UI#

https://github.com/oobabooga/text-generation-webui/

Text Generation Web UI, often referred to as Oobabooga or Text Gen Web UI is a relatively simple and straightforward way to run LLMs.

Supports Nvidia, AMD, and Intel GPUs as well as CPUs.

COVER HOW TO ADD AND LOAD MODELS AND THE BASIC PREREQUISITES NEEDED FOR A FIRST TIME SETUP AND MAYBE A LITTLE BIT ABOUT EXTENSIONS AND API (Hardware support?) (OS Support?)

Aphrodite Engine#

https://aphrodite.pygmalion.chat/

Aphrodite Engine (AE) supports a bunch of different quantization methods and is great for advanced users with beefier hardware who want to serve LLMs efficiently for their own uses. While AE supports GGUF quantizations, it cannot offload models to CPU & RAM because of its paged attention system. It has relatively higher generation speeds than its counterparts, but the paged attention system isn’t as memory efficient for the GPU-poor.

Supports most popular quantization methods.

vLLM#

https://docs.vllm.ai/en/latest/

Very robust and memory-efficient inference engine.

Supports most popular quantization methods.

Whisper Web UI#

https://github.com/jhj0517/Whisper-WebUI

Super useful speech to text transcription tool. Let’s you transcribe audio files, video files, and YouTube links of videos. Can transcribe into SRT, WebVTT, TXT, and LRC files.
Has a simple to use and (mostly) self-explanatory user interface. Also has features for diarization (detect different speakers), background music removal (to split music track from spoken voice), text to text translation, and can even directly transcribe from your microphone whatever you’re saying. Supports a large variety of Speech to Text models. I personally use Large-V3-Turbo on INT8, with that, I can transcribe an hour of audio in less than 5 minutes on a 1080Ti, ~30-45 seconds on a V100, or ~10-15 seconds on a 4090, all with diarization enabled (not including model load times, just inference).

Whisper Web UI works well on Nvidia GPUs and, albeit slower, on CPU. I am pretty sure you could get it working on AMD GPUs with ZLUDA, but I haven’t personally done that yet.
