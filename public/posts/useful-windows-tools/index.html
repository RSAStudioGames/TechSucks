Here are some tools I’ve found to be quite useful for me when working with Windows.

Directory Opus - https://www.gpsoft.com.au/ An incredibly good replacement for Windows Explorer. I absolutely love this thing. Huuuuuuuuuuuge range of customization, including its own scripting language. Amazing tool for power users who are frustrated with the limitations imposed by microsoft.

WinUtil - https://github.com/ChrisTitusTech/winutil
Has tons of options for installing programs via Chocolatey, tweaking your PC, or debloating windows overall.

O&O ShutUp10++ - https://www.oo-software.com/en/shutup10
Tons of Windows 10 & 11 tweaking options for changing your feature and privacy settings without needing to know how to work in the registry or group policy editor.

LibreOffice - - https://www.libreoffice.org/ A free, simple, and familiar replacement for Microsoft Office and all their BS. I’ve personally switched entirely from MS Office to LibreOffice and I will never go back.

LittleBigMouse - https://github.com/mgth/LittleBigMouse/
For users with multiple monitors of different resolutions so the mouse moves across all the screens cohesively.

Persistent Windows - https://github.com/kangyu-california/PersistentWindows
Useful if you have multiple monitors and Windows keeps moving your windows from where you last left them every time the monitors turn back on or after restarts.

JDownloader2 - https://jdownloader.org/
Amazing download manager. Completely free to use. Has TONS of integrations for hundreds of websites, including downloading videos and audio directly from youtube.
(Might do an in-depth tutorial on using it eventually and the many plugins and features it has.)

OBS Studio - https://obsproject.com/
Screen recording tool

Espanso - https://espanso.org/
Useful text replacer and macro tool

Bloatbox - https://github.com/builtbybel/bloatbox
Helps you to debloat Windows. See more on /debloating-windows-os

Privatezilla - https://github.com/builtbybel/privatezilla
Helps you to debloat Windows. See more on /debloating-windows-os

DisableWinTracking - https://github.com/bitlog2/DisableWinTracking
Out of date and the github hasnt been updated in a while, but it is still an effective tool to quickly block telemetry/tracking addresses that Windows tries to use to spy on you.

Zenmap / Nmap - https://nmap.org/zenmap/
Nmap as a GUI so you don’t need to learn the CLI. Powerful port scanning tool.

NTLite - https://www.ntlite.com/
Very useful tool that allows you to edit Windows installation ISOs.

PrismMC - https://prismlauncher.org/
Great replacement to the Minecraft launcher. Allows you to connect multiple MC accounts, many different profiles, and has built-in support for modding and one-click downloads of modpacks. Very feature-rich.

PowerToys - https://github.com/microsoft/PowerToys/releases A collection of handy tools for Windows made by microsoft. I recommend disabling the PDF viewer unless you absolutely need it as it is not good (very low-res renders and only up to 10 pages).

Ollama - https://ollama.com/
Easy way to get into serving LLMs for your own use. Covered in more detail on /machine-learning

GPT4ALL - https://www.nomic.ai/gpt4all
Easy way to get into using LLMs. Covered in more detail on /machine-learning

Remote Desktop Connection Manager - https://learn.microsoft.com/en-us/sysinternals/downloads/rdcman
Useful tool to manage your different connections in Remote Desktop.

Markdown Previewer - https://github.com/Atrejoe/MarkdownPreview Adds previews to .md files in the windows file explorer. (Also works for Directory Opus with no additional setup). PowerToys has this feature and does it better.

Files - https://files.community/ Fancy file explorer similar to that of Windows 11. Free to use replacement for file explorer.
